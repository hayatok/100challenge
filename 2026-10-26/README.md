# 潮還り / SHIOGAERI

潮に沈む港町から戦利品を持ち帰る、スマホ向けのターン制探索ゲーム。装備を選んで出発し、敵と潮に対処しながら、旧灯台の集光芯を港へ運ぶ。

倒れると、持ち出した装備と拾った品をすべて失う。港の倉庫は残り、武器がなくても貸し出しナイフで再出発できる。まずは一回の遠征を、出発から帰還・敗北まで遊べる開発版。

## 遊び方

1. 港で回収屋を選び、倉庫から持ち出す品を選ぶ。「基本の支度」でも準備できる。
2. 移動、攻撃、道具の使用、探索、待機で一手進む。持ち物や地図を読んでいる間は進まない。
3. 船着き場に戻り、「帰還する」で携行品を倉庫へ移す。灯台の集光芯と銅の端材を持ち帰ると、港の灯りを修復できる。

潮は32手ごとに変化し、浸水した低所で一手を終えると体力が1減る。高架の道は帰路として残る。構えた敵は次の手に直線へ突進する。横へ避けるか、道具で対処しよう。

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 一手移動・隣接する敵への攻撃 | 方向ボタン・隣のマス | 矢印 / WASD |
| 待機 | 「待つ」 | Space / . |
| 調べる・帰還 | 「調べる」/「帰還する」 | E |
| 持ち物 | 「持ち物」 | I |
| 地図 | 「地図」 | M |
| 閉じる・方向選択の取り消し | 閉じる・設定 | Esc |

回収屋は4人。イサナは携行枠が2つ多く、リツは最大体力が4多い。コハクは近接攻撃力が1高く、スイは視界が1マス広い。4人とも最初から選べる。

## 起動と開発

Godot 4.7.2、GDScript、Compatibility描画を使用。Webは単一スレッドで書き出す。Node.js 24を使い、このフォルダで実行する。

```sh
npm ci
npm run setup
npm run check
npm run preview -- --port 4316
```

ブラウザで `http://localhost:4316/` を開く。`setup` は公式配布元からエンジンとWebテンプレートを用意する。macOSではGodot 4.7.2をインストールするか、`GODOT_BIN` に実行ファイルを指定する。エディタは `npm run dev`、ネイティブ実行は `npm run play`。

`npm test` はルールと画面・保存のテスト、`npm run build` はWeb書き出し。Godotで編集するプロジェクトは `game/project.godot`。シーン、人物、AnimationPlayer、マップ、UIをエディタから確認できる。

## 保存と素材

Webの進行と設定は、このブラウザのlocalStorageへ保存する。サーバーへは送信しない。サイトの保存領域を消すと進行も消える。保存に失敗した場合は画面に表示する。ネイティブ版はGodotのuser領域へ保存する。

現在の画面は、青緑の海と白壁が明るい港町を舞台にしている。人物の顔を使ったHUD、アイコン付きの鞄、戦利品の集計に加え、歩行・攻撃・回収の演出と場面に応じた音楽を実装した。音と動きは設定で調整できる。

素材は港町の画風と人物設定を決めてからGPT画像生成で制作した。4人の立ち絵・探索用の人物、背景、地形、敵・小物を使用。生成記録は `game/assets/art/asset-manifest.json` と `game/assets/art/r2/manifest.json`、音の制作記録は `game/assets/audio/manifest.json`、ライセンスは `THIRD_PARTY_NOTICES.md` を参照。

ゲームの設計は `docs/PLAN.md`、現在の画面と演出の方針は `docs/PRESENTATION_R2.md` に記録している。初回の検証は `docs/verification/RESULTS.md`、今回の改修は `docs/verification/r2/RESULTS.md` を参照。実機のiPhone・Android、Safari、音の試聴、長時間のプレイと人間による面白さの評価は未実施。
