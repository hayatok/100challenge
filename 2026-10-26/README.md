# 潮還り / SHIOGAERI

潮に沈む港町から戦利品を持ち帰る、スマホ向けのターン制探索ゲーム。装備を選んで出発し、敵と潮に対処しながら、回収区画の集光芯を港へ運ぶ。

倒れると、持ち出した装備と拾った品をすべて失う。港の倉庫と完了した依頼は残り、武器がなくても貸し出しナイフで再出発できる。開発版はv0.6.0。4地区の探索、港の復興、仲間の依頼に加え、毎回変わる街を最大3層まで探索できる。Pagesの公開版はv0.5.0のまま。

## 開発状況

v0.6では遠征の構成と荷物の操作を作り直した。部屋の形、接続する道、目的の荷箱、敵と戦利品が遠征ごとに変わる。1層目で依頼品を回収して帰るか、今の体力と装備で次の層へ進むかを選べる。

港では武器・防具を明示して選び、倉庫と携行品を移す操作を分けた。遠征中は荷箱を1手で調べ、品を選んで回収する。読む間は0手。鞄が満杯でも、箱の品と携行品1個を1手で交換できる。使う・装備する・置く操作の後も、鞄の画面を開いたまま内容を確認できる。

依頼帳には品の探し場所と納品後の変化を表示する。仲間の依頼を完了すると、物資の購入割引や部屋の地図を利用できる。灯台の修理後は、報酬と必要品が切り替わる回収依頼も届く。

既存の4人の立ち絵と2Dの探索画面を使う。3D試作は保留を続け、原本と検証記録を保持する。設計は [v0.6再設計](docs/V06_REBUILD.md)、操作と検証の範囲は [検証記録](docs/verification/v06/RESULTS.md) を参照。

## 遊び方

1. 港の依頼帳で仕事を選び、航路で行き先を確認する。回収屋を選び、「荷物」から持ち出す品を選ぶ。「基本の支度」でも装備を揃えられる。
2. 移動・攻撃・道具の使用・待機で1手進む。荷箱は隣で調べ、回収する品を選ぶ。調査と回収はそれぞれ1手。持ち物や地図を読む間は進まない。
3. 船着き場に戻り、「帰還する」で携行品を倉庫へ移す。依頼帳から倉庫の品を届けて報酬を受け取る。復興が進むと、新しい地区への航路が開く。物資交換では品を売り、次の遠征の道具を買える。

港の復興は、灯台の波止場、中庭市場、群島運河、岬の観測所の順に進む。中庭と裏路地、島をつなぐ橋、外周の回り道など、地区ごとに道が変わる。復興の依頼は4件、回収屋それぞれの個人依頼も1件ずつ。納品すると必要な品は倉庫からなくなるので、持ち出す分との配分を考えよう。

潮は32手ごとに変化し、浸水した低所で一手を終えると体力が1減る。高架の道は帰路として残る。構えた敵は次の手に直線へ突進する。横へ避けるか、道具で対処しよう。

数字の旗がある通路に立って調べると、次の層へ進める。進行に1手かかり、体力・道具・技の残り回数を引き継ぐ。前の層に残した品には戻れない。各層に帰還地点があり、3層目が最奥。方向ボタンにはその一手で受けるダメージを表示する。

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 一手移動・隣接する敵への攻撃 | 方向ボタン・隣のマス | 矢印 / WASD |
| 待機 | 「待つ」 | Space / . |
| 調べる・帰還 | 「調べる」/「帰還する」 | E |
| 持ち物 | 「持ち物」 | I |
| 地図 | 「地図」 | M |
| 仲間の技 | 技名のボタン | Q |
| 閉じる・方向選択の取り消し | 閉じる・設定 | Esc |

回収屋は4人。イサナは携行枠が2つ多く、リツは最大体力が4多い。コハクは近接攻撃力が1高く、スイは視界が1マス広い。4人とも最初から選べる。

新しい遠征では、各回収屋の技を3回使える。イサナの「運び足」は空いた道を一手で2マス進み、リツの「踏ん張る」はその手に敵から受ける攻撃をそれぞれ3軽減する。コハクの「押し返す」は隣の敵を攻撃して押し戻し、スイの「見通す」は壁越しの周囲も一時的に見渡す。効果と残り回数は技の画面で確認でき、取り消しや効果のない使用では手数も回数も減らない。

## 起動と開発

Godot 4.7.2、GDScript、Compatibility描画を使用。Webは単一スレッドで書き出す。Node.js 24を使い、このフォルダで実行する。

```sh
npm ci
npm run setup
npm run check
npm run preview -- --port 4316
```

ブラウザで `http://localhost:4316/` を開く。`setup` は公式配布元からエンジンとWebテンプレートを用意する。macOSではGodot 4.7.2をインストールするか、`GODOT_BIN` に実行ファイルを指定する。エディタは `npm run dev`、ネイティブ実行は `npm run play`。

`npm test` は旧ルール、新しい地形・移行・荷物・準備画面・保存のテスト、`npm run build` はWeb書き出し。Godotで編集するプロジェクトは `game/project.godot`。シーン、人物、AnimationPlayer、マップ、UIをエディタから確認できる。

## 保存と素材

Webの進行と設定は、このブラウザのlocalStorageへ保存する。サーバーへは送信しない。サイトの保存領域を消すと進行も消える。保存に失敗した場合は画面に表示する。ネイティブ版はGodotのuser領域へ保存する。旧形式の保存も読み込める。新形式で初めて保存する際は、移行前データの控えを残す。控えを保存できなければ元の進行データを上書きしない。

v0.5までに出発した遠征は、移動中の位置、地図、体力、携行品と旧ルールを保って再開する。その遠征を終えて次に出発すると、v0.6の地図と荷物の操作に切り替わる。

現在の画面は、青緑の海と白壁が明るい港町を舞台にしている。人物の顔を使ったHUD、アイコン付きの鞄、戦利品の集計に加え、歩行・攻撃・回収の演出と場面に応じた音楽を実装した。音と動きは設定で調整できる。

v0.3では4人の立ち絵と地形を描き直し、探索中の前向き・後ろ向き・横向きの姿を追加した。歩くたびに踏み出す足が変わり、攻撃前の構えと、被弾・帰還・敗北の動きがある。動きを減らす設定では移動や揺れを止め、向きと結果が分かる姿を表示する。

素材は港町の画風と人物設定を決めてからGPT画像生成で制作した。4人の立ち絵・探索用の人物、背景、地形、敵・小物を使用。生成記録は `game/assets/art/asset-manifest.json`、`game/assets/art/r2/manifest.json`、`game/assets/art/v03/` 内の各manifest、音の制作記録は `game/assets/audio/manifest.json`、ライセンスは `THIRD_PARTY_NOTICES.md` を参照。

最初の設計は `docs/PLAN.md`、画面の方針は `docs/PRESENTATION_R2.md`、今回の再設計は `docs/V04_REBUILD.md`、`docs/V04_ART_BRIEF.md`、`docs/V05_PRESENTATION.md` に記録している。各段階の検証は `docs/verification/`、公開の区切りは `docs/VERSION_PLAN.md` を参照。今回の依頼はv0.6の実装と検証まで。次のPages公開は従来の2バージョンの区切りか、別途公開の指示があった時点で行う。実機のiPhone・Android、Safari、音の試聴、長時間のプレイと人間による面白さの評価は未実施で、商用品質への到達は未確認。
