# 潮還り：最初の遠征

## 目的と完了条件

スマホブラウザで、装備を選んで出発し、道具を使って探索し、生還または死亡する遠征を一周遊べるようにする。ユーザーが選んだ条件は、ターン制と、死亡時に携行品をすべて失う仕組み。潮に沈む街を最初の遠征の舞台として仮採用する。

エンジンはGodot 4.7.2を使う。ユーザーは軽量化より表現と制作のしやすさを重視し、Godotでの開発を承認した。高性能なスマホを主な対象とし、灯り、水面、キャラクターの動きと画面の仕上がりに力をかける。GDScript、Compatibility描画、単一スレッドのWeb書き出しで作る。

登場人物は海辺の回収組合に所属する成人女性4人。ユーザーの希望に合わせ、髪型、肌の色、体格、服装、性格と役割に違いを持たせる。出発時に一人を選び、同じ世界の衣装と画風で描く。詳しい制作方針は `ART_DIRECTION.md` に記録する。

戦利品を拾うと帰還したくなるか、失敗しても次に変える行動が分かるかを試す。実装・検査・ブラウザ操作と、人間による面白さの評価は分けて記録する。

## 遊び

倉庫から持ち出す品を選び、干潮で露出した港町へ向かう。移動・攻撃・道具の使用・探索・待機で一手が進む。読書やメニューでは進まない。同速の敵が各一回行動する。突進前の構えや音への反応を見せ、道具と位置で対処できるようにする。

帰還地点まで戻れば、携行品を倉庫へ移せる。死亡すると、装備中の品も携行品も失う。倉庫は残る。貸し出し用の最低限の装備で、全ロスト後も再出発できる。拾った物を倉庫へ移す処理は一度だけ行う。

潮は手数に応じて進み、低い場所から浸水する。高所の帰路は残す。浸水前に地図とHUDで予告し、通行時の損失を説明する。地形は用途と目印のある区画で構成し、戦利品や巡回などを遠征ごとに変える。

最初の目標は旧灯台から部品を持ち帰り、港の灯りを修復すること。灯りの修復は次回の探索にも反映する。爆薬は敵への攻撃と壁の破壊、発煙筒は敵の誘導、回復品は遠征中の生存に使う。

## 画面と表現

- タイトル：夜明け前の港、黄土色の雨具の回収屋、遠い灯台。題名と開始操作を主役にする。
- 港：倉庫と持ち出す品を並べ、携行数と死亡時の損失を確認して出発する。
- 探索：濡れた石、青緑の水、錆色の器具。キャラクターは小さくてもシルエットが読める描き込みにする。
- HUD：体力、潮の段階、手数、携行数を常時表示。帰還地点と次の行動が分かる状態を作る。
- 持ち物：品の用途と消費する手数、装備状態を表示。対象を選ぶ道具は方向を選んでから使う。
- 生還：倉庫に移した実物を表示。死亡：失った品と最後の原因を表示し、再出発へつなぐ。
- 設定：音、動きを減らす設定、操作説明。フォーカス喪失中は演出と音を止める。

共通UI色はこのゲームでは夜の港に合わせて置き換える。`--ui-canvas` は #101d25、`--ui-surface` は #1d3037、`--ui-ink` は #efe4ce、`--ui-muted` は #b6b8a7、`--ui-line` は #526268、`--ui-accent` は #e4b36b、`--ui-success` は #a8c7ad、`--ui-error` は #f19a83。意味は共通定義と同じ。輪郭と余白、文字を併用して状態を伝える。

日本語には同梱のNoto系書体を使い、ライセンスを併記する。題名、本文、数字に大きさと太さの役割を付ける。日本語、数字、矢印の実表示を確認する。本文16px、補助文13pxを基本とし、枠とボタンは直線と小さな角丸で統一する。

移動は短い踏み込み、攻撃は予備動作と打撃、被弾は揺れと体力表示、生還は港の暖かな灯りで返す。演出は一手の結果に追従し、入力を重ねて複数手が進まないようにする。動きを減らす設定では移動補間と揺れを止め、結果の表示は残す。

## 実装と検証の順序

1. 確定した条件とルール、APIを記録する。
2. 純粋なターン処理と敵、地形、道具、持ち帰り、全ロストを実装する。
3. 画面、素材、操作、保存、音を統合する。
4. 通常の生還、部品の回収、死亡と再出発、中断復帰を操作する。
5. 小画面とデスクトップを確認し、日本語の検査とAstraレビューを行う。
