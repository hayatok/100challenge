# 残響の魔女 モーションと演出

## 今回の目的

魔女と魔物の動き、攻撃・被弾・撃破の反応、ボスと報酬の見せ方を改善する。プレイ中のキャラクターと小さな火花・破片にドット絵を取り入れ、夜の絵本の背景、タイトル、日本語の魔術書GUIと組み合わせる。

参照する実装は戦闘モデル、残像の履歴、庭園の描画と保持、音と設定。今回の開始コミットは6fa3cc6。三章・装備・成長のルールをもとに、描画専用の状態を追加する。

## 動きと反応

| 場面 | 見せるもの |
| --- | --- |
| 魔女 | 静止時の呼吸と本、歩く脚・ケープ・帽子、詠唱で本を掲げて戻す動き、被弾の姿勢 |
| 残像 | 2秒前の移動に合わせた足運びと向き、残像自身が魔法を使う時の詠唱。本体とは青と点線の輪で区別する |
| 通常敵6種 | 走る脚、羽ばたき、突進の溜めと回復、弓を引く動き、盾を構える動き、炎と灯火。種別ごとに形を分ける |
| ボス3体 | 茨の枝、浮く鏡片、鐘の舌を動かす。出現・攻撃の溜め・後半への移行を区別する |
| 命中と撃破 | 命中点の短い火花、受けた側の姿勢、形が崩れて消える撃破。挟撃は青と金が交わる反応で示す |
| 節目 | ボスの名と出現、宝箱、進化、章の開始と踏破を、画面の用途に合う光・文字・音で示す |

## 守る制約

- 攻撃の威力、当たり判定、敵AI、出現時刻、残像の2秒の履歴、戦闘の乱数と成長配分は変えない。
- 歩行は実移動から求め、壁に向かって入力を続けても走り続ける表示にしない。残像の移動と詠唱は本体と別に追う。
- 敵の予告と発動する範囲を一致させ、味方の魔法より手前に描く。演出がHP、時刻、進路を覆わないようにする。
- ポーズ、フォーカス喪失、強化、宝箱、章間では戦闘中の動きと演出を止める。タイトル、再挑戦、章変更で追跡と残留を消す。
- 演出軽減ではカメラの揺れ、強い点滅、装飾の移動を抑え、行動の姿勢、輪郭、予告を残す。
- 素材と描画リソースを保持して使い、死亡や火花の件数に上限を設ける。新しい外部通信やライブラリは追加しない。

## 完了条件

状態の検査と実際の画面を分けて確認する。通常速度のWeb版で移動、静止、詠唱、敵の予備動作、被弾と撃破、ボス、報酬を確認し、変更前後の動きが分かる画像列を残す。1280×720と960×540、演出軽減、休止と復帰、再挑戦を操作する。描画リソースとメモリを比較し、全三章を通した検査、日本語の推敲、AstraレビューとCIをそろえる。
