# 残響の魔女 3分版

## Goal

移動だけで魔法を撃つ魔女と2秒遅れの残像が、別の場所から大群を倒す遊びを確かめる。初版を実際に3分遊べる形にする。

## Context

承認済み企画は「残響の魔女」。夜の庭園、藍色と骨白の絵本風。9分版への拡張に先立ち、残像の読みやすさと位置取りを検証する。既存のGodotゲームのWeb出力と共通UI方針を参考にし、既存アプリは変更しない。

## Constraints

- 主対象はPCブラウザ、1280×720。Godot 4.7.2の2Dと単一スレッドWeb出力を使う。
- 1キャラ、障害物のない1面、雷と月輪の2武器、敵3種、強化3択、180秒生存、敗北、再挑戦。
- WASDまたは矢印キーで移動。攻撃は自動。数字1〜3またはクリックで強化。Escでポーズ。
- 雷は近い敵を狙う貫通攻撃。月輪は周囲を攻撃。各武器は弾数、範囲、速さなどの形が変わる強化を持つ。
- 本体のみ接触と敵弾で被弾する。短い無敵時間を設け、多重接触で一瞬に死亡しないようにする。
- 残像は2秒前の位置と攻撃を再現する。攻撃内容は発射時に保存、照準は再生時の近い敵。無限の残像や過去の敵IDへの依存を避ける。
- 強化中、ポーズ、フォーカス喪失では全てのゲーム時間を止める。復帰はボタンやEnterで明示する。リトライで敵、弾、経験値、演出、位置と攻撃の履歴を初期化する。
- 敵は追従する群れ、直線突進する獣、予告して射撃する射手。スポーンと射撃・突進は回避できる距離と時間を確保する。
- 序盤に残像と最初の強化を体験。中盤で3種を組み合わせ、終盤に成長した武器で大群を倒す。180秒到達で勝利、HPゼロで敗北。
- 本体、残像、敵、経験値、敵の攻撃予告は形と輪郭でも区別する。画面揺れ・点滅を減らせる設定を最初から用意する。

## Done when

- タイトルから実際のキー操作で開始し、強化、ポーズ、復帰、勝利または敗北、再挑戦まで動く。
- 2秒遅れの位置・攻撃、強化前の攻撃内容保持、停止、再挑戦初期化をテストする。
- 3分の通常速度プレイと、必要な状態の実画面を記録する。自動操作と人間の面白さ評価を混同しない。
- 1280×720、1920×1080、小さい横画面、縦画面で文字・枠・主操作を確認する。
- GodotのエラーがないWeb出力、読み込み失敗の案内、適切なライセンス表示を確認する。
- 日本語推敲、Astraレビュー、PRとCI結果を記録する。公開は別の依頼で扱う。
