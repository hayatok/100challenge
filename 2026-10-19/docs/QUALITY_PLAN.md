# 第2版の品質改善

## Goal

3分版を再評価し、残像を意識した位置取り、攻勢と回収の切り替え、成長の選択に意味を持たせる。キャラクター、庭園、魔法、文字と枠を同じ作品の表現として整える。

## Context

開始コミットはe4cc52d。初版は動作するが、雷の長い射程と敵との速度差により逃走を続けやすい。雷の本数による同じ敵への重複命中、加算型の強化、全周ランダムで増えるスポーンにも偏りがある。実装と保存画像の独立評価、通常Chromeでの操作をもとに改善する。

## Constraints

既存の3分・1面・雷と月輪・敵3種を維持する。移動と自動攻撃を軸にし、追加の操作キー、恒久強化、ショップ、ボス、外部通信を増やさない。元checkoutの作業を保持し、既存の専用worktreeとPR #195で継続する。公開・タグ・main統合は今回も含めない。

## Plan

1. 射程と重複命中を調整し、離れた本体と残像による挟撃に追加ダメージと経験値を付ける。
2. 30秒の節に攻勢と回収の間を設け、既存敵の配置を組み合わせる。
3. Lv.4の専門化で得意と弱点を選び、強化の頻度を調整する。
4. 魔女と敵の透過イラスト、石畳と花の地紋、魔法・命中・挟撃の演出、HUDと全画面を統合する。静かな音楽と挟撃音を加え、停止と音OFFに従わせる。
5. productionテスト、複数パターンのモデル比較、通常速度の実キー入力、実画面と文字の確認、日本語推敲、Astraレビュー、PRのCIで確認する。

## Done when

挟撃の成立と不成立、雷の一体一回、専門化の排他、節の切り替え、停止と再挑戦を検証する。改善後の3分を実キー入力で完走し、敗北画面も操作する。1280×720と小さい横画面で本体・残像・敵・予告・文字を読める。モデル比較、自動操作、エージェントの評価、人間の試遊を区別して記録する。
