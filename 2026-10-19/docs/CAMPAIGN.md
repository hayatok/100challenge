# 残響の魔女 本編仕様

[Issue #196](https://github.com/hayatok/100challenge/issues/196)の計画から、庭園・書庫・塔を続けて攻略する本編を実装する。中心となる操作は、移動で2秒後の攻撃位置を仕込み、本体と残像で挟撃すること。レベル、装備、専門化を持ち越し、第三章のボス撃破で勝利とする。

対象は`2026-10-19/`、Godot 4.7.2のCompatibility描画・単一スレッドWeb出力。主対象はPCのキーボードとマウス、論理画面は1280×720。小さい横画面960×540と、縦画面の案内を用意する。

## 三章の構成

各章は180秒の通常戦と固有ボスで構成する。通常戦は30秒ごとに敵の組み合わせと回収の間を変える。時間切れで勝利にはならず、ボスを倒して章を進める。

| 章 | 地形と回収 | ボス |
| --- | --- | --- |
| 眠りの庭園 | 四つの花壇と広場。射線を切り、花壇の外側にある宝箱を取りに行く | 茨の庭守。円形の茨と三叉の道を予告する |
| 鏡の書庫 | 六つの書架・柱と複数の通路。長い射線を抜け、左右の宝箱を回収する | 鏡の司書。交差する射線と鏡の円で通路を狭める |
| 夜鐘の塔 | 六つの石柱と円形の床模様。内側と外側を行き来し、上下の宝箱へ向かう | 夜鐘の主。音の輪と十字の鐘波を放つ |

通常の宝箱は各章の30秒と105秒に出現する。55秒と125秒には精鋭が現れ、倒すと宝箱を落とす。見えている宝箱は接触して開けられる。

通常敵は影の群れ、月牙の獣、夜の射手、書庫の番人、迷い灯、夜羽の6種。接近、予告後の突進、射線、耐久、三方向の弾、速い群れに役割を分ける。ボスはHPが半分になると攻勢を変え、拾える回復を落とす。

地形のRect2は戦闘と描画で共有する。移動は円と障害物の衝突、敵の移動は共通グリッドの経路を使う。敵と宝箱は通れる場所に配置し、敵弾の遮蔽も同じ地形に従う。

章を進めるとHPを回復し、レベル、専門化、魔法と遺物を持ち越す。敵、弾、予告、ドロップ、演出、残像の位置・攻撃履歴は消し、次章で新しく2秒を記録する。

## 装備と成長

魔法は最大3枠。成長上限は第1章でRank 3、第2章で4、第3章で5。遺物は最大3枠。新しい装備を受け取るときに満杯なら、交換する装備の効果と失う成長を確認してから決める。交換画面から元の三択へ戻れる。

| 魔法 | 通常時の役割 | 進化 | 必要な遺物 |
| --- | --- | --- | --- |
| 雷 | 近い敵に向かう貫通攻撃 | 天裂の雷。4本に増え、別の敵へ連鎖する | 静電のインク |
| 月輪 | 自分の周囲を払う波 | 双月の環。広い波を3重に放つ | 月長石 |
| 茨針 | 扇状の針と毒 | 常闇の茨。7本の針と命中先の茨の庭 | 茨の種 |
| 鬼火 | 壁を越える追尾弾と爆発 | 道しるべの灯。広い爆発と最大3回の跳躍 | 灯火の油 |
| 霜結 | 地面の霜と減速 | 冬の庭。広い範囲と短い凍結 | 氷晶 |
| 鐘波 | 輪状の攻撃と押し戻し | 暁の鐘。二重の輪とボスへの短い足止め | 銀の音叉 |

Rank 5と対応する遺物をそろえ、第3章の宝箱で進化を選ぶ。通常のレベルアップでは進化を提示しない。発射済みの魔法は成長・交換の前の内容を保ち、後から強化されない。

レベルアップと宝箱は三択。引き直しと見送りは各3回、残回数を表示する。引き直しは直前と別の候補を優先する。専門化はLv.4以降に雷・月・残響から一つ選び、各系統の弱点も表示する。専門化は引き直せない。

遺物の効果はカード、図鑑、実際の計算で同じ定義を使う。

| 遺物 | 効果 |
| --- | --- |
| 静電のインク | 本体の4回目の詠唱ごとにその攻撃の威力+45%。残像にも記録する |
| 月長石 | 魔法の範囲と太さ+22%。射程は変えない |
| 茨の種 | 3秒間、毎秒3の毒。茨針の毒には毎秒3を加える |
| 灯火の油 | 残像の威力+30%。元の詠唱時に記録する |
| 氷晶 | 1.2秒間、移動を30%遅くする。霜結の強い減速を弱めない |
| 銀の音叉 | 挟撃で0.45秒の足止め。ボスには0.2秒 |
| 風縫いの靴 | 移動速度+15%、魔法の威力−8% |
| 星屑の環 | 回収範囲+90、経験値の雫から得る量+20% |
| 守り葉 | 18秒ごとに次の被弾を防ぐ盾を用意する。上限1枚 |
| 赤い小瓶 | 最大HP+24、12体倒すごとにHPを2回復 |
| 砂時計 | 詠唱間隔−15%、魔法の威力−10% |
| 欠けた鏡 | 挟撃に必要な距離を100から70にし、挟撃の追加威力+10 |

経験値の雫に加え、回復、経験値を引き寄せる吸引、防護、周囲への攻撃と敵弾消去の4種を拾った場で使う。低HP時は回復候補も出す。進化などの主要な成長が終わる時点と、回復だけの選択が増える回数を通し検証に残す。

## 残像と挟撃

残像は本体の2秒前の位置と発射内容を再現する。発射時の魔法、威力、形、遺物による補正を保存し、再生時にはその位置から近い敵に再照準する。残像から新しい残像は作らない。

本体と残像が十分に離れ、同じ敵へ短い間に攻撃すると挟撃になる。各敵の受付時間と待機時間を持ち、追加ダメージと経験値を得る。毒、足止め、押し戻し、凍結もモデルの時刻に従う。

## GUIと保存

タイトル、開始武器、戦闘HUD、強化、交換、宝箱、章間、結果、装備、休止、設定、図鑑、保存の案内を同じ魔術書の書体と枠でそろえる。配色、文字の役割、予告と演出の描画順は[ART_DIRECTION.md](ART_DIRECTION.md)に定義する。

強化は変更前後の実値、進化条件、空き枠を表示する。結果では被ダメージの主な原因と解放を示し、その周回の装備を確認して再挑戦できる。図鑑は遭遇・取得・進化した項目を記録する。

ブラウザ内の保存は設定、開始武器の解放、図鑑、章の踏破、自己記録を扱う。最初の開始武器は雷と月輪。第1章で茨針・鬼火、第2章で霜結、第3章で鐘波を解放する。通常戦の候補には全6種が入り、恒久的な能力強化はない。進行中の戦闘は保存しない。

保存データの版、識別子、数値、設定の範囲を検査する。壊れたデータと未知の版は元の内容を保ち、案内画面から退避と初期化を選ぶ。保存が拒否されても現在の操作は続けられ、失敗したことを表示する。ブラウザ間の同期、外部通信、アカウントは使わない。

## 停止と再挑戦

戦闘、敵、位置・攻撃履歴、予告、演出は一つのモデル時刻に従う。強化、宝箱、章間、休止、画面のフォーカス喪失で全て止める。復帰には明示操作が必要。設定や図鑑を閉じても、背後の戦闘は自動再開しない。

再挑戦では第1章、Lv.1、初期HPと選んだ開始武器に戻し、弾、敵、履歴、保留していた選択を消す。記録と設定は保つ。

## 検証と今回の完了条件

ルール検査、通常APIによる複数ビルドのシミュレーション、通常速度のWebキー入力、保存の異常系、実画面の目視を分けて記録する。検証用の公開状態は読み取り専用で、時刻、HP、敵を変更する操作を出荷しない。

三章の通し、装備の引き継ぎ、進化、敗北と再挑戦、停止、保存、解放を確認する。基準画面1280×720、小さい横画面960×540、1920×1080、縦画面の案内、検証用Chrome・Firefox・WebKitで確認する。WebKitの結果は実機Safariの確認と区別する。

実行時間、選択の回数と時点、敵・弾の上限、FPSとプロセスメモリ、曲の開始回数を残す。自動入力の完走で人間の面白さや初見の理解を確認済みとはしない。人間の試遊では、残像の説明、意図した挟撃、強化の理由、敗因と次の行動を観察する。
