# 残響の魔女の開発指示

ルートのAGENTS.md、docs/DESIGN.md、docs/FRONTEND.mdを併用する。

## 今回の目的

2秒前の位置と攻撃を再現する残像と戦う、3分の見下ろし2Dサバイバルを作る。今回は実装とローカル検証、レビュー、PRまで。公開、releaseタグ、mainへの統合は含めない。

## 設計と範囲

- 仕様と作業計画はdocs/SPEC.md。初版は1キャラ、1面、雷と月輪の2武器、群れ・突進・射手の3種。180秒生存で勝利、HPゼロで敗北。
- キャラクターと庭園、文字・HUD・強化選択・ポーズ・結果は同時に設計する。docs/ART_DIRECTION.mdを基準にする。
- Godot 4.7.2、Compatibility描画、単一スレッドWeb出力。PC横画面1280×720を主対象にし、小さい横画面と縦画面では可読性と操作の案内を確認する。
- game/には実行用コード、シーン、素材、Godotのテストを置く。スクリプト、文書、検証記録もこの日付フォルダ内に置く。
- 新しいJavaScript依存は追加しない。既存のNoto Sans CJK JPのフォントとOFLをコピーして同梱する。外部通信、アカウント、恒久強化、ボス、装備合成は今回の範囲に含めない。
- 残像は無敵。2秒前の位置と、元の発射時に記録した攻撃の種類・威力・弾数を再現し、再生時点の近い敵へ再照準する。残像の攻撃は再録しない。
- 移動・戦闘・攻撃履歴・敵予告・演出の時間は、ポーズ・強化選択・フォーカス喪失で一緒に止める。復帰には明示操作を必要とし、再挑戦で履歴を消す。
- テスト用の状態読取はWebの開発用公開関数に限定する。プレイ中のチート、時刻変更、無敵操作は出荷UIに追加しない。

## 検証

npm run checkでheadless import、残像と勝敗・強化・停止のテスト、Webビルドを実行する。npm run previewで実際のWeb出力を操作する。画面確認と自動テストを区別してdocs/verification/へ残す。日本語はyomiyasuのrunと実ファイルのverifyで照合する。完了前にai_slop_reviewer（gpt-6-astra）のレビューを受ける。
