# 残響の魔女

2秒前の位置と魔法を再現する残像と、三つの章を攻略する見下ろし2Dサバイバルです。庭園、鏡の書庫、夜鐘の塔を進み、各章のボスを倒して夜明けを迎えます。公開済み3分版から、本編・装備・図鑑・GUIを拡張しました。

戦闘中の魔女と魔物は、歩行・詠唱・予備動作・被弾・消滅を描き分けたドット絵です。背景と魔術書のGUIに合わせ、命中、撃破、挟撃、ボスと報酬の反応を加えています。

## 遊び方

- WASDまたは矢印キーで移動します。攻撃は自動です。
- 本体は白い帽子と実線の輪、残像は淡い青と点線の輪です。被弾するのは本体だけです。
- 本体と残像が離れて同じ敵を攻撃すると「挟撃」。追加ダメージと経験値を得ます。地形を回り、2秒後の攻撃位置を仕込みます。
- 経験値を拾ってレベルアップ。数字1〜3、矢印とEnter、クリックで三つの候補から選びます。選択中は戦闘も残像も止まります。
- 雷・月輪・茨針・鬼火・霜結・鐘波から魔法を3枠、遺物12種から3枠まで持てます。枠が埋まった場合は、手放す装備を確認して交換します。
- 魔法の成長上限は第1章でRank 3、第2章で4、第3章で5。Rank 5と対応する遺物をそろえ、第3章の宝箱を開くと武器進化の候補が出ます。必要な組み合わせは装備欄と図鑑で確認できます。
- Lv.4で雷・月・残響の専門化を一つ選びます。長所と弱点があり、選んだ後はその周回中に変更できません。
- 引き直しはR、見送りはX。各3回まで使えます。専門化の引き直しはできません。
- 各章の通常戦は3分。その後、固有ボスを倒すと次の章へ進めます。魔法・遺物・レベル・専門化を引き継ぎ、HPを回復します。最後のボスを倒すと勝利、HPがゼロになると敗北です。
- 回復、経験値の吸引、防護、周囲への攻撃と敵弾消去のドロップ品は、拾った場で働きます。ボスが落とす回復も、近づいて拾う必要があります。
- Escで休止。画面を離れた場合も止まり、操作するまで再開しません。休止中は装備、図鑑、設定を確認できます。

PCのキーボード・マウス操作が対象です。基準は1280×720、小さい横画面は960×540です。縦画面には横に広げる案内を表示します。タッチ操作は未対応です。

## 記録と設定

最初は雷と月輪を開始武器に選べます。第1章を踏破すると茨針と鬼火、第2章で霜結、第3章で鐘波を開始武器に選べるようになります。通常戦の候補には初めから全6種が登場し、恒久的な能力強化はありません。

図鑑の発見、章のクリア、自己記録、設定をこのブラウザ内に保存します。外部サービスへは送信しません。進行中の戦闘は再開用に保存されません。ブラウザのデータ削除や別の端末・ブラウザへの移動では引き継がれません。

設定ではBGMと効果音の音量、音のON/OFF、演出軽減、文字拡大を変更できます。保存できない場合も現在の画面内では設定を反映します。読み取れない保存データは勝手に上書きせず、保存の案内画面から退避と初期化を選べます。

## 開発

Node.js 24、Godot 4.7.2とWeb出力用テンプレートを使います。JavaScriptの追加依存はありません。

```sh
npm ci
npm run setup
npm run check
npm run preview
```

ブラウザで `http://127.0.0.1:4197/` を開きます。`PORT=4198 npm run preview`のようにポートを変更できます。`npm run dev`はGodotエディタ、`npm run play`はネイティブ起動です。`GODOT_BIN`でGodot 4.7.2の実行ファイルを指定できます。macOSでは既存のGodot.app、Linux x64では公式アーカイブを使い、新規ダウンロードは公式SHA-512と照合します。

## 検証

`npm run check`でインポート、戦闘・成長・保存・GUI・音声・素材の検査、Web出力を実行します。通常ルールの複数ビルドによる通し検証は、Godotから`game/tests/simulate_campaign.gd`を実行します。

Web上の`window.echoWitchSnapshot`は読み取り専用の状態です。ゲームの時刻やHPを変える機能はありません。ブラウザ検証には別途Playwrightと検証用ブラウザを使います。

```sh
BASE_URL=http://127.0.0.1:4197/ npm run qa:browser
BASE_URL=http://127.0.0.1:4197/ npm run qa:storage
BASE_URL=http://127.0.0.1:4197/ npm run qa:edge
BASE_URL=http://127.0.0.1:4197/ npm run qa:motion
```

`qa:browser`は通常速度で三章を進める自動キー入力です。`QA_MODE=smoke`なら序盤の操作だけを確認します。`qa:storage`は独立した保存領域で正常・破損・保存拒否を検査します。`qa:edge`は敗北、再挑戦、停止、画面幅、読み込み失敗を確認します。`QA_BROWSER=firefox`または`webkit`で別の検証用エンジンも選べます。`qa:motion`は実入力による歩行・詠唱、残像の遅れ、停止、再挑戦と演出軽減を確認します。これらは人間の面白さの評価や実機の性能測定とは分けて記録します。

Playwrightを別の場所に置いている場合は、`PLAYWRIGHT_MODULE`にその`index.mjs`、`CHROMIUM_BIN`にChromeの実行ファイルを指定してください。
