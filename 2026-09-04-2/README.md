# プリン通勤

押して加速、離してブレーキ。倒れかけたプリンを短い押し直しで戻し、停止線を狙うワンボタンゲーム。

## 開発

```sh
npm ci
npm run dev
npm run check
node scripts/create-cover.mjs
```

React / TypeScript / Vite / Vitest / oxlint。新規依存、外部API、アカウント、実行時の画像ダウンロードなし。

## 操作

- 画面のボタンまたはSpaceを長押しすると、そのまま出発・加速。離すとブレーキ。
- 最高速から離し続けるとプリンが前に倒れる。伸びたところで短く押し直すと揺れが戻る。ただし電車も前進する。
- 赤い範囲を黒い▼に重ねて停車。3駅とも止まると完走。
- 駅の通過、プリンの転倒、1駅20秒経過で失敗。失敗した駅から即再挑戦できる。
- 再挑戦では同じseed・駅・完了済み駅の点数を維持。前回の失敗位置を薄い線で表示する。
- 「別のコース」で駅間距離を再生成。「遊び方」からseed付きURLをコピー可能。
- Esc / 一時停止 / タブ非表示で停止。再開は明示操作。Enterでも主ボタンを操作可能。
- 音は初期状態でなし。任意で有効にするとWeb Audioによる立て直し・停車・失敗の短い効果音。

## 得点と物理

停車100点 + 停止位置0〜600点 + 速さ0〜150点。転倒寸前から戻して停車すると250点。1駅最大1100点、3駅最大3300点。失敗駅には加点しない。

- 120Hz固定ステップ、描画はrequestAnimationFrame。描画フレームの揺れで物理は変わらない。
- `lean` は皿の半幅を1とする符号付き重心変位。カラメル中心が皿の縁を越える境界を転倒判定と描画で共有。
- 速度ゼロだけでは停車を確定せず、プリンが安定してから0.25秒で確定する。
- 初駅は許容±2.4m、2駅目±1.8m、3駅目±1.3m。全駅の加減速性能と皿のサイズは共通。
- 最高記録は `pudding-best-v2` に保存。旧版とは採点が異なるため分離。保存不可でも遊べる。

## デザイン

承認済み案は `design/approved-screen.png`。元のクリーム・ミント・カラメルの配色、太い輪郭と硬い影を継承。`src/Scene.tsx` のSVGパスを物理に応じて変形するため、画像の単純な回転や市松模様の除去は不要。

旧生成原稿 `assets/source/` は履歴用。ゲームには配信しない。公開一覧画像 `public/pudding-cover.svg` は実際の描画と物理から `scripts/create-cover.mjs` で生成する。

reduced-motionでは背景の移動と落下・停車の追加演出を省略。判断に不可欠なプリンの傾きと停止線は保持し、転倒は文言と薄くなった姿でも表示する。

## 検証

`npm run check` でlint、11テスト、型チェック、本番build。

- 100seedで押しっぱなしが必ず通過失敗、立て直し操作で3駅完走できること。
- 離すだけの転倒 / 早すぎる停止 / 精密な停止 / 遅すぎるブレーキ / 安全運転の差。
- 80 / 120 / 160msの単発の押し直しでも初駅を救えること。
- 同じ駅への再挑戦、未確定・失敗時の加点禁止、終端状態、固定時刻、seed入力。
- DEV限定 `?seed=1&replay=catch|safe|brake|early|late|hold|idle` で入力方針を実際の物理へ流して画面再生。主ボタンで開始/次駅。リプレイは記録を保存せず、本番では無効。
- 375 / 768 / 1024 / 1440pxでレイアウト・スクリーンショット確認。

描画は同期的なSVGで、初回の画像読み込み待ち・画像通信エラーはなくなった。未プレイは0点、保存失敗とコピー失敗には専用の文言を用意。

自動入力リプレイと実ブラウザのボタン・キー・再試行・一時停止は検証するが、実機タッチ長押しによる通しプレイと、人による楽しさの最終評価は未実施。テスト成功を楽しさの保証とは扱わない。
