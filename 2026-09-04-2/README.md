# プリン通勤

押して加速、離してブレーキ。車内のプリンを守り、毎回違う3駅を走るワンボタンゲーム。

## 開発

```sh
npm ci
npm run dev
npm run check
```

React・TypeScript・Vite・Vitest・oxlint。隣接アプリと同じ構成。外部API・アカウント不要。

## 操作とルール

- スマホ：黄色の加速ボタンを長押し。離すとブレーキ。
- PC：出発後、スペースキーを長押し。Escまたは一時停止ボタンで休憩。
- 加減速でプリンが傾き、線路の継ぎ目は速度に応じた揺れを起こす。
- 大きな傾きが続くと皿の端へ滑る。落ちる前に姿勢を戻せば回復。
- 緑の停車範囲で止まると到着。停車位置400点・定刻300点・安全300点、3駅で最大3000点。
- 遅刻や駅の通過は減点。プリンの落下だけがゲームオーバー。
- 次駅への出発、同一路線の再挑戦、新路線の出発は運転ボタンと同じ場所から操作。
- タブを離れると自動で一時停止。再開は明示操作。
- 最高記録はブラウザ内だけに保存。保存不可でもゲームを継続できる。

## 路線生成

`?seed=56` のような正の32bit整数で再現可能。路線コピーはseed付きURLをコピーする。

- 3駅の名前、駅間距離、停車範囲、継ぎ目位置、景色をseedから決定。
- 最初の駅は難所なし。2駅目は継ぎ目1か所、3駅目は2か所。
- 発車から100m以上を確保、継ぎ目間70m以上、最終継ぎ目から駅までは最高速の制動距離＋30m以上。
- 時間は距離と駅順から計算。プリン物理・加速/減速性能は全路線共通。
- 物理演算は120Hz固定、描画は最大約30Hz。画面更新頻度に物理を依存させない。

## アセット

承認済みのレトロ鉄道ポスター風画像は `assets/source/`、配信素材は `public/art/`。一覧画像には承認済みコンセプトボードを使用。

- `pudding-expressions.png`：平常・不安・危険・安堵。描画時に枠を切り出して底面を合わせる。
- `plate.png`：独立した皿。
- `train-interior.png`：車内。窓部分はマゼンタキー。
- `background-residential.png` / `background-bridge.png` / `background-station.png`：住宅街・鉄橋・駅。

生成PNGの市松模様は本当の透過ではないため、`src/art.ts` で描画用Canvasテクスチャを作る際に除去。窓のマゼンタも同時に透明化する。元ファイルは保持。生成プロンプトと原稿の実寸法は `assets/PROMPTS.md` と `assets/manifest.json`。

背景は区間素材をリピート表示し、駅画像を手前へ差し込む。シームレスタイルではないため区間境界が見える場合がある。つり革は静止画の一部。音声/BGMは初版の対象外。

## 検証

`npm run check` はlint・9テスト・TypeScript・本番buildを実行。

- 500seedの生成制約、100seedを慎重な操作で完走できること。
- 加速/制動/停止、後退しないこと、落下/回復、定刻/遅刻/通過、終端状態、seed入力検証。
- キー色除去がプリン・陶器・輪郭を残すこと。
- 375 / 768 / 1024 / 1440pxでブラウザ確認・スクリーンショット目視。
- 初期/走行表示/停止/到着/落下/完走、同一路線/新路線、キーでの出発、読み込み失敗からの再試行を操作確認。

開発サーバーだけで `?demo=station|won|lost|loading|error` を指定すると検証用状態を表示。検証用状態は記録を保存せず、本番buildでは無効。

実機タッチ端末での長押し通しプレイは未確認。入力ハンドラのポインターキャプチャ・キャンセル解除を実装し、走行全体は固定ステップのテストで検証。
