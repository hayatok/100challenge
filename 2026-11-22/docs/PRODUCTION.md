# 宵待町の制作条件

舞台は昭和百年祭の翌年の大阪。金星の舞台と市内四十店舗の客席を中継鏡が結んでいる。主役は若頭の真壁、仲間は辰を含む六人。金星の興行を取った兄貴分を追うか、梶の弟を鏡の前に連れて行くかを、実時間の行動で決める。

|版|実装と検証の単位|
|---|---|
|0.1|通りから金星に入り、指揮、交渉、銃撃、降参、追跡または中継の決着、敗北、再試行をWindowsビルドで操作。|
|0.2|一晩の店の確保と収入、失敗時の喪失、約束の永続化、再挑戦の異なる人選・配置。|
|0.3|系列店を結ぶ通り、営業・出演者・客・顔見知りの移動、店を回る順序の違い。|
|1.0|抗争の全編と結末、初回から再挑戦と最終局面までの配布ビルド、動作・美術調整。|

照明は蜂蜜色の舞台灯、葡萄色の客席、外の冷たい看板光の三系統。文字は店の屋号に明朝、操作と進捗には日本語ゴシック、強調枠は古い真鍮。体力、選択中の組員、行動と結果は文字でも表示する。環境の細部が読めるようHUDは外縁に置く。店の外から入る、辰が梶と座る、弟が中継鏡に映る三場面を実機で比較する。参照は [Rockstar公式 GTA VI](https://www.rockstargames.com/VI) の「Trailer 2」の会話、クラブ、複数人物の場面。RTX 4070 Ti・1920×1080を初期計測条件とし、60 fps（16.7 ms）を目標とする。完成時には測定値と不足を記録する。
