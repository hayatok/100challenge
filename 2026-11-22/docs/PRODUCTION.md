# 宵待町の制作条件

舞台は昭和百年祭の翌年の大阪。金星の舞台と市内四十店舗の客席を中継鏡が結んでいる。主役は若頭の真壁、仲間は辰を含む六人。金星の興行を取った兄貴分を追うか、梶の弟を鏡の前に連れて行くかを、実時間の行動で決める。

昭和45年の大阪万博では、来場者にテレビ電話を実演した。当時の「遠くの相手の顔を見ながら話したい」という期待から、架空の宵待町を設計した。商店主たちは店ごとに客席と舞台の映像を送れるよう共同送像所を作った。2026年の朝、喫茶ロータスの澄子はサイフォンを温めながら卓上の管面を拭き、堺で暮らす元奏者のために最後の一曲を頼む。針音堂の兵藤が試聴盤を貸し、送像所の村瀬が回線を取る。真壁は三人を訪ねる順番を自分で決める。[NTT東日本「電信電話のあゆみ」](https://www.ntt-east.co.jp/databook/history-telecom.html)

|版|実装と検証の単位|
|---|---|
|0.1|通りから金星に入り、指揮、交渉、銃撃、降参、追跡または中継の決着、敗北、再試行をWindowsビルドで操作。|
|0.2|一晩の店の確保と収入、失敗時の喪失、約束の永続化、再挑戦の異なる人選・配置。|
|0.3|系列店を結ぶ通り、営業・出演者・客・顔見知りの移動、店を回る順序の違い。|
|0.4|二つの約束から最終夜が開く。真壁が原盤を運び、組員が回線と客席を引き受け、地元四十店の共同放送か金星専属興行を決める。旧版の帳面を引き継ぎ、両結末を保存する。|
|0.5|高架と生活階を通りから見分ける。真壁は三店のカウンターで仕事と商品を近くから見られる。兄弟の中継では管面から顔に光が返り、専属興行では座長がレバーを下ろして一番券を発行する。|
|0.6|通常出撃で組員を立会人に選ぶと、真壁は舞台で兄貴分の勝負を受けられる。舞台を預かる歌手と伴奏者、実音源と動く鍵盤、入口の街頭テレビを同じ出撃で確かめる。|
|0.7|組員が金星西側の札口へ通し札を運ぶ。真壁が自分で防音引戸を開けると、舞台脇から入店できる。楽屋の印刷物、通路の張地、寸法から作り直した舞台マイクを両視点で確かめる。|
|0.8|組員を二つの班に登録し、別々の場所へ送る。随行・持ち場・休息を一括で指示し、交渉や立会には一人を選ぶ。真壁の濃紺の上着は、肩越しの画面と腕を伸ばした姿勢で確認する。|
|0.9|宵待西口と送像所前で昇降台に乗り、実際に二両の電車に乗降する。列車から街の窓、運河と橋、東側の修理店を見渡せる。乗り越し、降りた先からの指揮復帰と出撃までWindowsで確かめる。|
|0.10|最終夜で選んだ結末の翌朝を歩く。共同放送では曲のリクエストを送出卓に届け、専属興行では前売りの一番券を針音堂に運ぶ。時間帯ごとの照明、店主の仕事、地上への復帰と帳面を確認する。|
|1.0|空の帳面から通常夜の二つの約束を取って最終夜を開き、二通りの結末と翌朝を実機で通す。店主の口・まぶたと視線、朝の楽曲と鍵盤、車内の商店広告、橋と修理台の夜間照明を調整する。|
|1.1|専属興行の翌朝、真壁が印字機から一番券を抜き取り、左手で運び、針音堂の受け皿に置く。兵藤が同じ券を載せたまま皿を引く。夜の客車に横向きの乳白ガラス灯を取り付け、窓と反対側からも乗客の頬と耳を照らす。|

照明は蜂蜜色の舞台灯、葡萄色の客席、外の冷たい看板光の三系統。文字は店の屋号に明朝、操作と進捗には日本語ゴシック、強調枠は古い真鍮。体力、選択中の組員、行動と結果は文字でも表示する。環境の細部が読めるようHUDは外縁に置く。店の外から入る、辰が梶と座る、弟が中継鏡に映る三場面を実機で比較する。参照は [Rockstar公式 GTA VI](https://www.rockstargames.com/VI) の「Trailer 2」の会話、クラブ、複数人物の場面。RTX 4070 Ti・1920×1080を初期計測条件とし、60 fps（16.7 ms）を目標とする。完成時には測定値と不足を記録する。
