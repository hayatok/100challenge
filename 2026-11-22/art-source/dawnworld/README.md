# 翌朝の町の制作と検証

ロータスで澄子が受像機を拭いている既存のGPT Image「lotus-dawn」と、真壁が帳簿に向かう「kinsei-ledger-dawn」を色と道具の参考にした。新規の朝空は既存の半径73 mの夜空ドームのUV用に計算した画像である。太陽の方位約61度、仰角約18度と、朝の平行光の方向を合わせた。窓は元の型板ガラスを保ち、発光だけを12%に落とす。夕方の反射プローブは金星の室内向けの既存設定を使う。

共用カウンターの天面y=1.120 mを測り、ロータスの依頼札箱と台ふき、針音堂の真鍮の硬貨皿を実寸で設置した。札は幅48～65 cmの木製スタンドに組版原稿を貼る。切符はゲームにある金星興行FirstTicketの元画像を8.7×12.5 cmに印刷。紙もの2シート、受像機用の試験信号と朝空をこのパッケージで作成した。実物の字体にはWindowsのMS明朝とメイリオを用いた。フォント本体の同梱はない。printed-proofs.jpgは印刷面と空の色校である。

## 接続

KinseiWorld.SetDawnProgramme(branch,step)、KinseiDistrictPeople.SetDawnSchedule(branch)をRuntimeから呼ぶ。branchは0=夜復帰、1=共同、2=専属。stepは0=受取前、1=運搬中、2=届け済み。同じ組み合わせを複数回指定できる。専属興行の朝は座長がレバーを引いて券を送り出す。真壁が券を受け取ると印字機の排出口から左手に券が移り、針音堂で渡すと窓口の皿に残る。

|---|---|---|

|共同送像所|16.85, 1.389, −18.16|共同の配達前は朝番組準備中。配達後は放送中の番組札と通電した卓上受像機。|
|金星|−1.94, 1.258, −5.415|専属では帳場の札に前売りを針音堂に案内。|
|針音堂|0.65, 1.459, −18.59|専属では前売り準備から受付へ。紙の一番券が皿の右区画に届く。|

## CPU検査と実機で見る箇所

Unity付属Roslynと現行プロジェクトの参照でゲーム全体をコンパイルし、統合差分のgit apply --checkを確認。天板からの札台底面はロータス+0.26、針音堂−0.10、送像所+0.46、金星+0.96 mm。朝空画像の経度境界で各RGB成分の平均差0.40、最大2/255。画像の入力合計2,424,832画素。Python・Pillow・NumPyで make_art.py <出力フォルダ> を実行すると原稿4点を再生成できる。

朝に一度だけ構築。新規平行光1灯（ハードシャドウ）と10 Rendererのうち、共同では7、専属では最大10を有効にする。空球面、街頭テレビ、受像卓の描画面を再使用。夜では追加のメッシュ、平行光ともルートごと非表示。街頭テレビのライブカメラの手動Renderを朝は停止し、最後の画像を約1.38秒かけて減光する。朝の日中に受像卓を更新するのは状態変更時だけ。夜に戻る際、空、霧、環境光、住宅窓の発光、対象ランプの光量、受像機の映像と通電状態を戻す。店員の夜の経路も復帰する。

[澄子と兵藤の設定画2枚と生成記録](concept-provenance.md)では、共同放送と専属興行で店主が手に取る物を比較できる。
