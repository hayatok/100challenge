# 金星の声を送る手と、町で聞く人

金星の舞台から流した同じ発言を、二つの場所から描いた。Codex組み込みのGPT Imageで各1点を生成し、2点を採用した。どちらも1536 × 1024。再生成用に[指定全文](prompts.json)を保存した。

- [金星の実況係](desk-hand.png)。係員は右のつまみを親指と人差し指で回す。左の管面に兄貴分の顔が映り、盤の上に赤い送出灯が点く。つまみの縁に指をかける位置と、暗い盤から指先を浮かせる光を検討するための原画。原画では右手で縦並びのつまみを回す。ゲームの実況卓は管面を係員の右に置き、左側に二つのつまみを横に並べた。係員は左手を使う。
- [ロータスの客席](../../Game/Assets/Resources/Art/lotus-listens.png)。店の人がカップを持つ手を止め、カウンターの常連が壁のテレビを見る。兄貴分は舞台と同じマイクで話している。町内中継を選んだときの決着画面に使う。テレビと常連の横顔を右半分に残し、左の暗い部分に結果と帳面を重ねる。

実況係の原画のSHA-256は `ebc1a73831253552b5cf72f29defafc89013c58385ad861cca69fd551ac8a7d2`、ロータスの原画は `2fc9fd23fea59943c9547df36f87fbd54c01f2f39e80ca11b34bfecd36d16fa7`。
