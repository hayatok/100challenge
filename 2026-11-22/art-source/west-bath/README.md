# 運河橋と西の湯

橋を渡って「西の湯」に近づくと、青緑のタイルの前に葡萄色の暖簾が掛かっている。外壁の受像機には金星の舞台が映る。湯客の文子は右手に籐籠、喜一は左手に洗面器を持ち、西岸には二人を引き留める瀬尾が立つ。[原画と実機の掲載頁（補遺34～36頁）](../Kinsei-Art-Supplement.pdf#page=19)

## 表面と持ち物

MOSS-Imageの原画は、タイル一枚の釉薬、橋の石の骨材、暖簾の木綿、玄関マットのゴム、戸と番台窓の型板ガラスの5点。型板ガラスの原画では、透過光に浮かぶ細い筋の型押しを参照した。各面のPNGを保存し、メッシュに反復して貼る色画像を別に作った。原画はすべて1024角で、寸法、個別の実行ID・seed・SHA-256と加工手順は[表面材の生成記録](materials/README.md)にある。

衣装は各人物のスキンメッシュとして仕立て、籠の持ち手と洗面器の縁をそれぞれの掌の位置に合わせた。追加した籐の編み目、タオル、茶瓶、洗面器の縁と、元衣装のライセンスは[西橋の三人](cast/README.md)に記録した。[Windows版で撮影した橋・玄関・湯客](../../evidence/v15/README.md)
