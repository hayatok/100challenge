# 建築の表面

金星の床、木壁、歩道、幕に Poly Haven の CC0 写真測量・実材テクスチャを使用。1K JPEG の diffuse と OpenGL normal を API マニフェストから取得し、配布元記載の MD5 と照合した。Unityで法線画像として読み込み、塗装色と粗さを店内の灯りに合わせる。

- [Herringbone Parquet](https://polyhaven.com/a/herringbone_parquet)　寄木床とダンスホールの象嵌
- [Smoked Walnut Veneer](https://polyhaven.com/a/smoked_walnut_veneer)　壁面および舞台の木部
- [Worn Asphalt](https://polyhaven.com/a/worn_asphalt)　店舗の前の濡れた舗装
- [Velour Velvet](https://polyhaven.com/a/velour_velvet)　舞台幕
- [Interior Tiles](https://polyhaven.com/a/interior_tiles)　ロータスの水回りを緑に釉掛けし、目地と陶板の凹凸を残した。
- [Beige Wall 002](https://polyhaven.com/a/beige_wall_002)　街区三店舗の塗装壁。近距離で粒が読めるよう、壁幅に合わせて繰り返した。
- [Rectangular Facade Tiles 02](https://polyhaven.com/a/rectangular_facade_tiles_02)　高架奥の集合住宅の外壁。
