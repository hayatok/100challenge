# 通りの両端の灯具と調整信号

西の橋は既設欄干の両端4本の石柱天端に、黄ばんだ乳白ガラスと黒ずんだ亜鉛の籠・雨蓋を載せた。夜の実照明は対角の2灯にまとめて橋面と手すりを拾う。水面には4灯の座標を映し、視点に応じて反射の中心を動かす。風による明滅を加え、岸寄りを照らす。翌朝は街灯の発光と実照明を消し、水色を朝空に合わせ、街灯の反射を落とす。

東の庇に付いた反射笠2本と白色直管が仕事場を示す。庇下には広角スポット1灯。3台の画面にそれぞれ波形・幾何学調整と階調・段階波を表示する。翌朝は笠の照明を消し、ブラウン管の発光を落とす。試験信号、灯具、水面シェーダーは本作のために制作。既存亜鉛材を再使用し、新規の外部画像・フォント・3D素材を使用しない。

## 統合とCPU検証

街路の建物と灯具は共通の形状検査で数える。既存のcheck.ps1後にpreview.pyを起動すると、新旧の両方を含む形状が出る。make_patterns.pyの第1引数はテクスチャの出力ディレクトリ。実行にPillowを使用。

Unity付属Roslynで全ゲームC#アセンブリをコンパイル。従来の検査で28,938三角形を実際に出力した。追加分は灯具フレーム600、乳白ガラス48、直管32、管面6の合計686。4メッシュ・4材、追加コライダーなし。水材は従来の既設メッシュに割り当てている。夜の実照明3灯は影なし。日の出後は3灯とも無効。半透明や環境カメラの再描画を追加していない。パス・CPU/GPUフレーム時間・色はWindows本番で要確認。views.jpgは全頂点から作ったフラットな検査画像。

## 実機で同じ構図を確認する位置

* 西の街路は目の位置 (−18.67,1.65,−10.17) から (−32,1.05,−10.25) を狙う。より手前の欄干を横から見る場合は (−21.25,1.7,−13.30) から (−30.85,−.45,−14.6)。橋の床下にある水面はy=−1.34、欄干の長手はx=−33.77〜−27.92である。正面からは橋面で水の一部が隠れる。
* 東は (20.6,1.65,−10.70) から (26.55,1.38,−13.52) を狙う。正面パネルはz=−13.368、3台の中心はx=25.18、26.45、27.72。実波形の視認は距離で変わるので、店頭の矩形と作業台の縁がTPSで読み取れるかを見る。
* 同じ地点でSetDawnProgramme(1,0)と(0,0)を切り替え、昼のガラスと消灯、再度夜の灯と水際を確認。既存の夜/朝の環境色を変更する処理は加えていない。
