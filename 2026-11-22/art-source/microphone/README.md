# 金星の舞台用リボンマイク

[商品撮影風の設計画](reference.png)を、Codex の組み込み GPT Image でこの作品のために生成した。左右の止めねじ、横桟の陰に見える金網、磨いた銀色の縁、布巻きリード線を3D形状に採り、画像右の「金星」の赤いホーロー銘板は実際の下部カバーに貼った。[組み上げと分解](assembly.jpg)はBlenderのCPUレンダーで、左が舞台に入れる完成形、右が金網、カバー、モーターの位置を見せる分解図。

## 取付と寸法

台座の中心はワールド座標 (-5, 0.48, 3.4) m。歌手が触れる高さ1.835 mでシャフトの中心線を維持した。握り部分は外径34 mm。ヘッドの上下カバーは高さ118.4、幅58.4、奥行42.4 mm。前後の保護支柱を含む奥行は45.0 mm、両側のすり割り付きつまみねじを含む幅は88.1 mm。台座は外径290 mm。架空の修繕品として設計した。

FBXは14個の名前付きメッシュからなり、全体で38,450三角形。各金網には0.44〜0.48 mm径のワイヤと1.36 mmのピッチを与えた。9段のガードリブの間に透視できる空間が残る。内部の波形リボンと磁極、支持ゴム、左右の回転軸、底面のコネクタと蛇腹、布の編み目が見えるケーブル上端を個別に制作した。ケーブルはスタンドの足元から舞台裏へ逃がす。メッシュは舞台の既存の静的結合に参加し、1枚のカラーアトラスと1枚の金属度・滑らかさアトラスを共有する。

## 再制作

- 元画像の生成記録は [generation.json](generation.json)。既成製品の写真や第三者のロゴを使っていない。
- Pillow と NumPy が使える Python で finish.py に reference.png と出力用の KinseiMicrophone ディレクトリを指定する。PBRアルベドの銘板領域は元画像の (934,349) から (1463,542) の部分に由来する。銀地に見える真鍮、鋳鉄、ゴム、編み布の質感は作成スクリプトで描いた。
- Blender 5.3 のバックグラウンドモードで model.py を実行し、二重ハイフンの後に KinseiMicrophone と、2枚の検査用PNGを出す既存ディレクトリを渡す。FBXはメートル単位。書き出し後の資産を verify.py で再読込すると各部品の頂点数と外寸を確認できる。Unityでは同梱の .meta と RibbonMetal.mat を保持する。
- 実際の舞台フレームと歌手の手、受像機越しの映りは統合したWindowsプレイヤーで確認する。
