# 一番券の受け取りと夜の車内側灯

美術用の新規設定画2点。OpenAI GPT Image（Codex組み込み）で個別生成し、出力PNGを原寸で保存した。実際の入力文と参照原画は [prompts.json](prompts.json) に収録した。

## 左手と一番券

[発券口の原画](ticket-pickup.png)を採用。人差し指の腹と親指が同じ紙角を上下からつまみ、露出した板ばねの下から「0001」の紙が浮く。券の切断面の繊維、くすんだ赤インキ、指先の皺と袖の細かな杉綾まで識別できる。真壁が券を引き出すときの接点、券の反り、金属と未塗工紙で異なる光の返りを決めるために使う。参照した[兵藤と前売り札](../dawnworld/needle-first-ticket.png)から券の色と通し番号を引き継いだ。

## 側灯の下の横顔

[夜の車内の原画](car-sidelight.png)を採用。曇りガラスの凹凸が残る側灯を起点に、右耳の暖かな縁、櫛目に沿う細い反射、後頭部に沈む影の三段が読める。暗部の髪を持ち上げすぎず、窓外の住宅の灯りを横へ流す際の露出基準に使う。[高架線の客室原画](../railway/studies/car-at-night.jpg)から赤い座席・吊革・窓枠を引き継いだ。両点ともゲームの実機撮影は別途行う。
