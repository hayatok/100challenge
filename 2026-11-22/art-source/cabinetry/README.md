# 金星の建具の突板と板割り

客席の東壁・奥壁、楽屋通路側の南北壁とまぐさ、サービスバー、舞台・テラス・右階段、三店舗の側壁・入口框・カウンターの腰板、針音堂のレコード箱の木面を対象とする。元のウォルナット画像はPoly HavenのSmoked Walnut Veneer（CC0）。出典と同梱画像は既存art-source/Surfaces.md、Game/Assets/Resources/KinseiSurfacesを参照。新しい画像やシェーダーは追加していない。

床から立ち上がる化粧板は幅上限560 mm、長さ上限2,420 mmで面に均等割り付け。18 m×6 mの奥壁は33列×3段、一枚約545×2,000 mm。厚さ等の指定はこの架空の店の製作用設定。木目の1リピートは木の繊維方向800 mm、横620 mm。上長押・間口に渡す踏板は木目を水平方向に揃え、同じベニヤ板を裏返して突き合わせるように幅方向のUVを交互に反転・移動する。目地は両側合計2.2 mmのV溝、最深1.5 mm。外周1.1 mmで溝を止め、隣接面との境界を閉じる。長辺1.90 mの各踏面は一枚張り。

既存のBoxColliderを元の実寸に設定し、その中心・親・回転・外周を維持。銅製段鼻、踊り場の開口、木部以外の材、キャラクター/入力に変更なし。既存のwoodのUV倍率(U=2)を座標生成側で相殺する。静的材質結合時に既存と同じ共有レンダラーへ統合し、個別の素材複製、追加ドロー、毎フレーム更新なし。結合済み一時メッシュは解放する。

## 検証

Unity付属Roslynで全ゲームのC#アセンブリをコンパイル。runtime.patchはgit apply --checkを通過。probe.ps1はゲームと同じC#メッシュビルダーを単独実行し、18×6×0.25 mの奥壁、4.45×0.98×0.78 mの店頭腰板、1.90×1.60×0.37 mの階段箱を出力する。compare.pyは各代表メッシュの外寸、三角面の非退化と元の面方向への正の投影面積を確認する。comparison.jpgは同じ範囲の画像を旧正規化箱UVと新メッシュのUVでCPUサンプリングした比較。旧面は正面基準で、拡散色と溝の簡易陰影のみを描画する。

    ./probe.ps1 -Project <日付フォルダ> -Out <一時出力フォルダ>
    python compare.py <日付フォルダ> <一時出力フォルダ> <比較画像の出力フォルダ>

Windows実画面の夜間照明、圧縮後の法線・ミップによる木目、RTS時の見え方は統合後の確認対象。
