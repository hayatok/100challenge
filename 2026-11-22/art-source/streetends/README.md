# 宵待町の通りの両端

西の運河には橋、欄干、護岸、電柱を置いた。向こう岸の住宅には外階段と物干しがある。東の電器修理店では庇の下に修理台と大きさの違うブラウン管を3台置き、裏の作業場に排気筒を3本立てた。木製の窓枠、屋根の継ぎ目、軒樋と引込線は立体で作った。

実機の肩越し視点から金星の両脇に空きが見えたため、仕立屋と理髪店を含む4棟を加えた。仕立屋では軒下の電球が引戸を照らす。運河の底よりさらに下に連続した地面を敷き、高架や橋から見下ろした際の地表の切れ目を塞いだ。追加した街並みは歩ける区画の外にある。

建物は地区の[美術資料](../district/README.md)、v0.8の実画面と既存店舗の高さを参照して配置した。外壁には地区共通のモルタル、窓には住宅の室内タイル、路面には既存のアスファルトを使う。仕立屋、理髪店、電器修理店の屋号はゲーム内の日本語書体で組む。

## 造形の検査

[6方向からの検査画像](views.jpg)はゲームと同じC#が出力した四角面をCPUで単色投影したもの。西の歩道では実際に背景の切れ目が見えた地点（−18.67, 1.65, −10.17）に視点を置いた。東の歩道、高架からの西・東の眺め、運河と修理店を見下ろした図も収録した。色、画面の文字、照明と重なり順は[Windows実機記録](../../evidence/v09/README.md)で確認できる。

v0.9の追加建物・街路・水面は材質別の7メッシュ、56,504頂点、28,252三角形。屋号の文字3枚と軒下灯1灯はこの集計に含めていない。水位は−1.34 m、連続した地面の上面は−2.01 m。ここに1.0候補で[石柱灯・仕事灯とブラウン管](../street-lighting/README.md)の686三角形を加えた。追加造形は住民や列車の当たり判定を変更しない。

再計測はこのディレクトリの check.ps1 に日付フォルダと出力先を指定して行う。preview.py に geometry.bin と画像の出力先を渡すと、図とメッシュ別の個数を出力する。画像作成にはPillowとNumPyを使う。
