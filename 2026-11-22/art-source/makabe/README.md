# 真壁の背広

[正面・側面・背面と腕を動かしたときの比較](fitting.jpg)は、上段が従来の濃紺スーツ、下段が真壁の仕立て直し。頭、髪、手、服はゲームで使う3Dメッシュを同じ照明で撮影した。[襟・ベントの接写](seams.jpg)には実際の服のUVと法線を使った。BlenderのCPU撮影で、Windowsプレイヤーの画面はアプリの evidence に収録する。

金星の[真壁の衣装画](../atelier/plates/makabe.jpg)と[布見本](../atelier/plates/swatches.jpg)の黒に近い紺、肩の傾き、二つの見える前釦を引き継いだ。元の縦縞を抑え、肩甲骨二枚の張り、脇に抜ける短い斜めの余り、背縫い、上襟の返りと、裏のあるセンターベントを作った。背の裾を最大約2 cm下げて裏側の重なりを取り、腰に布のゆとりを残した。肩を前に出すと同じ側の肩甲骨から袖山に布が引かれ、裾が少し上がる。

## 原型と実装

[Margaret ToigoのCC0原型、元の許諾・ファイルと加工](../wardrobe/SOURCES.md)を基に、ゲームに同梱済みの Single.bytes、Navy.jpg、SingleNormal.png から加工した。元の Single.bytes の SHA-256 は 4f22e2527070aad41e09f87125423f8a8206aadfdd88012a4c4e60e5b2abc991。服地の画像を人物の上に合成していない。元服は9,795頂点・16,250三角形で、この数と10本のボーンを保った。上衣につながる5,099頂点を選び、他の人物の衣装は共通のまま使う。元のズボン・シャツ・タイ・釦のUVと上衣のUVには1,024ピクセルで調べた範囲で重なりがなかった。

2,048ピクセルの染め・法線には6.4 mm幅で綾を折り返す杉綾、背中心の断続する縫い目、肩と肘の弱い摺れを描いた。256ピクセルの追加法線では12.8 mmに40本の経糸・緯糸を通し、0.32 mmピッチを表した。UVチャートごとに三角形から布上の距離を求めて第2UVを作った。シャツやズボンの第2UVは平坦な法線を指す。1人分の衣装を既存と同じスキン描画1回で扱う。

左右の袖の補正はメッシュ作成時に二つのブレンドシェイプとして登録し、各肩の向きから重みを求める。最大重みでの局所補正は左16.42 mm、右16.37 mm。フレームごとの配列生成・メッシュ再構築はない。布の完全な衝突シミュレーションは行っていない。

## 再制作と検証

1. Python、NumPy、SciPy、Pillow で tailor.py に Game/Assets/Resources/KinseiWardrobe と、出力する既存の KinseiMakabe ディレクトリを渡す。Unityのマテリアルとインポート設定は同梱の .mat と .meta を使う。
2. pose.py に KinseiWardrobe、KinseiMakabe、一時出力先の順に渡す。直立、両腕の構え、右手を前へ伸ばした姿勢について、既存ボーンの位置と4ウェイトでメッシュを変形し、CPU撮影用のデータと寸法検査結果を出す。
3. Blender 5.3 のバックグラウンドモードで render.py を実行し、二重ハイフンのあとに Game/Assets/Resources、KinseiMakabe、手順2の出力先を渡す。正面、側面、背面、構えと片手伸展の斜め後方、襟とベントの寄りをCPU Cyclesで出力する。

構えでは左右の補正が19%・73%、片腕伸展では13%・85%入った。3姿勢ともUVの継ぎ目で同一の位置にあった頂点間の分離は0.0000 mm。上着の高さにある実面積0.05 mm²以上の三角形について、元の10%未満まで潰れた面は3姿勢とも0枚。構えでの面積比の1〜99パーセンタイルは0.856〜1.776。モデル全体の連続した布と、実際に重ねてある襟・ベントの折り返しは区別して点検した。ゲーム内の歩行・舞台照明・遠景での見え方は統合版の実画面で確認する。
