# 金星帳場の手動発券機

角を丸めた鋳鉄フード、真鍮の紙受け、板ばね、番号窓の意匠を作品の原画から起こした。形状と表面材は本作用に制作した。紙の出口とレバー支点は既存の帳場の実寸に合わせた。[受け取り場面の原画](../ticket-and-car/ticket-pickup.png)・[改修前の実機で券をつまむ場面](../../evidence/v11/pinch-cuff.png)・[帳場の紙送りとレバーの実装](../../Game/Assets/Kinsei/World/KinseiBoxOffice.cs)

## 配布モデルの実測

| 項目 | 値 |
| --- | --- |
| 外形（幅 × 高さ × 奥行） | 232 × 143.14 × 187.5 mm |
| 既存の券（幅 × 長さ × 厚み） | 87 × 125 × 1.8 mm |
| 左右のガイドの内幅 | 95 mm。券との隙間は左右各4 mm |
| 板ばね下面と印刷面の最小高低差 | 3.995 mm |
| 厚紙下面と真鍮の受け面の高低差 | 1.6 mm |
| 全送り量126 mmで券の通過範囲と交差した三角形 | 0 |
| 固定外装の頂点数／三角形数 | 12,393／8,290 |
| モデルファイル／頂点・インデックスの合計 | 359,577／495,888 バイト |

形状と隙間はメートル単位で書き出したメッシュおよび設計座標から算出した。板ばねの下面は機械原点から25.295 mm、券の印刷面は21.3 mm。厚紙の下面は19.1 mm、受け面は17.5 mm。固定外装を1メッシュ・1サブメッシュ・1材質で描く。基本描画パスでは1回のドローを使い、影と追加ライトは別パスで描く。実機のGPU時間は未計測。[形状の生成コード](design.py)・[交差と法線の検査](measure.py)

Windows版の同じ受け取り位置で券をつまむと、1.1の四角い覆いがあった位置に、1.2では角を丸めた濃緑の蓋と「0001」の番号窓が見える。真鍮の紙受けと券の間に暗い隙間が残る。この版で座長が動かす部品はレバーで、ローラーは固定外装に組み込んでいる。[1.1の実画面](../../evidence/v11/pinch-cuff.png)・[1.2の実画面](../../evidence/v12/final-pickup.png)

## 再生成

Python 3.13.5、NumPy 2.4.2、Shapely 2.2.0、Pillow 13.0.0で確認した。このフォルダで次を実行する。各スクリプトは自身の位置からゲームの素材を解決する。

```sh
python design.py
python measure.py
python preview.py
```

最初のコマンドはUnityが読み込むモデルを再生成する。2番目は全三角形と券の通過範囲との交差を検査する。最後はゲームに含まれる印刷原稿とモデルから、このフォルダの比較画像を生成する。左は固定外装、右は63 mm送った券を排出口の高さから見たところ。照明と摩耗表現はCPUで近似している。[比較画像](press-inspection.png)・[印刷原稿](../../Game/Assets/Resources/KinseiPrintworks/FirstTicket.png)・[Unity用モデル](../../Game/Assets/Resources/KinseiPrintworks/TicketMachine.bytes)
