# 三店の店主の会話

真壁がEで話した店主は、視線を真壁に移し、頭を向けてから発話する。字幕の長さと文字の区切りから開口と円唇の量を決め、発話が終わると店主は台の上の仕事に目を戻す。台詞は字幕で表示する。客と店主が近くに立っているときは、画面の名前で相手を確かめられる。

通常夜のロータスでは、カウンター左の通路から澄子に話しかける。Zで顔に寄ったままにすると、安静、発話、手元へ視線を戻すまでを同じ画角で見られる。兵藤と村瀬にもそれぞれの店で話しかけられる。

| 店主 | 正中で測った唇の間隔・安静時 | 最大開口時 |
|---|---:|---:|
| 澄子 | 1.58 mm | 7.48 mm |
| 兵藤 | 1.24 mm | 7.13 mm |
| 村瀬 | 1.56 mm | 7.46 mm |

[形状比較図](source-lip-comparison.png)は3D頭部をCPUで単色投影した。各頭部は17,169頂点、34,224三角形。最大開口時に向きが反転した三角形は0だった。[全測定値](source-measurements.json)。既存のMakeHuman由来のメッシュを用いた。[澄子と村瀬の素材](../residents/README.md)・[兵藤の素材](../cast/README.md)。

形状検査は measure.py にゲームの Game ディレクトリを渡して実行する。Play Modeでは KinseiResidentSpeechRegression.Run が常連と3店主を通常の会話操作で選び、発話する人物、瞬目、安静への復帰を検査する。
