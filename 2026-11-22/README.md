# 金星の一夜

2026年、大阪・宵待町。若頭の真壁は六人の組員とキャバレー金星へ戻る。兄貴分を追う、二階の梶に弟の無事を知らせる、立会人を立てて舞台の勝負を受ける。店内を移動しながら、金星の夜の終わらせ方を決める。

## Windowsで遊ぶ

Windows版の `Kinsei-Windows-v1.7.0.zip` をフォルダに展開し、中の `Kinsei.exe` を実行する。タイトルで Enter を押すと表通りから始まる。

## 最初の晩から翌朝まで

若頭の真壁は、梶と金星の座長から一つずつ約束を取りつける。どちらを先に取るかはプレイヤーが決める。同じ帳面で何度でも出撃できる。

| いつ | 真壁と組員ができること |
|---|---|
| 最初の晩 | 表通りから金星へ入る。組員を左の中継卓へ送り、真壁が弟と梶を会わせると、梶が次の晩の客席を取り置く。 |
| 別の晩 | 組員を右の通用口へ送り、真壁が兄貴分を追って興行を取り戻すと、座長が前売りを引き受ける。失敗した晩の未精算の伝票は失う。先に取った約束は帳面に残る。 |
| 二つの約束がそろった後 | タイトルまたは帰還画面で **F** を押して「最終夜　四十軒の朝」を始める。真壁が針音堂から預かった原盤をどこに渡し、組員がどこの持ち場に着くかで、共同放送か金星専属の興行が決まる。 |
| 結末の翌朝 | 共同放送の翌朝は、喫茶ロータスの澄子が堺へ送りたい曲を頼む。専属興行の翌朝は、真壁が金星で最初の前売券を受け取り、針音堂の兵藤に届ける。同じ帳面から最終夜を再訪し、もう一つの結末と翌朝も遊べる。 |

ホールに入る前なら、通りの店を訪ねる、高架線に乗る、西の湯へ迎えを出す、楽屋口へ回る順番も選べる。

[同じ帳面で通常夜から二つの結末と翌朝まで遊んだ実機記録](evidence/v17/campaign/README.md)

## 最初のホールで組員を指揮する

金星の正面入口を入ったら **Tab** で指揮に切り替える。数字か名前札で組員を選び、**Z** で左の中継卓、**X** で右の通用口へ送る。地図のブラウン管か開いた扉の印をクリックしてもよい。Shiftを押したまま選ぶと複数人に一度に頼める。床の線は組員の移動経路を示す。名前札をダブルクリックすると、その組員に指揮カメラを合わせる。**H** で休息や梶の席への派遣など、ほかの指示を開ける。

たとえば千代を通用口へ、源を中継卓へ送り、真壁はTabで現場に戻る。組員の到着後、画面の「移動中」が持ち場の様子に変わる。用心棒が守っている側は準備が途中で止まる。真壁がそこへ向かい、相手をひるませて突破口を作る。手薄な側で真壁が加勢して先に決めてもよい。どちらかの組員が持ち場を確保すると、反対側の班は真壁の随行に戻る。

- **通用口を押さえる。** 兄貴分が舞台から通用口へ出てくる。逃走の猶予が18秒延びる。組員がその場で兄貴分を押しとどめている間に真壁が追えば、反撃される前に先手を取れる。
- **中継卓を通す。** 弟が降参して卓へ走る。残った用心棒を退かせたら、真壁が卓でEを押して中継係に合図する。派遣した組員が鏡を操作するので、辰を二階に送らずに梶と弟を帰せる。

これまでどおり、真壁がその場で弟に肩を貸す、組員に用心棒を名指しする、舞台の立会人を選ぶ、といった進め方もできる。

[ホールで二つの組に指示を出したWindows版の映像と検証](evidence/v17/README.md)では、組員の現在地、真壁が援護に入った側、決着を順に確認できる。

## 操作一覧

|場面|操作|
|---|---|
|真壁を操作|WASDで移動、Shiftで走る。右ドラッグまたは左右の矢印で視点を回す。Qで注視する相手を変える。|
|争いの最中|相手に左クリック、またはSpaceで照準に向けて射撃。近い相手にはFで打撃。|
|現場で話す・追う|相手または鏡の近くで、表示された行動をEで実行。|
|店の商品と作業を見る|カウンターに近づき、Cで寄る。送像所では左側に村瀬の調整卓、右側に音楽回線のVU計がある。Cか移動で肩越しの視点へ戻る。|
|店主と話す|Eで近くの人に話しかける。店主のそばでZを押すと相手の顔に寄る。もう一度Zを押すか、歩くと肩越しの視点へ戻る。|
|指揮|Tabで切替。1～6または顔札で組員を選び、地面を右クリックして移動。WASDで地図を動かし、ホイールで拡縮。|
|班を組む|Shiftを押しながら数字または顔札を選ぶと、組員を追加・解除する。F3で一班、F4で二班に登録し、F1・F2で呼び戻す。右クリック・F・G・Rで選択した全員に指示する。|
|組員への指示|Eで辰を梶の席へ、Fで随行、Gでホールの持ち場、Rで表通りに下げて休息。|
|用心棒を名指しする|ホールで組員か班を選び、紺谷・浦の人影または名前を右クリック。担当者は相手を追う。地面を右クリックすると持ち場を変え、Fを押すと真壁のもとに戻る。|
|降参した用心棒を見る|真壁で紺谷か浦に近づき、Zを押し続けると片膝をついた相手を正面から見る。キーを離すと肩越しに戻る。その間も仲間と敵は動く。|
|舞台の立会|指揮で組員を選び、Vで舞台袖へ送る。同じ組員にVで取り消し。立会人が着いたら、真壁で舞台の階段前に行き、Eで勝負を受ける。|
|楽屋口から入る|入店前に指揮で組員を選び、Bで金星西側の札口へ送る。真壁は通りを左へ進み、「楽屋口」の看板の下を通る。組員が札を差し出したら、真壁は引戸の取手の前でEを押して戸を開ける。|
|宵待高架線に乗る|通常夜の入店前に、向かいの店と店の間を奥へ進む。昇降台でEを押してホームに上がり、停車中の戸をWASDで通る。降りる駅でホームへ歩き、昇降台で地上へ戻る。|
|西の運河橋|金星へ入る前に表通りを西へ歩き、ロータスを過ぎて橋を渡る。銭湯の前で真壁が瀬尾に近づいてEを押すと勝負になる。橋では、指揮画面で組員を一人か二人選び、Eで湯客を迎えに出せる。|
|金星の帳場|伝票を取りに行く組員を選び、Tで入口の帳場に送る。真壁で帳場まで歩き、Eで受け取ることもできる。|
|幕間|Escで一時停止・設定。再開、やり直し、タイトル、終了を選べる。F12で実機の写真を撮影する。|

初めてなら、表通りで指揮に切り替え、辰に二階を任せてから入店するとよい。弟が降参した後も時計は進む。梶は相手の顔を自分で見るまで席を立たない。

班分けはその夜の間、TPSに戻っても残る。たとえば二人を一班に登録して表通りで休ませ、別の二人を二班に登録してホールの持ち場へ送れる。交渉、伝票の回収、舞台の立会、楽屋口の通し札は、顔札で一人を選んで任せる。

紺の縞背広と眼鏡が紺谷、桑色の上着と白い胸飾りが浦。真壁が一方を組員に任せると、TPSに戻ってもう一人と戦える。同じ用心棒を降参させたいときは、指名した組員の一発と真壁の一撃を1.55秒以内に続ける。どちらが先に当ててもよい。降参した用心棒は片膝をついてホールに残り、担当した組員は真壁への随行に戻る。終幕で、どちらが手を引いたかを確認できる。

舞台の勝負では、合図灯が描く輪からWASDで離れ、大振りのあとの隙に近づいてFを押す。舞台に上がるまで、弟との中継や兄貴分の追跡も選べる。

楽屋口から入ると、真壁は舞台脇の床に出る。そのまま立会人を呼ぶことも、ホールを横切って弟と梶を帰すこともできる。通路の額の前ではCで歌手の写真と衣裳札を近くから見られる。組員の行き先を変えて正面から入ることもできる。新しい晩には店が再び戸を閉める。

## 出撃を重ねる

v0.2から金星の伝票は帰還時に精算する。初日の売上は12,000円。敗北や帰還前のやり直しで、その晩に預かった伝票を失う。梶と弟を帰すと次回から梶が客席を2,000円分取り置きし、梶の四人も長く待つ。興行を取り戻すと座長が前売り4,000円分を加える。帰還して記帳した売上と約束は次の起動にも残る。

二晩目には茂の代わりに鉄、三晩目にはハルの代わりに鈴が入り、用心棒の立つ側も変わる。鉄と鈴は体力135で始まる。辰を二階に専念させながら、助っ人に帳場かホールを任せられる。新しい晩が始まるたびにタイトルの出撃回数が進む。

v0.3から、金星に入る前に向かいの通りを歩ける。西からロータス、針音堂、共同送像所が並ぶ。真壁が針音堂の盤を送像所に届けると、兄貴分は一曲分の八秒を待つ。間にロータスを訪ねて常連のリクエストも聞けば、梶の四人がさらに十四秒待つ。店主は用事で戸を閉めるため、留守なら通りで呼び止めるか、帰りを待つ。近くの人にはEで話す。

## 通りと高架線を行き来する

西の湯では、瀬尾が文子と喜一の帰り道をふさいでいる。真壁が一人で勝負を受けた場合は、瀬尾の踏み込みをかわし、隙に近づいてFで二度返す。仲間を迎えに出した場合は、選んだ組員が橋を渡って客を連れ戻す。瀬尾がそばに立つと客が足を止める。真壁が瀬尾に姿を見せ、その場から離れると、瀬尾があとを追う間に組員が客を案内できる。

勝負を受けるか迎えを頼むと38秒の時計が動く。真壁が勝つか、客が二人とも金星側に着けば、二階の浜口はその夜の加勢を見送る。橋から引き返したり、瀬尾が勝っても、そのまま金星へ向かえる。

湯の暖簾をくぐると、真壁は番台と靴箱の間を歩ける。玄関先のテレビは金星で演奏している二人を映す。真壁がテレビに近づくと、同じ曲が右隣の丸いスピーカーから聞こえる。指揮に戻している間も演奏は続く。[西の湯を歩いたWindows版の映像と録音](evidence/v15/README.md)

高架の宵待西口と送像所前は36 m離れている。真壁が上にいる間も組員は地上の仕事を続ける。真壁はどちらの駅でも降りられ、乗ったまま元の駅に戻ることもできる。

雨上がりの晩は、金星入口の右側にある街頭テレビの前に水が残っている。真壁を水たまりの手前で止め、指揮で辰たちを向かいの縁石へ送る。肩越しに戻ると、辰の赤茶のズボンが水面に映ったテレビのつまみを横切る。真壁も同じ場所を歩ける。靴が水に触れると、その足を起点に波が広がる。[Windows版で組員が水たまりを横切る映像](evidence/v16/README.md)

## 金星の舞台で勝負する

通常出撃では、真壁が入口右手の街頭テレビに近づき、Cを押すと今夜の歌手と伴奏者が映る。指揮に切り替え、組員を一人選んでVを押すと、その組員が舞台右の袖に向かう。立会人が着いたら真壁を舞台正面の段へ進め、Eで兄貴分の勝負を受ける。舞台の白い明かりが、Fで打ち返せる時間を知らせる。勝つと座長が次の興行の前売りを約束する。真壁が勝負を受けるまでは同じ組員にもう一度Vを押して立会を取り消せる。

舞台に上がってからもTabで指揮に切り替えられる。立会人とは別の組員を一人選び、Eで実況卓を任せる。同じ組員にもう一度Eを押すと担当を外せる。指揮中にCを押し続けると、係員が送出つまみを回す手元が見える。Cを離すと舞台全体の指揮に戻る。真壁が兄貴分に一度打ち返し、実況係が送出音量を上げると、マイクを開く選択が加わる。舞台中央のマイクを挟んで兄貴分の反対側に立ち、Eを押す。兄貴分が町の客に自分の言葉で舞台を返し、座長が次の興行の前売りを約束する。そのまま舞台の勝負を続けて決着をつけることもできる。

## 最終夜を遊ぶ

v0.4では、梶と金星座長の両方から約束を取ると、タイトルと帰還画面に「最終夜　四十軒の朝」が現れる。Fで最終夜を始める。Enterを選べば通常の出撃に戻れる。以前の版で獲得した約束も使える。

真壁が針音堂で原盤を受け取ったら、Tabで指揮に入り、組員を一人選んでEで送像所に向かわせる。組員が回線をつなぐと、真壁は共同送像所の卓で原盤をかけるか、金星の帳場で座長に原盤を渡せる。共同放送を選んだら指揮でロータスの客席に、専属興行を選んだら金星の帳場に組員を送る。最初の放送を終えると帳面に結末が残る。同じ帳面で最終夜をもう一度遊び、もう一方を選べる。

## 結末の翌朝を歩く

最終夜を終えて帳面に共同放送を記すと、タイトルと帰還画面で「1　共同放送の翌朝」を選べる。真壁はロータスで澄子の依頼を受け、共同送像所の卓でEを押して「堺の朝」をかける。受像機に信号が入り、卓上の札が「演奏中　堺の朝」に変わる。金星のピアノは、この朝に流れる曲の楽譜に合わせて動く。

専属興行の結末を記すと「2　専属興行の翌朝」が開く。真壁を金星の帳場にある印字機の正面に立たせ、券が出たらEを押す。真壁が左手で券を抜き取る。通りを渡って針音堂のカウンター左端に回り、もう一度Eを押すと、真壁はその一枚を真鍮の皿に置く。兵藤が皿を手元に引いて前売りを始める。Cで皿と前売りの札を近くから見られる。

どちらの朝も三店と高架線を行き来できる。Escで幕間を開いてタイトルに戻る。朝を再訪しても出撃回数、売上、約束は増減しない。

## ソースからビルド

Unity 6000.3.28f1・Windows Standalone。PowerShell でこのフォルダの `./Build-Windows.ps1` を実行する。プレイヤーは `Builds/Windows/`、Editor のログは `Builds/editor.log` に出力する。画面解像度は標準の `-screen-width`、`-screen-height`、`-screen-fullscreen 0` で指定できる。計測用に `-kinsei-metrics` を付けると、決着時に描画間隔の中央値と95パーセンタイルがプレイヤーログに記録される。
