## 初回候補の開扉時間

RTX 4070 Ti、1920×1080ウィンドウ。実際に勝利した経路をUnity側で計測した2870フレームの中央値は16.67ms、95パーセンタイルは17.78ms。開扉開始から通行可能になるまでのゲーム内時間は1.23秒だった。

720pで再度Eを押し、Windows Graphics Captureが届けたフレームのタイムスタンプを独立採取した。Eの1.5秒前までの63間隔、開扉中から通知後0.1秒までの45間隔、続く110間隔の各区間ともp95は34.73ms、最大41.67ms。戸の開放時だけに生じる大きな表示停止はこの試行では観測しなかった。Windows側のフレーム配送には合成・取りこぼしが含まれる。Unityの1フレームごとのGPU処理時間は未計測。[各配送間隔](door-delivery.csv)

初回候補ZIPのSHA-256は 696ae1363408507bd48e6fe1e51636d6f85524c47c298078371e5242aecb7f82。96,197,168バイト。独立コピーから起動し、格納135件の相対パスと各ファイルのSHA-256がすべて一致した。Assembly-CSharp.dllは 04eae47d13d7313ae2ab091fb164b0eba75f2ac66da269ce7c0d0370ab44bb41。
