# v0.10 翌朝の宵待町の Windows 実機記録

[共同放送と専属興行の朝を歩いた映像](v010-scenes.mp4)。v0.4の実機で通常夜・最終夜を終えた[共同・専属両印の帳面](../v04/ledger-release-both.json)を、各経路用の独立したフォルダにコピーした。両方の朝とも、入る直前と幕間から表題へ戻った直後でJSONのSHA-256は 43b19eaa49093e41f482e79a860202142dfaf92f2f378fa5820a850c4b332146 のままだった。出撃4、帰還4、累計28,000円を保持した。

| 通常入力で遊んだ経路 | 実機で確認したこと |
|---|---|
| 共同放送の朝（720p） | 1キーで開始。ロータスの澄子の仕事台をCで拡大し、8.33秒に依頼を受領。22.09秒に村瀬の卓で放送を再開した。番組札は「堺の朝」を次の曲に掲示した。東昇降台に乗って34.67秒に上昇、39.56秒に下降。幕間から表題へ戻り、その後の通常夜で舞台決着まで進んだ。[澄子の手・カップ・朝の照明](coffee-joint.png)・[共同の入力ログ](player-joint.log) |
| 専属興行の朝（1080p） | 2キーで開始。3.83秒に金星の帳場で座長から受け取った券が真壁の手に見えた。針音堂で16.97秒に渡すと前売りを始める台詞が出て、手から券が消えた。Cで新譜棚と札を確認した。通常夜へ戻って舞台決着し、その結果画面から1で共同の朝へ移った。[受渡し直前の券と店頭札](give-exclusive.png)・[専属と結果画面からの再訪ログ](player-exclusive.log) |

720p・1080pとも、表題と結果の右下に二種類の朝を選ぶ欄があり、左側の夜の操作、説明、帳面の金額と重ならない。[720p表題](title-joint.png)・[1080p結果](result-exclusive.png)

カフェの寄りでは澄子の顔、手、カップとサイフォンが画面内に収まった。共同の送像卓では「放送中」「次の曲　堺の朝」が判読できるが、VU計のC表示では番組札が左端と下端から一部はみ出す。専属の針音堂では棚のC表示で前売り札下部がHUDに隠れた。[送像卓の番組札](meter-cards.png)・[針音堂の前売り札](records-exclusive.png)

この版の共同放送では、依頼を届けると卓の札に「次の曲　堺の朝」と出る。そこで聞こえる音源は夜の曲「金星、閉店前」と共通で、放送再開時の再生位置から聞こえる。

RTX 4070 Ti。共同の朝に1080pで送像卓の前に立ったときのゲーム内表示は60 FPS。朝を出てからの通常夜は、720pで2979フレーム・p95 16.68ms、1080pで1026フレーム・p95 16.76ms（両方とも中央値16.67ms）。朝全体のフレーム時間分布は取得していない。[朝のFPS表示](fps-cards.png)
