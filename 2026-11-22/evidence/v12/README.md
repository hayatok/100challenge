# 金星の一夜 1.2.0 発券機のWindows実機確認

[最終配布版・専属最終夜の発券と翌朝の引き抜き](ticket-press.mp4)。夜は離れた位置と印字機正面の2回。座長がレバーを倒し、券がガイドから送り出される。最後は翌朝の真壁が券を左手で抜く。それぞれ1920×1080のWindowsプレイヤーをキーボードとマウスで操作し、実時間の映像とゲームのステレオ音声を収録した。3場面を時系列に並べ、各場面の中にカットは入れていない。

## 最終夜の開場指示

両方の約束を実プレイで得た隔離帳面からFで最終夜を開始。真壁で原盤を受け取り、千代に接続を任せ、金星の帳場で専属を選んだ。下表の各地点から指揮視点で源に開場を指示した。時刻と座標は各試行のプレイヤーログによる。

- **前版でレバーが隠れた位置。** 旧版の x −3.44、z −2.90 に対し、最終配布版では x −3.45、z −2.89。どちらも1280×720・DX11。旧版では手前の胴が座長の手とレバーを覆ったが、再試験では手とレバーの往復を追えた。靴は右方の卓外に見え、券面の「0001」を覆わなかった。[旧版のレバー](broadcast-2-smallshow.png)・[最終版の同地点](broadcast-2-near.png)・[旧版の接写](broadcast-7-smallshow.png)・[最終版の接写](broadcast-6-near.png)
- **翌朝の印字口。** 左手と紙の端が金色のガイドから離れる。1.1の同角度に比べて、濃緑の曲面、上蓋とねじ、板の縁の細い影、ベゼルと4桁の番号窓を見分けられる。機械下側は暗いが、外装全体は黒く潰れない。ローラーとばねは固定部で、最終夜に動くのは紙とレバー。開口部右側のばねの巻きは原寸で見え、縮小すると暗い線に近づく。[配布版の引き抜き](final-pickup.png)・[1.1の同じ引き抜き](../v11/pinch-cuff.png)

- **離れた地点での再試験。** 初版で手が見えた x −4.93、z −2.93 付近に真壁を置いた。今回のFHD・DX12実測位置は x −4.89、z −2.88。取っ手の手前に指、上面の奥に送り出される券が見えた。[配布版のレバー](broadcast-2-clear.png)・[配布版の券面](broadcast-5-clear.png)

- **印字機正面から動かずに指示。** 真壁は原盤を渡した x −1.55、z −6.34 に留まった。西側からの3.61秒の寄りで取っ手、押した指、機械右へ送られる券が順に見える。人物の手が紙の右端の近くに見えるが、券面と0001は読めた。[西側の握り](broadcast-0-front.png)・[送り出し後の券](broadcast-5-front.png)

## 最終配布版の実測

| 区間 | 描画API・画面 | 開場／決着または朝の受渡し | Unityフレーム数 | 中央値 | p95 |
|---|---|---|---:|---:|---:|
| 手前の人物で隠れた地点 | DX11・1280×720 | 22.45秒／26.05秒。[ログ](player-near.log) | 1528 | 16.67ms | 16.67ms |
| 離れた地点 | DX12・1920×1080 | 24.24秒／27.85秒。[ログ](player-clear.log) | 1637 | 16.67ms | 16.68ms |
| 印字機正面 | DX12・1920×1080 | 20.60秒／24.21秒。[ログ](player-front.log) | 1419 | 16.67ms | 16.68ms |
| 専属翌朝 | DX12・1920×1080 | 5.36秒に金星で抜き、13.65秒に兵藤が受領。[ログ](player-pickup.log) | 1095 | 16.67ms | 16.68ms |

GPUはRTX 4070 Ti。最終配布ZIPは109,562,558バイト、SHA-256は `5c3726c06b86fbdf0d425f576a1c035cd4115ecb20337e4678d90e66c30acdaf`、ゲームDLLは `2ffa5c21b3b353cd1615d096a88ce4c04187c3d0d655b9ae93b2846ecd2db273`。全135ファイルの相対パスと展開後SHA-256が独立した実行コピーと一致した。各地点の近く数cmまで通常の移動操作で再現した。すべての立ち位置を網羅した試験ではない。
