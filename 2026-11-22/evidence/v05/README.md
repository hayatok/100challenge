## 中継と決着

通常夜に真壁が帳場の伝票を受け取り、プレイヤーが辰を二階の梶との交渉に送った。真壁がホールで梶の弟に肩を貸し、受像機まで連れて行った。下階では点灯したテレビと手の動き、金属部への照り返し、上階では画面の中の弟の目と手が映る。中継開始18.99秒、解放23.59秒、和解31.32秒。[下階](mirror-hand-final-mirror.png)・[上階](mirror-gaze-final-mirror.png)・[入力と和解](player-final-mirror.log)

共同は針音堂の左卓で受取、Tab→2→Eで交換卓へ指示、自分で送像所の卓に運んでE、Tab→3→Eでロータスの一番席へ指示。専属は交換卓に組員を送ったあと自分で金星の帳場へ運び、別の組員に開場を指示した。[共同放送](broadcast-1-final-joint.png)・[共同入力ログ](player-final-joint.log)・[配布版の専属入力ログ](player-shipped.log)

専属最初の構図は前景の組員が帳場を大きく遮った。次の版はレバーへの接点を見せたが、券の一部が筐体に隠れた。続く券を追う構図では印刷が上下逆向きに見えた。配布版では手が離れたあとカメラが券を追い、券の「金星」「専属興行」「0001」をほぼ正立した状態で左から読めた。[最初の遮蔽](broadcast-0-ticket.png)・[回転修正前の券](broadcast-5-final-ticket.png)・[押印中](broadcast-2-shipped.png)・[配布版の券](broadcast-5-shipped.png)

## Windowsと計測条件

各版のWindowsプレイヤーを独立フォルダから起動し、`KINSEI_SAVE_DIRECTORY` に検証専用の一時フォルダを指定。Fで最終夜を選ぶため、v0.2で通常プレイして両約束を獲得した帳面のコピーを使用した。移動、C、Esc、Tab、E、戦闘、指示と帰還は実際のキー入力を使用。Windows Graphics Captureで対象ウィンドウのクライアントだけを取り込み、対象プロセスのWASAPI音声を48 kHzステレオで収録した。

各値はRTX 4070 Ti、D3D12で実行した1経路ごとのゲーム内フレーム時間。動画の24 fpsとは別の値。和解では下階CRTを29.97 Hzに制限し終了後に中継カメラを止めた版で、同じFHD録画条件のp95が20.73 msから16.69 msになった。
