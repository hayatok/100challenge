# v0.9 高架線の Windows 実機記録

[乗車から地上へ戻るまでの音声付き映像](v09-scenes.mp4)。通常夜に班を登録し、西の昇降台へ歩き、東駅で降りた後も同じ晩を続けた。動画は通常速度・24fps。乗越しの二駅の停車表示だけは初回候補720p、その他は車窓改良版の1080p。

同じ配布版（07daff…）の720pで、二人班の保持を別の一晩で追試した。辰を1で選択し、Shift＋2で千代を加え、F3で「一班に2人を登録した」と表示された。西で39.16秒に乗り、東で58.68秒に降りた。東昇降台で地上へ戻ってからいったん源を選び、F1で「一班の2人を選んだ」と表示され、辰・千代の顔札が両方選択色になった。同じログには、F1直後の随行命令が乗車前4.24秒と地上復帰後78.39秒のどちらも組員0・1の2件ずつ残っている。[乗車前の登録](registered-verify.png)・[東から戻った後の呼出](after-verify.png)・[二人班の追試ログ](player-verify.log)

1920×1080、RTX 4070 Tiの実時間8518フレームは中央値16.67ms、p95 17.01ms。窓際で視点を横と車端へ振り、モケット、吊革、窓外を見られた。車端正面からは線路が見通せる。採取した姿勢では顔や車壁による画面全体の遮蔽はなかった。走行中に戸へ歩いても降車せず、ホーム停車後に移れた。

1280×720の初回候補では、39.16秒に宵待西口で乗車し、送像所前、宵待西口に停車する間も乗り続けた。次の送像所前で97.68秒に徒歩降車（x22.53）。車内HUDは停車駅名と乗降操作、走行中は行先・残り秒数に切り替わり、下端の枠内に収まった。115.13秒に昇降台で下降し、119.88秒に地上で指揮に切り替えた。[初回候補のログ](player-rail.log)

街路西端で北を見ると、初版で空に抜けていた区画を店舗の壁と窓灯が埋めるようになった。[北向きの実画面](canal-glass.png) 西向きの橋と東の修理店は街路端から見えるが、床・水面・欄干の境目と店頭の機器は深い影に入り、自然な肩越し視点では細部を判別しづらい。[西の橋方向](canal-west-escape.png)・[東の修理店方向](repair-escape.png)
