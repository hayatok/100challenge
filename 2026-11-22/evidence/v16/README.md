### 実画面と操作

1. [金星入口](wide-pixel1080.png)から街頭テレビへ歩くと、暖色の入口灯から緑色のケースへ水面に映るものが変わる。[真壁の肩越し](water-pixel1080.png)では、選局つまみ2個、グリル、番号窓の逆像が路面に並び、その下にブラウン管の明るい枠がある。右の高い部分は石板の歩道で、路面との段差が見える。テレビ前のCで歌手と鍵盤奏者を見る。下部のつまみとスピーカーが画角に入り、真壁の後頭部が中央で一部重なる。[Cの実画面](dial-pixel1080.png)
2. Cを解除し、z約−10.73、x4.4～6付近を真壁で左右に往復。乾いた側のx4.11、z−11.94へ退いてTab。1とShift+2で辰・千代を選択し、CRT前を右クリックで往復するよう命令した。Tabで肩越しに戻り[二人が通る瞬間](feet2-pixel1080.png)を観察。カメラ位置を固定してさらに向こう岸へ送ると、[到着前](feet3-pixel1080.png)と[到着後](second3-pixel1080.png)で水の中に赤茶のズボンの脚が二筋映り、選局器の右側に重なる。FHD原寸のx850～1350、y570～850で比較できる。
3. 店内へ進み、[720pの指揮画面](inside-rts-pixel720.png)で入口の外へ移動指示を出した。屋外の明暗と班の札、行き先の案内は同時に読める。俯瞰では、どちらの靴が着水したかまでは判別できない。
4. FHDではホールで相手を降した後、弟にEで肩を貸し、鏡まで歩いてE、兄弟の和解へ。[和解の結果](result-pixel1080.png)　720pの別出撃は舞台袖で兄貴分に近づいてE、Qで注目しSpaceで追跡を完了した。[追跡の結果](result-pixel720.png)

### 接地と映像

FHD録画ありでは真壁17件、組員8件の接地座標が記録された。t=21.61で辰・千代へ同時に移動命令。t=21.865に辰の右足（x4.647、z−10.960）、22.122に左足（x5.411、z−10.708）が水面に着いた。逆方向への指示直後の24.199にも右足（x4.929、z−10.625）を記録。真壁が入店した後も37.358に屋外にいるseat=5の左足（x−1.042、z−10.804）が記録され、37.96には屋内から千代への命令が成立した。[FHD実機ログ](player-pixel1080.log)

[連続した27秒の実機映像](rain-television-and-steps.mp4)は同一出撃から時間軸を保って切り出した。ゲームウィンドウだけをWindows Graphics Captureで収録し、ゲーム音声をWASAPIループバックで取得した。映像は1920×1080、24 fps、音声は48 kHzステレオ。648フレームと音声を末尾までデコードし、音声の平均−25.3 dB、最大−8.9 dBを確認した。

[踵の後ろに立つ水の縁・原寸3コマ](step-at-native-scale.png)は同じ収録のx850、y630から250×200画素を切り出して並べた。公開動画の18.25秒、18.33秒、18.46秒に対応。中央のコマでは赤茶のズボンの靴の左下に薄い水色の円弧が立つ。通常画角で一粒ずつの飛沫や靴先の鏡像を識別するのは難しい。

### 描画時間

Windows DX12、RTX 4070 Ti。数値はUnityが出撃中に測った各フレームの時間。ZIP内の136ファイルを実行フォルダーの136ファイルと個別に照合して全件一致した。

| 実機条件 | 結末 | フレーム数 | 中央値 | p95 |
|---|---|---:|---:|---:|
| 1920×1080、録画・F12なし | 和解 t=64.99 [ログ](player-pixelquiet.log) | 3,716 | 16.67 ms | 20.83 ms |
| 1920×1080、映像・音声収録 | 和解 t=68.66 [ログ](player-pixel1080.log) | 3,877 | 16.67 ms | 22.17 ms |
| 1280×720、映像・音声収録 | 追跡 t=50.50 [ログ](player-pixel720.log) | 2,903 | 16.67 ms | 21.12 ms |

比較用の7a697460版では、同じ録画なしFHD経路の1回が3,650フレーム、中央値16.67ms、p95 21.64msだった。各候補1回の比較で、移動時間や映る人物の位置は少しずつ異なる。採録した画像と映像は4e6a1eef版のみ。
