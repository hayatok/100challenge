# 金星の一夜 1.0.0 Windows 実機記録

初版の1.0.0 ZIP（109,443,845バイト）のSHA-256は 8e228af9adf65ed22910630c5e1f8bd6ff38556273ac7810ef848939b734473e。独立した実行コピーと比較して、格納135ファイルの相対パス・SHA-256がすべて一致した。Assembly-CSharp.dllは 2197d434b979a514afd468b4331bb1da73ed65fa2d9826da477a5742a891cf8a。

## 新しい一冊の帳面での通しプレイ

本番用の帳面とRC1検証で作った帳面を使わず、空の専用ディレクトリから開始した。各夜の帰還後にプレイヤーを閉じ、同じ保存先で再起動した。すべての進行にゲームのキーボード・マウス操作を使用した。

| 夜 | 実機での決着 | 帰還した帳面 |
|---|---|---|
| 1・追跡 | 辰を交渉、千代を伝票、源を持ち場に指示。真壁の直接操作に切り替えて兄貴分を追い、21.27秒で決着。 | 1出撃1帰還、12,000円、舞台の約束。[入力ログ](player-pursuit.log)・[帳面](ledger-pursuit.json) |
| 2・和解 | 辰を梶へ派遣し、真壁が弟を中継まで護送。19.65秒に中継、31.98秒に兄弟が退場して和解。 | 2出撃2帰還、28,000円、梶と舞台の両約束。[入力ログ](player-accord.log)・[帳面](ledger-accord.json) |
| 3・共同 | 最終夜で原盤を受け取り、交換卓を千代に任せ、真壁が送像所で共同を選び、源がロータスで開席。38.39秒に決着。 | 3出撃3帰還、28,000円、共同の印。[入力ログ](player-cooperative.log)・[帳面](ledger-cooperative.json) |
| 4・専属 | 同じ帳面で金星の帳場と開場を選択。35.08秒に専属の印を獲得。 | 4出撃4帰還、28,000円。両約束・両印。[入力ログ](player-exclusive.log)・[帳面](ledger-exclusive.json) |

続けて同じ帳面で両方の朝に入った。共同は7.54秒に澄子の依頼を受け、35.92秒に村瀬の卓で送出。専属は3.23秒に座長から一番券を受け取り、13.00秒に兵藤へ渡した。表題へ戻る前後の帳面SHA-256は両経路とも 43b19eaa49093e41f482e79a860202142dfaf92f2f378fa5820a850c4b332146 で一致した。[共同の朝ログ](player-dawnjoint.log)・[専属の朝ログ](player-dawnexclusive.log)

## 最終配布ZIPでの追試

最終ZIPは109,443,554バイト、SHA-256は `61834231583788fbc43b7494b057f77e7ff60828f70a3b40ba2693e1d0ee511e`。別の実行フォルダへコピーし、ZIP全135件のパスと展開後のSHA-256を照合した。初版との変更は髪シェーダーの代替描画設定で、両方のゲームDLLのSHA-256は同じ。

- **夜の車内。** Direct3D 12、1920×1080。西駅で真壁を歩かせ、第1車両に乗車した（39.14秒、x −22.38）。側面では耳の後ろから襟足までの輪郭、背面では暗い毛筋と首の境界を見分けられる。車内の光では分け目は弱い。[後頭部と妻壁広告](other-ads-firstcar.png)・[車内の横顔](saloon-firstcar.png)・[乗車ログ](player-firstcar.log)
- **金星の木工。** 西路地の木壁には細い縦目地が走り、隣の板と木目が異なる。壁沿いを歩け、押し当てると止まった。東階段を地上から歩いて上り、高さ3.24mの踊り場で引き返して地上まで下りた。踏み板の木目と金属の段鼻が人物の足幅より細かく見える。[西路地](west-lane-nighttrain.png)・[路地の接触ログ](player-nighttrain.log)・[階段](mid-staircase.png)・[階段の往復ログ](player-staircase.log)
- **針音堂の帳場。** 上記の初版・専属の朝に、カウンター前まで歩いて店主へ券を渡した。続けて前進しても z −17.47 で止まり、腰板に入り込まなかった。[帳場の木目](wood-counter-dawnexclusive.png)
最終版のDirect3D 11（機能レベル11.1）では別の空帳面で再出撃し、1920×1080で追跡を再完走した。18.71秒に追跡へ入り、20.44秒に兄貴分が倒れた。1164フレーム、中央値16.67ms、p95 16.78ms。[最終版の追跡ログ](player-shipped.log)

Direct3D 12の車内では、車窓が動く間にカメラを約4秒かけて回した。24fpsの収録映像を確認した範囲では、髪の消失、ピンク表示、強い反射の明滅は見られなかった。[第1車両のログ](player-firstcar.log)

ロータスの澄子にEで依頼を受けてZで寄ると、顔の下に会話字幕が出た。中央の操作帯は消え、顔を隠さない。寄ったまま再度Eを押すと澄子の台詞が「一番席は空けたで」に変わった。その直後のCで仕事台を映し、足元の操作説明は「C 元の視点へ」。もう一度Cで通常視点へ戻った。1280×720の実画面でこの一連の入力を確認した。[会話中のE](same-caption.png)・[発話直後のC](C-during-speaker-caption.png)・[朝の入力ログ](player-caption.log)
