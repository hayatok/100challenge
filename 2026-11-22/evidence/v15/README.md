# 西の湯　1.5.0のWindows実機記録

配布ZIPのSHA-256は `f03c934064a9c03af6827df845f6e6f617ca05dd1bf4e3ea4ac3c6dd5a1d68db`、141,633,063バイト。独立展開した136ファイルすべてがZIPと一致した。ゲームDLLは `731100c7a3a9decf937b073e187bfe5bb3b0b8f1721ce6f6c263dc736b3c744e`。各出撃は隔離した空の帳面から通常入力で開始した。画像は実際のゲームウィンドウを原寸で保存した。

**二つの渡り方。** 金星の前から西へ歩き、運河橋を渡った。一騎打ちでは瀬尾の前でE、踏み込みを横移動でかわし、隙にFを二度押した。瀬尾は銭湯前から路地奥の門に移り、文子と喜一が橋を渡った。もう一晩は720pで、橋の上からTab、1とShift+2で辰・千代を選び、Eで迎えを指示。瀬尾の注意を西岸北縁 (−40.56, −7.95) へ引き、33.78秒で開通した。小さい顔札にも迎え先と体力100が収まる。開通後の金星では「浜口は席に残った。二階の加勢は三人や」と出て、弟を鏡まで送り届ける通常和解へ進めた。[橋と欄干](bridge-west15.png)・[720pの迎え](escort-ordered-escort15.png)・[橋を渡る二人](bridge-walk-b-title15.png)

**人物と玄関。** 文子の指にかかる籠の把手と中の瓶、喜一の左指と洗面器の縁が読める。横からは内側の親指の一部が縁に隠れる。玄関内 (−39.17, −15.75) では型硝子の網模様と桟、番号付き靴箱と棚の靴が見えた。右を向いても旧版で奥壁に重なった外階段は見えず、振り返ると暖簾の裏から通りが見える。受像機東側 (−38.28, −13.35) から北基準約−40°へ向けても、真壁、客、路地が見えた。[正面](bath-front-west15.png)・[暖簾とタイル](curtains-west15.png)・[型硝子と靴箱](lobby-west15.png)・[手と持ち物](cast-side-west15.png)・[受像機脇の検証位置](camera-fixed-west15.png)

[実音付き32.23秒の動画](west-bath.mp4)は同じ配布版の通常入力から選んだ実時間の抜粋。玄関、一騎打ちと瀬尾が道を空ける瞬間、二人の渡橋、別晩の迎え、受像機と指揮、表題への復帰、最後に和解を収録した。720pの区間は映像内で1080pに拡大している。全編をデコードし、場面の切り替わりと最終フレームを確認した。

**受像機と実音。** FHDの肩越しで、金星の歌手と鍵盤奏者が同じ管面に映る。ゲームプロセスの48 kHzステレオ録音を同じワルツの原音と照合した。受像機前→指揮→TPSで、録画時刻52.60、57.10、60.42秒に対応する原音の位置は15.53、20.03、23.37秒。指揮を挟んで曲は進み、近くでは中域に対して低音・高音が弱くなった。指揮の俯瞰では外壁が管面を隠すので、指揮中の鍵盤の絵の更新は直接判定できない。別出撃で受像機前の幕間から「表題に戻る」をクリックすると、実際にタイトルが表示された。近くと表題でそれぞれ1.6秒を照合すると、原音に対する30–180 Hzの差は約−16 dBから約0 dBへ戻った（400–2000 Hz基準）。[受像機・指揮・玄関のログ](player-west15.log)・[渡橋と表題復帰のログ](player-title15.log)
