## 同じ帳面での帰還と操作の回帰

空の専用フォルダーから通常出撃を開始し、[最初の和解後の帳面](ledger-after-relay.json)で1夜完了と梶の約束を確認した。同じ場所から再起動して追跡を達成し、[2夜目の帳面](ledger-after-door.json)では2夜完了、梶・舞台の両方の約束がtrue、両方の最終夜は未達だった。2夜目のSHA-256は 1e3784a3730d560a68e7773637fff0b0f1d9dd287f6562d179cc8ad394edf537。同じ帳面で[二つの最終夜と翌朝の仕事](campaign/README.md)まで進んだ。720pの出撃冒頭にフォーカスが外れて一度自動ポーズが入った。収録に採用した範囲は復帰後の店内から結果まで。

- **降参者を観察するZ**　別帳面の出撃で紺谷を源に指名し、t=5.20の源の命中と直後の真壁の射撃で5.28に降参。真壁が近づいて止まると下段に[「Z長押し　紺谷を見る」](hint-portrait.png)が表示された。キーを保持して[顔・開いた掌に寄った画面](held-portrait.png)、離して[元の肩越しの画面](released-portrait.png)を確認した。接写時の距離は2.06 m。[独立出撃ログ](player-portrait.log)
- **足止め中の班を呼び戻すF**　別の出撃で通用口に着いた二人を選んでFを押すと、t=23.40に両方が随行へ戻った。右側の札が「兄貴分を足止め」から「逃走猶予 ＋18秒」に変わった。[上下の原寸比較](exit-before-after.png)はこの出撃の720pの同一箇所を、上に呼び戻し前、下に呼び戻し後の順で切り出した。[独立出撃ログ](player-withdraw.log)
