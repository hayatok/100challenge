# 金星の一夜 1.1.0 Windows 実機記録

## 専属翌朝の一番券

[印字機から針音堂まで・連続12秒](ticket-continuous.mp4)。最終の 4c2703 版を1920×1080で操作。真壁が左手で券を抜き、金星を出て通りを横切り、針音堂で兵藤に渡すまでを、カットや速度変更を加えずに収録した。映像は24fps、ゲームプロセスの音声は48kHzステレオ。

金星の印字機の南で「E 座長から一番券を受け取る」が出る。左手が一枚をつまみ、印字口から引き抜くのが見える。目的表示は「針音堂のカウンター左端で一番券を渡す」に変わる。針音堂では中央の「E 兵藤に一番券を渡す」で着盆に移る。場所と相手を読んで進めるが、印字機の南側という細かな立ち位置は、近づいて「話す」が「受け取る」に変わることで判別した。[印字口の券と左手](pinch-cuff.png)

盆の右側に券が残り、兵藤の右手が下がり、指腹と木の縁が接してから券と盆が一緒に奥へ動く。縁の内側へ突き抜けて見えた中間版の指先は最終版で解消した。引き量の設計値は19cmで、画像から実寸換算はしていない。指を離して持ち上げても、肌色の前腕が紺の袖の折返しまでつながる。袖内の丸い関節は見えるが、以前のように手が離れて見える箇所はなかった。1920×1080と1280×720の両方で確認した。Cで寄ると受付札・兵藤・盆・券が同居し、眉付近に細い陳列レールが重なる。[指腹と盆の縁](rim-contact-cuff.png)・[手を上げた瞬間](wrist-lift-cuff.png)・[前売り窓口のC](tray-card-cuff.png)

| 最終版の確認 | 実機結果 |
|---|---|
| 専属・1920×1080 | 5.35秒に印字機で取り出し、13.75秒に窓口で受領。Cから通常視点に戻り、表題へ。[操作ログ](player-cuff.log) |
| 専属・1280×720 | 動作中の4.39秒でEsc。ゲーム内時間は同時刻に復帰。5.09秒に取り出し、13.22秒に受領。操作案内と字幕に重なりや欠けは見られなかった。[操作ログ](player-cuffsmall.log) |
| 検証用帳面 | 1.0実機の4夜で両決着を得た帳面を隔離保存先へ複製。この最終版の両テストの前後は毎回SHA-256 `43b19eaa49093e41f482e79a860202142dfaf92f2f378fa5820a850c4b332146` のまま。通常夜の車両用には別の保存先を使用。 |

## 夜の第1車両と描画時間

車両コードが同一の直前版（b35ab7）で西駅から第1車両へ39.08秒に乗車。窓側から1.0と同じ操作で横を向くと、横灯で頬、耳前の毛筋、耳の軟骨と襟足が見える。15.67秒後にEscで表題へ戻り、ゲーム自身が車内だけを数えた `scene=occupied-coach` を記録した。[b35ab7版の車内](saloon-occupied.png)・[最初の同角度比較に使った1.1写真](saloon-coach.png)・[1.0の同じ横顔](../v10/saloon-firstcar.png)・[表題に戻った車内ログ](player-occupied.log)

| 計測した版と区間 | 解像度 | Unityフレーム数 | 中央値 | p95 |
|---|---:|---:|---:|---:|
| 4c2703・専属翌朝 | 1920×1080 | 1105 | 16.67ms | 16.67ms |
| 4c2703・専属翌朝 | 1280×720 | 999 | 16.67ms | 16.67ms |
| b35ab7・夜の第1車両・表題で計測終了 | 1920×1080 | 938 | 16.67ms | 16.81ms |

別の通常夜で西駅第1車両に39.15秒に乗車し、58.68秒に東駅で歩いて降りた。19.53秒の乗車分が下車でも出力され、1163フレーム・中央値16.67ms・p95 17.58msだった。[東駅での下車ログ](player-alight.log)

GPUはRTX 4070 Ti、Direct3D 12。Unityの `-kinsei-metrics` を使用した。
