# v0.8 Windows実機記録

## 最終配布版で未登録の班を呼び出す

720pで辰と千代を選んでから未登録の一班をF1で呼び出すと、二人の顔札の選択色が消えた。そのまま舞台左の床を右クリックすると「動ける組員を選んでください」と表示され、二人とも随行を続けた。同じ二人を選び直し、同じ床を右クリックすると、初めて二人分の移動命令が記録された。実機で再現したのは未登録班の条件。[選択解除直後の右クリック](no-order-empty.png)・[同じ晩の命令ログ](player-empty.log)

配布ZIPは ef574db4d80349b97e85b024e1d1458fbd8b5776971904c0aaa913f0e69af2dd、96,996,074バイト。独立した実行コピーと格納135件の相対パス・SHA-256がすべて一致した。Assembly-CSharp.dllは 410d2ae9f31cfb6db54f81aa77529f605891731e70591f8f3497bd2290ac8e4d。

## 指揮表示と真壁の上着を更新した候補

1920×1080の実機で、F3・F4への別々の二人の登録、F1・F2の呼出、指定地点への分離を再現した。顔札の組番号、班名、単独仕事の暗いラベルと補助説明は、前候補より明るく、二人選択時の指示も枠に収まる。結果から次の晩に入ると班は空に戻った。[班の登録と移動、走行、開扉、舞台の録画](v08-scenes.mp4)・[FHDの班名と指示](second-weave.png)・[入力結果](player-weave.log)

通路の照明下で走り、止まると、背と肩の縁に青みと暖色の光が残る。取手に右腕を伸ばす動きと舞台の反撃を確認した。記録した範囲では背・肩・袖に裂け目、白く潰れた布、目立つ細縞のちらつきは見えなかった。細かな織り自体を肩越し視点から追える場面は少ない。録画は24fpsで、静止画は実機の元解像度。[停止後の背面](stop-weave.png)・[取手に腕を伸ばす場面](hand-weave.png)

RTX 4070 Ti、3703フレーム、中央値16.67ms・p95 18.65ms。ZIPは 2d606ef6c7ed35c6645e52cfcad81f5e427f7fd011f477554d511787f3629071、96,996,062バイト。実際に起動した独立コピーと135件のファイル名・SHA-256がすべて一致した。Assembly-CSharp.dllは a03d2793208b69d2b377ef60e618a5d26990ffa3598b2528d4918d6e958d67db。

## 720pでの二班の指揮

新規専用帳面を使い、Shift＋2で辰・千代を選んでF3へ、3を押してからShift＋新田の顔札をクリックし、源・新田をF4へ登録した。TPSに戻ってから再度指揮画面を開き、F1、F2で先ほどの顔札が選択状態に戻ることを確認した。

一班選択中にE、V、Bを押し、下段の班ボタン・顔札・上段の目的欄の上で右クリックした。この区間の命令イベントは0件。続いて舞台左手とホール右側の床を右クリックすると、それぞれ2人分の移動命令が記録され、4人が左右へ分かれて歩いた。舞台で決着した後、同じプロセスで次の晩へ進むと一班・二班がともに0人に戻った。[別方向への移動](separate-squad.png)・[次夜の指揮画面](new-night-squad.png)・[ゲームの入力結果](player-squad.log)

1280×720で顔札6人分、班名、各ボタンの末尾、操作説明が枠に収まった。顔札右上の班名と個別仕事の無効表示は暗め。RTX 4070 Tiで舞台決着まで3315フレーム、中央値16.67ms、p95 17.57ms。初回候補の配布ZIPは 7255dab325c76ba1646e915a6e24bc7c89ffa39eac7adf1a9358711a4a2f953f、96,948,206バイト。実行コピーとの相対パス・SHA-256は135件すべて一致した。DLLは f996595bf4b3eb0682f01dcbb78a7b5cd5f558d41df61ce2b53574cf096b93ef。

初回候補は1920×1080でも両組の分離から舞台決着まで確認した（3800フレーム、中央値16.67ms、p95 18.75ms）。西の街路x−18.67、z−10.17で真壁を西向きに止めると、建物の外側を向いた肩越しカメラに広い青い空と暗い平坦な路面が現れる。[西端で停止した実画面](stop-squad.png)
