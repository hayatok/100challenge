# 金星の一夜 1.3　舞台の声を町へ送る

[最終配布版の一出撃・実況卓の手元から喫茶ロータスまで](dial.mp4)。FHDのWindowsプレイヤーで、表題から結果までをキーボードとマウスで操作した。画面とゲームプロセスのステレオ音声を同期収録。24fps、途中のカット・速度変更なし。

## 指揮から手元へ、手元から放送へ

千代を立会人にし、階段のEで舞台へ上がった。白い隙でFを一度返し、兄貴分の体力を66にした。Tabで指揮画面を開き、源を選んでEで実況卓へ送った。

1. **Cを押し続ける。** 俯瞰から実況器の正面へ切り替わる。画面には選択中の源とCの説明が残る。「実況係が送出音量を調整中」と出る間、源の左手が向かって左のつまみへ伸び、白い指掛けに指が触れる。調整前は白い印がほぼ縦、手が離れた後は左上から右下の斜め向きになった。握っている間は指掛けの一部が手に隠れる。[調整前](grasp-dial.png)・[指を掛けた瞬間](rotation-dial.png)・[解放後の角度](release-dial.png)
2. **Cを離し、Tabで舞台に戻る。** Cの解放で通常の指揮地図と選択枠が戻り、その後のTabで肩越しに戻った。FHD録画では24.32～25.07秒に指揮地図が見える。720pでも同じ順番を確認。着任から準備完了までのゲーム内時間は両解像度とも1.23秒。今回の開始位置 x −5.86、z 3.08 はマイクから約0.92mで、Fを返してから一歩も動かずEでマイクを開けた。[C解放後の指揮画面・720p](return-map-dial720.png)
3. **声の行き先を見る。** 白服の兄貴分の顔と掌を映した後、実物の実況器の金枠CRTに切り替わる。CRT内で顔、上着、マイクと扇を識別できる。続く喫茶ロータスの結果画では、カウンターに座る常連と右上の壁掛け受像機の人物が見える。結果説明は左、操作ボタンは左下でテレビと重ならない。[実況卓の終幕](monitor-final.png)・[喫茶ロータスの結果画](result-dial.png)

発話「金星を取ったんは、わしや。幕を返す。」の4.22秒全体をゲームプロセスのPCM16・48kHzステレオのループバックで確認。左右平均と原音を8kHzへ変換して求めた正規化相関はFHD 0.9971、720p 0.9843。FHD動画の26.28秒が素材の先頭に対応する。添付WAVはその0.65秒前から始まる。表情と掌の動きは映像で確認できるが、各音節の口形との一致は判定していない。[実録した音声・5.57秒](dial-testimony-loopback.wav)

## 指とつまみの接触、既存経路の検査

Unity Play Modeで新田と千代の左手を各43フレーム変形後に採寸した。把持中は親指と人差し指が指掛けの反対側に触れる。親指の最大の食い込みは0.56 mm、人差し指は3.33 mm。各人とも着任後1.2166秒ではEを受け付けず、1.2333秒でマイクを開けた。この測定では真壁をマイクの脇に固定した。[変形メッシュと指掛けの測定値](grip-playmode.txt)

最終ビルドのソースでUnityの7系統の回帰を実行した。指揮と班の戦線離脱、弟を送る・兄貴分を追う分岐、舞台の勝ち・負け・放送、鉄道、発券機のカメラ、両方の翌朝、店先の会話が通過した。
