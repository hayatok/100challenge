# v1.8　地図指揮と肩越し操作

Windows版をキーボードとマウスで操作した。通常の帳面とは別の保存先を使った。

| 操作 | 実機で確認した結果 |
| --- | --- |
| [表通りの地図](map-orders.jpg)で千代を選ぶ | 同じ構図で「表で休息」「帳場の伝票」「真壁へ呼び戻す」「舞台袖で立ち会う」を順にクリック。左右どちらのボタンからも派遣でき、移動中の千代に次の仕事を頼めた。 |
| [Shiftで追加選択](select-crew.jpg) | Homeで真壁へ戻り、左列の3人を囲んだ。Shiftを押して右列の3人を追加し、F3で一班に登録。6人全員に休息を指示し、別の組員を選んだあとF1で呼び出して6人を随行に戻した。同じ晩に組員をホールの中継卓へ派遣した。 |
| [真壁の肩越し照準](aim.jpg) | マウスで左右を見回し入店。Qで紺谷に合わせ、右ボタンで構えて左クリックすると用心棒に命中。Tabで指揮を往復したあと、QとSpaceでも同じ用心棒に命中した。 |
| [幕間で操作を変更](settings.jpg) | 右ドラッグ方式に変更して感度を調整。再起動後に設定の保持を確認し、自由視点・見回し100％・構え45％に戻した。別ウィンドウに切り替えると自動で幕間になり、復帰後にEscで再開できた。 |

[Playerの操作イベント抜粋](player-events.txt)と[1920×1080の地図](map-1080.jpg)。表通りとホールの操作は1280×720、地図と幕間の表示は1920×1080でも確認した。初めて遊ぶ人を対象とするテストと両方の翌朝までの通しプレイは、今回の検証範囲外。

Unity 6000.3.28f1で、既存の班指示・ホール二方面・用心棒の指名・舞台・分岐・西の湯・翌朝の7系統を実行した。Editorの検索索引初期化で例外が記録される環境で、判定には各テスト固有のPASS行を使った。Windows版ZIP内の136ファイルはビルド先とバイト単位で照合した。
