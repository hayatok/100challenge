# 金星の一夜 1.4.0　Windows実機記録

配布ZIPは120,164,577バイト、SHA-256は `b0c1e4f5898e12341041d8da682a8ad4a5a36bffde2129734320023eb1759eaf`。独立展開した136ファイルを全件照合した。ゲームDLLは `b1f4d389a210e1c4f9ae600ac9c7ed56b3b0d7abb8a62c56adbec1a92831cb50`。Windowsプレイヤー、RTX 4070 Ti、出撃ごとに空の隔離帳面を使用。通常のキーボードとマウスで操作した。

**同じ夜で二人が降参する25.5秒。** 源を選んで敵の名前を右クリックし、肩越しに戻ってQで同じ相手を捕捉、Spaceで射撃した。源の指名命中から降参まで紺谷は0.05秒、浦は0.10秒。動画は一出撃の連続区間で、二人の発話、Zで紺谷と浦に寄る様子を収録した。ゲームプロセスの48 kHzステレオ出力を録音し、原音を8 kHzモノラルで照合した相関は紺谷0.950、浦0.734。MP4は全編をデコード確認した。[実録動画](hall-voices.mp4)・[一人目の降参後の指揮画面](second-map-published.png)

**正面の実画面。** FHDの紺谷は真壁の位置 (−1.32, 0.78) から20°・2.06 m、浦は (0.93, 1.55) から0°・2.06 m。紺谷の眼鏡と細い縦縞、浦の桑色とチーフ、二人とも袖口から出た指、上げた左掌、膝に置いた右手が見える。紺谷の画面左には実況卓の脚が入る。Zを離すと弟と真壁を含む肩越しに戻り、保持中のTabで指揮へ、Sで後退に復帰。退走時計は寄り画面でも進んだ。[紺谷・FHD](kontani-view-published.png)・[浦・FHD](ura-view-published.png)・[紺谷・西から720p](kontani-west-pubwest.png)

**実況卓。** 舞台の勝負で反撃し、源を実況卓に派遣。Cを保持した実画面では濃い塗装の粒、ねじと金色の縦溝、白い指掛けに届く左手が見える。Cを離して指揮画面に戻り、Tabで肩越しに切り替えた。真壁がEでマイクを開いて町内中継に決着した。[実況卓・FHD](rotation-pubdesk.png)
