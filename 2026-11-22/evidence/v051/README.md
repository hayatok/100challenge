# v0.5.1　袖口と動き軽減の実機検証

## 初回ビルドの所見

ゲームアセンブリ `d6431df5413501cefedc39e02834cedfba417bbbec8352c446c5988dcdb1851c` のWindowsプレイヤーを1920×1080で起動した。TPSで両店に歩き、カウンターのCから各約5秒を継続撮影。下の比較は各店とも別の時刻の実画面から同じ領域を原寸で切り出した。

- **澄子**はスプーンの軸に親指と指を回し、先端はカップの中を動いた。袖から掌へは肌色が続く。周期の片側で袖口の上縁に薄い三角形、付け根の下に平坦な肌色の楔が見えた。[手とカップの等倍比較](coffee-cycle-detail.png)
- **村瀬**は白い袖口から右手が出て、緑色の工具の持ち手に指が回る。手は周期中につながるものの、伸ばした端では袖口の先が鋭い三角片になり、肌の付け根にも平らな突起が現れる。受像機の縁が指先の一部に重なる。[曲げた端と伸ばした端の等倍比較](operator-cycle-detail.png)・[全体](operator-8-work.png)・[移動とCのログ](player-work.log)
- 幕間で「揺れ・点滅を抑える」を**入**にし、最終夜を専属で完走。発券の開始と終了の2フレームで同じ床領域350×270ピクセルの平均画素差は0。固定画角から券全体と0001は見えたが、文字は横倒しに近い。発券31.17秒、決着34.78秒、2,054フレーム、中央値16.67 ms、95%点16.68 ms。[設定](reduced-motion-reduced.png)・[発券後](broadcast-5-reduced.png)・[専属のログ](player-reduced.log)

プレイヤー実行中は検証専用の台帳と、バックアップ・退避した通常環境とは別の一時PlayerPrefsキーを使用した。終了後に通常のキーを元の名前に戻した。
## 配布版での再検証

[配布版の作業周期と発券](work-and-ticket.mp4)は同じWindowsプレイヤーの映像で、音声は対象プロセスだけを48 kHzステレオで収録した。各作業の両端を等倍比較し、初回画像と照合した。

|場所|配布版で見えたこと|
|---|---|
|ロータス|丸い袖口の内側から肌が続き、曲がった親指と向かい側の指がスプーンの軸を挟む。両端とも先端はカップ内にある。手首の曲がりは角張って見える一方、初回の薄い三角片と肌の平坦な切断面は見えなかった。[原寸2コマ](coffee-release-cycle-detail.png)・[作業台全体](coffee-6-tailoring.png)|
|共同送像所|袖口から手首、手の甲、緑の持ち手まで描画が連続し、伸ばし切った位置でも薄い三角片は出ない。親指は握りの反対側に見える。指先の一部は受像機の縁に隠れる。[原寸2コマ](operator-release-cycle-detail.png)・[調整卓全体](operator-4-tailoring.png)・[両店のC入力](player-tailoring.log)|
|金星の帳場|幕間の「揺れ・点滅を抑える　入」を確認。発券の開始から終了までカメラは同じ位置を保ち、手元の卓に出た券を正立に近い向きで「金星」「専属興行」「0001」と読めた。最初から最後まで6フレームを抜き、画面左側の卓の同一区画150×120ピクセルを比べると差は0。専属の結果まで到達。[設定](reduced-motion-fixed.png)・[固定画角の券](broadcast-5-fixed.png)・[帰還](ending-fixed.png)・[入力ログ](player-fixed.log)|
