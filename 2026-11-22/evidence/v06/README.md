# v0.6　舞台中継と立会勝負の実機記録

[通常操作の抜粋映像](stage-and-showdown.mp4)では、街頭テレビ、舞台前の演奏、演者の退場、立会の予告と打撃、新規の勝敗、通常の射撃追跡を確認できる。Windowsプレイヤーのクライアント画面と対象プロセスの48 kHzステレオ音声を収録し、場面の境目でカットした。

## 公演と中断

- 通常夜に表通り x5.54、z−9.97 の街頭テレビ前へ歩きCで拡大。初版では中央の白服の兄貴分と緑の照り返しが歌手を遮った。次版では歌手が左のマイク前、ピアニストが右の鍵盤前に見え、明るい背景から顔が分離する。手と腕は放送中に動く。Cで街路視点に戻り、もう一度CからTabで指揮画面へ切り替えた。[初版](singer-win.png)・[修正後の中継](singer-stage.png)・[Tabで指揮へ](tv-map-stage.png)
- 演者と楽器の位置は、戦闘が始まらない最終夜にも舞台前へ歩いて確認。歌手はマイク前で身振りをし、奏者はベンチに座って両腕を鍵盤へ伸ばす。実プレイの録音には演奏が入る。初版テレビ視聴中の3秒は音声平均−26.7 dB、ピーク−12.2 dB。個々の指の打鍵と音高の1音単位の一致は検証していない。[客席側から見た舞台](piano-music.png)・[この移動のログ](player-music.log)
- 通常夜にホールの手前で指揮地図を舞台へ向け、TPSで敷居を越えて再度指揮に切り替えた。抗争開始後、歌手がマイクを離れ、奏者が椅子から立ち、別々に幕裏へ移動。最後にマイクと空いた鍵盤だけが残る。[同一動画の等倍3コマ](stage-exit-sequence.png)

## 立会人、色灯、決着

出撃直後にTab→2→Vで千代を指名し、もう一度Vで取消。3→Vで源、2→Vで千代に交代した。千代から到着報告があり、x−4.9、z1.36の階段でEを押すと、真壁と兄貴分が舞台に上がる。橙の輪が出た最初の一撃はWで外れ、直後の白灯でFを入力。その後の予告では輪内に残って被弾し、次の隙に反撃した。[立会の指示](witness-stage.png)・[修正版の予告灯](amber-stage.png)・[入力と状態遷移](player-stage.log)

- **舞台での勝利**は有効なFのたび兄貴分の体力が100→66→32→0となり、「舞台でついた決着」に移る。[勝利](result-stage.png)
- **舞台での敗北**は予告中にその場に留まり、5回被弾して「舞台を降りた夜」に移る。[敗北](result-lose.png)・[ログ](player-lose.log)
- **従来の追跡**は立会を開始せずにプレイ。通常の射撃で護衛を倒し、兄貴分を追って勝利。専用の舞台勝負に入らず最後まで成立した。[通常の結果](ending-shoot.png)・[ログ](player-shoot.log)

## 輪の表示修正版の床の輪

輪の表示修正版の通常設定では、構え中の灰色照明から橙の予告と輪へ、攻撃受付中は白い輪と「隙　近づいて F」へ変化した。同じ手番のゲーム時刻29.98秒に受付開始、30.85秒にFが届いて体力66→32。白い輪が消え、表示が「打撃が届いた　次の合図を待つ」に変わる。その後のFで体力0となり、34.55秒で舞台勝利。受付前後の実画面は同じ立ち位置・画角で比較できる。[橙の予告](amber-colour.png)・[白の受付](opening-1-colour.png)・[入力直後](answered-1-colour.png)・[通常設定の入力ログ](player-colour.log)

同じ輪の表示修正版で「揺れ・点滅を抑える」が入った状態からも舞台勝利まで進めた。通常の照明切替は、幕間で切へ戻した後、別の出撃で収録した。[設定を切にした画面](motion-normal-colour.png)・[軽減設定での勝利ログ](player-lamps.log)

|輪の表示修正版・1920×1080|フレーム数|中央値 ms|95%点 ms|

輪の表示修正版のAssembly-CSharp SHA-256は `7e7fe3424b73ba43c1d3862f66fc03ec655d4af4fbd464368a4661db633bf359`。ZIPは86,918,545バイト、SHA-256は `537e973a4928e7ac705e39dc0be595d8eec7c57d3407a0c883498b86e5a44c1a`。実機テストに使用した独立WindowsコピーとZIP内全135ファイルのSHA-256が一致した。この段階では被弾後に二人の胴体が重なる手番があった。通常追跡、舞台敗北、演者退場は上表の初版またはテレビ構図修正版で確認した。


## 配布版での被弾後の間隔

舞台に上がったあと、移動キーを押さず、カメラだけを左へ向けて黒服の真壁と白服の兄貴分を斜めから撮影した。2回目の橙の予告は輪の内側で受けた。ゲーム時刻17.79秒に真壁が被弾し、体力76→52。白い受付輪が出たとき、二人の胸と腰の間に舞台の床が見える。18.37秒、同じ立ち位置でFが届き、兄貴分の体力は66→32、白い輪が消えた。3回とも真壁のログ座標は(-5.86, 0.51, 3.08)。最後のFで体力0、22.34秒に舞台勝利。1080pで1,294フレーム、中央値16.67 ms、95%点16.69 ms。[予告](amber-spacing.png)・[被弾直後の白輪](opening-1-spacing.png)・[同じ手番に反撃](answered-1-spacing.png)・[修正版の入力ログ](player-spacing.log)

配布版のゲームアセンブリは `d57dca96baffb41be6f1ee179d7aec3b7a7a03039dcfdc74ef3675c44be9be37`。ZIPは86,918,668バイト、SHA-256は `3e9e02da19a913475ee99316ce9ba1f7718711ea78403d0c2d1936fb2ac5d1ff`。独立テストコピーとZIP内の全135ファイルがSHA-256で一致し、余分なファイルもなかった。抜粋映像の舞台勝利はこの配布版に差し替えた。
