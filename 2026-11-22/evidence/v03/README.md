# v0.3　宵待町の表通り

[配布版の抜粋映像](release-highlights.mp4)で、三店のうち二店の店頭、ロータスの仕事場、二両編成の高架電車、中継鏡の二つの顔を確認できる。全てWindowsプレイヤーを通常操作して録画した。抜粋は実時間の映像を場面の境目でカットし、ゲーム音声を残した。

## 配布版で確認した画面

2026年11月22日04:44に出力したv0.3.0を独立したフォルダから起動した。配布ZIPと実行フォルダの全135ファイルは一致。ZIPのSHA-256は `a12e157df6763e815b886727fa32e43b7d48aabe23a3c38204f081900890b52a`、ゲームアセンブリのSHA-256は `d1c572aa53795e299945d75e306dbae5ddadce0e97e4612a402c778a34eed7c6`。

- [針音堂のジャケット](needle-sleeve-final03.png)と[ロータスのソーダ掲示](lotus-print-final03.png)は、営業中に引戸が退避する側と反対側にあり、通りから読める。調整前は[開いた引戸が掲示に重なった](needle-front-request.png)。
- [ロータスの店内](cafe-work-final03.png)では、緑のタイル、棚のカップ、透明なサイフォンと店主の澄子が同時に映る。組員は表通りに残る。食券を受け取ってから正面へ戻った。
- 店舗の間から見上げ、[高架の二両編成](elevated-train-final.png)が窓明かりと共に通過するところを撮影した。表通りでは逆光の人物が暗く、顔の細部は読み取りにくい。
- 金星に入って和解まで進めた。[一階の鏡](mirror-dial-final.png)では梶の顔、筐体のダイヤル、真壁の手を確認できる。[二階の鏡](mirror-eyes-final.png)には弟の目元、髪と上がった手が映る。目の周囲は深い影に入る。確認した場面にピンク色の代替マテリアルやHUDのはみ出しはなく、ログにもシェーダエラーや例外は出ていない。[連続映像](final03.mp4)・[ログ](player-final03.log)

## フレーム時間

RTX 4070 Ti、60 fps制限、ウィンドウ表示。計測はイベントログの実フレーム時間を使用。タイトル、結果、各フェーズの最初の0.2秒を含まない。各経路1回の値。映像は24 fps、48 kHzステレオ。

| 実行 | 解像度 | サンプル数 | 中央値 | 95パーセンタイル |
| --- | ---: | ---: | ---: | ---: |
| 配布版・カフェと高架を撮影して和解 | 1920×1080 | 11,185 | 16.67 ms | 16.68 ms |
| 04:34版・常連リクエスト、外出・帰店、和解 | 1920×1080 | 13,466 | 16.67 ms | 16.68 ms |
| 04:34版・通常放送、追跡 | 1280×720 | 5,059 | 16.67 ms | 16.67 ms |

04:34版の1080p計測時には画像生成用GPUは空いていた。配布版の確認中は同じGPUで画像生成も動作していた。シーン別のGPU時間や、他の機種での再現性は未計測。
