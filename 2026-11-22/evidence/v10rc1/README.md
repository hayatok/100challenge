# 金星の一夜 1.0.0-rc.1 Windows 通しプレイ

[四つの決着、店主との会話、車内広告の実機映像](v10rc1-scenes.mp4)。ロータスで話しかけ、Zで顔に寄って通常視点へ戻る部分は、操作を飛ばさず実時間で収録した。澄子の寄りでは、次のE操作を示す黒帯が顎の近くに残る。また、この版は発話中にCで商品へ寄ると、下端にZの会話案内が残る場合がある。商品拡大を閉じる操作はC。後者はコードレビューで確認した。

## 店主との会話と翌朝の仕事

共同の朝は澄子から7.59秒にリクエストを受け、33.14秒に送像所で放送した。ロータスの売り場では夜勤帰りの鳥井が別の台詞を話し、Zを押しても店主の顔に切り替わらなかった。左通路（x−18.79、z−18.68）まで歩き、澄子にEで話しかけてZを押すと、澄子本人の顔と台詞が出た。Zで通常視点に戻り、依頼を続けた。村瀬のVU計をCで見ると、針と「放送中」「演奏中　堺の朝」の印刷が同時に全体まで見える。[左通路から話す澄子](owner-dawnjoint.png)・[放送中の札と針](live-card-dawnjoint.png)・[共同の朝の入力ログ](player-dawnjoint.log)

専属の朝は金星の座長から3.33秒に一番券を受け取り、真壁の左手に券を持ったまま針音堂へ歩いた。13.05秒に渡した後、兵藤の顔へZで寄った。Cの画面には「前売り受付」「一番券到着」の文字の四辺と、皿に置いた小さな券が収まった。[札と一番券](advance-ticket-dawnexclusive.png)・[専属の朝の入力ログ](player-dawnexclusive.log)

## 高架線と街路灯

通しプレイの帳面を保持し、夜の街路と列車だけは別の空の保存先で撮った。西駅から2両目へ歩いて乗車し、車内を移動して左右の妻壁を見上げると、それぞれ異なる広告が見えた。[車内の妻壁広告](other-ads-nighttrain.png)・[乗車ログ](player-nighttrain.log)

西の欄干・橋面の灯りと東の修理店の照明を、夜と共同の朝で見比べた。西の橋面に映る暖色の光と東の軒下の光は朝に消え、欄干と店頭の機器は外光で見えた。[西の夜](bridge-nighttrain.png)・[西の朝](bridge-dawnjoint.png)・[東の夜](repair-nighttrain.png)・[東の朝](repair-dawnjoint.png)
