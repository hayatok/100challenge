# Reality Sandbox

## Goal

片手の手のひらと人差し指の動きで、3D 空間の物体を押し、弾ける Sandbox を開発する。Desktop Chrome を主対象とし、iPhone の前面・背面カメラからも操作できる構成にする。

## Scope

- Vite + TypeScript の静的アプリ。Three.js、Rapier、MediaPipe Hand Landmarker を責務別に配置する。
- モデルと WASM は `public/` に固定し、カメラ映像とランドマークは端末内で処理する。
- 20 個のボール、床、カメラプレビュー、状態表示、実測 debug 指標、Mouse Mode を用意する。
- ボール・箱・ドミノの追加、全消去、20 個への復元、100 個の負荷プリセットを扱う。上限は 100 個。
- 手のひらと伸ばした人差し指の簡易 collider、速度を使うフリック、画面上の交差に基づく接触補助、前面・背面カメラ切り替えを扱う。
- Grab、指全体の骨格、特殊ジェスチャー、ゲームモードは現在の対象外。

## Design

暗い実験空間と明るい物体で、手と衝突点をすぐ見分けられるようにする。操作部にはルート `docs/DESIGN.md` の意味色とフォーカス規則を使う。カメラ像は小さなプレビューに留め、前面のみ鏡像にする。水色の手と黄色い指先を照準として見せ、触れられる物体に白い輪を出す。スマートフォン幅では物体編集パネルを畳み、遊べる空間を確保する。

## Verification

`npm run check` で相互作用テスト・型・lint・build を確認し、実ブラウザで開始、許可拒否、Mouse Mode、カメラ追跡、ボールへの接触、フリック、画面幅を確認する。実カメラと iPhone で未確認の項目は明示する。
