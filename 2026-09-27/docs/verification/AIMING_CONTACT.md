# 照準・接触の検証（2026-09-27）

## 原因と変更

- 以前は仮想の手の collider が `z=0` に固定され、奥行きの異なる物体と画面上で重なっても衝突しない場合があった。
- 描画位置の手・人差し指と物体を同じ画面座標で比較する。狙える物体には白い輪を出す。手がその物体を横切ったら、Rapier の固定 step で速度上限付きの impulse を与える。従来の kinematic collider も維持する。
- iPhone 幅では物体編集パネルがボールを覆っていたため、プレイ中は畳む。`EDIT` で展開し、`CLOSE` で戻す。
- 操作方法を開始画面とプレイ画面に日本語で表示する。

## 確認

- `npm run check`: 操作テスト 8 件、lint、型検査、Vite build が成功。追加テストは画面上の線分が物体を横切る場合、静止時は照準のみ、接触時の物理 impulse を確認。
- ローカル Chrome の Mouse Mode: デスクトップと 375×812 の両方で、物体に白い輪が付き、横への操作で `PALM HIT!` が表示されてボールが動く。
- 375×812: 開始画面の説明と 3 ボタンを表示。プレイ中はパネルがボールを覆わず、`EDIT` で全操作を開ける。
- 1280×720: 開始画面の説明、プライバシー表示、3 ボタンが収まる。
- 768×900、1024×900、1440×900: 開始ボタンとプライバシー表示が収まり、横スクロールなし。

## 未確認

- 実機 iPhone の前面・背面カメラで手を動かしたときの位置合わせ、追跡遅延、指先判定と操作感は未確認。Mouse Mode の確認だけでこれらを実証したとは扱わない。
