# Catch mode 実装計画

## Goal / Done when

Issue #127。カメラへ手のひらを向け、画面奥から手前へ飛んでくる12球を受け止めて得点を競べる。Mouse Mode でも同じルールを試せる。Sandbox へ戻り、再挑戦できる。

## Core loop

光る奥行きレーンを見る → 手のひらをカメラに向けたまま左右へ移動する → 迫る球を受け止める → 得点と短いフィードバックを見る。最初の球は中央、以降は左右に広がる。手が消えたら進行を一時停止する。

## Spatial hand

MediaPipe の手中心を画面から3Dへ投影し、world landmarks の相対3D形状から手の向きとシルエットを描く。絶対距離は得られないため、画面上の手の幅を初回認識時の幅と比較して相対奥行きを推定する。再中心合わせを用意し、平滑化と範囲制限を施す。ゲーム判定には手のひら中心と大まかな向きのみを使い、指先位置は使用しない。

## Incoming balls

球は重力を受けず、画面奥の z=-2.2 から手前へ一定速度で飛ぶ。光るレーンの輪が進路を示す。手のひら中心と球が3D空間で近づいたときにキャッチし、カメラを向く手のひらには広めの判定を与える。球が手前を通過するか、衝突で進路が変わって一定時間が過ぎるとミスになる。単眼カメラの奥行き推定は相対値なので、判定は多少広く取る。

## Constraints / Verification

既存の静的構成とカメラ処理の端末内完結を保つ。ゲームの新規依存は追加しない。`npm run check`、実ブラウザの Mouse Mode、レスポンシブ画面、失敗・終了・再開を確認する。実機カメラの奥行きと手の向き、iPhone Safari は別途実測が必要。
