# こわさず、壊す。

建物の接合部を切り、崩れた床や梁を道に変える2D物理パズル。大切な陶器を、緑の梱包箱へ無傷で届けます。石膏・木・真鍮・陶器を思わせる、小さな建築模型のアトリエです。

## 遊び方

- 真鍮の番号をクリック / タップ、または **1〜9** で接合点を切断。
- **Space / 一時停止** で考える時間をつくれます。停止中も接合点を切れるので、同時に外したい時にも使えます。
- **R / やり直す** で即再挑戦。**H / ヒント** は2段階、必要な時だけ。
- すべての陶器が箱の内側に入り、落ち着くと成功。**N / 次の模型へ** で進みます。
- 面選択から全8面を自由に選べます。成功した面と最少切断数を端末内に保存します。
- 切断数の「目安」は任意の目標。上限・時間制限はありません。音のON/OFF、Tabのフォーカス操作に対応。

硬い部材への強い衝突で陶器が割れます。破損地点、軌跡、原因を見て次の一手を考えてください。箱の緑の内張りは衝撃を吸収します。物理を利用した別解も認めます。

## 全8面

| 面 | 模型 | 判断 |
| --- | --- | --- |
| 01 | 片方だけ、ほどく | 片側の支点を残して坂をつくる |
| 02 | 残す側を、見きわめる | 箱の方向から残す支点を選ぶ |
| 03 | 水平のまま、降ろす | 台ごと落とす。片側から降ろす別解も可能 |
| 04 | 壁だった、橋 | 立った梁を倒して橋へ変える |
| 05 | ふたつの、小さな命 | 両側から2つの陶器を集める |
| 06 | 触れない、勇気 | 不要な屋根の切断を避ける |
| 07 | 帰り道を、先に | 下流で折り返す坂を準備する |
| 08 | こわさず、壊す。 | 2つの陶器を、ひとつの橋で搬出する |

## 開発・実行

Godot **4.7.2** / 型付きGDScript / Compatibility / WebGL 2.0 / シングルスレッド。実行時のnpm依存はありません。Godot実剛体・ピン接合を使用し、120Hzでシミュレーションします。端末間の完全な決定性は保証しません。

```bash
cd 2026-09-08
npm ci
npm run setup       # Linux実行ファイル、公式Webテンプレート
npm run dev         # Godotエディター
npm run play        # ネイティブ実行
npm run check       # import/型検査、物理テスト、UIテスト、Web build
npm run preview     # http://127.0.0.1:4208/
```

macOSでは `/Applications/Godot.app` を使用。`GODOT_BIN` でも指定できます。モバイル幅では操作パネルを模型の下に配置し、短い画面ではページをスクロールできます。スクリーンリーダーへのゲーム盤面の読み上げは未対応です。背景タブでの物理進行は対象外です。

## 構成

- `game/core/world.gd`: 接合、剛体の生成、成功・失敗、模型描画
- `game/core/ceramic.gd`: 接触法線方向の相対速度による破損判定
- `game/core/levels.gd`: 手作り面・任意ヒント・検証用解法
- `game/main.gd`: 操作、レスポンシブUI、画面遷移
- `game/core/progress.gd`: 型・版・範囲を検証するローカル保存
- `game/tests/`: 実エンジンの解法・失敗・安定性・UIテスト

企画と検証は [PLAN.md](docs/PLAN.md)、[VERIFICATION.md](docs/VERIFICATION.md) を参照。日本語フォントは既存アプリと同じNoto Sans CJK JP、ライセンスは `game/assets/fonts/LICENSE.txt`。効果音と模型描画はコードで制作しています。
