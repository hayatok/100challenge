# こわさず、壊す。

建物の接合部を切り、崩れた床や梁を道に変える2D物理パズル。大切な陶器を、緑の梱包箱へ無傷で届けます。石膏・木・真鍮・陶器を思わせる、小さな建築模型のアトリエです。

## 遊び方

- 真鍮の番号をクリック / タップ、または **1〜9（10番は0）** で接合点を切断。
- **Space / 一時停止** で考える時間をつくれます。停止中も接合点を切れるので、同時に外したい時にも使えます。
- **R / やり直す** で即再挑戦。**H / ヒント** は2段階、必要な時だけ。
- すべての陶器が箱の内側に入り、落ち着くと成功。**N / 次の模型へ** で進みます。
- 面選択から全16面を自由に選べます。成功した面と最少切断数を端末内に保存します。
- 切断数の上限・時間制限はありません。音のON/OFF、Tabのフォーカス操作に対応。
- **搬出台帳**で、救出した作品と最少切断数を見返せます。作品を選んで再挑戦でき、最終面からも台帳へ進めます。
- 演出の設定スイッチはありません。Webは起動時のOSのモーション低減設定を内部で反映します。

硬い部材への強い衝突で陶器が割れます。破損地点、軌跡、原因を見て次の一手を考えてください。箱の緑の内張りは衝撃を吸収します。物理を利用した別解も認めます。

## 全16面

| 面 | 模型 | 判断 |
| --- | --- | --- |
| 01 | 片方だけ、ほどく | 片側の支点を残して坂をつくる |
| 02 | 残す側を、見きわめる | 箱の方向から残す支点を選ぶ |
| 03 | 水平のまま、降ろす | 台ごと落とす。片側から降ろす別解も可能 |
| 04 | 触れない、勇気 | 不要な屋根の切断を避ける |
| 05 | 壁だった、橋 | 立った梁を倒して橋へ変える |
| 06 | ふたつの、小さな命 | 両側から2つの陶器を集める |
| 07 | 帰り道を、先に | 下流で折り返す坂を準備する |
| 08 | 橋を渡る、二作品 | 2つの陶器をひとつの橋で運ぶ |
| 09 | 長い、帰り道 | 橋と折り返しを組み合わせる |
| 10 | まだ、切らない | 水平な床で受け止めてから傾ける |
| 11 | 床も、荷物になる | 受け止めた台を箱へ降ろす |
| 12 | 合流して、折り返す | 高さの異なる陶器を合流させて運ぶ |
| 13 | 二枚の床の、役割 | 台を運ぶ床と坂になる床を区別する |
| 14 | 最後のひとつを、待つ | 全員が受け皿にそろってから降ろす |
| 15 | 重ねた床を、ほどく | 下段の準備、合流、受け渡しを組み合わせる |
| 16 | こわさず、壊す。 | 5枚の床と二つの出発点から搬出手順を作る |

前半は支点と経路、後半は待機と複数段階の組合せ。タイミングを競う設計ではなく、途中の水平な床で止まって考えられます。旧8面の記録は、対応する模型の番号へ自動移行します。

## 模型の表情

採光のアトリエ、煉瓦の中庭、青い収蔵庫、夕暮れの展示室を巡ります。陶器の釉薬と模様、木材の木口・真鍮の留め具、石膏の縁、箱の緩衝材を描き分けています。背景の窓・壁面は舞台美術で、衝突するのは前景の梁・支柱・箱です。

切断では真鍮の留め具と火花が弾け、梁の着地では粉塵と低い打音、破損では大きな陶片が広がります。救出が確定すると箱の蓋が閉まり、搬出印と紙片、上昇する和音で締めくくります。演出は物理に介入せず、再挑戦も待たせません。WebのRetina表示でも、44pxの接合点と文字を表示上のピクセルで配置します。

## 開発・実行

Godot **4.7.2** / 型付きGDScript / Compatibility / WebGL 2.0 / シングルスレッド。実行時のnpm依存はありません。Godot実剛体・ピン接合を使用し、120Hzでシミュレーションします。端末間の完全な決定性は保証しません。

```bash
cd 2026-09-08
npm ci
npm run setup       # Linux実行ファイル、公式Webテンプレート
npm run dev         # Godotエディター
npm run play        # ネイティブ実行
npm run check       # import/型検査、物理テスト、UIテスト、Web build
npm run preview     # http://127.0.0.1:4208/
```

macOSでは `/Applications/Godot.app` を使用。`GODOT_BIN` でも指定できます。モバイル幅では操作パネルを模型の下に配置し、短い画面ではゲーム内を指・ドラッグ・ホイールでスクロールできます。スクリーンリーダーへのゲーム盤面の読み上げは未対応です。背景タブでの物理進行は対象外です。

## 構成

- `game/core/art.gd`: 空間と作品の共通描画
- `game/core/visual_effects.gd`: 物理に干渉しない切断・破損・梱包演出
- `game/core/ledger.gd`: 搬出台帳、面選択
- `game/core/world.gd`: 接合、剛体の生成、成功・失敗、模型描画
- `game/core/ceramic.gd`: 接触法線方向の相対速度による破損判定
- `game/core/levels.gd`: 手作り面・任意ヒント・検証用解法
- `game/main.gd`: 操作、レスポンシブUI、画面遷移
- `game/core/progress.gd`: 型・版・範囲を検証するローカル保存
- `game/tests/`: 実エンジンの解法・失敗・安定性・UIテスト
