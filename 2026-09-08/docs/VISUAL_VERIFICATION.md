# ビジュアル改善の検証（2026-09-08 / Issue #100）

## 今回の変更と判断

- 物理・解法を維持し、採光のアトリエ／煉瓦の中庭／青い収蔵庫／夕暮れの展示室を追加。舞台美術は低コントラスト、実際に衝突する木材と石膏・緩衝箱は前景に置く。空間の色はart.gdの役割別パレットに集約し、ユーザー承認済みの建築模型の方針を継続。
- 釉薬と模様の異なる作品を各面に割り当てる。丸い胴体・首の輪郭と当たり判定は維持。双子の白磁は同じ釉薬、最終面は異なる二作品。台帳の絵も同じ描画関数を使う。
- 切断の小さな欠片、破損の陶片、梱包箱の蓋と搬出印を追加。演出用Node2Dだけが終了後も動き、剛体の位置・速度・衝突層・勝敗条件を変更しない。即リトライで残像・欠片を破棄。
- 梱包は0.65秒で閉じる。台帳の演出低減を有効にすると切断の粒子を省き、陶片と箱の最終状態をすぐ表示。Webは起動時にprefers-reduced-motionを読む。手動設定は起動中のみ維持。常時点滅、画面揺れ、操作を待たせるトランジションは追加しない。
- 台帳は既存の成功記録を読み、8面の搬出状況・最少切断数・作品を表示。未搬出の面も選べる。最終面の「全作品を見返す」を台帳へ接続。開いている間は物理を停止し、閉じると元の停止状態に戻す。

「面を進む楽しみが強まる」「守る作品に愛着が生まれる」は設計仮説。第三者の初見プレイによる評価は未実施。

## 目視で発見して修正したこと

- 通常の内蔵ブラウザはCSS 1280×720に対しcanvas 2560×1440、DPR=2だった。旧版のdisabled stretchは物理ピクセルでUIを配置し、ボタンと文字が半分の表示サイズになっていた。Window.content_scale_factorをDPRに合わせ、表示上の幅でレイアウトする。高解像度のcanvasは維持。倍率変更は0.5秒間隔で検出。
- フォーカス時に台帳ボタンの文字が背景と同化した。Buttonのフォーカス文字色を明示し、台帳の往復でラベルが残ることを確認。回帰検査を追加。
- 375pxで台帳の説明が不自然に折り返され、未搬出の文言がタイル端で欠けた。説明を2行、記録文を短くし、タイル内の文字幅も検査。04/06の説明文と失敗理由も意味を保って短い文へ調整。句点だけの行や文字欠けを防ぐため、長い日本語は実画面で行末まで確認する。
- 破損後の未切断ピンに既定の四角いdisabled背景が出た。真鍮の丸い無効状態を明示。

公式参照: [Godot 4.7 Windowのcontent_scale_factor](https://docs.godotengine.org/en/4.7/classes/class_window.html)、[Multiple resolutions](https://docs.godotengine.org/en/stable/tutorials/rendering/multiple_resolutions.html)。今回のDPRの値と画面結果は実測。
