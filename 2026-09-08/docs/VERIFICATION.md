# 検証・判断記録

## 確認済みの実装判断

- 2026-09-08、Godot 4.7.2.stable.official.ed1daf0bf（macOS）を確認。
- 120HzのGodot 2D剛体、CCD shape、質量比1:3、反発ほぼ0、24 solver iterations。床はピン接合を外して動き、描画用アニメーションで位置を誘導しない。
- ピン角度制限の試作は意図した停止を示さなかった。可視の石膏の受け柱に床を着地させる構成へ変更。設定だけで安定したと扱わず、実際の接触で確認。
- 陶器の破損は接触法線方向の相対速度390px/s超。接触法線は実測でワールド方向を返すことを確認し、陶器の回転を二重適用しない。箱の緩衝材との接触は破損対象外。
- 成功は全陶器が箱の内側に入り、速度55px/s未満の状態が0.65秒継続した時。箱に一瞬触れただけでは成功にしない。
- 初期案の「橋を先に」は唯一の解法ではなかった。逆順と同時切断も成功したため別解として保持。後半の07は折り返しの坂と箱の庇を設け、準備の遅れが破損につながる面へ調整した。
- 03では片側だけの切断でも救出可能。目安2を達成上限にせず、1切断の工夫を認める。
- 狭い模型で44pxの接合ボタンが重なる問題を発見。引出線を付けて間隔48pxを確保し、全8面・5幅と短い画面のUI回帰検査へ追加。その後の目視で陶器の遮蔽も発見し、引出線を上へ逃がす処理と「陶器を隠さない」回帰検査を追加した。

## 実エンジンの自動検証

- 物理106チェック成功。全8面の意図した解法を各10回、初期X位置±1pxと切断時刻0〜0.2秒差で検証。
- 全切断は03以外の7面で失敗。01の誤った支点切断、07の下流準備の遅れ（②を0.5秒、③を6.5秒）は実接触で破損。
- 07の同時切断、03の片側切断は別解として成功。
- 未切断状態を全8面20秒ずつ観察し、破損も自動成功もない。
- 不正な接合番号、重複切断、終了後切断、破損/不正な保存データを検証。
- UI930チェック成功。375/600/768/1024/1440px、1440×720px × 全8面の枠内配置、接合点44px以上、接合ボタンの非重複、初期陶器をボタンが隠さないこと。
- 実UIの停止中切断→再開→成功→次面、失敗で停止、再試行で復元、二段階ヒントを検証。成功時の面選択印の即時更新、フォーカスが再試行ボタンにあってもSpaceで一時停止できることも検証。UIテストはユーザーの保存データに書き込まない。

## 実画面の確認

- Godotネイティブ画面（1280×800設定、Retinaの取得画像は640×432）で模型、番号キー切断、床の傾斜、箱への救出、成功表示を目視。
- Web 1440×900で初期状態、破損位置・理由、R再試行、Space停止→切断→再開、橋の面で④→②の救出成功を確認。
- Web 1024×768、768×1024、375×850を目視。768pxは模型を大きく保つため縦配置へ変更。375pxでは初面の救出→次面、および03の停止→2点切断→再開→台ごと救出を操作。
- モバイルの面選択は高さ約46px/行。小さな模型の接合点は引出線で上へ逃がして陶器を見せる。
- 再読み込み後の成功印と最少切断数を確認。初回の未記録表示も確認。
- 読み込み進捗表示を実際のショーケースからの起動で確認。開発サーバーの `/qa-loading/` は同じローダーを表示し続ける目視用fixture。`/qa-load-error/` は相対スクリプトを404にし、エラー案内と再読込ボタンを検証。
- ショーケースの11件表示、登録カードから `/2026-09-08/` への起動を確認。07の折り返しもWebで③→②の救出を操作確認。
- 375×667の短い画面で、Godot標準ScrollContainerによるドラッグ→画面外の面選択へ移動→スクロール後の接合点切断→救出を実際に確認。Webのtouchイベントがブラウザ標準panを止めるため、HTMLページのスクロールに依存しない構成へ修正した。マウスからのタッチエミュレーションを有効にし、標準のドラッグスクロールを使用。
- 1440×720で操作説明と面選択が重ならないよう盤面の高さに余白を確保。実シーンの375×667でスクロール範囲、UIの移動、再試行時の先頭復帰も回帰検査。
- ショーケース経由の通常起動と短い画面でのプレイで、ブラウザのwarn/errorログは0件。

## 限界

自動テストと開発者によるプレイは、第三者の初見プレイテストの代替ではない。判断を学べる構成を実装し解法を検証したが、初見の楽しさ・難易度の評価は未実施。スマートフォン実機のSafari/Android、端末間の完全な物理決定性、スクリーンリーダーによる盤面読み上げは未検証/未対応。Webの背景タブ進行は対象外。

公式参照: [PinJoint2D](https://docs.godotengine.org/en/stable/classes/class_pinjoint2d.html)、[PhysicsDirectBodyState2D](https://docs.godotengine.org/en/stable/classes/class_physicsdirectbodystate2d.html)。APIの一般説明と、この版での実測結果は区別した。
