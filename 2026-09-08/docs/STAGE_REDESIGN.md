# 「こわさず、壊す。」16面の再設計案

**設計レビュー用 / 未実装 / 2026-09-08 / Issue #104**

現16面の延長ではなく、面構成を置き換える提案。今回の成果物はこの設計書と[図解版](stage-redesign.html)まで。ユーザーが設計を確認する前に、ゲームコード、ステージデータ、物理設定、公開版は変更しない。

## タスクと根拠

- **Goal:** 「下り坂を作って流す」だけで解ける構成から、支え・荷重・空間・部材の用途を先読みする16面へ変える。
- **Context:** `core/levels.gd`、現行画面、[前回の計画](DIFFICULTY_PLAN.md)、[前回の検証](DIFFICULTY_VERIFICATION.md)。基準は main `4fc499f`。ユーザーから難易度と面の重複について再指摘があった。
- **Constraints:** 操作の核は接合部の切断。模型の見た目と簡潔な画面を維持。切断回数制限、狭い入力タイミング、見えない正解順序で難しくしない。ギミックの追加は提案段階で、実装済みと混同しない。
- **Done when:** 16面それぞれの配置、判断、誤解法、手がかり、基準手順、同型性を除く条件がレビュー可能になり、採用前に必要な検証が明記されていること。実際の難易度・物理成立・面白さの確認は、設計承認後の別工程。

### 前回は何を見逃したか

現在の1・2面は左右反転に近く、5・8・9面は橋の形成、10面以降の多くは受け皿・合流・追加の切断で長くした構成になっている。物体や切断が増えても「経路を用意 → 流す → 受ける」の判断は変わりにくい。冒頭の説明が解き方を教えている面もある。

前回の成功経路と早切り・逆順の検証は、特定の操作で成功・失敗することを確認したもの。違う面で同じ考え方が通用するか、初見で考える必要があるかを確認する代わりにはならなかった。今回の難易度評価はすべて**設計仮説**であり、既存のテスト合格数を根拠にしない。

## 共通の約束

1. **初級の純粋な操作練習は1面のみ。** 2面からもっともらしい誤解法を置く。後半は、目の前の救出が次の救出を壊す状況まで扱う。
2. **ひっかけの原因は最初から見える。** 梁の長さ、支点、支えている物、つながった綱、重量の違いを隠さない。「実は固定されていない」など外見と異なるルールは使わない。
3. **時間ではなく状態を読む。** 陶器が待機棚に収まった、梁が受け座に載った、箱がドックに止まった、といった静止状態で次の判断ができる構造にする。
4. **正解手順を照合しない。** 下記は基準解法。安全性と物理条件を満たす別解は認める。面の中心課題を無視した一手で救出できる場合は、隠れた失敗条件を加えず配置を作り直す。
5. **説明は目標と新しい物体の性質まで。** 下記の見出しはレビュー用の説明名。実際の面名や常時表示文で解法を明かさない。ヒントは任意で、観察箇所 → 関係性 → 手順の順に出す案とする。
6. **派手な演出で原因を隠さない。** 将来の演出強化でも、重要な接合部と陶器の輪郭は読めるようにする。演出切替スイッチは設けない。今回、演出自体は実装しない。

### 見取り図の読み方

図解版は上下・左右・接続関係を示す模式図であり、寸法、実際の回転軌道、衝突形状は確定していない。破線は経路や部材の移動先の候補。切断操作の全箇所は、下記の文章を基準にブロックアウトで配置する。

- **V / A / B:** 救う陶器。複数ある面はすべて同じ梱包箱へ入れる。
- **C:** 内側に緩衝材のある箱。7面以降は動く箱も使う。箱に入っただけで消去・無重力化せず、収容物の重さは残る。
- **W:** 救出不要の角形の石の重り。陶器と外形・材質・重量表示で区別。
- **P / Q:** 木の梁や受け座。固定軸は中実の丸、切断できる留め具は開いた真鍮の輪。見た目を使い分ける。
- **待機棚:** 側壁と浅いくぼみがある安定した置き場。箱と見分けられ、途中で陶器を置いてもクリアにはならない。
- **綱・滑車:** 張力の経路を常に見せる。重りは陶器より重いことを刻印でも表す。正確な重量比を暗記させない。

## 各面の設計

### 01 — 残す支点

- **配置:** 陶器Vが両端で留められた短い床Pの中央に立つ。箱Cは右端の少し下。床の真下には安全に着地できる棚がない。
- **固有の判断:** 「どこを切れば落ちるか」から「何を残せば右へ運べるか」へ視点を移す。
- **誘う誤解法 → 失敗:** 両端を切って最短距離で落とす → Vは箱より左へ落下。左端だけ切る → 箱から離れる方へ傾く。
- **基準解法:** 右の留め具を切る → 左の支点を残した床が傾く → VがCへ滑る。次の操作を必要としない、唯一の純粋な導入面。
- **手がかり:** 左右の留め具と、箱の水平位置が同時に見える。失敗時は落下位置と箱のずれが分かる。
- **任意ヒント:** 観察「箱は陶器の真下にある？」／関係「切らなかった側が回転の中心になる」。
- **採用条件:** 一切切らずに成功しない。全切りの自由落下が偶然Cへ入らない。2面目に鏡写しを作らない。

### 02 — 倒れる途中

- **配置:** 左の待機棚にV、右下にC、その間に縦長の梁P。Pは右へ倒すと谷を渡せる長さ。V側へ倒した場合の回転域には、Vの棚の縁が入る。Pを保持する左右の綱と底の軸、Vの出口止めを見せる。
- **固有の判断:** 完成した橋だけではなく、橋になるまでに梁の先端が通る空間を読む。
- **誘う誤解法 → 失敗:** 箱に近い留め具から切る／底の軸まで切る → PがV側へ振れるか倒れ込み、棚上のVを押し落とす。Vを先に出す → 未完成の谷へ落ちる。
- **基準解法:** 底の軸と右へ倒すための支持を残し、反対側の保持綱を切る → Pが右の受け座へ載る → Vの出口止めを切る。
- **手がかり:** 綱の張る方向、梁の傾き、先端とVの近さ。反対側の受け座は見えるが、正解の矢印は常時出さない。
- **任意ヒント:** 観察「梁の先端は倒れる途中でどこを通る？」／関係「終点が安全でも途中が安全とは限らない」。
- **採用条件:** 綱を切る側と倒れる側の関係を、実際の張力・重心で成立させる。Vへ当たる誤解法と安全な回転の間に十分な空間差を取る。Pを自由落下させるだけの別解が中心課題を消すなら配置を棄却。

### 03 — まだ坂にしない

- **配置:** 左上の床にV。その下に、厚い緩衝材を載せた水平受け皿P。CはPの右下。Pを先に傾けるとVの垂直な落下線から受け皿の有効部分が外れ、硬い縁へ当たる。
- **固有の判断:** 同じ床を「受け止める物」と「運ぶ坂」として、違う状態で使う。
- **誘う誤解法 → 失敗:** 下流から全部坂にしておく → Vが緩衝面を外れて割れる。上流もPも同時に解放 → 落下中に受け皿が逃げる。
- **基準解法:** Pを水平に保ったまま上の床を解放 → VがPのくぼみに落ち着く → Pの片側を切ってCへ送る。
- **手がかり:** 上下の位置関係と緩衝材の幅。正しい中間状態ではVが何秒でも待てる。緩衝材の性質は初登場時に一度だけ説明する。
- **任意ヒント:** 観察「最初に陶器が触れるのは、どの面？」／関係「この床は、最初と最後で仕事が違う」。
- **採用条件:** 誤解法は見える幾何学の違いで失敗させ、ほぼ同じ接触速度の微差で分けない。この受け皿の待ち順だけを増やした面は以後作らない。

### 04 — 邪魔な柱の仕事

- **配置:** VからCへの坂を柱Sが塞ぐ。Sの上には、Vの経路まで張り出す重い天井H。脇に倒せる梁Pと、Hを受けるためのくぼんだ受け座がある。
- **固有の判断:** 通路の障害物と建物の支持物が同じ物であると見抜く。
- **誘う誤解法 → 失敗:** 邪魔なSから切る → Hが落ちて通路を潰す。Vを先に出す → Sで止まり、後からSを抜くとHの下敷きになる。
- **基準解法:** Pを受け座へ倒してHの荷重を引き受ける → Sを保持する綱を切り、斜めのガイドで通路外へ退かす → Vを送る。
- **手がかり:** SとHが直接接触していること、Pの長さと受け座の対応。飾りの柱と物理的な柱を同じ外見にしない。
- **任意ヒント:** 観察「柱の上をたどってみよう」／関係「通路を開ける前に、柱の仕事を誰かに渡す」。
- **採用条件:** Pは接触と受け座によって支える。正解順の入力で天井を見えない固定状態へ変えない。Sだけ切っても偶然天井が橋になる構成は避ける。

### 05 — 重さで上へ

- **配置:** Vは低い昇降台。Cへ続く出口は一段高い。台とWを綱でつなぎ、Wは上段の切れる床に載る。W側には「綱を切って捨てる輪」と「床を開く輪」が別に見える。上段には台の受け止め爪とVの出口止め。
- **固有の判断:** 重い物は排除すべき危険物とは限らず、上昇のための動力になる。
- **誘う誤解法 → 失敗:** Wの綱を切って危険を除く → Wだけが落ち、Vは高い出口へ届かない。台の底を先に開く → 下の硬い床へ落ちる。
- **基準解法:** 綱を残してWの支持床を切る → Wが下がり台が上がる → 台が上の受け止め爪に載る → Vの出口を開く。
- **手がかり:** 綱の全経路と滑車、出口との高低差、Wの重量刻印。爪に載ったことは接触位置で見える。
- **任意ヒント:** 観察「箱までの道は今より高い」／関係「落ちる力を、別の場所の上がる力に使える」。
- **採用条件:** Wの落差と重量で実際に上がること。上昇後は操作を急がず待てる。精密な質量当てではなく、大きな重量差で安定させる。

### 06 — 荷物が降りたあと

- **配置:** Vを乗せたシーソー状の橋P、反対側に小さなW。Vが載った時は出口側の受け座へ下がるが、Vが降りるとW側へ戻る。脇に落として挟める木のくさびK。Vには独立した出口止めがある。
- **固有の判断:** Vを荷物だけでなく、橋を押さえている荷重として読む。
- **誘う誤解法 → 失敗:** 橋が出口に届いた時点でVを出す → Vが離れるにつれPが戻り、Vを押し上げて硬い縁へ飛ばす。重りの綱を切るだけ → Pの反対側が落ち、出口の高さを失う。
- **基準解法:** Vを止めたままPを受け座まで下げる → Kの支持を切って受け座とPの間へ挟む → Pが戻れない状態で出口止めを切る。
- **手がかり:** 支点の両側の荷物、くさびが入る隙間。木のくさびは切断可能な接合部ではなく、形で動きを止める部材と分かる。
- **任意ヒント:** 観察「陶器が降りた後、どちらが重い？」／関係「届いている状態と、届き続ける状態は違う」。
- **採用条件:** 戻りの力が見える質量関係に由来すること。くさび挿入はVを静止させて行える。4面との差は、既存の柱の代替ではなく、救出によって新しく発生する荷重変化を防ぐこと。

### 07 — 箱の迎え

- **配置:** Vは左の高い孤立棚。空のCはさらに高い右側にあり、Vの棚横へ下る案内レールに載る。レールには途中の邪魔な止め木と、棚横でCを止める最後の止め木がある。Cが最後の止め木を越えると、Vから離れた低い床まで落ちる。
- **固有の判断:** 目的地を陶器へ近づける。その際、通路の障害物と必要なブレーキを区別して、残す物を選ぶ。
- **誘う誤解法 → 失敗:** レール上の止め木を全部切ってCを流す → Cが棚横を通り過ぎ、低い床へ落ちる。Vを先に出す → まだCがいない硬い床へ落ちる。低い床に止まったCへVを落とす → 落差で破損。
- **基準解法:** 途中の止め木だけを切り、棚横の最後の止め木を残す → Cの上段保持を切る → Cが重力で下って棚横に止まる → Vの出口止めを切って短い落差で収める。
- **手がかり:** Cの車輪、下りレール、二つの止め木とVの高さの関係。Cが低い床へ落ちると戻す手段がないことも配置で読める。
- **任意ヒント:** 観察「箱が陶器の横へ来た後、何が止める？」／関係「道にある物を、すべて取り除けばよいとは限らない」。
- **採用条件:** Cを上昇させる5面の対象入替えにしない。固定した陶器に対し、箱の終着点を止め木の取捨選択で作る。Cは重力で下り、棚横では静止して待てる。通過の一瞬にVを落とす操作を基準解法にしない。

### 08 — 先に救えない一個

- **配置:** AはCのすぐ上の吊りかご。Bは離れた棚。Aのかごから伸びる綱が、Bの通る橋Pを支える。AをCへ落とすためのかご底と、Bの出口止めをそれぞれ切れる。
- **固有の判断:** 先に救いやすい陶器が、まだ救えない陶器のための重りであると読む。
- **誘う誤解法 → 失敗:** 目の前のAを先に梱包する → かごが軽くなりPが下がる → BがCへ渡る経路を失う。
- **基準解法:** Aをかごに残してBをP経由でCへ送る → Bが橋から離れた後、Aのかご底を切ってCへ収める。
- **手がかり:** AからPへの綱を画面内でたどれる。かご単体ではPを支えきれないことを、刻印と物体の大きさで示す。
- **任意ヒント:** 観察「近い陶器のかごは、何につながっている？」／関係「一個を救うと、別の場所の重さも変わる」。
- **採用条件:** Bの着地と後から入るAが衝突しないよう箱内の緩衝区画を分ける。6面の単純延長ではなく、「どちらを先に救うか」の誤選択を置く。救済順をシステムで禁止しない。

### 09 — 一枚を二度使う

- **配置:** 上段左のVから、右のくぼんだ待機棚へ短い谷。Pはその橋にできる。待機棚の下には細い縦の開口と、さらに下の谷、その先にC。開口はVと縦向きのPなら通るが、横向きのPは通らない。
- **固有の判断:** VとPをいったん分離し、同じ梁を二つの高さで使う。
- **誘う誤解法 → 失敗:** Vを乗せたままPを下へ落として一気に運ぶ → Pが開口に引っかかり、Vが硬い縁へ落ちる。最初からPを下へ送る → Vが上段の谷を渡れない。
- **基準解法:** Pを上段の橋にする → Vを待機棚に置く → 空のPを片端から回して縦向きに開口へ通す → 下段の受け座に載ったPを橋にして、待機棚の底を開く。
- **手がかり:** 開口の幅、Pの長さ、空の待機棚、下段の二つの受け座。Vが待機棚へ入った後もPは画面内に残す。
- **任意ヒント:** 観察「下の谷を渡す梁は、どこにある？」／関係「同じ物を同じ向きのまま運ぶ必要はない」。
- **採用条件:** 細い隙間を一瞬で狙う操作にせず、ガイドがPの姿勢を受ける。梁とVを分けない偶然の一括落下で解けるなら不採用。3面の待ち順との違いは、部材の所在と向きの変更が不可欠なこと。

### 10 — 支点の引越し

- **配置:** Vを載せた長いPが左の切断可能な軸で保持される。少し下に、Pの中ほどを受けられる叉形の台Q。Cへの出口は、最初の軸では届かない反対側にある。最初の左軸とQの間には、梁の下に吊ったWがあり、Vの止め具は独立。
- **固有の判断:** 初めは残した方がよい支点も、途中で不要になり、別の支点へ荷重を渡す必要がある。
- **誘う誤解法 → 失敗:** 左の軸を最初に切る → Pごと落下。最初の軸を最後まで残す → PがQを中心に回れず、出口へ届かない。Vを途中で出す → 未接続の端へ滑る。
- **基準解法:** 保持綱を切り、左軸を中心にPをQへ下ろす → QがPを受けた状態で左軸を切る → Wにより今度はQを中心にPが出口へ傾く → Vを出す。
- **手がかり:** 左軸からの円弧では出口に届かない長さ、Qの位置、Wの側。Qは新しい自動接着ジョイントではなく、梁が収まる形の受け座。
- **任意ヒント:** 観察「この梁は、途中でどこに触れられる？」／関係「回転の中心を変えれば、同じ梁の届く場所が変わる」。
- **採用条件:** 支点変更で行ける領域が明確に変わること。4面の支え交換だけでは解けず、二段階の回転を読む必要があること。Qに載る中間状態で静止できる構造を作れなければ再設計する。

### 11 — 重りの残り仕事

- **配置:** Vの前には上げる必要のある橋P、その先にはCの入口を塞ぐ扉G。一個のWは上段の吊りかごにある。かごが中段まで下がるとPが上がる。その下にはWを受けてGを開くてこ。Pを保持するくさびKもある。
- **固有の判断:** Wの一回目の働きを構造に保存してから、残りの落差で二回目の仕事をさせる。
- **誘う誤解法 → 失敗:** かご底からWを直接落としてGを開ける → Pが上がらない。Pが上がってすぐWを抜く → Pが戻る。Wを残したままVを出す → Gに突き当たる。
- **基準解法:** かごの上段保持を切りWでPを上げる → Kを落としてPを保持 → かご底を切りWを下のてこへ渡す → Gが開いた後にVを送る。
- **手がかり:** Wの通り道を上段・中段・下段まで見せる。かご底と綱の切断点の違い、Gにつながるてこが読める。
- **任意ヒント:** 観察「重りが中段へ来た後、その下には何がある？」／関係「最初の仕事が元に戻らなければ、同じ重りを次に回せる」。
- **採用条件:** 二度目に使う落差が実在し、重りを自動で元の高さへ戻さない。9面との差は経路部材の再利用ではなく、動力と状態保持の分離。正解が精密な重さの釣り合いに依存しない。

### 12 — 橋にしない梁

- **配置:** VとCの間に谷があり、長いPを寝かせれば橋になりそうに見える。しかしCの入口は閉じている。上のWの下には、Pを斜めに置いた時だけ届く横の受け鉢があり、その鉢が入口の機構につながる。Vには別の短い可動床がある。
- **固有の判断:** 見慣れた長い梁を陶器の橋にする定石を疑い、重りの誘導路として使う。
- **誘う誤解法 → 失敗:** 先にPを水平の橋にする → Wが鉢を外れ、下の深いくぼみに落ちる → 入口を開く力を失う。Wを先に落とす → 同じく回収できない。
- **基準解法:** Pを斜めの受け座へ下ろしW用の滑り台にする → Wを滑らせて受け鉢へ入れる → 開いた入口に向けてVの短い床を倒し、Cへ送る。
- **手がかり:** 受け鉢から入口までの接続、Wの直下と斜め下の行き先。Pを橋にしただけでは入口が開かないことも初期画面で分かる。
- **任意ヒント:** 観察「箱の入口は何で動く？」／関係「道が必要なのは、陶器だけではない」。
- **採用条件:** 精密な跳ね返りを使わず、側壁付きの滑走でWを運ぶ。Pを不要な飾りとして放置しても解けるなら不採用。11面との差は使用回数ではなく、どの物に道を与えるかを選び直すこと。

### 13 — 箱が支えている

- **配置:** 車輪付きCの上枠が天井Hを支えている。Vは右上の棚。Cを棚へ引くレールとWがある。代わりの支柱にできる梁Pは二つの受け座へ倒せる。一方はHを支えるがレールを横切り、もう一方はレールの外側でHを支えられる。
- **固有の判断:** 「支えればよい」と「箱を動かせばよい」を別々に解かず、両方を満たす支えの位置を選ぶ。
- **誘う誤解法 → 失敗:** Cをすぐ動かす → Hが落ちる。最寄りの受け座にPを置く → Hは保ててもCの通路が塞がり、Vを迎えに行けない。
- **基準解法:** Pをレール外側の受け座へ倒す → Hの荷重をPへ移す → WでCをVの棚へ引く → Cが止まってからVを収める。
- **手がかり:** C上枠とHの接触、二つの受け座、Cの幅とレール。どちらの支柱配置でも天井は支えられそうに見えるが、移動空間が違う。
- **任意ヒント:** 観察「支柱を置いた後、箱の幅は通れる？」／関係「今の荷重と、次に使う空間を同時に残す」。
- **採用条件:** 4面と7面を順番に並べるだけにしない。支持を作る選択そのものがCの移動可否を変える必要がある。Cの上枠の荷重支持は見える剛体接触で成立させる。

### 14 — 遠回りのための解体

- **配置:** Vは中央上の床、Cは右下。右へ直行するにはPを回して橋にしたいが、Pの回転域にはVがいる。左下に一段低い退避棚があり、その底からさらに下の右向き経路へ戻れる。中央の床は空にすれば下段の橋の材料になる。
- **固有の判断:** 箱に近づくことをいったんやめ、工事のために陶器を反対側へ退避させる。
- **誘う誤解法 → 失敗:** 箱側の床から切って近道を作る → 回るPがVを挟む。Vと床をまとめて落とす → 下段の経路が組み上がる前にVが硬い底へ着く。
- **基準解法:** 上の床を左へ傾けてVを退避棚に置く → 空いた中央でPと床材を下段の受け座へ移す → 右のCまで経路がつながった後に退避棚の底を開く。
- **手がかり:** 左の棚のくぼみ、中央を横切る長いP、左へ行っても高さを下げて右へ戻れる段差。退避先は無意味な飾りに見せない。
- **任意ヒント:** 観察「梁を動かすための場所に、何がいる？」／関係「箱との距離を縮めることだけが前進ではない」。
- **採用条件:** 退避の役割が時間待ちではなく回転空間の確保になっていること。Pを先に動かしてもVへ当たらない場合は面の中心が消えるため不採用。逆走はすべて段差を下る経路で、手動で押し戻さない。

### 15 — 渡り終えても必要

- **配置:** A入りの吊りかごが橋Pの釣り合いを保つ。BはPの手前、渡った先に待機棚。CはAの直下にあり、Aを受けた後でPを通ってBの棚へ下れる。Bの初期位置は、代替重りWを支え側の受け鉢へ通すシュートも塞いでいる。
- **固有の判断:** Bが渡ればPは不要、とは限らない。次に「A入りの箱」も同じPを使うことまで考える。
- **誘う誤解法 → 失敗:** 8面の定石で「Bを渡す → Aを救う」と進める → Aがかごから抜けてPが下がり、CをBの所へ運べなくなる。Wを最初に落とす → シュート上のBを押し落とす。
- **基準解法:** Bを対岸の待機棚へ移す → 空いたシュートからWを受け鉢へ送り、Aに代わる荷重を用意 → AをCへ収める → Cの止めを切りPでBの棚へ下ろす → BをCへ送る。
- **手がかり:** Cの車輪とPへ続くレール、A・Wの受け側とPの接続、Bとシュートの重なり。救出と単なる退避を見分けられる。
- **任意ヒント:** 観察「Bが渡った後、この橋をもう一度通る物は？」／関係「Aを抜く前に、その重さを代わりの物へ引き継ぐ」。
- **採用条件:** Aが既にCへ入った時にも質量が残り、CとAの合計荷重でPを渡れること。Wは橋を保持する受け止め構造と併用し、重量の微妙な一致を要求しない。Bを最初からCへ直接送れるなら不採用。

### 16 — 往路と復路

- **配置:** Aは左上、Bは左下の別棚。Cは右下の昇降ドック。一本のPは上段でAから上がってくるCへの橋になり、空にして回すと、上段右から左下のBの棚へ向かうCの下り道になる。Wは一度目の落下でCを上げ、さらに下へ落とすとドックの出口止めを退けられる。
- **固有の判断:** 陶器・箱・梁・重りを、それぞれ必要な場所に残しながら仕事を引き継ぐ。今使える近道で、未来の移動手段を失わない。
- **誘う誤解法 → 失敗:** Pを最初から下段の道にする → Aが上段のCへ渡れなくなる。Wを早く二段目へ落とす → 道がないままA入りCがドックを出る。Pの旧支点を受け座へ載せる前に切る → 復路用の梁を失う。
- **基準解法:** Wの一段目でCを上のドックへ上げ、爪で保持 → 上段のPでAをCへ送る → 空のPを下段の受け座へ回し、支持を移してCの下り道にする → Wを二段目へ渡してドックの出口を開く → A入りCがBの棚で止まる → BをCへ入れる。
- **手がかり:** 上下両方のPの受け座、ドックの保持爪と出口止めが別であること、Wの二段の落差。9・10・11面で扱った形と表示をそのまま用い、最終面で新しい物体ルールを増やさない。
- **任意ヒント:** 観察「箱が上へ来る前と、一個目が入った後で、必要な道は同じ？」／関係「梁は往路の仕事を終えてから復路へ。重りも一段目を固定してから二段目へ」。
- **採用条件:** Wの残りの落差で二段目が動き、Cの復路は重力で下る。箱がPへ移る前は安定して待てること。Aを上段から直接落とし、最後にCでまとめて受ける近道が成立するなら、面構成から作り直す。長い手順を覚える面にせず、各状態で次に足りない支持・経路を画面から推論できること。

## 承認後の採用審査

以下は**未実施の検証計画**。今回、設計書の論理と表記を確認しても、実機で成立したことにはならない。

### 1. 個別の機構から先に成立させる

05の昇降、06の荷重変化、09の梁の移送、10の支点変更、動くCの収容と移動を小さなブロックアウトで検証する。ここで不安定なら、その要素に依存する後半面を量産しない。

基準解法は切断間隔を変えて繰り返し実行し、到着後に3秒・10秒待っても崩れないことを確認する。許される操作時点は見える安定状態で説明できること。寸法、摩擦、質量の安全余裕は実測してから確定する。

### 2. 手順の成功と、浅い解法の排除を別に記録する

各面で、基準解法、全切り、箱に近い順、下流から準備、陶器を先に解放、重りを先に捨てる、役割変更を省く、を試す。可能な少数手の切断部分集合も探索する。自動試行で勝てないことだけでは難易度の証拠にせず、どの予測が必要かを人が確認する。

誤解法が安全に成功した場合は、その別解が中心課題を解いているかを分類する。工夫した別解なら残す。一手の偶然で中心課題を回避できるなら、配置を再設計する。「正しい順序で切らなかったため失敗」といったフラグは使わない。

### 3. 同じ面かどうかを比較する

面名・左右・色・陶器数を消して、物の役割と因果関係だけを書き出す。別の面の解法を物の名前だけ置き換えて使えるなら、独立した面として採用しない。

特に類似の危険がある組を個別に監査する。

| 比較 | 残すべき違い | 違いが消えた場合 |
| --- | --- | --- |
| 02 / 14 | 02は安全な回転方向を選ぶ。14はどの回転も今は危険なので退避して作業空間を空ける | 14を配置から作り直す |
| 03 / 09 | 03は同じ場所で受けて傾ける。09は陶器と梁を分離し、梁だけを別階へ移送する | 下段の受け皿を足すだけにしない |
| 04 / 10 / 13 | 04は支持の代替。10は支点変更で動きの範囲を変える。13は支持位置と箱の通路の同時制約 | 柱の数を増やすだけなら棄却 |
| 05 / 07 | 05は動力を残して陶器を上げる。07は重力で下る箱の終着点を止め木の取捨選択で作る | 07が陶器と箱の入替えだけなら再設計 |

### 4. 初見プレイで順序を決め直す

各面の説明を見ていない人のプレイで「切る前の予測」「最初の誤解法」「失敗理由を説明できるか」「次に何を変えたか」「ヒントの使用」を記録する。クリア時間だけを難易度にしない。

後半も盤面を読む前に同じ操作を繰り返して成功するなら不合格。逆に、仕組みを見抜いても物理のぶれや文字の小ささで失敗するなら難易度ではなく不具合として直す。上の順序は、この確認後に入れ替わり得る。

### 5. 画面と成功判定

設計承認後の実装ではGodotとWebを実操作し、375 / 768 / 1024 / 1440pxで重要な支持・綱・箱を同時に読めるか確認する。小画面で切断点が密集する面は難関として扱わず、部材配置を修正する。15・16面は特に部材の増えすぎを検査する。

複数陶器は、全対象がCに収まり、Cが安定してから成功。Cへ入った陶器の物理上の重さを消さない。途中で詰んだ場合は見える原因を示し、即座に再挑戦できるようにする。
