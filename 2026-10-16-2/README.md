# まちの続き

家や店を建て、道をつなぐ。住民の願いをかなえ、1955・1973・2000年の三つの時代を歩く、小さなまちづくりゲームです。

## ローカル起動

Node.js 22以降。追加パッケージのインストールは不要です。

```sh
cd 2026-10-16-2
npm run dev -- --open
```

`http://127.0.0.1:4318/` で開きます。macOSでは `ゲームをひらく.command` からも起動できます。終了は起動ターミナルでCtrl+C。ポートが使われている場合は `npm run dev -- --port 4319 --open`。

## 遊び方

1. 「町をつくる」から始める。まずは商店を選び、光っている空き地を選びます。
2. 建てる前に、予算と買物へ行ける人数を確認して「商店を建てる」。人が道を歩き出します。
3. 家を増やし、すべての願いをかなえると次の時代へ。町と最大3の予算が引き継がれます。
4. 川を渡る橋、診療所、公園を加え、三つの時代を達成します。

家から目的地へは、建物に隣り合う道を歩きます。道は上下左右につながり、歩く距離は通る道のマス数。商店4、仕事場7、診療所3、公園2マス以内。仕事場は6人までです。家を選ぶと、届いている目的地と道を見られます。

一手戻す、建物を返す、この年代をやり直すことができます。保存は端末内だけ。矢印キーで土地を移動し、Enterで選択、もう一度Enterで建てられます。Escapeはひと休み。設定で音と住民の動きを切り替えられます。小さい画面では「拡大」で町を大きくし、左右にスクロールして場所を選べます。

## 事実と、この町のルール

政府統計はestat CLIの取得済み原出力を使います。5つの全国値と4つの史実を、対象・分類・原値・出典・未確定の範囲とともに紹介します。町の12人、工事予算、徒歩マス数、建物の効果は遊びのための作者設定です。全国統計から個人の需要や費用を算出しません。

元の調査台帳と歴史閲覧版は `2026-10-16/` に保持しています。新作は別アプリです。最初の版は3年代の短い一周に絞り、1900年以降の全歴史を再現したゲームとはしません。
