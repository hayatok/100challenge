# 日本の変わりかた

写真を観察し、数字を動かし、当時の人の記録を読む。1900年から2026年までの日本の近現代史をたどるインタラクティブな教材です。

[公開版をひらく](https://hayatok.github.io/100challenge/2026-10-16-2/)

## 起動

Node.js 22以上。追加ライブラリ・APIキーは不要です。資料と写真は同梱され、出典リンクを開く場合を除きネット接続は不要です。

```sh
npm run dev
npm run check
npm run preview
```

`http://127.0.0.1:4320/`。別ポートは `npm run dev -- --port 4321`。

## 読み方

- **時代を読む**：8章の問いと解説。写真の番号から見どころを読み、出来事や当時の人の記録へ進みます。
- **写真を比べる**：銀座・東京駅の昔と今を、境目を動かして観察。全14点の写真を拡大して細部と出典を確認できます。
- **データを動かす**：人口・仕事・食卓・物価・学校・通信・住まい。項目と観測年を変え、説明図とグラフで変化をたどります。
- **年表を調べる**：394の出来事と105の暮らしの記録を、年代・地域・テーマ・言葉から探します。

全53表・557系列・15,728観測と出典291件を保持しています。政府統計は調査台帳第3版でestatを使って取得した原値です。欠測と対象の変化を補間で消さず、詳細から定義・欠測・元の値を確認できます。写真は撮影時期・場所・利用条件を確認して同梱。説明図は数値を読むためのオリジナル図版です。

2026-10-17に箱庭シミュレータから教材へ変更し、ゲームエンジン・架空人物・自動進行を配布物から削除しました。過去版の仕様と検証記録は履歴資料として残しています。調査正本と旧歴史閲覧版は `../2026-10-16/` に保持しています。
