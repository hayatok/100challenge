# 箱庭日本

史実と政府統計は固定したまま、架空の町と人々の暮らしを眺めるローカル作品。1900年から2026年10月まで自動で時間が流れます。

## 起動

Node.js 22以上。追加ライブラリ・APIキー・ネット接続は不要です。

```sh
cd /Users/hayatok/Documents/dev/100challenge/2026-10-16-2
npm run dev
```

ブラウザで `http://127.0.0.1:4320/` を開きます。他のアプリがポートを使っている場合は `npm run dev -- --port 4321`。停止はターミナルでCtrl+C。

```sh
npm run check
npm run preview
```

## 眺め方

- 開くと時間が進みます。1倍はおよそ2秒で1か月。停止・1/4/12倍・年代入力・時間軸で眺める速さと年を変えられます。
- 町を押すか場所を選ぶと、同じ世界へ近づきます。人物を押すと、現在までの日常を追えます。家族の次世代にも観察を移せます。
- 「別の暮らし」で人・家族・配置・日常が変わります。史実と統計の値は変わりません。
- 「こんな日々を、のぞいてみよう。」から7つの地方の記録へ移れます。水汲み、買物、織り仕事、共同出漁などの架空の日常を眺め、人物や「着想の記録」から元の史料へ進めます。移った直後は時間を止めます。「眺める」で続けられます。
- 数字を押すと、出典、実観測の時期、模型への対応が読めます。資料庫には全53表・557系列・15,728観測、184出来事、105生活史料、259出典と未解決94件の理由があります。
- 続きはこの端末のlocalStorageに保存します。別の画面へ移ると停止します。「動きを減らす」は人・乗り物・波の連続した動きを抑えます。

## データと模型の境界

政府統計は調査台帳第3版でestatにより取得した原値です。11信号が人の密度・働く場所・住宅・水道・通学・米屋・物価の札・バス・鉄道・通信機器・家庭のエネルギーの模型に結びつきます。出生数・死亡数は当年の記録として表示し、架空人物の出生・死亡の抽選へ変換しません。

統計のない年を補間せず、過去の断面を風景の参考にする場合は実観測年を併記します。1900〜1974年の人口動態の基礎人口は、国籍・対象地域・基準日の違いを分け、1975年以後の総人口と接続しません。2011年の就業欠測、教育の母集団差、2020年4月の交通調査変更も保持します。地域別の実人口や個人の人生を再現するモデルではなく、町と人物は架空です。現在の地形と歴史的領域は同一ではありません。

生活史料からの場面は年代と地域を確かめた7点に限り、記録の当人を再現しません。新規20点のうち年代の両端が定まらない13点は資料庫に残し、年別の日常へ自動割当しません。天気・植生・会話・家族とその運命は創作です。原家計帳の額を全国の生活費へ換算しません。

原史料の写真・原簿・映像は同梱せず、独自の要約と出典リンクを示します。確認水準と欠測を保持します。元の調査台帳と歴史閲覧版は `../2026-10-16/` に保存し、旧配置パズルは撤回・削除しています。
