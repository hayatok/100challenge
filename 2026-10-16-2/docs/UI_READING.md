# 全画面の読む体験（v0.3.3）

Issue: https://github.com/hayatok/100challenge/issues/180

- Goal：町・人物・歴史・統計を、内容と必要な操作を中心に読めるUIへ整理する。
- Context：町の注釈を除いた前回の変更では、JSON由来の調査メモが他画面へ流れる経路と、資料詳細の重複説明を見落とした。
- Constraints：原データ・史実・数値・出典・欠測・ゲーム動作を保持。新しい調査・機能・ライブラリ・画風変更を混ぜない。
- Done when：全画面の本文と操作、資料の任意の詳細を実画面でたどり、既存の値と欠測を確認。チェック・CI・公開配備を完了する。

| 画面 | 内容と操作 | 補足の置き場所 |
| --- | --- | --- |
| 町・日本全景 | 年代・場所・時刻・季節、動く暮らし、人物・歴史への移動 | 共通説明は作品について |
| 人物・一日 | 名前・年齢・仕事・行動・予定・家族・人生の記録 | 当時の暮らしから個別史料へ |
| 歴史 | 日付・場所・出来事・本文・検索・町への移動 | 出典、必要な固有条件だけ任意の詳細 |
| 統計・比較 | 読める名前、原値・単位・期間、点と範囲の操作 | 出典、対象・単位・欠測、年ごとの数字 |
| 資料検索 | 統計・出来事・暮らし・出典、検索と年の絞り込み | 調査上の不足は作品についてから別に読む |
| 作品について | 創作と史実、資料の読み方、保存 | 94件の未収録範囲と理由 |

統計53表の名称と定義、必要な比較条件を表示専用に編集。全557系列の区分番号と階層記号を整形し、対象・年齢・人数・時期は保持する。歴史・生活史料も本文の内容と調査作業を分け、史料の本文未読などは個別の詳細へ残す。原JSONと55組のestat取得証拠は変更しない。

検証結果は `evidence/browser/all-screens/`、配備の記録はIssueへ保存する。
