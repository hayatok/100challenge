# 追加調査を箱庭へ反映する計画

2026-10-17。Goalは第3版の調査を「箱庭日本」に採用し、眺めるだけで地域と時代の変化に気づける作品へ育てること。

Contextは既存の紙模型、日本全景と12の架空の町、人物と家族の追跡、出典と原値の閲覧。入力は隣の研究フォルダに保存した第3版の53表・15,728観測・184出来事・105生活史料・259出典・115課題。変更前の画面を起動し、一時停止・人物・町と資料の流れを確認した。

Constraints:

- 史実、原値、単位、欠測、時点、地域・国籍・分類の留保を乱数で変更しない。新旧系列を無条件につながない。
- 人口・教育・就業・交通の採用を更新し、鉄道・通信・家庭エネルギーを加える。統計を個人の寿命・就職・進学の抽選へ変えない。
- 小さな行動と配置に再現可能な乱数を使う。個別史料は創作の着想として明記し、実在の話者を架空人物の人生に置き換えない。年代不明の史料を年別風景へ自動割当しない。
- 季節の色、地域景観、道具・衣服・荷物、作業や近所の交流を一緒に描く。史実の災害・戦争被害・観測天候をランダム生成しない。空模様は架空の演出。
- 初期表示は動く町を近くから眺める。全景へ戻り、場所・人・年を選ぶことは任意。日常を読む間を作り、史料のある旅先への移動・資料閲覧・フォーカス喪失時は停止する。
- ローカル実装と検証のみ。研究正本・旧版・無関係な作業物を保持。コード送信・公開・配備・マージ・タグ作成はしない。

Done when:

1. 全追加記録と原値に到達でき、新しい指標が風景へ実際に結び付く。
2. 地域・時代・季節によって住民の行動と道具が変わり、人物・日誌・風景の意味が一致する。
3. 「この町の一日」から住民と着想の史料を読め、史実と創作を区別できる。史料のある風景へ一操作で移動できる。
4. seed変更で史実・マクロが不変、出典/欠測/境界/年代不明・保存互換を検証する。
5. 実ブラウザで1440×900と390×844を主に、全景/町、1930年代・戦中・戦後・近年、停止/速度/追跡/出典/原値/欠測/保存/再試行を操作し、表示とコンソールを確認する。

Game-designのsystemsとguidance-and-feedbackを参照。観察の動詞を中心に、風景で見えた行動→短い日常→着想の記録へつなぐ。勝敗、建設費、達成課題、資源管理を追加しない。眺めて面白いかは仮説として扱い、実画面の操作・見え方の確認と分けて報告する。

担当はデータ（archive/driver/原値検査）、模型（日常と時点選択）、描画（Canvas）、親（UI/統合/ブラウザ検証）に分離する。
