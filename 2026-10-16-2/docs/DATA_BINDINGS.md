# 箱庭日本：第3版資料の採用

2026-10-17。第3版の統合正本 `../2026-10-16/data/revisions/20261016-v3/merged/` から53統計表、15,728観測、184出来事、105生活史料、259出典、115残課題を取り込んだ。観測は15,594数値・134原記号で、5セルは年未確定のまま。第2版の14,083観測は全属性を不変に保つ。日本の全史・全住民の経験を調査済みとするものではない。

研究正本・旧版アプリ・CLI原証拠は編集していない。政府統計の新規取得やWeb値による置換も行っていない。第3版の統計を人物の個人確率へ変換しない。

## 固定資料と作者の模型

全国の原値、対象、単位、時期、欠測、史実はseedで変わらない。模型の人数、家・田畑・工場・機器・車両の数、エネルギー表現への縮尺は作者の描画ルールで、公式推計とは区別する。人物の名前・移動・日常や架空の町の配置だけを乱数で変える。

地図に置く模型の町は実際の地域分布ではない。全国値を地域へ統計的に配分したものと説明しない。人口動態の出生・死亡から1900年人口を逆算しない。新しく得た基礎人口も現在の総人口と同じ対象ではない。

### 人口の範囲を変えずに参照する

D3-ST001の値を一続きの現代総人口にはしない。segmentsには次の区分を定義した。すべて同じ原系列の観測点を使い、対象が変わる境界を読者向けの説明とともに残す。

- 1900～1919：旧内地の内地人、1月1日の遡及推計。1920国勢から遡った推計であり、直接国勢調査値ではない。
- 1920～1939：外国人を含む旧内地人口、原則10月1日の現在地人口。
- 1940：銃後人口に内地軍人・軍属の推計を加算した値。
- 1941～1943：外国人を含む旧内地人口。
- 1944：2月22日。陸海軍の部隊・艦船の人と外国人を除く。
- 1945：11月1日。軍隊・外国人を除き、沖縄と北海道・東京・九州の一部も対象外。
- 1946：4月26日。外国人と外国人世帯の人を除くなど前年と異なる。
- 1947～1949：戦後の現在地人口。外国軍隊・公館員と家族、沖縄等を除外。
- 1950～1951：常住人口へ変更。1952～1953は十島村、1954～1966は奄美を含む区分。
- 1967：日本人人口へ変更。1968～1972は小笠原、1973～1974は沖縄を含む区分。
- 1975以後：従来のSD-STAT016による10月1日総人口。前の日本人人口との増減率を計算しない。

原系列には1899年や1975以後の点も全て残るが、この模型の適用区間と全資料の閲覧範囲は別。旧植民地を加えた帝国人口を描いたり、復帰日と統計への加算年を同一視したりしない。原注記の推計/国勢/版・年別例外も出典で残す。

### 教育・産業・交通の切替

教育は2017年に表示用の参照をSSDへ切り替える。旧大学在学者は大学院等を含み、新SSD大学学生は学部のみ。大学の増減をこの境界をまたいで比べない。小学校は旧DBとSSDが1975～2015年で一致する一方、2016年は6,386,207と6,483,515で不一致。両原値を保持し、原因は未解決と表示する。新SSDの5月1日断面と卒業/進学の3月値も年平均とは違う。

産業は1920/1930/1940/1950国勢の旧分類、1953以後の労働力、2003製造業区分、2007第12回、2011以後の15歳以上/第12・13回を分ける。農業と製造業だけを全産業構成にせず、家族従業者と就業者総数を加算しない。2011年のD3-ST004は震災による全国年平均非掲載の「…」。0、2010年、補間値に置換しない。2026年平均も作らない。

バスは2020年4月の調査/集計方法変更でsegmentを切り替える。旧新公表値の連続性は保証されず、接続係数や増減率を独自作成しない。鉄道は別の月次数量で、月報と年報再集計の版差を留保する。鉄道営業キロも資料一覧へ残すが、この版の走る列車は旅客数量を参照する。

### 通信と家庭エネルギー

通信はPCを第1チャネルとし、1996～2004のsegmentは1996～2000のPC/携帯の過去資料、2005は別の単年表、2006～2009はPCのみ、2010以後はPC/スマホを参照する。旧携帯とスマホは別対象。携帯4区分の包含差を合成しない。2017以後のAPI未取得部分を最新値に見せず、最終2016年の資料を使う場合には観測年と過去の断面であることを明示する。2024/2025のCSV目録は保存しているが数値は未採用。

家庭エネルギーは2017以後の本調査の全国4種合計を参照。2015試験調査や電灯需要の口/MWhへつなげない。2024年度以後の偶数年度は非実施なので、値がないことを0や前年値に置換しない。模型を2026年に進めても、参照した点は「2023年度の資料」とする。エネルギー全体が個々の家の明るさを実測したものとは説明しない。

## 年・頻度・欠測を変えないデータ契約

seriesのグループキーは `statId / 全非時間次元 / timeDimension / observation_frequency`。旧IDは維持し、新観測の頻度がある系列は `:frequency=…` を付けた。時間軸がcat02で新頻度があるエネルギーには `:axis=cat02` も付ける。

E3-ST007の観測年はcat02の `全国_元号年度_西暦`。原 `time=000107 / 令和5年度` は収録版で、全35値を2023年へ置かない。グループ化ではcat02を時間軸として除外し、版のtimeは固定次元に残す。読者向け系列名は「収録版：令和5年度」と明記。原コード/ラベルは変更しない。

E3-ST006電灯需要84セルは、月次72・年度6・上半期6として6系列に分ける。月次と期間計を同じ線へ入れたり合算したりしない。家庭調査のGJとは別の資料として全値を閲覧に保持する。

描画に使う点は `point.year/timeLabel/raw/unit/source_id` を保持する。過去のsnapshotは欠けた年を埋めた統計ではなく、資料の年を添えた模型。未来の点を先取りせず、原記号に遭遇したら前の数値で覆わない。期間外、未取得、欠測、対象外を区別する。モデルが期間外をunavailableとする場合も、原資料閲覧から観測を削除しない。
