# 日本の変わりかた — 教育コンテンツへの再構成

## Goal / Context / Constraints / Done when

- Goal：既存の公開作品を、1900年から現代までの日本を写真・イラスト・データで理解できるインタラクティブな教材へ作り直す。
- Context：2026-10-17、ユーザーがゲーム要素の撤去と教育コンテンツ化を明示。旧箱庭の外観修正ではなく、学ぶ体験を再設計する。
- Constraints：元調査台帳・archive・史実・統計原値・出典・欠測を保持。追加統計はestat。写真の年月・場所・再配布条件を個別に確認。共通説明は一箇所、内部仕様や作業メモをUIに出さない。無関係な作業を保持。
- Done when：8章を読み進め、写真の見どころと昔/今の比較、統計の年や期間を動かす操作、暮らしの一次資料、年表の検索を実ブラウザで使える。旧ゲームは画面・配布コードから撤去。CI・公開版の実操作・同配備の成果物照合を完了。

## 主な体験

1. **8つの時代を読む**：一枚の実写真と問いで始まり、暮らし・制度・地域の3つの視点、出来事と当時の人の記録、統計の読み取りへつながる。次章へ読み進められる。
2. **昔と今の写真を比べる**：銀座・東京駅など同一の場所の写真をスライダーで比較。写っている道具・交通・建物を拡大し、見どころを押すと解説が出る。
3. **データを動かす**：人口・仕事・食・物価・学校・通信・住まいの問いを選ぶ。二つの実際の観測年を図版で比べ、原値のグラフを操作し、その年の出来事と結ぶ。全557系列も検索できる。
4. **年表を調べる**：394出来事と105暮らしの資料を年代・テーマ・地域・言葉で検索。写真と章から来ても元の文脈へ戻れる。

## 見せ方

明るい紙色と濃い藍、朱の印。大きい明朝見出し、読める本文、写真を大きく使う編集型の画面。写真へ長文を重ねず、年代・場所・短い見どころだけを添える。図版は統計を読むためのSVGで、ゲームの模型や架空の住民を描かない。凡例・年月・対象は数字を読むのに必要な位置に置く。原史料の写真と説明図を混同しない。

## 品質の確認

- 最初の画面で主題と次の操作が分かる。章を替えると写真・問い・本文・資料が全部その章に変わる。
- 写真比較・ホットスポット・拡大は、実際の写真に写る内容を説明する。
- グラフと図版が同じ観測値を示す。年平均/月次/四半期と対象の境界を保持し、欠測をゼロにしない。
- 戦前を空白に隠さず、1900年人口、1920年の仕事、戦前の個別家計等へ到達できる。
- 政治と経済だけでなく、地方、労働、支配と住民被害、生活の再建、公害、権利と暮らしを扱う。
- PCの写真と図の読みやすさ、主要な学習導線を反復評価。小画面は操作不能と表示崩れだけを短く確認する。
