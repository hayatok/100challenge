# 箱庭日本：模型と町の日常

## 目的と観察の循環

地方の架空の町で、人が何を持ち、どこへ向かい、何をしているかを眺める。人物を選ぶと同じ場面が日誌に入り、その着想元へ移れる。年代を戻すと同じ家族・場面を再現し、別の暮らしでは史実と統計を固定したまま人・配置・日常が変わる。

`game-design` の systems / critique を参照した設計仮説は「人物の小道具・行き先・文章・史料が一致すると、背景を見るだけの状態から、小さな用事を追う観察へ移れる」。勝敗や資源管理は追加しない。この仮説の面白さは自動テストでは証明できない。実画面で姿勢と道具を認識できること、読み終わる時間があること、旅のしおりから着想を見つけられることを別途確認する。

## 証拠と創作の境界

- 統計の原値・原記号・単位・観測時刻・系列・出典、出来事、生活史料本文は固定。seedはこれらを変更しない。
- 名前、家族、寿命、仕事、家、日常、天気、町への置き分けは作者の創作。統計を個人の死亡・被害・所有の確率へ変換しない。
- 人物の生年は家族ごとの作者設定に25年の世代間隔を足す。寿命68〜92年。家族の記録は実際に生成した子の生年を使い、未来の記録は表示しない。死亡年以後も過去の人生と家族IDを保持する。
- 全国値は模型全体の縮尺にだけ使う。12町は広域を参考にした架空町で、全国値から実在地域の人口を推計していない。模型人物を町ごとに順繰りに置くのも作者設定。
- 家計帳の額を全国価格へ変換せず、記録された人物や家族を架空人物へ置き換えない。場面は史料からの着想で、当人の再現ではない。

## 区分・時刻・欠測

`drivers.version=1` の `segments` は `from` / `through` の月を両端とも含む。空配列は既存の区分なし参照。区分がある系列は当月の区分だけを選び、期間外・区分開始前の観測を背景に持ち越さない。年次観測は原観測年の1月から参照可能とする月単位の閲覧規則であり、実際の調査基準日を変更しない。基準日は区分説明・原時刻ラベルを併記する。月次は原時刻ラベルから月を読む。年度の原ラベルも保持する。

観測年・月に一致すれば `exact`、同じ区分の過去断面は `historical`、未取得・区分外・最新原記号が欠測なら `unavailable`。欠測は0にしない。欠測が最新ならさらに古い数値へ戻らない。同じ系列内の比率も区分の最初の正の数値から取り直し、未来の基点を使わない。

特に人口の旧内地・国籍・沖縄等の境界、2017年教育の大学対象差、2007年以後の産業分類、2011年就業欠測、2020年4月の交通系列切替を分離する。参照人口1900年の43,847,000人は旧内地人・1月1日の遡及推計で、現代SSD総人口と同一の範囲ではない。

## 人と一日の契約（品質改善版）

`person.scene` / `dailyEvent` は従来どおり、その月の日誌に残す代表場面。着想元を見つけるしおりと保存の互換性を保つ。実際に描く人物と「今していること」は `routineAt(person, clockSeconds)` を使う。代表場面と進行中の場面は同じものではない。

`routines.js` の `DAILY_CYCLE_SECONDS` は96秒。`dayClockAt(seconds)` は6:00〜22:00の架空の日常時計、`dailyHour` / `timeLabel` / `dayIndex` を返す。歴史の年月とは独立した観察用の時計で、当日の実際の勤務時間や暮らしの再現ではない。日常時計を止めると移動・姿勢・今の用事・時計が一緒に止まる。時間を戻す場合は同じ入力から同じ行動を再現できる。

人物は `routine.days` に3通りの一日、`routine.stages` / `sceneStages` に最初の一日の予定を持つ。各stageには `startsAt` / `endsAt`（秒）、`startHour` / `endHour`、`phase`、`from` / `to`、`scene`、`companionIds` がある。実行時 `routineAt` は人物情報に現在の座標・場面・`stageIndex` / `stage` / `nextStage` / `sceneStages` を重ねて返す。日ごとに3通りを巡回する。

朝の支度→外出→仕事または学び→昼休み→午後の持ち場→用事→趣味→顔なじみとの交流→帰宅→夕方と夜、という11〜16段階をつなぐ。場所が変わるときは必ず移動stageを挟み、前stageの`to`と次stageの`from`が一致する。帰宅して一日を閉じるため、日境界でも座標が飛ばない。幼児は家族のそば、学齢の人は教室、65歳以後は庭の手入れや家族への手仕事に切り替える。史料の着想場面がある場合は最初の一日の用事に入れ、次の日にも必ず同じ用事をしているとは扱わない。

13職種（農・漁・商店・木工・繊維・事務・教師・配達・大工・食事・修理・手当て・工場）、6性格、8趣味をseedから決める。漁の仕事は作者設定の沿岸町に限る。職種は個人の統計上の割当ではなく、幼児・学び・現役・経験者という年齢に合う表示へ切り替える。慎重な人は移動、こつこつ派は仕事、好奇心旺盛は趣味、のんびりは休憩、世話好きは夕方の家事に長く時間をとる。話好きは交流時の身振りを強くするための`conversationEnergy`を1.4（その他は1）で返す。趣味に合う場面を候補へ入れるが、写真などの道具を出さない年代には別の休息を選ぶ。

独立した行動57種類を定義した。畝作り・種まき・収穫・網の繕い・水揚げ仕分け・品出し・帳面・レジ・木材削り・組立・糸巻き・縫製・書類・画面作業・授業・便り仕分け・配達・寸法測り・調理・修理・手当て・検品・箱詰め・幼児の遊び・読書・習字・掃除・球遊び・小川・庭・手仕事を教える・井戸・買物・投函・修理相談・洗濯・荷の受取・連絡・趣味・雪かき・行事・雨宿りなど、場所・小道具・姿勢・年齢・職業・季節が違う場面で構成する。朝食・昼休み・移動・交流・帰宅・夜はこれに含めない。2seed×6年代×4季節の監査で57種類すべてが実際の予定に出現した。

`relationships` は、その年に生存している親・子・きょうだい・近所の知り合い・通学仲間をID・名前・年齢つきで返す。stageの `companionIds` はこの関係の中から選ぶ。朝や仕事中のIDは同行・顔を合わせる意図であり、常時の物理的な同席を保証しない。

交流は72〜80秒（架空時計18:00〜19:20）の固定窓で待ち合わせる。窓より前の予定は0〜72秒、後の帰宅・夕方・夜は80〜96秒へ配分し、交流への到着・出発でも座標を飛ばさない。日ごとに家族、年の近い仲間・学友、近所の小さなグループを作る。幼児は家族のcaregiverと同じグループにする。各グループは広場近傍の別の座標を使い、大勢が一点に重なることを避ける。町の観察人数は全国統計から独立して選び、待ち合わせ相手は必ず`world.placePeople`に現れる生存する同町人物に限定する。

実際の同席者は `routineAt(...).companions` と `stage.companions` にID・名前・関係kind・年齢・職業・性格・趣味つきで最大2人返す。実行時`companions`は交流中だけ存在し、その他の時間は空配列。`meetingId`は少人数グループで共通、`memberIds`はメンバーのソート済ID、`facingId`は顔を向ける相手のID。描画は既にあるグループ座標にメンバーごとの小offsetを足すだけにして、別のグループ中心へ再配置しない。選択人物と町の住民は同じ待ち合わせを使う。会話内容の自律生成や交渉は行わず、架空の日常の挨拶・待ち合わせとして扱う。

## 場所と人数

`world.people` は従来の全国統計から換算した模型総数を保つ。町を近くで観察するときは `world.placePeople[placeId]` の20〜28人の固有住民を使う。これは観察密度のための作者設定で、地域人口や全国人数の追加推計ではない。全国と町で同じIDは同じ人物であり、町から人物を選ぶと追跡を続けられる。

家は町にある点灯中の住宅模型の座標へ家系ごとに結びつける。商店・畑・学校・工場・水場の行動は、対応する模型があれば必ずその建物の座標を使う。作業場は工場、事務・郵便・手当ての場は商店に併設した作者設定。模型がない施設は固定の町の目印を使い、統計から施設を発見した扱いにしない。浜は(.94,.24)、川岸は(.96,.32)、駅は(.18,.75)、広場は(.48,.48)。住宅・農地・工場・商業を道沿いの地区へ並べ、seedによる小さな位置差を残す。建物総数と各統計の換算式は変えない。

poseは walk/work/rest/talk に study/play/care/eat/queue を追加。propは bucket,basket,net,cloth,letter,book,tools,food,phone,broom,ball,cart,briefcase,camera,radio,umbrella,bicycle,tablet,sewing またはnull。日誌の代表場面は人物・季節に対して安定し、日常時計は実行中のstageだけを進める。生活史料の適格性は毎月判定し、史料の期末を越えて持ち越さない。
