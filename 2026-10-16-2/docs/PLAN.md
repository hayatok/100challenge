# 箱庭日本：制作計画

## 目的と撤回した実装

ユーザーは配置パズルを撤回し、「歴史とマクロを変えず、ランダムな暮らしを基本見るだけで進む日本シミュレータ」を指定した。旧ゲーム本体は削除し、旧PRは閉じた。調査台帳と歴史閲覧版は保持する。

作品の中心は日本列島の模型。起動すると1900年から時間が流れ、人が歩き、地域の家や働く場所が変わる。選択する課題・勝敗・建築操作は置かない。時間の停止、速さ、年代、場所、人、別の暮らしの再生を観察の道具にする。

## 固定する史実とランダムな暮らし

- 固定：原統計14,083観測、史実177件、史料85件、出典213件、対象期間・単位・欠測・留保。
- ランダム：架空の町の建物の配置、人の名前・家族・日常・移動。同じ種なら同じ暮らしを再生し、種を変えても歴史と統計は変わらない。
- 現在の日本の地形を背景の参考にする。地形は歴史上の領域や統計の調査範囲を表さない。12か所は地域を案内する架空の町であり、実際の地域人口の推計ではない。
- 年代ごとの建物の意匠は作者の表現。戦争・災害・差別の被害を無根拠に個人へ抽選しない。出来事は固定された日付と留保付きの記録として現れる。

## 統計が画面を変える対応

採用する統計の厳密な出典・分類・式はDATA_BINDINGSとモデルのdirectivesに記録する。数値そのものを乱数や独自補間で変えない。

| 信号 | 見える変化 | 使わない推論 |
| --- | --- | --- |
| 全国人口1975–2024 | 人の模型の総数・密度 | 1900の人口逆算、地方への実人口配分、個人の生存確率 |
| 農業・製造業の断面 | 田畑と工場の模型の量 | 分類をまたぐ接続、残差で第三次産業を作ること |
| 総住宅・空き家1978–2023 | 家の模型と灯りの消えた家 | 個人の退去・実在地区の空き家位置 |
| 上水道給水人口1975–2023 | 水道設備の模型 | 全国人口と割った独自普及率、電化率 |
| 小学校・大学在学者1948–2016 | 学校と通学の人影 | 個人の進学・合格確率 |
| 米の供給純食料1960–2023 | 米屋に積む米俵・食の模型 | 個人の摂取量・家計の購入量 |
| 2025年基準CPI1970–2025 | 商店横の実際の指数と推移 | 円への変換・架空の建築費 |
| 乗合バス輸送人員2010–2020月次 | 走るバスの模型の量 | 独自の年平均、実在の路線・車両数 |

観測がない年はその年の数値を表示しない。模型が過去の観測断面を背景にする場合は、画面に「模型が参考にしている記録」と実際の観測年を示す。未来の観測を先に使わず、欠測記号を0にしない。1940年代以前は統計のない量を作者の模型の数として明記し、生活史料の範囲を伴って当時の暮らしを案内する。

## 最初から含める画面と流れ

1. 自動で進む日本全景。時代と年、動く町、8つの数字の参照状態、当時の出来事が一画面に見える。
2. 地域をのぞく。町を押すか地域選択を使うと同じ世界の拡大風景になり、人を観察できる。全国へ戻れる。
3. 架空の人を追う。現在年までの記録、家族、日常を表示する。時間の移動に応じて年齢・動きが変わる。
4. 当時の実際の記録。史料の年・場所・誰の経験か・代表性の限界を表示し、架空人物と同一視しない。
5. 出典をたどる。全41表/498系列/14,083観測・177出来事・85史料と、未確認の範囲を検索する資料庫。原時間ラベル、単位、記号、出典リンクを確認できる。
6. 読み込み/失敗/再試行、終端、保存復元、動きを減らす設定、フォーカス喪失時の停止を設計する。

## 作業の分担と検証

- データ担当：正本とCLI証拠の全観測照合、archive/drivers、DATA_BINDINGS。
- 模型担当：原値不変、乱数、時刻移動、人物、統計→模型の対応。
- 描画担当：地理資料・日本全景・町の拡大・図形・動き・表紙。
- 親：UI、統合、起動/build、資料庫、実ブラウザで観察の流れを確認。

完了条件はbuildだけではない。実画面で自動進行、停止、速さ、過去/現在、全景/町、人の追跡、別の暮らし、原値/欠測/出典を確認する。主画面1440×900と小画面390pxで操作と可読性を確認する。公開・配備・マージ・タグは行わない。
