# まちの続き：最初の遊べる版

2026-10-16。参考資料を読むだけでは目的が分からなかったという指摘を受け、まちづくりを新規制作する。既存の歴史閲覧版と調査正本は保持する。

核の行動は「建てる」。住民の願いを見る → 店や道を選ぶ → 置く場所と予算・届く人数を確かめる → 建てる → 住民が実際に歩き、達成に近づく。限られた土地と工事予算の中で、近さと将来の拡張を両立させる。

最初の一手は、既存の家と職場の間に商店を置くこと。店が届いた人数が0から3へ変わり、家から店へ人が歩く。最初から全ルールを読ませず、川を越える橋、近場の診療所と公園を年代ごとに加える。

最小の一周は1955・1973・2000年の3場面、5〜10分を目標とする。最初は6人の住まいと買物・仕事、次は9人の町と川の両岸、最後は12人が近くで通院・憩いを持てること。全体の達成は結果画面と町の年表に残り、章をやり直して別の配置を試せる。

マクロの史実・estatの全国統計は、時代の課題を考えた背景として出典と範囲を残す。工事予算、歩ける道のマス数、人数、建物の効果は架空の町の作者設定。全国値から個々の住民の確率や需要を推計しない。元資料にない年を補わない。

制作順は①ゲームモデルと解ける配置の検証、②ミニチュアの建物・住民と画面、③3年代・達成・やり直しと保存、④出典・設定・音と動き、⑤実ブラウザで一周し目的の読みやすさと機能を確認。担当を分けた成果は親が統合する。
