# 箱庭日本のアートと地理

## 新しい描画

旧配置パズルのタイル・建物SVGを再利用せず、`app/src/renderer.js` にCanvas2Dの箱庭を新規制作した。全景は実際の日本列島の輪郭へ12の架空町を配置し、町の拡大は不規則な紙の地面に家、田畑、学校、工場、水道、商店を置く。マス目・配置可能タイル・勝敗・予算の図形は持たない。

海 `#d8e9e7`、陸 `#c8d9aa`、輪郭 `#42584b`、朱屋根 `#b85744`、淡い屋根 `#d47b5b`、木材 `#c9ad7e`、クリーム壁 `#f2e7c9`、樹木 `#759b67` / `#4b795b`、川 `#8bbcc0`。印刷した博物館の紙模型のように、薄い輪郭、自然な面の明暗、足元だけの淡い影で統一する。家の窓・玄関、庇と商品、工場の鋸屋根と煙突、学校の時計と旗、高架水槽、米俵、田の畝、樹木の幹を描き分ける。

人、通学人影、バス、参照値のある列車、工場の煙、波・洗濯物・木の揺れは呼出元の時計で動く。2026-10-17の品質改善では、町の線路・最低1両の列車と1台の小さな交通風景を作者の年代美術として採用した。これらは統計量の模型とは別で、実際の開業・普及・運行を示さない。全景の列車は取得されたrail信号で描く。人物や建物の数、人物の同一性、史実と原値は描画側で変えない。草木・山・川・井戸・洗濯物・作業台・係留小舟は作者が作った背景であり、実際の施設・航路・当人の暮らしの復元ではない。建物形状の年による差も模型の演出である。

地図は経緯度の単純な平面投影で、経度方向へ `cos(36°)` を掛ける。主な表示範囲は東経125〜147度・北緯24〜46度周辺に合わせ、遠方の離島の一部は画面の外に出る。ソースGeoJSONから離島を削除してはいない。面積・距離・人口密度を測る地図ではない。

**現在の日本列島の地形輪郭を参照しており、1900年その他の年の政治領域、国境の変遷、領有の主張を示す歴史地図ではない。** 政府統計ではない。12地域の町の中心、山並み、川、建物の位置は作者設定であり、地域人口・実際の施設・地形を推計していない。再利用用帰属は `app/assets/map-attribution.txt` に記録し、静止カバー `app/assets/japan-cover.svg` も同じ輪郭と自作図形を使う。

## モデルから見た目への対応

全国の原値と観測年を守るのは `model.js`。描画はモデルが作った `snapshot.world` と各町の `visual` を使う。

| 信号 | 拡大画面で見えるもの | 留意点 |
| --- | --- | --- |
| population | `world.people` の架空住民の数と歩行 | 出生死亡・人物の運命を全国値から抽選しない |
| industry | `farm` の田畑と畝、`factory` の工場と煙 | 農業と製造業の模型。全産業の比率ではない |
| housing | `house` の軒数、`lit=false` の暗い窓 | 空き家の模型配置は作者設定 |
| water | `water` の高架水槽と給水管 | 電化率・水道全体の普及率へ変換しない |
| education | `school` の校舎、`visual.students` の学校前の通学群 | 通学群は匿名模型で、追跡する架空家系から分離 |
| rice | `rice` 1個に米俵を1俵 | 供給純食料の縮尺模型。摂取量・購入量ではない |
| prices | 商店の「指数 XX.X」札 | 円や商品の価格として表示しない |
| bus | `world.vehicles` のバス | 輸送人員を作者の台数へ縮尺した模型で実車数ではない |
| rail | `visual.rail` / `directives.railCount` がある町の線路・列車 | 作者配分された模型数。未取得時には線路・列車を描かない。路線・運行史の再現ではない |
| communication | `visual.device` の机上の通信機器 | 世帯保有割合から作る作者模型。個人の保有率や所有する機種ではない |
| energy | `visual.energy` / `directives.energyGlyphs` の燃料束とかまど | 家庭の全エネルギーの量の模型。電化率・電力・燃料別構成には変換しない |

全景では住宅2軒を1つの小さな家へ縮め、通学群も2人影を1人影へまとめる。町の拡大では `world.buildings` の建物を描き、通学群もモデル数を描く。町の拡大は人・建物を奥行き順に並べ、追跡対象は足元の楕円、頭上の朱印と行動の吹き出しで識別する。各町の人はモデルの `from` / `to` を目的地として、`routineAt(person, elapsedSeconds)` の同じ架空日常時計で移動・到着・仕事・休憩・会話・食事・学び・遊び・世話・待機を描く。町では `world.placePeople[placeId]` の観察用住民を使う。全国の人数模型は `world.people` のまま保つ。選択で架空人物のIDを親へ返す。全国統計を町ごとの実測値と呼ばない。

## API・操作・文字

`createRenderer(canvas, { geometry, onPlaceSelect, onPersonSelect, onViewChange })` を名前付きexportし、`{ render, resize, destroy }` を返す。

- `render(snapshot, elapsedSeconds, { view:'japan'|'place', placeId, selectedPersonId, reducedMotion, zoom:1, dailyHour })`。呼出元のrAFで実行する。内部にタイマーを持たない。
- `resize()`。CanvasのCSSサイズと端末比率へ合わせる。描画倍率は2倍まで。
- `destroy()`。クリックとpointermoveの登録を外す。
- 全景の町・地域名はクリックで `onPlaceSelect(id)` と `onViewChange('place', id)`。町の追跡可能な人は `onPersonSelect(id)`。

Canvas内の文字は海名、地域名、町名、店の指数札と選択住民の短い行動だけ。住民の吹き出しは紙色・朱輪郭・小道具のアイコンを組み合わせ、長い行動は省略し、詳細をHTMLに任せる。観察の案内はHTMLの説明にまとめ、Canvas底部へ重ねない。全景の地名は紙色の面と墨色の字、選択地域は朱の字と町の楕円。ラベルの衝突と親UIの右上切替領域を避け、列車より前面に描く。日本海の文字は年表示と重ならないよう左中央の高さ40%に置く。HTMLの見出し、統計、再生・停止・速度、出典、人物記録は親UIが担当し、共通 `--ui-*`、16px/1.6の本文、44px操作面、2px輪郭、3pxフォーカスを使う。Canvasの小さな絵だけを唯一の操作手段としない。

`reducedMotion=true` でも人物の実行中場面と架空日常の時刻は呼出元の時計を使う。草木・煙・交通・手足など装飾の連続アニメーションだけを0に固定する。停止・フォーカス喪失・速度変更では親が時計の進行を管理する。外部フォント、外部画像、画像生成、追加npm依存を含まない。

## 第3版：地方の日常の描き分け

`place.atmosphere` の任意フィールド `season`、`landscape`、`weather` を受け取る。なければ月と作者の地域設定で従来のデータも描画できる。春は淡い緑と小さな花、夏は青緑、秋は黄褐色の畝・穂・稲束、冬は抑えた緑。snow のときだけ屋根・山・紙面の積雪と小粒の雪を描く。rain は薄い雨線であり、史実の災害を生成しない。空模様はモデルの架空設定で、年次の気象観測ではない。

海辺は砂色の岸・桟橋・網干し・係留小舟、山は段畑と石色の縁、川沿いは曲線の水路と木橋、町は平らな生活道を持つ。茶の畝、柑橘の木、白い幹、南のヤシ形は作者の地域を連想する装飾で、地域の植生分布・作付面積の資料ではない。地域の史料を一つの町全体の代表にはしない。

`person.scene` は `prop` と `pose` を読み、桶・籠・網・布・手紙・帳面/本・道具・食べ物・電話の自作図形を人物の手元に描く。walk は歩幅、work は手元の作業、rest は腰掛け、talk は小さな会話の印を使い分ける。人物の出典資料ID・文章・場面を選ぶ判断はモデル、説明と出典を開く操作はHTMLの責務。描画側で新しい史料や個人史を作らない。

2026-10-17確認：変更前後の実ブラウザで四国の段畑、沖縄の海辺・網干し・井戸、選択住民の輪郭/吹き出しを確認。構文チェック、実モデルの4年代×全景/町の8描画に加え、任意scene/atmosphereを入れた5地域×4季節×320/760/1200pxの60描画をCanvasコマンドアダプタで実行。座標にNaN/Infinityがないこと、reducedMotionで異なる経過秒でも同一出力になることを確認。後者は描画単体の確認であり、ブラウザの小画面・DPR・全操作・速度の体感は主担当の統合確認で扱う。既存のAPI、DPR上限2、外部タイマーなし、人物の最小12pxヒット半径を維持した（以下の拡大調整前）。

2026-10-17追記：町の追跡可能な住民だけを足元原点のまま1.4倍へ拡大し、手持ち道具・選択印も同じ倍率で描く。ヒット中心は拡大後の胴体中央、半径は最小14pxに合わせた。吹き出しの縦位置と接続線も人物の表示倍率に合わせ、行動アイコンは1.5倍で描く。全景の人物と匿名の通学群の数・倍率は変更していない。構文、既存8描画と60地域/季節/幅/reducedMotion描画を再確認。実画面の操作確認は統合担当が継続する。


## 2026-10-17：町の品質改善

### 狙いと純粋API

変更前の町は、同じ数軒の家が広い地面に散在し、1965年と2020年の違いが少なかった。年代は文言を読まずに屋根と街の高さで分かり、人物は町の実際に見える目的地へ向かうことを今回の完了条件とした。game-designのinterface/guidance-and-feedbackを参照し、年代のランドマーク・道・小道具・選択の反応へ情報を担わせる。古い `docs/GAME_DEV_SKILLS.md` 参照先は現リポジトリに存在しなかった。

`app/src/era-art.js` は `ERA_PROFILES`、`eraProfile(year)`、`buildingArt(year,seed,kind,placeId)`、`dailyLight(hour)` をexportする。DOMやCanvasに依存しない。境界は1900/1920/1940/1955/1978/1998/2018年で、年を資料から推計した数値へ変換するAPIではなく、作者の画風の区切りである。看板名、階数、交通の有無・形状、屋根、窓、道路、屋上の設備は創作であり、史実の施設・普及率・災害被害の復元として用いない。

### 町の構造

住宅・商店・工場・田畑の地区化はモデル側の同じseed座標を使う。描画側で建物の位置を独自に動かさない。街路はworld x/y=.28,.52,.76の等角格子、建物の足元へ枝道、中央に広場を置く。後方の街並み帯、神社、小さな公園、庭の畝、電柱、洗濯、係留舟、山・川・海は作者が作った周囲の美術であり、全国の住宅数・耕地面積・施設数の縮尺模型へ加算しない。

駅はworld {.18,.75}、線路はx=.15の対角線。井戸は{.24,.67}、川岸は{.96,.32}、海辺は{.94,.24}付近。行動モデルの目的地と同じ位置へランドマークを置く。住民の重なりを避ける足元近傍の小さな表示offsetは目的地を変えない。人物と建物の前後順は同じ奥行きで並べる。

北国の白樺と屋根、沖縄の赤い屋根とヤシ、山地の段々風景、沿岸の港、東海の茶畑風の帯、四国・九州の果樹を描き分ける。季節はsnapshotの月、天気は生活モデルの架空空模様。昼夜は `dayClockAt(elapsedSeconds)` の6時〜22時の創作日常時計を使い、史実年月や実際の日照時間とは独立させる。空・日/月・薄い夕夜の色・窓・街灯・ヘッドライトで時間を見せる。

`options.zoom` は1〜1.6。既定は1。拡大しても人物hit座標と吹き出しは同じ倍率を使う。`dailyHour` を渡す場合は任意の架空日常時刻として空の描画だけに使う。`reducedMotion` は装飾アニメーションの時計だけを0に固定し、`routineAt` と昼夜は現在の日常時計を使う。

### 第二改善：展示列から小地区へ

親の1440×900実画面（`evidence/browser/quality-loop/pass1-1900.jpg` / `pass1-1985.jpg`）で、年代差は出たが後方の同じ一列が展示台のように見え、前景の空地と人物の重なりが残っていた。これを受けて後方を3つの不均一な住宅・小店のブロック、左前を6軒の小道沿いの住宅商店、右前を畑・工房寄りの小集落に変更した。高層化の割合を抑え、低層・高層・余白の混在を残す。創作背景の量の変更であり、モデルの原countは変更しない。

人物は前版の1.33倍、静止場面の同居人は足元近傍の表示幅を34local pxへ拡大。選択者は最前面にも再描画し、薄い紙色の輪郭と移動中の行先線・到着点で観察できるようにした。追跡線は人物モデルのfrom/toを使う。森の群、畑の区画と柵、茶畑・果樹、防波堤・灯台と木箱、川岸の草と橋で地域の違いを増やした。
