# まちの続き：町と操作のアート

## 自作のミニチュア

`app/src/art.mjs` の図形は、このゲーム用にコードで描いたオリジナルSVG。生成画像、外部画像、外部フォント、外部素材、SVGライブラリは使用しない。手描きの墨線を思わせる丸い接合と輪郭、木材のクリーム、朱の屋根、青い川、草木の緑をそろえる。図形を構成する点や色は固定し、乱数や画像通信を使わない。

| 役割 | 色 | 表現 |
| --- | --- | --- |
| 墨の輪郭 | `#343c34` | 1.35単位の丸い接合、主要な構造を明瞭にする |
| 土地 | `#a9bb7c` | 芝、細い草、石、10単位の土の厚み |
| 木の壁 | `#f2dfb4` / `#d6bc8c` | 面の向きで明暗を分ける |
| 1955年の屋根 | `#ba5841` / `#d37552` | 温かい朱、住宅の瓦筋 |
| 1973年の屋根 | `#905e4d` / `#b57959` | 落ち着いた瓦と外壁 |
| 2000年の屋根 | `#5d7c78` / `#789991` | 青緑、住宅に小さな屋根パネル |
| 河川 | `#74b7bd` | 明るい波、暗い水面の筋 |
| 樹冠 | `#618b51` | 葉の塊、木の幹、淡い緑の枝模様 |

| 診療所の看板 | `#347d77` | 青緑の面にクリームの葉。赤十字の標章は使わない |

家は大きな切妻屋根・玄関・窓・鉢植え、商店は縞の庇・商品台・果物、工房は煙突・作業扉・木箱、診療所は葉の看板・ガラス入口・階段、公園は2本の木・ベンチ・小さな花で識別する。色だけで種類を表さない。影は薄い固定の四角形で、地面の菱形に収める。ぼかしフィルターや余白を占める大きな影は使わない。

年代は屋根材・壁・庇の小さな変化で表す。建物の種類や操作を読み直させない。この絵は架空の町の表現であり、実在した建築物や年代ごとの建築比率を再現した史料ではない。

## SVG API と座標

以下の4関数を名前付きexportする。呼出元は町のSVG内へ断片を差し込み、各タイルの位置へ `translate` する。APIからユーザー文字列や任意の色をSVG属性へ差し込まない。

- `terrainSVG(kind, connections = [])`：`land` / `river` / `mountain` / `road` / `bridge`。中心 `(0,0)`、地表は `(0,-20) (40,0) (0,20) (-40,0)`、土の下端は `y=30`。未知のkindは土地へ戻す。
- `buildingSVG(type, era = 0)`：`home` / `shop` / `workshop` / `clinic` / `park`。足元を中心にして土地の上へ重ねる。建物はおおむね `x=±33`、住宅の屋根は `y=-62`、工房煙突は `y=-67`。eraは0/1/2、その他は0の配色。未知のtypeは空文字。
- `residentSVG(tone = 0)`：足元 `(0,0)`、高さ約12、幅約8。約2.5頭身。6色の服・3色の肌。色番号は有限数だけ受け、NaN等は既定色。人物の移動や歩行演出は描画側が担当する。
- `toolIconSVG(type)`：上記の建物5種と `road` / `bridge` / `erase`。`<svg viewBox="-44 -76 88 108">` を含む完成SVG。町と同じ絵を使い、ツールを選んだ後の見た目を予測できる。SVGは `aria-hidden="true"`、操作名は呼出元のボタンに付ける。

接続配列は `[N,E,S,W]` のboolean4個。隣接タイルの中心はN `(40,-20)`、E `(40,20)`、S `(-40,20)`、W `(-40,-20)`。道路は接続方向の共有辺中央まで延ばし、接続のない単独の道も中央の菱形が見える。橋は川面と欄干付きの木の橋を返す。E/Wだけが接続する場合は橋の向きを反転し、それ以外はN/S方向。橋が使える接続ルールはゲームモデル側で定義する。

SVG内部には文字、ID、script、イベント属性、外部参照、アニメーションを持たせない。重ねて描いてもIDの重複が起きない。すべての断片は親SVGの座標で描く。

## 文字・枠・操作への受け渡し

町の朱屋根と青緑の水を作品部分の固有色として使う。操作面は共通 `docs/DESIGN.md` の `--ui-*` を使用する。本文は端末の日本語システムフォント16px/1.6、見出しは端末の日本語明朝体へフォールバックし、数字は桁がぶれないように扱う。配布フォントを含めない。

タイトル、町のHUD、年代達成、全体結果、ポーズと設定は墨の輪郭とクリームの紙面でそろえる。操作の44px以上の面、2px輪郭、3pxフォーカスは共通方針を守る。建物名・費用・接続人数・配置不能理由は呼出元の文字領域に示し、SVGの小さい看板へ文言を詰めない。ツール名と形の両方で選択対象を識別する。

配置・到着・達成の反応は主描画側で行い、絵自体には自動アニメーションを埋め込まない。置ける場所と置けない場所は色に加えて輪郭と説明で示す。ポーズ、フォーカス喪失、動きを減らす設定による演出停止も主描画側が扱う。
