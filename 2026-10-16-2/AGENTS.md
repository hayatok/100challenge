# 日本の変わりかた

## Goal / Context / Constraints / Done when

- Goal：1900年から現代までの日本の近現代史を、実際の写真、解説図、動かして読める統計、当時の人の記録で学ぶ教育コンテンツにする。
- Context：2026-10-17、ユーザーは箱庭ゲームを撤去し、インタラクティブでグラフィカルな教材へ変更するよう明示した。以前のシミュレーション設計は撤回。8つの章を読む、同じ場所の写真を比較する、数字の変化を調べる、年代や地域から史料へ進むことを中心にする。
- Constraints：ゲームエンジン・架空人物・自動進行・乱数・保存状態のUIを配布物から削除。調査正本と数値・対象・単位・観測期間・欠測は保持する。統計の追加取得にはestatを使う。写真の撮影時期・場所・撮影者・出典・利用条件を確認し、実写真と説明図を区別する。既存の無関係な変更を含めない。
- Done when：8章で歴史の仕組みを読める。写真の見どころ・拡大・前後比較、項目と年を変える図、全557系列のグラフ、394出来事・105生活史料と個別出典を実操作できる。本文と写真・統計の主張が対応し、欠測や対象の変化を消していない。PCで実画面の読みやすさと学びの道筋を反復評価する。

## 実装と編集

HTML/CSS/ES modules、SVG、Node標準のサーバー/build。外部ライブラリや配布フォントなし。配色・文字・図の方針は `docs/DESIGN.md`、今回の計画は `docs/EDUCATION_PLAN.md`。写真台帳はmedia.json、解説はlessons.json、統計の選択・整形はeducation-data.js。既存archive.json・history-expanded.json・drivers.jsonは保持する。driversは統計の範囲と区切りの参照に限り、ゲームへ再利用しない。

写真の数字を押すと写っている対象の説明へ切り替わる。比較写真は同じ場所と確認できるものだけで組み、撮影角度・範囲の相違を比較の見どころに記す。現代写真を過去の記録として表示しない。原写真の全体は拡大で読めるようにする。

統計は原観測点を示し、欠測、未観測年、定義や調査対象の境界をまたいで線を引かない。異なる単位は別の目盛り・比較選択に分ける。旧教育系列の未確認単位を人数と断定しない。集計人数から個人の移動や運命を断定しない。家計の一例を全国平均へ置き換えない。

## 読者のUI

内部仕様・調査手順・管理ID・入力系列コード・モデルの説明を通常画面へ表示しない。本文は問い、観察できる事実、暮らしと制度の関係を中心にする。共通の注意は「この本について」の一箇所。個別の出典、対象、単位、欠測は任意の詳細から確認できる。単なる注釈の増量で正確さを示さない。

本文16px以上、44px操作面、3pxフォーカス。明朝の見出し、ゴシックの本文、Georgiaの年と数字を使う。日本語はシステム書体で、フォントファイルの再配布はしない。写真上の番号と図・グラフの色を共通配色でそろえる。初回表示・読み込み失敗・検索結果なし・範囲入力のエラーも設計する。

## 検証と公開

主対象のPC画面で、8章の移動、写真の見どころと拡大、2組の比較、7テーマの数値図、1900年を含む統計操作、出典、暮らし検索、補足を確認する。小画面は横にはみ出さず操作できることを最低限確認する。面白さ・分かりやすさをbuild成功や件数だけで判断しない。

`npm run check`で原値の保持、史料の参照整合、欠測と単位、説明図の量、構文と配布物を確認。実際に操作した範囲と未確認範囲は分けて記録する。

ユーザーの「公開しちゃっていいよ」という指示は継続。今回の教材への更新に必要なPR・CI・main統合・既存GitHub Pages配備を行う。公開URLで実操作とconsoleを確認し、同じ配備runの成果物と公開ファイルをSHA-256で照合する。リリースタグ追加は不要。以前の箱庭の文書と検証記録は過去版として保持する。
