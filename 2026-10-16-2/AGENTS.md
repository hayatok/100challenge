# 箱庭日本

## Goal / Context / Constraints / Done when

- Goal：1900年から現在までの史実・政府統計の流れを固定し、その中でランダムな人・家・店・移動を眺める箱庭日本シミュレータを新規制作する。
- Context：ユーザーは直前の配置パズルを面白くなく、膨大な調査を生かしていないと評価し、抹消・作り直しを明示した。基本は見るだけで進み、歴史やマクロデータは改変せず、ミクロにランダム性を持たせる。
- Constraints：旧「まちの続き」は撤回・削除。調査台帳と歴史閲覧版 `2026-10-16/` は保持。2026-10-17にユーザーが「公開しちゃっていいよ」と明示。箱庭日本の公開に必要なPR・CI・main統合・GitHub Pages配備を進める。既存の無関係な変更は含めない。政府統計の取得はestatのみ。原値・単位・対象期間・欠測・出典を保持する。
- Done when：日本列島の箱庭が自動で時代を進み、住民と交通が動き、複数の統計が目に見える変化に結びつく。同じ歴史・統計のままランダムな暮らしを再生でき、停止・速度・年代・追跡・出典を操作し、実画面で確認できる。

## 固定するものと変えるもの

歴史の出来事、政府統計の値、対象・単位・欠測は固定。プレイヤーが歴史や全国人口・景気を書き換える操作を置かない。模型の人の名前・家族・配置・移動・日常の小さな出来事をseed付き乱数で変える。模型を実在個人の人生や統計上の追跡結果と呼ばない。

2026-10-17の追加指示により、第3版の53表・15,728観測・184出来事・105生活史料・259出典を入力とする。使った内容と未採用を明記し、全データを万能な式へ混ぜない。表示上の欠測を補間・前年値に置換しない。過去の資料を模型の背景に使う場合も観測年を明示する。追加採用の計画は `docs/RESEARCH_ADOPTION_V3.md`、生活描写の規則は `docs/MICRO_LIFE.md`。

## 実装とUI

HTML/CSS/ES modules、Canvas/SVGによる日本の箱庭、Node標準のサーバー/buildを基本とする。依存が必要なら理由を説明する。操作UIは共通 `--ui-*`、本文16px/1.6、44px操作面、3pxフォーカス。外部フォントファイルなし。

配置、予算、勝敗、目標達成のパズルを持ち込まない。開くと動き始め、眺めるだけでも世界が変わることを第一にする。操作は一時停止・速度・年代・興味のある場所/人の観察・別の暮らしの再生。内部仕様や台帳の作業語をUIに置かない。出典と確かめられていない範囲は自然な日本語で示す。

グラフィックとデータの結びつきを実装前に `docs/PLAN.md` に記録する。人口、働き方、住まい、交通、食や消費など、採用できた複数の信号が何を変えるかを明示する。見た目だけ年を変えた箱庭と扱わない。地図の輪郭・地域と全国統計の範囲を同一視しない。

複数担当を使う場合は編集範囲を分け、親がデータの採用・グラフィック・観察体験を統合する。自動テストは原値の保持、seedを変えてもマクロが変わらないこと、乱数再現性、年の境界と欠測、追跡の持続、保存と再生を確認する。ブラウザで自動進行・停止・速度・年代・人物/場所の観察・出典を実操作する。

## 公開の完了条件

ユーザーの公開指示を記録した `docs/RELEASE.md` に従う。既存のDeploy GitHub Pagesをmainの対象コミットで手動実行し、成功した配備の成果物と公開ファイルをSHA-256で照合する。公開URLで年代・場所・人物・出典/欠測・保存・小画面を実操作してから完了とする。リリースタグの追加は不要。
