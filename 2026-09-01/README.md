# やってる感

具体的なことを言わずに、進んでいる感じを出す進捗報告ジェネレーターです。

## Goal

対象、実際の状況、文体、曖昧さを入力し、事実を増やさずに進捗報告の文字数だけ増やします。

## Modes

- 通常モード: ローカルの文型と語彙を組み合わせて即時生成
- ローカルAIモード: WebLLMとQwen2.5 0.5Bを使い、端末内だけで生成
- フォールバック: WebGPU非対応、読込失敗、生成失敗時は通常モードを維持

ローカルAIモードはユーザーが明示的に有効化した場合だけモデルをダウンロードします。入力した対象や状態をアプリのサーバーへ送信する処理はありません。

## Development

```bash
npm install
npm run dev
npm run check
```

## Product decisions

- ログイン、バックエンド、外部LLM APIは使わない
- 完了、リリース、合意などの事実を捏造しない
- 生成結果は編集可能にする
- AIが使えなくても主要機能を失わない
- ジョークは文言と画像で表現し、操作の分かりやすさを犠牲にしない
