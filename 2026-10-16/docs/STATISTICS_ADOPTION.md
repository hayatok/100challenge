# 初期年表の統計グラフ採用点検

点検日：2026-10-16。対象は「生まれ年を選び、その年の年齢と統計・出来事・生活史料を並べる」初期体験。機械可読の判断は `data/adoption/statistics_checks.json` に記録した。既存v2正本とExcelは変更していない。

取得済みestat出力・メタデータ・raw注記、v2で確認した公式方法文書を照合した。4数値ファイルのreceipt SHA-256が一致することも確認した。今回、新しい統計値は取得していない。採用可は出典にある観測値の表示を認める判断であり、比較条件や歴史研究がすべて解決した意味ではない。

## 全グラフに共通する契約

- 1900～2026は作品のナビゲーション範囲。各統計の収録期間を1900～2026へ拡張しない。2026年を選んだとき、2025年値を2026年値として表示しない。「この年の採用値なし。最終取得年は○年」とする。
- 年コードを明示的に解釈する。観測年・公表日・更新日を分け、取得済みコード以外の年を生成しない。ソート順は昇順、重複キーはtable_idと全次元コードで判定する。
- 欠測と収録範囲外と未取得を区別し、空白を0にしない。欠測をまたぐ補間・外挿・平滑化はしない。年次平均の線を表示しても、線上の中間位置に新しい数値を返さない。
- 生まれ年だけの入力では `選択年 − 生まれ年` を「その年に迎える年齢」と表示する。誕生日前後の満年齢を確定した表現にしない。出生前は「生まれる前」。統計はその人のコーホートを追跡した値ではない。
- 値の詳細には指標、年、単位、地域、母集団、出典リンク、原値と表示換算を付ける。人と件、円と指数は同じ数量として積み上げない。出来事と統計の同時変化だけから因果関係を示さない。

## CPI

[表0004052037](https://www.e-stat.go.jp/dbview?sid=0004052037) の `area=00000 / cat01=0001,0002 / tab=1 / time=YYYY000000` のみ。56暦年×2指標が取得済み。1970～2025内は公式接続指数として線をつないでよい。歴代品目・ウエイトは固定ではなく、接続指数から計算した変化率と公式公表変化率が一致しない場合がある。

初期版の変換は年コード・表示桁だけ。旧2005／2020年基準の水準を継ぎ足さず、前年比の再計算を公式率として表示しない。1900～1969はこの系列の未取得、2026は採用した暦年平均値なし。家計支出の実質化や個人の生活費換算は採用範囲に含めない。

## 家計月額

[表0002070003](https://www.e-stat.go.jp/dbview?sid=0002070003) の `area=00000 / cat02=03 / tab=01 / cat01=059,060,102,152`。消費支出・食料・住居・教育の名目月額年平均。農林漁家を含む二人以上世帯で、単身者を含む全世帯平均や同一家族の追跡値ではない。月額の確認根拠はv2出典E2S05/E2S15。

2000年を開始点とし、1985～1999の60個の「-」は描画値にしない。2026の月次値を年平均へ代用しない。円から千円・万円への表示換算は可。消費支出は食料等を含む総額なので、総額と内訳を合わせた積み上げは不可。住居支出を市場家賃や帰属家賃込みの住宅費と説明しない。分類・調査方法改定の全履歴は未照合であり、値の変化を物価だけの変化や家族個人の変化に帰さない。

## 出生・死亡・婚姻の実数

[表0003411561](https://www.e-stat.go.jp/dbview?sid=0003411561) の `cat01=00110,00150,00270`。元証拠の369値には1899年の3値があるが、初期体験では除外して366値を使う。全国人口や率で割り直さず、原表の掲載実数を棒・点で提示する。出生数・死亡数は人／年、婚姻は件／年で別図にする。万人・万件への表示換算のみ可。

1944～1946は戦災による資料喪失等資料不備で省略されている。1943と1947を線で結ばない。1947～1972は沖縄除外、1973で集計範囲が変わる。初期版では1900～1943、1947～1972、1973～2024を分けて表示し、どの区間も全期の国籍・届出・領域対応は未確定であることを明示する。2025～2026に速報を無条件接続しない。

rawの1948／1949の概数注は「＊印」についての記述であり、今回の出生数・死亡数・婚姻件数では＊を確認していない。一律に概数表示する根拠にはしない。新生児死亡の定義変更や率分母の注を、採用していない指標からこの3実数へ転用しない。実数は個人の生存・婚姻・出生確率ではなく、出生数と死亡数の差だけを全人口の増減ともしない。

## 国勢地域人口は保留

[表0003410379](https://www.e-stat.go.jp/dbview?sid=0003410379) は全国＋47都道府県、1920～2020の21期で1008セルを取得済み。1945沖縄の1セルは「-」。人口推計やSSDを加えて年次化しない。

1920～1940の現在人口から戦後の常住基準への変更、1945年11月1日の人口調査、1950の6か月基準と1955以後の3か月基準、復帰前沖縄の異なる基準日、旧領域・地域組替え対応がある。1960の境界紛争地域は全国には入るが長野・岐阜いずれにも入らない。初期版で正確な比較表示をする負担に対して任意の指標なので保留する。後年や地域を限定した観測点表示を採用する場合も、範囲と基準日を確認した別の採用点検を必要とする。
