# ローカル作品版の実装計画

2026-10-16。ユーザーは試作を基に、生まれ年・年の操作で統計・出来事・暮らしをたどる作品のローカル実装を依頼した。追加でグラフィックを重視し、内部仕様めいたUI文言を避けるよう指定した。

## Goal / Context / Constraints / Done when

- Goal：実データと生活のイラストを用い、資料をめくるように日本の近現代をたどれる、単体で起動するWeb作品を作る。
- Context：既存試作、統計採用条件、再利用点検、177出来事・9生活カード・382統計セル。原台帳と初版・第2版のExcelは保持。
- Constraints：ローカルのみ。外部API/CDNへの依存なし。政府統計の数値はestat取得値、個別家計は明示した学術分析。元の原画像を転載しない。現在の日本の領域を過去へ遡及しない。欠測・未掲載・対象外を埋めない。
- Done when：一つの起動コマンドで開け、主要操作・出典・欠測・保存復元・狭い画面を実ブラウザで確認でき、生成画像が実際に組み込まれ、適切なテストとbuildが成功する。

## 制作順序

1. 既存の採用データを作品用の静的JSONと由来記録に書き出す。研究正本は変更しない。
2. ブラウザ標準の画面と、状態/年対応/統計表示の純粋関数を分けて実装。読み込み中・失敗・再試行と不正な保存を処理する。
3. 描き下ろしイラスト、二段の年表、統計図、生活の記録と出来事、出典を統合する。
4. ローカル保存・URL復元、キーボード、欠測・範囲端、画面幅を実操作で確認し修正する。
5. 実装・検証・未確認事項を記録。専用worktreeへ作品のソースを移し、研究原画像や無関係な作業を含めずレビューを用意する。

## 画面と画風

暖かな紙面と墨、朱、灰緑。見出しは端末の日本語明朝体、操作はシステムゴシック。追加フォントファイルを配布しない。共通 `--ui-*` トークンを使い、本文16px/1.6、補助13px、44pxの操作面、3pxのフォーカスを維持する。

上部は作品名と読み方。大きな年と年齢を、横長の暮らしのイラストに並べる。年の操作と出来事/生活記録のある年が分かる二段の年表が入口。資料は「暮らし」「社会の数字」「出来事」を読みやすい順で置き、出典と限界は各資料から開く。

イラストは3場面（教員の机、農村の日々、街の住まい）。年代帯に応じて表情を変えるが、選択した年・実在家族の姿を再現した史料とはしない。キャプションと読み方でイラストであると分かるようにする。絵の切替は自動再生せず、操作に対して短く応答。動きを減らす設定では補間しない。

空の年でも、近くの年の記録へ移れる入口を置く。その年の体験であるようには表示しない。時期が不明の地方史料は独立した棚から読める。年齢は年内に到達する年齢で、個人の生死や職業を推定しない。

## 技術と同梱

HTML/CSS/ES modules、ローカル同梱D3 7.9.0、Node標準の静的サーバーとファイルコピーによるbuild。D3は既存試作の軸と観測点を引き継ぐために使用する。フレームワーク・DB・認証は不要。npmの追加パッケージなし。

`app/data/history.json` が作品の採用済み配布データ。元の資料ID、原値、単位、対象期間、出典URLを保持する。`provenance.json` にestat由来と元入力ハッシュを残す。研究資料・大きなPDF・原画像・Excelはbuildへコピーしない。元台帳の再生成は作品の通常buildと分ける。

ブラウザの保存は生まれ年・見る年・指標だけ。URLの `y` / `b` / `m` に選択を反映し、不正な値は既定値へ戻す。外部へ送信しない。読み込みに失敗したら静かな説明と「もう一度開く」を表示。出典はHTTPSリンクのみを使う。
