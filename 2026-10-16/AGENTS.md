# 時代のとなりで

## 対象と制約

1900年から2026年まで、生まれ年と見る年を動かして統計・出来事・暮らしをたどるローカル作品。公開・配備・リリースタグは別の依頼があるまで行わない。Goal、画面方針、完了条件は `docs/LOCAL_APP.md`。

このcheckoutは作品と採用済みデータを扱う。元の調査正本・Excel・大型PDF・原史料画像は作業元のローカル調査フォルダに保持し、作品buildに含めない。

## データ

- 政府統計の検索・定義確認・数値取得は `estat` CLIを使う。コマンド、日時、終了コード、原出力、SHA-256を記録する。APIキーは保存しない。
- `app/data/history.json` が採用データ、`editorial.json` が読者向け説明、`provenance.json` が元入力と派生データのハッシュ。`tests/fixtures/estat/` の3表の原出力とreceiptで382セルを直接検査する。
- 欠測を0や補間値に置き換えず、収録前・未取得・欠測を区別する。2026年へ前年値を代入しない。人口動態は全期の領域対応が未確定なので線で結ばない。
- `docs/STATISTICS_ADOPTION.md` と `docs/REUSE_ADOPTION.md` の条件を守る。個別家計の学術分析は政府統計・全国平均へ読み替えない。原文・画像の転載許諾を事実紹介から推定しない。
- 期間が不明の史料を開始年だけでその年の生活へ割り当てない。留保・出典内の位置を落とさない。

## 実装と検証

本体 `app/`、Node標準のサーバー/build `scripts/*_app.mjs`、純粋関数と採用データの契約テスト `tests/`。同梱D3 7.9.0のほか新しいnpm依存はない。

- 起動 `npm run dev -- --open`
- 検証 `npm run check`（テスト・構文/資産/由来の点検・build）
- 静的出力 `npm run build`、確認 `npm run preview -- --open`
- 実画面の検証と未確認事項 `docs/LOCAL_VERIFICATION.md`

UIに試作・採用系列・正本・区分コード・台帳や開発工程の文言を出さない。読者に必要な対象・欠測理由・史料の限界は自然な日本語で残す。共通 `--ui-*` 配色、本文16px/1.6、44px操作面、3pxフォーカスを守る。日本語は端末の明朝体/システム書体を使い、外部フォントを読み込まない。

グラフィックは `docs/ART_ASSETS.md` の独自イラストと実データの図。絵と特定の年・家族の史料画像を同一視しない。UI変更は1440/1024/736/375/320pxで実際に操作し、出典・空状態・欠測・読込失敗/再試行・保存復元・キーボードを確認する。

将来のゲーム要素は `docs/GAME_DESIGN.md`。現段階は歴史閲覧で、創作のifや個人確率を事実表示へ混ぜない。
