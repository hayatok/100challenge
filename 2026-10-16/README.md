# 時代のとなりで

生まれた年を置いて、日本の近現代を行き来するローカルの歴史閲覧作品です。1900〜2026年を動かし、社会の数字、出来事、一人ひとりの暮らしをたどれます。

## 起動

Node.js 22以降を使用します。追加パッケージのインストールは必要ありません。

```sh
cd 2026-10-16
npm run dev -- --open
```

`http://127.0.0.1:4316/` が開きます。macOSでは `作品をひらく.command` をダブルクリックしても起動できます。終了は起動したターミナルでCtrl+C。4316番が使用中なら `npm run dev -- --port 4318 --open`。

## 読めるもの

- 生まれ年と見る年、和暦、その年に迎える年齢。
- 出生・死亡、物価、家計の消費支出。図や年表からも年を選べます。
- 177件の出来事。期間のある出来事はその期間の各年から読めます。
- 9つの生活記録。記録期間を確かめた4件と、時期・終期の不明な5件を区別します。
- 原値・対象・単位・欠測理由・集計範囲の変化、史料の出典と分かる範囲。
- 暮らしのイラスト3点。特定の年や実在家族を写した史料ではありません。

選択は端末に保存し、URLにも反映します。閲覧時の外部API・CDN接続はありません。出典リンクを押した時だけ外部の資料サイトへ移動します。

## データの範囲

政府統計はestat CLIで取得した382セルです。出生・死亡は1900〜2024年（1944〜46年は欠測）、2025年基準の物価は1970〜2025年、全国の二人以上世帯の消費支出は2000〜2025年。2026年を前年の数値で埋めていません。戦前を含む人口動態の国籍・領域の全期対応は未確定で、年を結ぶ線は描きません。

家計簿や回想の紹介は個別の事例です。O家・K家の現金家計費は学術論文による私的記録の分析で、政府統計・全国平均ではありません。原史料の画像・音声・全文を同梱していません。

`app/data/history.json` は採用済みの閲覧データ、`editorial.json` は読者向けの説明、`provenance.json` は由来と入力ハッシュです。研究正本全体は通常のbuildに不要です。`tests/fixtures/estat/` に3表の原出力と取得記録を同梱し、382セルを直接照合します。
