## 1. Task definition

### Goal

コンウェイのライフゲームを、8bitの小さな庭として眺めたり、種をまいて変化へ参加したりできる、勝敗のないブラウザミニゲームを作る。

### Context

- 共通方針: `../../docs/DESIGN.md`
- フロントエンド方針: `../../docs/FRONTEND.md`
- デイリーアプリの共通スタイル: `../../docs/DAILY_APP_STYLE.md`
- 生成済みアセット: `../public/life-garden-sprites-v1.png`
- 前作とは題材を変えつつ、「役目に対して設備と語り口が大げさ」という馬鹿馬鹿しさを継承する

### Constraints

- ライフゲームの基本更新則はコンウェイの `B3/S23` を使う
- スコア、ランキング、制限時間、ゲームオーバーを設けない
- ログイン、バックエンド、外部API、通信を必要としない
- マウス、タッチ、キーボードのいずれでも主要操作を行える
- 画面を常時派手に動かさず、変化はセルの世代交代と短い環境演出に限定する
- `prefers-reduced-motion` を尊重する
- 生成済みスプライトは原本を保持し、加工版は別ファイルとして作る
- ジョークは生命の死滅ではなく、それを観測する人間側の過剰な設備と文言へ向ける

### Done when

- 自動で世代交代する庭を眺められる
- 再生、一時停止、1世代進行、速度変更、新しい庭、全消去が動作する
- 盤面へ種を追加・除去できる
- 誕生、成長、安定、消滅が8bitの植物表現で区別できる
- 全滅しても操作不能にならず、穏やかに再開できる
- 初期画面だけで「小さな庭に対して装置が大げさ」というジョークが伝わる
- 375px、768px、1024px、1440pxで主要操作と盤面が成立する
- ゲームロジックの単体テスト、lint、型チェック、buildが通る
- 実ブラウザで通常、空、停止、再生、再播種、モバイル操作を確認する

## 2. Product concept

### Product name

**いのちの庭**

### One-line description

768マスの大自然を、必要以上の設備で見守る8bitライフゲーム。

### Primary experience

ユーザーは「高度生命観測装置 一号機」の前に座り、庭の変化を観賞する。必要なときだけ盤面へ触れ、変化のきっかけを与える。正解を探すのではなく、予想外の模様が生まれては消える時間と、そのためだけに用意された大げさな装置の馬鹿馬鹿しさを楽しむ。

### Experience principles

1. **見守ることが主役**: 操作パネルより庭を大きく見せる。
2. **生命は静かに変化する**: 誕生や消滅は短く穏やかに伝える。
3. **失敗を作らない**: 全滅や停滞も庭の状態として扱う。
4. **触ると応える**: 種をまいた場所から必ず視覚的な反応が返る。
5. **ルールは正直に**: 基本の生命判定は `B3/S23` のままにする。
6. **装置だけが大げさ**: 庭は静かに、外側の観測UIは用途に対して過剰に扱う。
7. **命ではなく人間を笑う**: 全滅を罰や嘲笑にせず、観測側の深刻ぶった態度をジョークにする。

## 4. Game rules

### 4.1 Logical board

- サイズ: 32列 × 24行、合計768セル
- 境界: 上下左右がつながるトーラス境界
- 更新: 全セルを同一世代の状態から同時更新する
- セルの論理状態: `alive` または `dead`
- 初期密度: 生存セル26〜32%の範囲からランダム生成
- 乱数: シード付き疑似乱数を使い、テストで再現可能にする

トーラス境界を採用する理由は、画面端で模様が突然欠ける印象を減らし、庭全体が連続しているように見せるため。

### 4.2 Conway B3/S23

各セルの周囲8セルを近傍とする。

- 死んでいるセルは、生存近傍がちょうど3個なら誕生する
- 生きているセルは、生存近傍が2個または3個なら生存する
- それ以外の生きているセルは死滅する

### 4.3 Visual metadata and transitions

論理状態とは別に、描画用メタデータを保持する。

- `age`: 連続生存世代数。誕生時は1
- `stableAge`: 自身と近傍構成が連続して変化しなかった世代数
- `bornAt`: 誕生した時刻。誕生演出だけに使う
- `diedAt`: 死滅した時刻。論理上は死だが、描画オーバーレイだけに使う

描画の目安:

| 状態 | 表現 |
| --- | --- |
| 誕生から220ms以内 | 明色ピクセルの芽。ぼかしや光彩は使わない |
| `age` 1〜2 | 小さな芽 |
| `age` 3〜5 | 二葉 |
| `age` 6以上 | 葉の多い植物 |
| `stableAge` 8以上 | 花。セル座標から決まる色を使う |
| 死滅から300ms以内 | 土へ溶けるピクセル |
| 死セル | 土または空のセル |

花は追加の生存能力を持たない。ゲーム結果へ影響しない純粋な視覚表現とする。

描画優先順位は `死亡オーバーレイ > 誕生演出 > 花 > ageによる植物 > 土` とする。死亡オーバーレイは次世代計算へ参加せず、300ms後に破棄する。同じセルが300ms以内に再誕生または手動追加された場合は、古い `diedAt` を即座に破棄して生存表示を優先する。手動で追加したセルは `age = 1`、`stableAge = 0`、`bornAt = 操作時刻` とし、手動で除去したセルは死亡オーバーレイだけを生成する。

`stableAge` は生存セルだけが持つ。各世代の更新後、そのセルを中心とする3×3の生死ビット列が、直前世代の更新後と一致した場合に1増やす。誕生、手動変更、ビット列の不一致では0へ戻し、死セルは常に0とする。

### 4.4 Extinction and stagnation

#### Phase state machine

ゲームは次の4フェーズのいずれかにある。

| Phase | Meaning | Automatic tick |
| --- | --- | --- |
| `running` | 自動再生中 | あり |
| `paused` | 生存セルがある停止状態 | なし |
| `reseeding` | 自然全滅後の1.5秒の待機 | なし |
| `empty` | ユーザー操作または1世代進行で空になった状態 | なし |

主な状態遷移:

| Event | From | To | Reset behavior |
| --- | --- | --- | --- |
| 自動tickで生命数0 | `running` | `reseeding` | 世代数は維持 |
| 再播種タイマー完了 | `reseeding` | `running` | 新しい盤面、世代0、速度維持 |
| 一時停止 | `running` | `paused` | 盤面、世代、速度を維持 |
| 再生 | `paused` | `running` | 盤面、世代、速度を維持 |
| 1世代進行で生命数0 | `paused` | `empty` | 世代は1進む |
| 手動編集で生命数0 | `running` / `paused` | `empty` | 世代数は維持 |
| 空の庭へ種をまく | `empty` | `paused` | 世代0、速度維持 |
| 新しい庭 | any | `running` | 新しい盤面、世代0、速度維持 |
| 全消去を確定 | `running` / `paused` | `empty` | 空の盤面、世代0、速度維持 |

`empty` では再生、1世代進行、全消去をdisabledにし、「種をまく」または「別の宇宙にする」を案内する。`reseeding` では再生、1世代進行、全消去をdisabledにし、待たずに再開したい場合は有効な「別の宇宙にする」を使う。

#### 自然全滅

生命数が0になった場合:

1. `reseeding` へ遷移し、自動更新を停止する
2. 合計1.5秒の間「生命反応を見失いました。装置は深刻そうに再播種します」と、風で種が運ばれる短い演出を表示する
3. 新しいシードで初期盤面を生成する
4. 世代を0へ戻し、全滅前と同じ速度で `running` を再開する

自然全滅とは、`running` の自動tickの結果として生命数が0になった場合だけを指す。手動編集、全消去、停止中の1世代進行で0になった場合は `empty` とし、自動再播種しない。

`reseeding` 中の操作規則:

- 盤面編集と新しい庭は、古い再播種タイマーを必ず破棄してから操作を実行する
- 盤面編集は `empty` からの編集として扱う
- 新しい庭は即座に `running` へ移る
- 再生 / 一時停止、1世代進行、全消去はdisabledとし、ダイアログや追加タイマーを発生させない
- 速度変更と操作説明はタイマーを破棄せず、再播種後へ設定を引き継ぐ

#### 完全な停滞・周期

同一盤面が連続した場合もゲームは継続する。Version 1では周期検出による介入を行わない。安定セルが花へ変わるため、静止状態にも観賞上の意味がある。

## 5. Interaction specification

### 5.1 Primary interaction: 種をまく

- 停止中・再生中を問わず、死セルを選ぶと生セルにする
- 生セルを選ぶと死セルに戻す
- ポインターを押したまま移動すると、開始セルで決まった操作を通過セルへ適用する
  - 死セルから開始: 通過セルへ種をまく
  - 生セルから開始: 通過セルを取り除く
- 同じドラッグ中に同じセルへ複数回入っても1回だけ処理する
- ドラッグ開始から終了まで自動tickを保留し、終了後は次の完全なtick間隔から再開する
- Canvasの表示矩形とポインター座標から `floor((x / width) * 32)`、`floor((y / height) * 24)` でセルを求め、範囲内へ制限する
- 盤面は `touch-action: none` とし、pointer captureを使う。`pointerup` と `pointercancel` の両方で編集状態とtick保留を解除する
- 盤面外では通常のページスクロールを妨げない
- 操作したセルは即座に短い土跳ねまたは発芽反応を返す

### 5.2 Controls

| Control | Behavior | Keyboard |
| --- | --- | --- |
| 観測を再開 / 時を止める | 世代の自動更新を切り替える | `Space` |
| 生命を1回だけ進める | 停止中に1回だけ更新する | `N` |
| 速度 | じっくり見守る、ふつうに見守る、せっかちに見守る | `1`、`2`、`3` |
| 別の宇宙にする | 新しいランダムシードで開始する | `R` |
| 庭を空にする | 確認ダイアログ後に盤面を空にし、停止する | `C` |
| 操作説明 | 短い説明パネルを開閉する | `?` |

テキスト入力中やダイアログ操作中はショートカットを発火させない。Canvasフォーカス中は `Space` / `Enter` をセル切り替えに使い、`preventDefault` して再生操作を発火させない。Canvas外では `Space` を再生 / 一時停止に使うが、ボタンがフォーカスされている場合はブラウザ標準のclickだけを発火させ、グローバル処理を重ねない。

### 5.3 Speed

| Label | Tick interval |
| --- | --- |
| じっくり見守る | 900ms |
| ふつうに見守る | 450ms |
| せっかちに見守る | 180ms |

保存済み速度がない場合の初期値は「ふつうに見守る」。速度を変更しても世代番号や盤面状態はリセットしない。

## 6. Screen specification

### 6.1 Main screen

#### User goal

庭の変化を眺め、好きな場所へ種をまく。

#### Information hierarchy

1. 庭の盤面
2. 観測を再開 / 時を止める
3. 別の宇宙にする
4. 速度と補助操作
5. 世代数、生命数、操作説明

#### Desktop layout: 768px以上

- 上部: 管理ラベル「LIFE OBSERVATION UNIT 01」、タイトル「いのちの庭」、短い説明
- 中央: 最大960px幅、4:3比率の庭を、過剰に頑丈そうな観測装置のフレームへ収める
- 装置上部: 「観測世代」「現在の命」と、静的なジョーク表示「宇宙への影響：ほぼなし」
- 庭の直下: 黄色い大型の「時を止める / 観測を再開」を中心とする操作列
- 下部: 速度、補助操作、操作説明
- 盤面以外をカードで囲まず、背景帯と罫線で区切る

#### Mobile layout: 767px以下

- タイトルと静的ジョーク「宇宙への影響：ほぼなし」を表示し、英語の管理ラベルと導入説明は初期viewportから省略する
- 盤面は左右16px以上の余白を確保し、幅いっぱいの4:3
- 主操作は2列以内で配置し、44px以上のタップ領域を確保する
- 速度は `じっくり / ふつう / せっかち` の短い3択を表示し、グループ名またはaccessible nameで「見守る速度」であることを伝える
- 補助操作は盤面の下へ折り返す
- 横スクロールを発生させない

盤面サイズは幅に加え、`100dvh` からタイトル・主要操作の必要高を引いた値を上限とする。375×667と1024×768でも、盤面と「時を止める / 観測を再開」が初期viewport内に見えることを優先する。44×44pxの対象サイズはHTMLコントロールへ適用し、Canvasは連続的に種を描く入力面として例外にする。モバイルでの単セル精密編集はVersion 1の必須要件にしない。

### 6.2 Visual direction

#### Metaphor

黒い生命セルを、小さな植物が生える「庭」として見せる。庭の外側は、用途に対して不必要に頑丈で仰々しい「高度生命観測装置 一号機」として構成する。世代交代は芽吹きと土への還元で表現する。

ジョークの中心は、768セルの小さな庭に対して、国家事業のような管理番号、計器、太い筐体、大型ボタンが用意されている設備過剰さとする。ジョーク用の別キャラクターや無関係な装飾は追加しない。

庭は全画面幅で最大の連続した面とし、装置より先に視線が向く大きさとコントラストを保つ。管理ラベル、計器、留め具は庭の外周へ従属させ、庭の上へ重ねない。

#### Palette

| Role | Color | Usage |
| --- | --- | --- |
| Canvas | `#F3EBD8` | 紙と土の間の明るい背景 |
| Ink | `#1C2B20` | 文字、太い輪郭 |
| Soil | `#6B4428` | 死セル、盤面の下地 |
| Leaf | `#4F8A3A` | 生存セルの主色 |
| Light | `#F2C94C` | 誕生、主操作、ホタル |

実装時にコントラストを測定し、本文と操作ラベルはWCAG AAを満たす。状態は色だけで表さず、形と動きも併用する。

#### Shape and typography

- 盤面と主要ボタンには2〜3pxの暗い輪郭を使う
- 影はぼかさず、2〜4pxの硬いオフセットに限定する
- 盤面は角丸カードにせず、太い外枠、四隅の留め具、機械ラベルを持つ観測モニターとして扱う
- 留め具はCSSの単純な円形と罫線で表現し、操作アイコンと誤認させない
- 主操作は黄色い大型の物理ボタン風にし、押下時だけ2〜3px沈む
- 装置全体をカードの集合にせず、1つのまとまった機械として見せる
- 計器の数値は固定幅を確保し、世代数・生命数の更新でレイアウトを移動させない
- 装置側へ常時アニメーション、点滅、針の振動を追加しない
- タイトルは太い日本語ゴシック、数値と補助ラベルは等幅書体
- UIアイコンの代わりに、意味が明確な短い日本語ラベルを優先する

### 6.3 Motion

- 世代更新時にセル位置を移動させない
- 誕生: 120〜220msの小さなスケールアップ
- 死滅: 180〜300msで土ピクセルへ縮小
- 開花: 250〜400msで1回だけ開く
- 全滅後の風: 1.5秒の `reseeding` 内で完了。入力された場合は演出を中断する
- 主操作: 押下中だけ大型ボタンが2〜3px沈み、離すと戻る
- 新しい庭: 装置の表示が150〜250msだけ横方向に切り替わる。画面全体を点滅させない
- 常時の浮遊、点滅、背景パーティクルは使わない
- `prefers-reduced-motion: reduce` では拡大縮小と飛来を停止し、スプライトの即時差し替えと短い文言だけで状態を示す

### 6.4 Copy and humor

#### Tone

- 装置は小さな庭を、世界的に重要な対象であるかのように真顔で扱う
- 文言は短く、機能の意味を失わない範囲で大げさにする
- ジョークを全要素へ入れず、初期画面で見える強いジョークは「宇宙への影響：ほぼなし」の1つに絞る
- 植物の誕生や死滅を嘲笑しない。「何も起きていないのに観測側だけが深刻」という方向に統一する
- 危険、故障、警報を多用せず、癒やしを不安や焦りへ変えない

| Storage unavailable | `観測装置は設定を忘れました。庭への影響はありません。` |

ジョーク調の可視ラベルには、平易な機能サブラベルを同じbutton内へ表示する。例: `別の宇宙にする` の下に `新しい庭` を置く。accessible nameはbutton内の可視テキストから得るか、明示する場合も `別の宇宙にする — 新しい庭を始める` のように可視ラベルを先頭へ含める。音声操作で画面上の言葉をそのまま発話できる状態を保つ。

状態通知は可視ジョークと分離する。`reseeding` ではpolite statusへ一度だけ「生命数0。1.5秒後に新しい庭を開始します」と通知し、可視コピーを重ねてlive announceしない。ショートカット説明でも機能の明確さを優先する。

## 7. Required states

| State | Expected UI |
| --- | --- |
| Initial loading | 盤面枠と「観測装置を必要以上に準備しています」。レイアウトを移動させない |
| Running | 世代が進み、主ボタンは「時を止める」になる |
| Paused | 盤面編集可能。主ボタンは「観測を再開」、「生命を1回だけ進める」が有効になる |
| Empty by user | 「観測対象なし。装置だけが待機しています。種をまくか、別の宇宙を始めてください」 |
| Extinct naturally | `reseeding`へ移り、「生命反応を見失いました。装置は深刻そうに再播種します」後、自動再播種する |
| Asset failure | 「高性能表示装置の準備に失敗しました」と伝え、単色のピクセル植物へフォールバックする |
| Storage unavailable | 「観測装置は設定を忘れました」と伝え、ゲームは継続する |
| Reduced motion | 状態差は保ち、移動・点滅を使わない |
| Hidden tab | 自動更新を停止し、復帰時に経過時間分を一括計算しない |

## 8. Persistence and privacy

### localStorage

保存する項目:

- 速度
- 操作説明を閉じたか

保存キーには `inochi-no-niwa:v1:` の接頭辞を付ける。Version 1では盤面、世代、再生状態、描画メタデータを保存せず、起動するたびに新しい庭を世代0から「ふつうに見守る」または保存済み速度で再生する。

保存に失敗してもゲームを止めない。速度は3つの許可値だけ、操作説明は真偽値だけを受け付け、破損データは無視する。

### Privacy

- 外部通信なし
- Cookieなし
- 解析タグなし
- 個人情報の入力なし

## 9. Technical design

### Proposed stack

- Vite
- React
- TypeScript
- Canvas 2Dによる盤面描画
- HTML要素による操作UI
- Vitestによるゲームロジックテスト
- oxlintによるlint

Reactは画面状態と操作UIを管理し、世代計算は純粋関数として分離する。Canvasは描画だけを担当し、ゲームルールを持たない。

### Proposed modules

```text
src/
  App.tsx                 画面構成と上位状態
  game/
    board.ts              盤面生成、近傍計算、B3/S23更新
    board.test.ts         ゲームルールの単体テスト
    metadata.ts           age、stableAge、描画状態
    random.ts             シード付き疑似乱数
    preferences.ts        速度と操作説明設定の検証・読み書き
  components/
    GardenCanvas.tsx      Canvas描画とポインター操作
    GardenControls.tsx    再生、速度、新規、消去
    GardenStatus.tsx      世代数、生命数、状態文言
    HelpPanel.tsx         操作説明
  assets/
    sprites.ts            スプライト座標とフォールバック定義
  styles/
    tokens.css            アプリ固有トークン
    app.css               レイアウトと状態
```

### Timing model

- `setInterval` をゲーム状態の正としない
- `requestAnimationFrame` 内で経過時間を測り、設定間隔を超えたときに最大1世代だけ進める。更新後は余剰時間を捨て、基準時刻をその時点の `now` へ置き換える
- バックグラウンド復帰時は差分を捨て、復帰時点から再開する
- visibility復帰、pointerup、pointercancel、速度変更時も基準時刻を `now` へ戻し、次の完全なtick間隔より前に更新しない
- React Strict Modeでタイマーが重複しないよう、開始・停止を明示的に管理する

### Rendering

- Canvasの内部解像度はCSS表示サイズ × `devicePixelRatio`
- 論理セルの位置は整数ピクセルへ丸め、画像補間を無効にする
- `imageSmoothingEnabled = false`
- 盤面の論理サイズは常に32×24、表示サイズだけをレスポンシブに変更する
- Canvasが利用できない場合は、簡易メッセージと再試行を表示する

## 11. Accessibility

- Canvasに「32×24のいのちの庭。現在N個の植物、世代M」のアクセシブルな名前を付ける
- 状態文言は世代ごとにライブ読み上げせず、再生・停止・全滅・再播種などユーザーに重要な変化だけ通知する
- 盤面編集用にキーボードカーソルを持たせる
  - Canvasへ初めてfocusしたときの位置は左上の列1・行1
  - 矢印キー: `preventDefault` してセル移動。端ではトーラス境界と同様に反対端へ回る
  - `Enter` / `Space`: 選択セルの生死を切り替える
- キーボードフォーカス中のセル位置を盤面上へ明確に描画する
- キーボードカーソルを移動したときだけ、専用のpolite statusへ「列X、行Y、芽あり / 空」を通知する。世代tickでは読み上げない
- セルを切り替えた直後も、同じstatusへ変更後の位置と状態を通知する
- ボタンのfocus-visibleを太い輪郭で表示する
- HTMLの操作対象は44×44px以上を目安とする。Canvasは連続描画面として例外にし、キーボードカーソルを代替手段として用意する
- 色覚に依存せず、芽・葉・花・土の形で状態を区別する

## 12. Testing strategy

### Unit tests

- B3: 死セルが近傍3個で誕生する
- S23: 生セルが近傍2個・3個で生存する
- 過疎と過密で死滅する
- トーラス境界で左右・上下がつながる
- ブリンカーが2世代で元へ戻る
- ブロックが静止する
- age、stableAge、bornAt、diedAtと描画優先順位が正しく更新される
- ブロックが安定し、定義した世代で開花条件へ到達する
- 同じ乱数シードから同じ初期盤面が得られる
- 速度・操作説明設定の正常、欠損、破損値を処理できる
- ユーザー全消去では自動再播種しない
- 自然全滅では再播種状態へ移る
- 手動編集または1世代進行で0になった場合は空のまま停止する

### Interaction tests

- 再生、一時停止、1世代進行
- 速度変更後も盤面を維持する
- クリック・ドラッグで意図した生死を設定する
- キーボードでセルを移動・切り替えできる
- Canvasフォーカス中のSpaceで再生状態が同時に変化しない
- pointercancel後に編集状態とtick保留が解除される
- `reseeding`中の盤面編集と新しい庭で古いタイマーが破棄される
- `empty` と `reseeding` では再生、1世代進行、全消去がdisabledになる
- 全消去ダイアログで確定時だけ空になり、キャンセル時は盤面とフォーカスが保たれる
- 非表示タブから復帰して世代が飛ばない
- 長いframe停止、visibility復帰、pointer終了、速度変更後は1世代だけ進み、次の完全なinterval前に連続更新しない
- キーボードカーソル移動とセル切り替えで位置・生死を通知し、世代tickでは通知しない

### Browser and visual checks

- Width: 375×667、768px幅、1024×768、1440px幅
- State: 初期、再生、停止、空、自然全滅、再播種、アセット失敗
- Input: マウス、タッチ相当、キーボード
- Motion: 通常、`prefers-reduced-motion`
- Layout: 文字欠け、重なり、横スクロール、盤面のぼやけ、初期viewport内の盤面と主操作を確認
- Humor: 初期画面で「小さな庭に対して観測装置が大げさ」という比喩が伝わり、ジョーク文言を読まなくても主操作の意味を特定できる。庭が最大の連続面で、装置が庭より先に視線を奪わない
- Tone: 空・全滅・エラー状態が攻撃的、不安を煽る、植物を嘲笑する表現になっていない
- Mobile humor: 375×667では英語の管理ラベルと導入説明を省略し、庭、主操作、短縮した速度ラベル、静的ジョークを優先する
- Screenshot: 375pxと1440pxで最低1枚ずつ保存して比較する
- Asset: alpha channel、160×128、20フレーム境界、チェッカー残存なしを機械確認し、白い花ときらめきを目視確認する

## 13. Acceptance criteria

1. 初期viewport内に庭と「時を止める / 観測を再開」が表示され、タイトル、短い説明、操作ラベルから目的を判断できる。
2. 保存済み速度がない初回表示では自動再生され、速度「ふつうに見守る」で約450msごとに1世代進む。
3. B3/S23とトーラス境界が単体テストで証明される。
4. ユーザーは盤面をクリック、ドラッグ、タッチ、キーボードで編集でき、pointercancel後も次の操作を継続できる。
5. 再生、一時停止、1世代進行、3速度、新しい庭、全消去が機能する。
6. 誕生、若いセル、成熟セル、安定セル、死滅が視覚的に区別できる。
7. 自動tickによる自然全滅後だけ1.5秒で再播種し、手動編集、1世代進行、全消去による空盤面は停止する。
8. `reseeding`中の盤面編集と新しい庭は古いタイマーを破棄し、後から盤面を上書きしない。再生、1世代進行、全消去はdisabledである。
9. Canvasフォーカス中のSpaceは選択セルだけを切り替え、再生状態を変えない。
10. 長いframe停止や画面非表示中に世代が進まず、復帰・pointer終了・速度変更後も次の完全なintervalより前に追いつき更新しない。
11. 派生atlasはRGBA 160×128、20フレームで、背景チェッカーを含まない。品質条件を満たせない場合もフォールバック描画でゲームを続行できる。
12. 外部通信を行わず、保存設定が不正でも起動できる。
13. 375×667から1440px幅まで横スクロールがなく、HTML操作は44×44px以上で、1024×768を含め初期viewport内に盤面と主操作が見える。
14. reduced motionでも誕生、成熟、安定、死滅、再播種を判別できる。
15. `npm run check` がtest、lint、TypeScript build、Vite buildをすべて実行して成功する。
16. キーボードカーソルは列・行・芽あり / 空をユーザー操作時だけ読み上げ、世代tickごとには読み上げない。
17. 初期画面に管理ラベル、過剰な観測装置の外枠、静的表示「宇宙への影響：ほぼなし」があり、用途に対して設備が大げさというジョークが伝わる。ただし庭が画面内最大の連続面で、装置より先に視線を集める。
18. 装置側には常時アニメーション、点滅、針の振動がなく、世代数・生命数の更新でレイアウトシフトしない。
19. 375×667では英語の管理ラベルと導入説明を省略し、庭と主操作を初期viewportで優先する。速度表示は `じっくり / ふつう / せっかち` とする。
20. ジョーク調ボタンのaccessible nameは可視ラベルを先頭に含み、続けて平易な機能名を伝える。`reseeding` は機能的なstatusだけを一度通知する。
21. 実ブラウザで主要状態と操作を確認し、375×667と1440px幅のスクリーンショットをレビューする。

## 15. Product decisions

### 2026-09-02 基本ルールはConway B3/S23を保つ

- Decision: 癒やし表現は描画と全滅後の再播種で加え、通常世代の生命判定は改変しない。
- Reason: 「ライフゲーム」としての予測可能性と面白さを残すため。
- Alternatives considered: 雨によるランダム死、低密度時の常時ランダム誕生。
- Revisit when: 全滅頻度が高すぎて観賞体験が継続しないと実測された場合。

### 2026-09-02 固定論理グリッドを使う

- Decision: 全画面幅で32×24を維持し、Canvas表示サイズだけを変える。
- Reason: リサイズで庭が変わらず、保存形式とテストを単純にできるため。
- Alternatives considered: 画面幅ごとにセル数を変える、無限盤面。
- Revisit when: 375pxでセルの識別・操作が難しいとブラウザ確認された場合。

### 2026-09-02 音はVersion 1から外す

- Decision: 初版は視覚体験に集中し、音楽・効果音を含めない。
- Reason: 自動再生制約、音量設計、ミュート状態まで含めるとデイリーアプリの範囲を超えるため。
- Alternatives considered: Web Audioの短い発芽音、環境音ループ。
- Revisit when: 無音では観賞体験が不足するとユーザーレビューで判断された場合。

### 2026-09-02 盤面は永続化しない

- Decision: Version 1で保存するのは速度と操作説明設定だけとし、起動時は毎回新しい庭から始める。
- Reason: 盤面だけでなく年齢・安定度・演出時刻まで正確に復元する複雑さを避け、日次ミニアプリの核へ集中するため。
- Alternatives considered: 盤面と世代だけを保存する、全描画メタデータを含めて保存する。
- Revisit when: 育てた庭を後から続けたいという要求が明確になった場合。

### 2026-09-02 大げさな生命観測装置をジョークの核にする

- Decision: 静かな庭を、用途に対して過剰な「高度生命観測装置 一号機」で囲み、真顔の機械ラベルと操作コピーで馬鹿馬鹿しさを出す。
- Reason: 前作の「真面目な道具として成立しながら、目的と演出の落差で笑える」温度感を、業務ジョークを繰り返さず継承するため。
- Alternatives considered: 植物を擬人化する、全滅時に派手なゲームオーバーを出す、キャラクター案内役を追加する。
- Revisit when: 装置の外枠が庭より目立ちすぎる、ジョーク文言が操作理解を妨げる、または全滅表現が癒やしを損なうとブラウザレビューで判断された場合。
