# Integration contract

Godot 4.7.2; root game/main.tscn uses main.gd. No global class_name required; preload scripts locally to avoid import ordering cycles. Strong explicit types where GDScript inference hits Variant.

World: world.gd extends Node3D, root adds it as World. _ready builds environment/floors/anchors/colossus but NOT enemies/player/UI. Methods get_spawn() -> Vector3 (0,0.15,7), get_enemy_spawns() -> Array[Vector3], get_checkpoint(position:Vector3) -> Vector3. Signals core_hit, core_destroyed. Own colossus.gd. Colossus core and anchors use group "tether_targets", kind metadata "anchor" or "core"; enemies use kind "enemy". Targets are Node3D whose global_position is tether arrival/aim point. Optional is_available()->bool. Core receive_hit(damage:int,launch:bool,origin:Vector3)->bool returns true when accepted. Core can take hits near shoulder platform. Main listens core_destroyed to finish; not just reaching position.

Player: player.gd extends CharacterBody3D, main instantiates then adds at world.get_spawn(). _ready constructs collider, model loader, camera rig; world enemies exist before play. Variables health:int=100, air_dashes:int=2, active:bool=false, current_target:Node3D, camera:Camera3D, state_name:String, combo:int, total_kills:int; methods reset_at(pos:Vector3), clear_input(), set_active(bool), apply_settings(Dictionary), take_damage(int,Vector3), play_animation(name:String). Signals damaged, died, action_performed(action:String), enemy_defeated. Camera rig owns camera; exposes camera property on player. Player emits actions e.g. dash, slide, wire, launch, slash, plunge, land. Input actions move_left/right/forward/back, jump, dash, attack, heavy, wire, lock, pause. Root sets keyboard + joy bindings. Mouse capture is root lifecycle; player only rotates camera if active and captured. Pause by tree paused; main/UI process_mode ALWAYS. Don't auto-capture in player. clear_input cancels held/queued actions, velocity but no resource loss.

Enemies: enemy.gd extends CharacterBody3D; main instantiates at world spawns. Target group "tether_targets" kind "enemy", group "enemies". Constructor is new(); set player via enemy.player after creation. Methods receive_hit(damage:int,launch:bool,origin:Vector3)->bool, is_available()->bool. Signal defeated(enemy). Player calls receive_hit and on final blow increments total_kills & air_dashes capped 2 and emits enemy_defeated. Enemy handles visual death but never awards duplicate kill. Enemy can be launched, gravity/fall applied. AI only starts attack on camera-visible enemy, telegraphs, no unfair offscreen new attacks. World/main controls resets by recreate enemies.

Art: hero.glb and sentinel.glb under game/assets/models. Rigged stylized angular cohesive characters with meaningful silhouette; feet at Y=0 after glTF export; face -Z. AnimationPlayer named clips idle, run, slide, jump, fall, wire, slash_1, slash_2, slash_3, launch, plunge, hurt, death (one-shot matching, idle/run looping). Player loads asset when available, finds AnimationPlayer recursively; use authored real rig motions, preserve blend source. Optional ruins.glb if useful but world owns architecture itself. No dependency between build script and art at runtime.

Root main/UI: owns title/start/restart/pause/settings/result, telemetry/FPS to log only (not user flow), custom drawn target reticle via camera unproject_position, health/dash HUD, stage contextual hint. Native Forward+ Metal and Web Compatibility feature override. Sound from local generated WAVs; no external calls.

QA: root may expose --qa runtime deterministic input harness separately documented; normal UI/player inputs remain primary proof. No auto-win. Never claim fixture tests are human playtest. Root writes game/tests/run.gd; gameplay worker may supply tests/notes to root but not own tests to prevent overlap.
