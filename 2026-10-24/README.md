# 天砕 — TENSAI

雲海に浮かぶ遺跡を、剣とワイヤーで駆け抜ける三人称3Dアクションの制作計画。

滑走から敵へ接近し、打ち上げて追撃し、地面へ叩きつける。敵を倒して空中ダッシュを補充し、次の敵や足場へ渡る。

macOSアプリを主対象にし、ブラウザ版も用意する。ブラウザの制約を理由にアプリ版の品質を落とさない。

- [このアプリの制作指針](AGENTS.md)
- [ローカルへの引き継ぎ](docs/HANDOFF.md)

現在は計画段階。ゲーム本体、アート素材、実行可能なビルドはまだない。計画内の時間・種類数・性能値は、初期検証で調整する目標値。

制作開始日は日本時間の2026年10月24日。既存アプリの変更と公開はこの計画に含めない。
