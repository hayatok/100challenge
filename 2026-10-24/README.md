# 天砕 — TENSAI

雲海に浮かぶ遺跡を、剣とワイヤーで渡る三人称3Dアクション。macOSを品質の基準にし、Web版も同じ操作・戦闘・区画を使う。

現在はG0〜G1の試作。開始足場から軽兵の広場を抜け、動く巨像の肩へ接続し、核を斬って急降下で帰還する一区画を実装した。主人公と軽兵には編集できるBlender原本・リグ・13種の動作がある。巨像は経路と衝突を検証する仮形状で、完成したボスではない。

試作への品質評価を受け、[新しいアートと戦闘の制作案](docs/REBUILD.md)を作成した。[人物・中庭・UIの設定画](art/direction-v2/README.md)は設計用の生成画像で、ゲームには未実装。以下の起動・操作説明は旧試作のもの。

## 起動と出力

Godot **4.7.2.stable** と同版のmacOS／Webエクスポートテンプレート、Node.js 22以上を使う。macOSでは `/Applications/Godot.app` を既定とし、別の場所にある場合は `GODOT_BIN` に実行ファイルを指定する。モデルの作り直しにはBlender 5.2.1を使う。npmの追加依存はない。

この日付フォルダで実行する。

```sh
npm run import       # 素材をGodotへ取り込む
npm test             # 衝突・接続・資源・ポーズの回帰検査
npm run dev          # macOS上でゲームを起動
npm run build:mac    # builds/TENSAI.zip と .app を作る
npm run build        # dist/ にWeb版を出力
npm run preview      # http://127.0.0.1:4248/
```

macOS出力はローカル試遊用のアドホック署名。Developer ID署名・公証・新規ダウンロード後の起動試験は未実施。Universal形式の出力でも、Intel Macを動作確認済みとは扱わない。Web版はHTTPで配信し、HTMLファイルを直接開かない。

## 操作

| 行動 | キーボード・マウス |
| --- | --- |
| 移動／視点 | WASD／マウス |
| ジャンプ | Space |
| ダッシュ／滑走 | Shift／地上で長押し |
| ワイヤー | E。小さな印が付いた対象へ接続 |
| 対象の固定／切替 | Q／固定中にホイール |
| 斬撃 | 左クリック。続けて入力すると三段 |
| 打ち上げ／急降下 | 地上／空中で右クリック |
| ポーズ | Esc |

空中ダッシュは2回、撃破で1回補充する。敵への空中接続は着地まで各1回。固定アンカーは敵がいなくなっても使える。核を3回斬った後、広場へ向けて跳び、急降下して着地すると帰還になる。

体力がなくなったら「再挑戦」。落下時は安全な足場へ戻り、体力を10失う。広場への到達と設定は端末内へ保存し、次回の「つづける」で広場から再開する。パッドの割当は実装しているが、実機パッドは未検証。
