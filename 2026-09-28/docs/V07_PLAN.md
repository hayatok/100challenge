# Alpha 0.7: 最初の一区画の質感と撃破演出

## Goal / Context
v0.6から、商店街入口の代表場面と着衣ゾンビ、手と銃、環境に絡む撃破を改善する。承認画像、V04_ENVIRONMENT、V06_MOTIONと既存入力・戦闘を参照。game-design/level-designの前ターン評価を継続する。

## Constraints
無料・登録不要でゲームへ配布できる素材。既存モデルのリグと演技を保持し、新規モデル追加と材質改修を区別する。通常戦ルール・期限・採点は変更しない。入力帯は固定、低モーションを維持。全面エンジン移行や全マップ追加はしない。割当量節約のため調査は再利用、素材取得/台帳はLuna、人物改修はSol、統合・区画・銃・確認はメイン。ファイル責務を分離。

## Plan
1. 既存画面を確認、前回公開mainから分岐。Issue #130を継続。
2. シャッター/アスファルトの1K PBR素材6枚を取得し出典/寸法/hashを記録。読み込み失敗時は既存手続き素材へ戻す。
3. 入口一区画の店舗奥行き、縞の庇・看板、荷物や商品を整理し、影と光の読みやすさを改善。左右の店先に反応する商品台を置き、通常撃破で小物が弾ける演出を加える。採点は通常撃破のまま。
4. 代表着衣ゾンビの顔・服・肌の読み分け、銃の材質・握り・見え方を改善。新旧を同じ照明下で確認する。
5. テスト/lint/type/buildと実画面で一区画の撃破・低モーション・全区間回帰を確認。PR/CI/Pages、配信ファイル照合と公開プレイ。

## Done when
入口、代表ゾンビ、手と銃に実ゲームで見分けられる改善がある。環境撃破は一度の撃破に一度だけ反応し、休止・再挑戦で正しく復旧する。新素材失敗でもプレイ可能。効果と未達の品質をスクリーンショット/検証記録へ正直に残す。
