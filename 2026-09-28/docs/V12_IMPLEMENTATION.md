# v0.12 店内の造形と一人称モデル

担当: Astra。範囲は現行の短い一勤務のアート改善。新しい面、待ち時間、入力数、採点ルールは追加していない。

## 変更前の診断

`art/verification/v12-before-store.png` は変更前の実ブラウザから保存した画像。`store-v11-target.png` と `journey-approved-v10.png` は構図・質感の参考であり、背景として貼っていない。v0.11では瓶・缶・袋の輪郭が似ており、棚の支柱、冷蔵ケース、天井の構造が薄く、大きい緑の面が画面を占めていた。人物の裸腕と禿頭、横向きに見える拳銃と離れた手も、店員と一人称の読みにくさにつながっていた。

## 実装

- `store-interior.ts`: 店内の造形を独立したモジュールで作り直した。低い天井、丸い二灯式蛍光管と吊り棒、金属支柱と穴、折り返した棚縁、胴・肩・細い首がある瓶、巻いた紙ラベル、缶の蓋、柔らかい米袋、紙パックを制作。棚は商品種ごとに陳列する。右側にはルーバー付き冷蔵ケース、傾斜ガラス、野菜の重なった葉と茎、結露した窓を配置。奥は開いた扉、側棚、箱、椅子、吊り灯のある作業室にした。
- 架空の商品・値札・看板、壁/金属/タイル/木の汚れはCanvasで制作。素材の色、粗さ、金属反射、光源位置を組み合わせ、冷たい売場と暖かい奥室に明暗差を付けた。背景の小物は材質ごとに静的ジオメトリへ結合し、個別の小物数だけdraw callが増えないようにした。
- `character-costume.ts`: 既存City GLBの身体・衣服から頂点とスキン属性を複製し、袖付きシャツ、店名入りエプロン、短い頭髪を制作。元スケルトンとbind matrixを維持するため、骨に貼った硬い板ではなく、歩行・反応・ねじりに沿って変形する。シャツと重なる元の破れた上着面は除き、二重面の交差を防ぐ。短髪は薄い頭皮表面とフラグメント単位の生え際を使う。既存の二種類の原型、アニメーションを維持。
- `characters.ts`: 袖と胴を同じ服色にし、肌に黄褐色を戻した。LuckyとBossのエプロン色を分ける。
- `weapon.ts` / `scene.ts`: 拳銃をカメラ中央へ寄せ、測定した元GLBのグリップへ左右の手を配置。使用していなかった別の腕GLBの読み込みを除いた。既存の銃口と発光位置 `(0,.03,-.28)` は維持し、銃と両手が同じ親で照準・反動に追従する。ショットガンへの切替時には拳銃の両手も非表示になる。

外部素材・依存の追加はない。元GLBの利用条件は `THIRD_PARTY_NOTICES.md` を継承する。追加の造形、印刷物、手続き的材質は本アプリ用のオリジナル制作。

## 検証

実ブラウザは1280×720で通常UIの開始→`go`→2キー相当の店内選択→路地の2語を入力して到達。生成画像や検証用の隠し状態は使っていない。

- 初回比較 `v12-store-draft.png`: 店内の密度と立体構造を確認。袖が白く、髪の縁が粗い問題を確認して修正。
- 第二比較 `v12-store-second.png`: ラベルの方向、短い髪、エプロンの胴への追従を確認。シャツと元衣服の交差、手元の低さを確認して再修正。
- 最終比較 `v12-store.png`: 低モーション/1280×720、袖〜胸の交差解消、肩紐、短髪、左右の手、棚/ケース/奥室を確認。
- 通常モーションの店内: 歩行・傾き・射撃の反応で衣装が身体へ追従。3文字を入力→休止→再開の `go`→残りを入力して撃破し、入力進捗が維持されることを確認。
- 低モーションの店内ルートを屋上と結果まで1周。店内3戦、Luckyの3文と+500点、ショットガン4群、拳銃への復帰と3体の狙い分け、Bossの3段階/5文、屋上→勤務終了を確認。最終5,150点、17連撃、100%正確率、巻き込み8体、Lucky大当り。保存: `v12-lucky.png` / `v12-fever.png` / `v12-boss.png` / `v12-roof.png` / `v12-result.png`。
- この周回でショットガンの構えが従来より低いことを見つけ、最終コードではショットガンの高さと左右照準角をv0.11の値へ戻した。主担当が最終ビルドの通常演出・搬入口ルートで構えと可読性を確認し、`v12-fever.png`を更新済み。
- 通し中のコンソールerrorはなし。マップ無し材質へ `undefined` を渡す警告を見つけ、`null`へ修正。
- `npm run check`: 83/83自動テスト、lint、TypeScript、production build成功。既存の700kBチャンク警告は継続。厳密なFPS計測、別ブラウザ/物理キーボード/IME/実音の聴取、375px、搬入口ルートはこの担当の検証に含まない。
- 設定は元の練習OFF・画面の動きONへ戻した。通常勤務の結果を上書きしない練習結果のみ1件保存された。

## 限界

参考画像の写実的な顔、指、布の厚み・皺、透過するガラス、細かな汚れやライティングには差がある。新しい完全な人物モデルや物理的な布シミュレーションは制作していない。小物は近距離でも形を読めるようにしたが、Canvasの印刷図柄や手続き的な造形に規則性が残る。build成功だけをアート完成とみなさない。
