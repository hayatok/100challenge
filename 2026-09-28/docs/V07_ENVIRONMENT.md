# v0.7 入口と環境反応

## 舞台と材質
入口左の一区画を、暖色の奥まった喫茶店「純喫茶 よなか」に変更。奥壁・床・天井・カウンター・カップ・吊り照明と、縞の庇・前向き看板を自作した。その他の区間を全面再制作したものではない。

路面とシャッターへPoly Havenの1K PBRを適用。色だけsRGB、凹凸/粗さは非色データとして同じUVで反復する。3枚のいずれかが失敗した面は一式を採用せず、既存の手続き素材を保持する。追加取得量は約4.20 MiBで、当初の約2MB目安を超える。無加工の原本を採用し、不要な追加素材は取得しなかった。

カメラに追従する1024pxの影と弱い環境反射を追加し、正面の均一な照明を下げた。既存の濡れた路面表現は静的な疑似反射であり、動的SSRではない。銃の光沢・凹凸・粗さを整え、銃と手を入力帯より上に持ち上げた。新しい銃や腕モデルではない。

## 商品台の反応
入口の左右に12本ずつ缶を置いた商品台を配置。近くで通常敵を直接撃破すると、敵位置から最寄りの未反応台へ跳弾が届き、天板が傾いて缶が弾ける。金属/ガラスの既存音を重ねる。敵そのものを棚へ投げ込む物理衝突ではない。

- 入口・距離7m以内、通常の直接撃破のみ。ボス・ラッシュ・巻き込みは対象外。
- 左右各1回。24個の缶と共有geometry/materialを再利用し、毎撃破の新規生成をしない。
- 簡単な重力・床バウンド後に停止。低モーションは初速・回転・天板の揺れを抑制。
- 休止でdelta=0、再勤務/チェックポイント復帰時は配置をリセット。
- 入力・スコア・コンボ・敵の期限には介入しない。

見た目の繰り返しが出やすい簡素な小物であり、全面破壊システムではない。参考画像の人物造形・手の握り・路面反射にはまだ差がある。
