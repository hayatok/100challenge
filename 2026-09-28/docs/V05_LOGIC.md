# v0.5 戦闘ロジック

## ねらいと進行

通常入力の緊張が続いたあと、短語を連続で撃つ解放区間を入れる。正面の作業員が爆発を持つ場合は、撃破前に隣接レーンへ届くことを示し、まとめて倒す選択を作る。ボス第2区間は短い反撃語を3回通してから次の区間へ進む。これらの秒数と得点は設計仮説で、体感の妥当性は実プレイで調整する。

## FEVER / ラッシュ

- 通常敵の直接撃破でチャージを18増やし、その語に誤入力・被弾がなければさらに7増やす。最大100。誤入力は残りのチャージを減らさない。ボス、爆発の巻き添え、ラッシュ中の短語では増やさない。
- チャージ100に達しても現在の敵と期限は変更しない。通常ウェーブの敵が全員解決した境界で開始する。1プレイ最大2回。開始時にチャージを0にし、2回目の開始以降は増やさない。
- 4語を1体ずつ生成し、間に0.18秒、最初だけ0.35秒の移動を置く。各語の期限は `0.8秒 + 標準キー数 ÷ 難度CPS × 1.45`。最後の解決後に通常進行へ戻る。
- `rushStart` / `rushEnd` はそれぞれ開始回数を `count` に載せる。`rushEnd.success` は4語をすべて撃破した場合だけ `true`。期限切れで進行した場合も区間は終わるが、完遂表示にはしない。`GameState.rushing`、`rushRemaining`、`rushes`、`EnemyView.rush` は表示用。`rushRemaining` はこれから解決する短語を含む数で、開始時4、終了時0。`rushes` は結果欄と同じ開始回数。
- ポーズと再開カウントダウン、ウェーブ間の移動では戦闘時計と期限が停止する。期限ちょうどの最終キーは成功、過ぎていれば攻撃を先に解決する。

## 爆発

- 第2ステージの第3ウェーブ、第3ステージの第2・第3ウェーブの作業員を爆発持ちにする。作業員は中央、ほかの敵は左右の別レーンに置き、`EnemyView.explosive` と `blastTargets` に、現在隣接する敵のIDを公開する。対象はレーン差が1以内の通常敵。ボスは対象外。
- 爆発持ちを直接倒した時点で対象を即座に解決する。直接撃破の `kill` に続き、各巻き添えに `kill` イベントを `collateral:true` で出し、最後に `explosion` を出す。`explosion.enemyId` は爆発元、`count` は巻き添え数。
- 巻き添えは1体75点。クリーンコンボ、チャージ、正打数を増やさない。`GameResults.chainKills` には巻き添えの累計を記録する。直接撃破の既存得点式は維持する。入力途中のロック対象へ別の敵に切り替えられない既存ルールを守る。

## ボスの反撃

- 第1区間と第3区間は従来の語を使う。第2区間は専用の短語を3つ、0.35秒の回復を挟んで順に出す。3語目の成功まで `bossPhase` は1のまま。期限切れでは同じ語を再提示し、成功してから次の語へ進む。
- `GameState.bossCounter` は第2区間で現在挑む語の番号1〜3、それ以外は0。`bossPhase` イベントは第2区間の最初の2語の成功時に `phase:1,count:1/2`、3語目の成功時に `phase:2,count:3` を出す。表示側は `phase:1` を区間完了として扱わない。
- 第1区間後の回復0.75秒、第2区間完了後の回復1.2秒を維持する。ボスの失敗時は従来どおり0.5秒で再提示する。

## 再現と検証範囲

結果に `seed`、`rushes`、`chainKills` を記録する。リプレイ用シードは0〜`0xffffffff`の整数に限る。語の選択と配置はシードから決まり、再試行チェックポイントはチャージ、ラッシュ回数、連鎖撃破数、使用済み語集合を復元する。自動テストでは語の重複回避、全難度の期限内入力、同時出現の先頭キー、正確な得点、休止、ラッシュ境界と期限ちょうど・超過、連鎖、ボス3語、チェックポイントを確認する。画面上の読みやすさ、爆発予告の理解、ラッシュの気持ちよさ、難度はブラウザでの通しプレイが必要。
