# v0.5 結果と次回目標

## 目的

プレイ後に一つだけ具体的な次回目標を示し、記録されたシードで同じ出題順を再試行できるようにする。結果の比較は同じルール番号、難易度、練習設定の記録に限る。

## 保存と互換性

- v0.5 の `rulesVersion` は `4`。スコア比較と自己ベストはバージョンごとに分離する。
- `seed` は 0 から 2³²−1 までの整数、`rushes` と `chainKills` は 0 から 10,000 までの整数を任意項目として保存する。不正な任意項目は除外し、結果本体は残す。
- `seed` がない古い記録には同じシードでの再プレイを案内しない。シードは出題順の再現に使う値であり、入力内容や操作結果まで再現するものではない。
- 保存コンテナ `version:2` のルール番号欠落行は v0.4 の `3`、それ以前のコンテナは `2` として読み込む。既存のベストと直近10件を保持する。
- `chainKills` は爆発する敵による隣接レーンへの巻き込み撃破数で、通常の敵撃破やボスへのヒットは含めない。

## 次回目標

`nextGoal(result)` は `{title, detail}` を一つ返す。前回が敗北なら完走を先に示す。クリア時は、記録に基づき「初ラッシュ」「初連鎖撃破」「次の最大コンボ境界 3 / 6 / 10 / 15」「次の正確率 90 / 95 / 98 / 100%」「リトライなし」の順に選ぶ。すべて達成済みなら、正確な完走をもう一度目指す。未記録の任意項目をゼロとはみなさない。目標は次回結果で達成を確認できるものに限定し、計算できないスコア到達を約束しない。

## 確認

自動テストでは旧記録のルール分離、任意項目の往復、不正シードや非数値の除外、目標の優先順位と上限を確認する。実ブラウザでの表示、同じシードでの再開、入力感触は別途確認する。
