# v0.8 音のご褒美設計

既存の配布済み銃声・打撃・金属・ガラス・ベルを使い、Web Audio の短い音階を追加した。新規素材・依存関係はない。音源の出典と配布条件は [ALPHA_AUDIO.md](ALPHA_AUDIO.md) を参照。

| 契機 | 音の変化 |
| --- | --- |
| 通常打鍵 | 3 種類の銃声と着弾を即時再生。最終打鍵には二発目の短い銃声、金属音、低音、上位段階では高い一音を重ねる。 |
| 撃破・コンボ | 打撃、金属、上位段階のガラスに、段階で音程と音数が増す短い和音を加える。段階到達と 20 コンボ以降の 5 刻みには別の上昇フレーズを使う。 |
| FEVER 入場 | 金属・ベル・低音と 4 音の上昇合図。連続する 4 体の撃破はそれぞれ 1 段ずつ高い和音になる。 |
| FEVER 完走 | ベル・ガラスと 5 音の上昇ファンファーレ、短い低音。失敗時は低い金属音だけで退場する。 |
| LUCKY 当たり | 入場・各単語に明るい音を加え、成功時は上昇ファンファーレとベル・ガラス。失敗時は静かな下降音。 |
| 最終勝利 | 既存のベル連打に 6 音の上昇を加える。 |

主銃声は打鍵時に遅延なく開始する。打鍵・撃破判定は音の完了を待たない。録音サンプルは gun 4、impact 5、accent 3、総数 12 ボイスまで。シンセは LUCKY のループ 32 とイベント音 24、低音 2 まで。各シンセ音のゲインは最大 0.22 で短く減衰し、最終段にはマスターのコンプレッサーを通す。効果音の音量・ミュートはイベント音を含めて設定に従い、ポーズ・停止時は予約済み音も止める。

実装接続: `rushStart()` でカウンターを 0 に戻し、FEVER 中の非巻き添え撃破ごとに `rushKill(1..4)` を呼ぶ。`rushEnd(event.success)` は完走と中断を区別する。`rushEnd()` の無引数呼び出しは互換のため成功扱い。`kill()` と `shot()` の従来 API は維持する。

自動テストは音程上昇、発音数の上限、ミュート、停止時の予約音破棄を確認する。聴感、実ブラウザでの音圧、長時間プレイ時のバランスは別途実機確認が必要。
