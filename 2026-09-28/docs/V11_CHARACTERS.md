# v0.11 人物の読みやすさ

## 目的と基準

店内の実画面 [`v10-store.png`](../art/verification/v10-store.png) では、近景の敵が肌も服も灰色の石のように見え、店員という役割も判別しにくかった。生成された [`journey-approved-v10.png`](../art/reference/journey-approved-v10.png) は衣服・顔・手の情報量の品質目標であり、実画面の証拠ではない。既存のライセンス記録があるリグ付き GLB を使い、店内を起点に全区画の人物を改善する。

## 変更

- 元 GLB の衣服と身体の別テクスチャを維持し、赤い傷と暗い縫い目の明度差をシェーダーで戻す。従来のほぼ一定の灰色化をやめた。
- 衣服の頂点高はメートル単位だったため、上着とズボンの境界を `0.90–1.07 m` に修正。従来の `87–103` は画像に見えるズボンへ適用されていなかった。
- 法線マップの強度をさらに下げ、肌が石の凹凸に見える印象を抑える。眼・歯の素材は顔から分かれる明度にする。
- 店員／店主／作業員の衣服色を分け、上半身とズボンの差を見えるようにする。ラッキー個体の識別色も残す。
- 攻撃予告中は胸の重心と両腕を少し前へ向け、元アニメーションの横へ伸びた腕が近景でT字に見える状態を和らげる。低モーション設定では補助姿勢の量を減らす。

外部素材、依存、原 GLB のライセンス条件は変えていない。骨に固定したエプロンの試作は、実画面で板状の布と襟が胴体から浮いたため撤去した。元リグの静止座標と変形後の胴体面が合わず、この方法では衣装として成立しない。人物本体は引き続きスキン付き3Dメッシュである。

## 検証と限界

`npm run typecheck`、`npm run lint`、`npm run test` を実施。実ブラウザの店内画面で肌の石状の質感が減り、顔の立体が前より見えることを確認した。最終版で浮いた衣装が残っていないか、他区画での見え方はアート全体の検証へ記録する。元モデルの頭髪、顔の造形密度、エプロン、袖と衣服の破れ、手の表情は未改修で、近景の写実性にはなお大きな差がある。
