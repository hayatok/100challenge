# アセット調達・制作方針

2026-09-28 / 方針案。個別の3Dモデル・動作・音源は未選定、購入なし。

## 承認された基準

[gameplay-approved-v1.png](../art/reference/gameplay-approved-v1.png)はユーザーが承認した画像生成コンセプト。
一人称、立体的な商店街、リアル寄りのゾンビ、手と銃、発砲と着弾、静止した入力帯を基準にする。
この一枚に3D形状や骨格、別方向からの見た目、アニメーションは含まれていない。画像をそのままゲーム用3Dモデルとして利用できるとは扱わない。

## 3Dと2Dの分担

- 3D：街、店舗、道具、ゾンビ、手と銃、カメラ、照明。ゾンビは骨格付きの立体モデルとして歩き、撃たれ、倒れる。
- 2D：日本語とローマ字、体力、コンボ、結果UI。銃口の炎・煙・火花にはカメラを向く粒子用画像も使う。
- ゲームジャンルは3Dレールシューター。移動と照準は自動で、操作をタイピングに集中させる。
- 部分的な2Dエフェクトは3Dゲームの構成要素。ゾンビと背景を一枚絵へ置き換える計画ではない。

## 全て自作にはしない

既存の高品質な汎用アセットを土台に、質感・衣装・動き・舞台配置・照明を合わせる。
画面に大きく映る顔、手、銃、被弾ポーズを優先し、単純な形状を寄せ集めたキャラクターを最終品質にしない。

| 対象 | 調達/自作の方針 | 採用前に確認するもの |
| --- | --- | --- |
| ゾンビ | 骨格・テクスチャのあるゲーム向け3Dモデルを探す。必要な服装・肌・色を調整 | 顔/手/服の近景、変形、歩行、GLB等への変換、ゲーム配信条件 |
| 歩行・攻撃・被弾・死亡 | モデル付属の動作を優先。足りない動作はMixamo等を候補に、骨格へ合わせて調整 | 接地、滑り、肩/手首の変形、動作間のつながり、被弾と死亡の切替 |
| 手と銃 | 一人称用の手・銃モデルと動作を優先して調達。必要なら組合せて修正 | 接写品質、握り、反動、銃の可動部、排莢位置。腕と銃が互いを貫通しないこと |
| 店舗と道路 | モジュール式の建物・小物を利用し、商店街の構成と目立つ店舗を制作 | 遠近感、反復の目立ち方、日本の街らしさ、描画負荷 |
| 路面・金属・壁の材質 | Poly Haven / ambientCG等のPBR素材を候補にする | 使用許諾、解像度、法線/粗さ、実寸の密度、濡れ感 |
| 日本語看板・ポスター・UI | 作品固有に制作。絵柄に必要なら画像生成を利用し、文字は別に組む | 可読性、造形の統一、ゲーム内の意味、素材の出所 |
| 発砲・薬莢・着弾・煙 | 既製の粒子画像や音を必要に応じ利用し、タイミング・光・動きを制作 | 高速打鍵時の重なり、キャラクター/HUDを隠さないこと |
| BGM・銃声・声 | 利用条件の合う録音素材を優先し、編集・ミックス・ゲーム同期を制作 | ステムの有無、ループ、反復感、クリップ、利用条件 |

Web/Three.jsを引き続き第一候補にする。アセットはできるだけ移植可能な形式で保持し、将来Godotを選ぶ場合も再利用可能にする。
モデルの追加や変換だけで見栄えが完成するわけではない。ライティング、素材の粗さ、霧、色調整、カメラの画角と敵までの距離を、実際の場面で統一する。
濡れた道の反射は環境反射・静的な照明・必要な限定的反射等を比較する。全画面の高コストな反射方式を導入すること自体を目標にしない。

## 調達元について確認したこと

- [Poly Haven公式ライセンス](https://polyhaven.com/license)：配布アセットはCC0。サイト自体の文章やプレビュー画像と区別する。
- [ambientCG公式ライセンス](https://docs.ambientcg.com/license/)：配布素材はCC0。実際に使用したasset IDと取得元を記録する。
- [Adobe Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)：キャラクター・動作のゲーム利用が案内されている。利用にはAdobe IDが必要。今回ログイン・取得・モデルアップロードは行っていない。

上記は候補サービスの情報で、特定のゾンビや銃が確保できたという意味ではない。
採用する各素材ごとに作者、元URL、取得日、ライセンス、改変内容、クレジット、ゲームへの組込み条件を記録する。元モデルをリポジトリへ公開できるかと、完成ゲームへ組み込めるかは別に確認する。
有料素材が必要なら、商品・価格・代替案と実際の見た目を提示してから購入を判断する。予算を仮定して購入しない。

## 最初に品質を確かめる順序

1. 基本ゾンビ、手と銃、街の一区画に絞って候補を選ぶ。
2. 実3Dシーンで、承認画像と同じ画角・敵の大きさ・照明に合わせる。
3. 正面の静止画を比較して、造形・材質・背景密度の差を修正する。
4. 歩行→発砲→被弾→撃破を動かし、入力と音を接続する。
5. 基準PCで性能と操作感を確認してから、残りの敵と区間を増やす。

生成画像と同一の画質・動作を現時点で保証しない。実モデルと実描画を並べて差を小さくしていく。素材が足りない場合は未解決として報告し、承認画像と異なる簡素な画風を黙って完成扱いにしない。
