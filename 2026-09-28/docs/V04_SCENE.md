# v0.4 出現・銃撃・決着

- 一般敵は0.85秒で店先側からレーンへ出る。出現演出中も打鍵可能。控えめ設定では横移動を省略。
- 通常敵の初期距離を6.6m、終点を2.8mにし、顔と手の見える大きさを確保。近づくと左右レーンを少し中央へ寄せ、画面外へ出にくくする。攻撃時計や得点は変更しない。
- 弾道と局所光は実際の頭/胸/肩の骨へ向ける。高コンボで最後のキーを受けた時だけ、0.16秒の局所光と0.7秒の薄い煙を返す。合計16個で上限管理し、フルスクリーンを白くしない。
- 撃破移動の水平速度に減衰を加え、回転を抑制。死亡クリップがある場合は跳ね上げない。ボスはルートを飛ばさず、骨による決着を使う。
- ボス区間への2.2秒の移動中に、店の奥z=-51から登場。同じ見た目の個体を本戦、段階回復へ引き継ぐ。最終撃破は3.1秒後に結果を表示。
- 銃の向きは敵の実際の横位置へ追従。GLBの独立したスライド2部品を反動に連動。最後のキーの反動は短い専用アクセントを付ける。
- 新しい閃光/煙のシェーダーもロード中に準備。ポーズ/カウントダウンで演出時計を止め、銃口光のランダム回転も止める。

入力・攻撃期限・BGMは演出待ちにしない。検証結果は `RESULTS.md` に集約。
