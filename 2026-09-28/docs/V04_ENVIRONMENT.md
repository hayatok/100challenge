# v0.4 商店街環境

2026-09-28。承認画像 `art/reference/gameplay-approved-v1.png` の湿った路面、暖色の店内と冷たい路地、古い店舗の密度を見た目の目標にした。画像そのものは背景として使用しない。全て `src/environment.ts` の Three.js 立体と固定シードの Canvas テクスチャで制作し、外部素材・追加ライブラリはない。

戦闘の通路はおおむね `|x| < 3.2` を空ける。小物・棚・支柱は歩道寄りに置き、敵と頭上ラベルの空間を確保する。屋根、看板、店舗、店内の棚と商品、裏路地の構造物、搬入口はすべて立体の形状である。

## 路面と光

- アスファルトの細粒に大きな雨染みを重ね、roughness map で濡れ具合を分けた。既存の小さな水たまり形状は残す。
- 固定シードで生成する透明 Canvas テクスチャ一枚に、各灯具の下の途切れた横筋と淡い色のにじみを描いた。動的な画面空間反射や追加の描画パスは使用しない。実際の店内灯・作業灯は影なしの局所 PointLight。
- 8 個の局所光はステージ沿いに離して配置し、屋根・店舗の奥行きで見え方を変える。コンボ時の明るさの変化は緩やかに限定。`update(time, level, motion)` の `motion=false` では灯りの揺らぎと埃の動きを止める。

追加素材の制作元、加工内容、利用条件はこの文書と `ENVIRONMENT_ASSETS.md` の既存台帳を合わせて参照。ブラウザでの画面比較・操作確認結果は `RESULTS.md` に記録する。静止画と型チェックだけで承認画像の品質到達や実操作の検証済みとは扱わない。
