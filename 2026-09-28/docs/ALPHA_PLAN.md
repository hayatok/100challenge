# Alpha 0.2 upgrade

Goal: 入力の正確さを邪魔せず、銃撃・撃破・コンボ到達の快感と遊びの厚みを増す。
Context: 承認済み3D画面、既存の24体+ボス3段階、既存のローマ字入力・保存・再開。
Constraints: PCキーボード/Web、リアル3Dの街とゾンビ。無料・登録不要、無料ゲーム配布に利用可能な素材（CC0限定なし）。有料購入・公開リリースなし。無関係なアプリを変更しない。

1. 別造形・別動作の敵モデルを追加し、役割とシルエットを対応させる。
2. 即時の発砲、強い命中反応、吹き飛びと撃破衝撃波、5段階のコンボ演出を実装。入力欄は固定。演出軽減を維持。
3. 実音源の銃声・着弾・撃破と、段階変化するBGMへ更新。
4. 通常300句以上・ボス12句以上、役割ごとの長さと出題制約を確認。
5. 敵の危険度・コンボ進捗・加点・ボス到達を伝えるHUDを統合。
6. 主要ロジック、ビルド、ブラウザでの通しプレイ・再開・設定・代表画面を確認。端末横断の性能計測はアルファの完了条件にしない。

Done when: 追加素材と音が実際のゲームで使用され、通常→高コンボの違いが見え、開始から結果まで通しプレイできる。出典、既知の制約、検証範囲を記録して既存PRを更新する。
