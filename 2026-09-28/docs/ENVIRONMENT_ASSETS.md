# 商店街環境の素材台帳

2026-09-28。`src/environment.ts` の商店街一区画から奥までの背景は、このアプリのために Three.js の立体形状と Canvas 生成テクスチャで制作した。外部配布のモデル、画像、音源、フォントファイルは現段階で組み込んでいない。

| 素材 | 制作元・形式 | 加工・用途 |
| --- | --- | --- |
| 舗道、古い壁、金属シャッター、屋根板 | 本アプリのコードで生成する 512×512 Canvas テクスチャ | 乱数を固定し、粒、汚れ、雨筋、金属の横溝を描く。商店街の 3D 面に反復貼付け |
| 日本語の店名、アーケードの吊り看板、ポスター、のぼり | 本アプリ用に書いた文字と Canvas で制作した 1024×256 または 256×768/384 のテクスチャ | 店舗ごとの色、退色、文字を描く。表示書体は端末にある日本語書体へフォールバックする |
| 屋根の骨組み、店舗、灯具、自販機、路上の小物 | 本アプリの Three.js 形状 | 建物の奥行き、曲面の屋根、シャッターの隆起、小物を立体で表す |
| 濡れた路面、灯りの映り込み | 本アプリの Three.js 形状とマテリアル | 舗装色に近い細長い濡れ面と、分断された細い暖色・寒色の光。画面全体の反射処理は使わない |
| 微量の浮遊粒子 | 本アプリの Three.js Points | 通路の左右に固定シードで配置し、ゆっくり微小移動する。射線と入力帯を避ける |

店名・ポスターの文字はゲーム用の架空表現。承認画像は構図・色・雰囲気の参照に使い、画像そのものを背景として表示していない。現状の街は手作りの軽量な 3D 環境であり、承認画像の写真に近い質感へ到達したという評価ではない。実ブラウザで正面から比較し、路面の光、店先の情報量、屋根の奥行きと描画負荷を調整する。
