# Alpha 0.4: 見た目・演出とPages公開

2026-09-28。ユーザーがv0.4案とGitHub Pages公開を承認。

## Goal
入口の30〜60秒で違いが伝わる人物・街・銃撃の改善を行い、通常24体と3段階ボスへ展開。公開URLで実際に遊べる状態にする。

## Context
承認画像 `art/reference/gameplay-approved-v1.png`、v0.3実画面と `docs/RESULTS.md`。既存Three.js/WebAudio/ローマ字判定を継続。Issue #130、PR #131。

## Constraints
無料・アカウント不要で無料ゲーム配布に使用可能な素材を採用し、帰属を残す。立体の街と敵を保持。演出で入力時計を止めない。文字帯と危険予告を最高演出でも読めるようにする。無関係なアプリと公開済み成果物を維持。性能p95・全ブラウザ網羅は厳しい条件にしない。

## 作業
1. 敵: 顔と衣服が分かるモデルを調査し、実際のリグ・歩行・出典を確認。粗い装飾や隠れた顔を改善。
2. 街: 湿った路面・汚れ・小物と照明。入口、アーケード、裏路地、終点の構図を区別。
3. 銃: 握りとスライドを実モデルの構成に合わせて改善。高コンボの最終打鍵だけに専用の衝撃と音。
4. 演技: 側方からの出現、短い被弾と減衰する撃破移動、ボス導入・回復・膝をつく決着。
5. 検証: 最初の区間の画面を見て調整。通し、最高演出、低モーション、ポーズ、結果。素材・音の実測と未確認の聴感を区別。
6. 公開: appチェック・共有テスト・PR CI後にマージ、releaseタグでPages配信。公開HTML/JS/GLB/音のHTTPと実ブラウザの開始〜結果を検証。

## Done when
変更前後の実画面で差を確認し、通しプレイで入力や期限が壊れない。作者・ライセンス・加工が記録される。GitHub Pagesの公開URLでモデル/音が読み込め、プレイと結果を確認。Issue/Projectに公開結果と残る課題を記録。
