# v0.3 キャラクター調整

2026-09-28。元の4体のGLBと歩行・攻撃・被弾・死亡クリップは保持した。GLBの再配布物は変更していない。

## 造形と明度

- `src/characters.ts` で4体の既存アルベドを維持しながら、材質の金属度を0、粗さを0.9に揃えた。明度係数は City 0.88、Thin 0.78、Granny 0.72、Creature 0.76。強い舞台照明で白飛びしやすい素材を抑える意図で、テクスチャの模様は消さない。
- ボスの変異体には小さな胸バッジを3D形状で追加し、胸の骨に装着して歩行に追随させる。素材はコードで自作した単色形状で、外部素材は追加していない。初案のエプロンは実ゲームで体を貫通し、次の肩当ては丸い人工物に見えたため除去した。専用の衣服・造形は未制作で、ボスの差別化は大きさ、姿勢、赤い光、HUDが担う。

## リグを使う動作

`src/character-motion.ts` はGLBの実際のボーン名に対応し、ミキサーの歩行・攻撃・死亡を進めた後に、背骨・頭・肩・上腕へ短い補助姿勢を重ねる。前フレームの補助回転を戻してからアニメーションを進めるため、繰り返しで姿勢が累積しない。ボーンを持たない別素材に差し替えても該当部位だけ何もしない。

- Granny: 元の歩行は胸、首、頭が強く前へ折れる。背骨2節・首・頭を段階的に起こし、顔と眼鏡が髪の下へ隠れにくい姿勢にする。実画面で初回補正が不足したため、首と頭の伸展を追加した。元造形の髪が顔に対して非常に大きく、姿勢補正だけでは全方向で顔が明瞭になる保証はない。
- 全4体: 頭・胸・肩の被弾に対応する部位が短く反応する。`target(zone)` は同じ骨のワールド座標を返し、弾道・着弾位置との一致に使える。
- Granny / Creature: 専用攻撃・死亡クリップがないため、接近時の胸の前進と両腕のリーチ、死亡時の背骨・頭・腕の崩れを補う。既存クリップのあるCity / Thinではそれを優先する。
- Boss: フェーズで胸と肩の圧、頭の向きを少し変え、後のフェーズほど大きく見せる。
- 低モーション設定では被弾の補助角度を42%にする。歩行と攻撃の予告は残す。

## 検証の境界

GLBのJSONで4体のスキン・ボーン階層・アニメーション名を確認した。Blender 5.2.1でGrannyの元歩行15フレーム目をレンダリングし、顔が深い前傾の下にある状態を確認した。補助姿勢の繰り返し適用・解除と頭部ターゲットの取得はThree.jsの骨で確認した。`npm run lint` は通過した。実ゲームの連続アニメーション、歩行中の足元、4体の最終的な画風・明度はブラウザ画面で評価する必要がある。特にGrannyは元造形の大きな髪が顔の見え方を制限する。
