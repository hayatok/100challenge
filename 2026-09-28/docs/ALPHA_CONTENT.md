# アルファ版の出題文

2026-09-28 時点の辞書は通常敵303件とボス12件、計315件。表示文はすべて独立した文で、同一文の重複はない。通常敵の内訳は配達員102件、会社員100件、作業員101件。元の90件は会社員の辞書に残し、新たな文を加えた。

配達員は看板・短い叫び・一瞬の発見を4〜7文字で読ませる。会社員は店と夜勤の生活感を含む標準的な短文。作業員は作業日報、店内放送、商店街の店先などから始まる長い一文。ボスは閉店できない店主の発話を3区間それぞれ4候補に分ける。失敗時は同じ区間の次候補に移り、4件を使い切ると循環する。

読みは表示文とは別にひらがなで指定する。全315件で `TypingSession` が受理する読みだけを登録し、標準ガイドを最後まで入力できることをテストする。読みの異なる漢字や発話の省略は表示文に合わせて個別に校正する必要がある。

出題は敵種ごとの辞書からシード順に選ぶ。同時出現する敵の初手キー集合が重なる候補は飛ばし、24体の通常敵とボス3区間という一周の構成を保つ。ローマ字の標準打鍵数の中央値は配達員12、会社員19、作業員51、ボス29。配達員の最長16打は作業員の最短40打より短い。作業員の長文には打鍵数に応じた猶予があり、ヒットのたびに期限が延びることはない。

自動検証では128シードを全打鍵して出題の衝突と一周の成立を確認した。16シード×3難度については、各課題に0.25秒の反応時間を取り、難度ごとの想定CPSで打ち切る順序を試し、被弾なしで一周した。これらは計算上の可解性であり、文の読みやすさ・面白さ、実プレイ時の疲労や難度はブラウザで別途評価する。
