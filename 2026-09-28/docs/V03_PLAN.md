# v0.3: 手触りと一周の完成度

Goal: 命中・撃破の区別、敵の芝居、音の明瞭さを優先し、一周の緩急と再挑戦につなげる。
Context: Alpha0.2、承認画像、4造形、24通常敵+3段階ボス、315出題、既存のローマ字/保存/再開。
Constraints: 既存Web+Three.jsを維持。新規ライブラリ・有料素材・アカウント登録不要。入力時計は演出から独立。主要操作の検証を優先し端末横断や性能p95を厳しい条件にしない。公開リリースなし。

1. 命中部位と最後の一発のイベント情報を持たせ、骨格の反応と弾道を一致させる。吹き飛びは体重別、ボスはその場で崩れる。
2. 4造形の材質・姿勢を調整。歩行アニメへ安全に戻せる骨格オフセットで攻撃と死亡を補う。老婦人の顔とボスの輪郭を改善。
3. 常時発光を落ち着かせ、到達時と5撃破刻みだけ大きく祝う。小さなヒットと大きな撃破に視覚・音響の階層を付ける。
4. 音のバスEQ、短いBGMダッキング、連打時の発音数、停止/再開を調整し、ボス段階と決着を区別。
5. 波ごとの優先順・配置・間を変え、最も迫る敵を表示。ボスの登場・3段階・決着を専用HUDと演出で表す。
6. 難度・練習・ルール版ごとに自己ベストを永続保存。評価と前回差を結果画面に表示し、即再挑戦を維持。

Done when: 各担当の意味ある自動テストとbuildを通し、実ブラウザで開始からボス・結果・再挑戦まで確認。最高演出と低モーション、比較の初回/更新/旧記録を記録。PR #131とIssue #130を更新する。
