# v0.11 場面ごとのアート改善

## Goal / Context
ユーザー承認（2026-09-29）: 店内の目標画像→実装→比較を最初に行い、路地・搬入口・広場・屋上も目標画像を作って実ゲームを近づける。全場面と人物・武器・モーション・照明を段階的に改善する。基準はv0.10の実画面と `art/reference/journey-approved-v10.png`。

## Plan
1. 店内接近戦の目標画像を保存。棚の品揃え・汚れ・照明・人物・武器を具体化。
2. 人物、武器、背景を独立担当で改善。主担当は照明、描画、画面構成と統合。
3. 店内の実画面を比較し、色・形・奥行き・人物の読みやすさを修正。
4. 他4場面の共通画風の目標画像を保存。各場面の密度、ランドマーク、導線を改善。
5. 全ルート、通常/FEVER、低モーション、休止、結果を実ブラウザで確認。テスト/CI/Pages公開後の配信確認。

## Constraints
Three.jsの立体世界と既存の入力/採点を維持。画像を一枚貼る背景や敵の板ポリゴンで代替しない。新素材は無料・登録不要・ゲームへの配布が許可されたもの。新しい依存は必要な場合のみ。低モーションとテキストの可読性を維持。生成コンセプトは実装画面ではなく目標と明記する。

## Ownership
人物: characters.ts/character-motion.ts。武器: weapon.ts。背景: district.tsとその分割モジュール。主担当: scene.ts/main.ts/描画/画面/統合/文書/公開。無関係なアプリは変更しない。

## Done when
店内と他4場面に画像と対応する実装・実画面があり、人物/武器/照明/背景/動作を横断して改善。両ルートが完走でき、対象画面で入力を隠さない。残る品質差、未確認事項は率直に記録し、画像との完全一致や人間の楽しさを自動テストから推定しない。

## 統合した描画
`scene.ts` は低解像度GTAO、照明・露出・銃の構えを管理。`atmosphere.ts` は512pxの平面反射1枚と固定180本の雨を管理する。反射は陰影の法線プリパスでは描画しない。雨は店内・屋上・低モーションで停止。実画面の比較で大きすぎる武器、浮いた衣装、白い奥室を修正。詳細な確認と未確認事項は [RESULTS.md](RESULTS.md) を正とする。
