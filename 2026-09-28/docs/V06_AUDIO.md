# v0.6 ラッキー遭遇の音

## 実装と制作元

`src/audio.ts` の Web Audio オシレーターで作った、この作品固有の短い伴奏。外部音源、追加ライブラリ、生成音源のダウンロードは使わない。120 BPM、イ短調を基に、低音、裏拍の二和音、短いキックと高い刻みを組み合わせた。通常戦の 165 BPM の暗い録音 BGM は遭遇中に約 20% へ下げ、ラッキーの音量は「BGM」設定に従う。銃声と着弾は従来の録音を使い続け、「効果音」設定に従う。

音符、リズム、音色と Web Audio の合成処理は今回の自作。既存の録音素材の出典と利用条件は `ALPHA_AUDIO.md`、`V04_WEAPON_AUDIO.md` を参照。文完成・大当たりは独立した上昇音、大当たりには既存の鐘素材を薄く重ねる。見逃しは下降する短い中立音で、誤答・被弾音にはしない。

## 呼び出し

- `setLucky(state.luckyActive)` を通常の更新ごとに呼ぶ。同じ値の連続呼び出しでは伴奏が二重にならない。`LUCKY_BPM` は 120。
- 登場時に `luckyStart()`。内部で `setLucky(true)` も呼ぶ。
- 正打は `shot({ lucky: true, ...通常の設定 })`。銃声・着弾に短い音を重ね、入力処理を拍まで待たせない。
- 文章完成時に `luckyWord(step)`。`step` は完了した文の番号（1、2、3）。
- 成功・見逃し時に `luckyEnd(success)`。内部で伴奏を終える。
- pause / quit / retry は既存の `stop()` / `start()` を使用。停止時に予定済みのラッキー音源ノードをすべて止める。

約 0.3 秒だけ先読みして音を予約する。16 ステップで繰り返し、発音中のシンセは 32 ノード以内に制限する。ブラウザのタブ停止で更新が飛んだ場合は現在時刻から再開し、取りこぼした拍を一度に再生しない。音量とミュートは既存設定に追随する。

## 確認範囲

`tests/audio.test.ts` で連続 tick、即時のキー音、発音数、個別音量、ミュート、停止・再開を確認する。実機での聴感、音楽と銃声の最終バランスは統合後のブラウザ確認が必要。
