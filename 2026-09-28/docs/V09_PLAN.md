# Alpha 0.9: 深夜のホラー筐体UI

## Goal / Context
ユーザーが承認した [UIコンセプト](../art/reference/ui-approved-v09.png) の赤黒の筐体、専用ロゴ、金色の演出文字、勤務伝票を実装する。参考画像は内蔵画像生成で制作した設計資料で、3Dの描画品質や現行実装の証拠ではない。

## Constraints
v0.8の3Dモデル・街・音・過剰演出と入力判定/採点/期限を維持。新規ライブラリなし。文字を画像に焼き込まず、実際の得点/コンボ/出題をDOMで表示する。44px操作面、フォーカス、休止、低モーション、保存/再挑戦を維持。ゲームデザインスキルのmenus-and-screensを参照し、設定は直ちに開ける・再挑戦に待ち時間を足さない。

## Plan
1. 現行画面とIssue #130を確認。承認画像を保存。
2. 中央ロゴ/勤務開始、体力/連撃HUD、固定入力プレートを制作。
3. サービスパネル風の設定/休止/入力確認と、評価印付き勤務精算伝票を統合。
4. 演出文字を連撃/限界残業/全員退勤/大当りに統一。意味と実イベントを一致させる。
5. 自動チェック、通常/低モーション通し、設定/フォーカス/再挑戦、各解像度を実ブラウザ確認。
6. PR/CIを経てPagesを更新し、本番URL/配信物/操作を確認する。

## Done when
タイトル/戦闘/結果が同じ筐体のデザインとして成立し、入力欄と敵ラベルは最大演出でも読める。1280×720/1440×900/1920×1080、1024×768で操作可能。375pxでメニュー/設定/結果の戻る操作とスクロールを維持。実スクリーンショットと検証記録を残す。
