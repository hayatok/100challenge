# v0.6 ラッキー遭遇のロジック

通常勤務では seed の最下位ビットが 0 のとき一度だけ発生する。練習は seed に関係なく一度発生する。seed の次のビットで第1・第2ステージを、続くビットでそのステージの通常ウェーブを選ぶ。同じ seed は遭遇位置と3文の組を再現する。通常ウェーブを片づけた後だけ始まり、同じ境界で FEVER が溜まった場合は4体の FEVER が終わってから始まる。

`EnemyView.lucky` が専用演出の判定値。敵種は `office` のままで、1体の `enemyId` を3文の間保持する。`GameState.luckyActive`、`luckyStep`（進行中は1〜3、それ以外は0）、`luckyRemaining`（秒）を表示に使う。`luckyStart`、各文の終わりの `luckyStep`（`step` は完了した文の番号1・2）、`luckyEnd` を発行する。通常の `hit`、`miss`、`lock` にも `lucky:true` を付ける。ラッキーから `kill`、`attack` は出ない。

制限時間は3文の標準打鍵数を難易度別 CPS で割った時間の2倍に6秒を加える。練習でも時間切れになる。最終キーは残り時間がちょうど0でも受け付ける。休止と再開カウントダウン中は時間が止まる。ラッキー中は通常敵の時計、勤務時間、正打数、誤打数、コンボ、FEVER チャージを進めない。誤打も体力を減らさない。

3文を完成すると500点と体力1回復（上限3）。`luckyEnd` に `success`、`scoreDelta`、`healing` を載せる。成功後は2秒、時間切れ後は0.8秒の移動状態を挟んで通常戦に戻る。結果は `luckyEncounters`、`luckyClears`、`luckyBonus` に分ける。ステージの checkpoint にこれらと遭遇済みフラグを保存し、リトライで報酬が重複しない。
