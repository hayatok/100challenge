# v0.5 ラッシュと連鎖爆発の音

## 呼び出しと音の役割

`setRush(active)` はゲーム状態から毎 tick 呼べる。変化がない時は何もしない。ラッシュ中は同じ BGM 録音の高域を 0.26 倍で並列に足し、主旋律のローパスを少し開く。両方を滑らかに動かすため、BGM の再生位置とループは変わらない。`start()` より前に設定しても再生開始時に反映される。`stop()` はラッシュ状態と層のゲインを戻し、次回のゲーム tick が現在の状態を再設定する。

`rushStart()` は金属音から高いベルへ移る短い合図、`rushEnd()` は低く落ちる短い金属音。状態の変更は `setRush` が担い、両合図は実際の開始・終了時に一度だけ呼ぶ。既存 `shot()` は互換のまま、`shot({..., rush: true})` を渡した時は最終打鍵の主銃声と短い重ね録りだけ少し強くする。通常の毎打鍵を大音量にしない。`kill()` は従来どおり撃破の重みを担当する。

`explosion(count)` は一度の連鎖に一度呼ぶ。count は 1〜6 に制限し、打撃の胴体、金属、ガラス、下降する低音を重ねる。数は強さだけに影響し、発音数は増えない。BGM は 0.38 倍へ短く下げて回復させる。これで正打の銃声、単体撃破、連鎖爆発、ラッシュ合図の役割を分ける。

## 音量と上限

元の master 0.64、効果音 4 / 5 / 3 系統・合計 12 ボイス、低音発振器 2 本、コンプレッサーを維持した。連鎖爆発が密集すると古い音を停止して上限内に収める。`stop()` は効果音と発振器を止める。`stop(false)` は従来の結果音の余韻を許す。ミュート、音楽・効果音の独立音量は維持する。

音源は既存の `body.ogg`、`metal.ogg`、`glass.ogg`、`bell.ogg` と銃声を利用する。出典・許諾は [ALPHA_AUDIO.md](ALPHA_AUDIO.md)。外部素材や依存関係は追加していない。

## 検証と残る確認

`npm run test` ではラッシュ層の冪等性と BGM が再起動しないこと、爆発を繰り返した時のボイスと発振器の上限、短いダック、停止・ミュート・音量・AudioContext 停止時の挙動を確認する。各サンプルの設定ゲインは 0.57 以下、ラッシュ中の最終射撃の主ゲインは最大 0.843。これは**設定値の上限**で、重なった音の最終ピークではない。

実ブラウザの WebAudio 出力を録音した測定、スピーカーとヘッドホンでの聴感、激しい連鎖でのピークは未確認。実際のゲームで、通常打鍵→最終打鍵→単体撃破→4 単語ラッシュ→連鎖爆発→ボス短語反撃を、低音量から聴き分け、ミュートと一時停止・再開も確認する必要がある。
