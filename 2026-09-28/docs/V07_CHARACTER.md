# v0.7 人物の質感調整

対象は既存の Rikindle3D 製 `zombie.glb` と `src/characters.ts` の材質処理。リグ、アニメーション、GLB、出典・ライセンスは変更していない。二種類の敵リグとラッキーゾンビも従来どおり使う。

## 元データの確認

GLB のマテリアルは `City_Man_Infected_Outfit1`、`City_Infected_Man_Body1`、`defaultPolygonShader1` の3種。前二者にはそれぞれ BaseColor、Normal、OcclusionRoughnessMetallic の画像がある。最後の無地マテリアルは実際の眼球と歯のメッシュで、顔の陰影ではなかった。Blender 5.2.1 でGLBを開き、マテリアル単位で分離して確認した。元の `KHR_materials_specular` は両者に白の `specularColorFactor: [2, 2, 2]` を指定していた。

元のベース色は赤・黒の傷と汚れが強い。v0.6のシェーダーはRGBの最大値を明るさに使ったため、赤い傷が明るい灰色へ変わり、肌と服の全体が同じ粒状に見えた。v0.7では緑・青チャンネルから黒い汚れを拾い、赤の超過分を控えめな傷色に割り当てた。元の衣服メッシュの静止姿勢の高さで上着とズボンを分け、同一リグのまま色を区別した。法線マップの強度を約3分の1にし、細かい光沢の原因となる粗さマップを衣服・肌では外した。強すぎる鏡面反射も抑えた。眼球と歯は淡い黄白色を維持する。

## 確認と残る差

- `npm run typecheck` は成功。
- ローカルの実ブラウザでタイトルからキーボード確認を通って戦闘画面を開き、通常の敵の上着、暗いズボン、淡い肌の境界を目視した。ブラウザのエラーログは空だった。
- 元のモデルは承認参考画像より顔・衣服の造形とテクスチャの密度が低い。色と反射の改善は、参考画像と同じ立体的な顔、服の襟・ネクタイ、髪などを再現するものではない。近景の人物品質は引き続き差がある。
