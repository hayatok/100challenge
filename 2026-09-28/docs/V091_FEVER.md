# Alpha 0.9.1 FEVER画面演出

## Goal / Context
プレイ後のユーザー指摘「フィーバーが弱い、画面全体で盛り上がる演出」を改善。v0.9は通常高コンボとFEVERの街の色が同じで、告知も側方バッジに留まっていた。

## Plan / Constraints
1. 専用の全画面演出を追加。突入は横断カットイン、継続は四辺の電飾/光線/リング、4撃破で段階変化、完走は全員退勤と紙吹雪。
2. 街のアーチをFEVER専用の金とピンクへ。通常高コンボとの差を作る。
3. 描画専用の時計で管理し、入力/採点/出題/期限は変更しない。入力欄と敵キーは上のレイヤー。固定24枚の紙吹雪、既存3Dオブジェクトを再利用。新規素材・依存なし。
4. 失敗は完走を出さず、休止でCSS/WAAPI/演出時計を停止、再勤務で消去。低モーションでは静止した四辺と文字だけでモードを示す。
5. 状態テスト、実画面で通常/低モーション、突入/撃破/完走、休止/再開を確認。CI/Pagesと公開後操作を確認。

## Done when
FEVERが通常高コンボと一目で区別できる。四辺と画面中央を使う演出が4連戦の間継続し、次の入力と先頭キーは読める。実画面と人間の爽快感評価を区別して記録する。
