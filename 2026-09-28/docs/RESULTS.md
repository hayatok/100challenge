# Alpha 0.2 の検証記録

2026-09-28 / macOS / Codex内蔵Chromium / ローカルproduction preview。

## この版で変わったもの

- 敵モデルを1体から4体へ拡充。既存の男性に、Thin Zombie、Zombie Granny、人型の変異体を追加。歩行・テクスチャ付き実GLBを使用。徘徊者、疾走者、巨体、ボスの役割へ割り当てた。
- 正打に即時の銃声・反動・鋭い銃口光・弾道・局所火花・短い敵ポーズ硬直。撃破に吹き飛び・破片・衝撃波。コンボ3/6/10/15で色、粒子密度、吹き飛び、HUDと音を変化させる。最大300粒子/10衝撃波/48薬莢。
- 固定入力欄、敵の残り時間バー、役割名、次の演出段階までの撃破数、CLEAN KILL・加点・到達表示。最後の撃破から結果まで1.2秒を確保。
- 通常303句（短文102/標準100/長文101）、ボス12句。敵種に応じた長さと先頭キーの重複回避。
- 実録銃声3種、Kenneyの打撃・破片サンプル、MintoDogの165 BPMループBGM。コンボで音を重ね、音楽フィルタを拍に合わせて開く。CC BY素材の作者・ライセンスリンク・加工をゲーム内にも表示。

## 確認したこと

- `npm run check`: 18テスト、lint（警告なし）、型チェック、production build通過。
- 315句の重複・全打鍵、128 seedの一周、16 seed×3難度の想定入力速度での成立、得点イベント、誤打・期限・ポーズ・リトライ・演出減衰・保存を自動検証。
- production previewで画面のガイドを読み、キーイベントだけで通常24体+ボス3段階をクリア。**7,050点 / 最大27コンボ / 正確率100% / 1分58秒 / 355 keys/min / リトライ0**。練習勤務での自動操作であり、人間の難度評価とは区別する。
- 1440×900で新規3造形、歩行、撃破、3体同時、長文、最高段階、ボス・結果を目視。長文の全文とローマ字が固定帯に収まることを確認。頭上は本文を短縮してキー候補を残す。
- 1280×720で低モーション設定、発砲、被弾3回で敗北、区間リトライで体力3、Escapeポーズ、半角go確認後の再開を確認。
- 4体のGLBと9音源がHTTP 200。音源はffprobeによる長さ確認済み。通しプレイ後のブラウザconsole error/warningは0。
- 画像: [追加敵3体](../art/verification/alpha-enemies.png)、[最高段階の銃撃](../art/verification/alpha-combat.png)、[通し結果](../art/verification/alpha-result.png)。すべて実ゲーム。

## アルファとして残す点

- 敵の造形は増えたが作者ごとの画風差はある。Grannyは強い猫背・大きな髪で顔が見えにくい。変異体は衣服のない人型。両者の専用攻撃/死亡クリップは不足し、前傾・吹き飛びの実装で補っている。ボスは変異体モデルを拡大使用。
- 完成済み音源を使用するが、ヘッドホン/スピーカーでの聴感、音量バランス、可聴遅延は未確認。人間による爽快感と難度の評価は次の調整段階。
- 握り姿勢、街の反復感、路面反射など、承認画像の精細さには差が残る。最高段階で発光が強いため、控えめな設定で選べる。
- 約771KBのJS chunkにViteのサイズ警告。端末/ブラウザ横断、性能p95、長時間負荷、実OS IMEは今回の厳しい完了条件にしない。重いフレームでは従来どおり250ms超で安全ポーズになる。

無料・登録不要の素材のみ。公開リリースは未実施。既存Issue #130とPR #131で継続。

# 初版の検証記録（0.1 / 過去記録）

2026-09-28 / macOS / Codex内蔵Chromiumブラウザ。

## 実装

Three.jsの立体商店街、実GLBのゾンビと銃・腕、歩行/攻撃/死亡、キー毎の発砲・反動・排莢・ヒット粒子、コンボ5段階の照明と合成音楽。90通常出題、24通常敵+ボス3段階、先頭キーによるロック、複数ローマ字経路、体力・敗北・区間リトライ、練習、設定・履歴保存。

入力/戦闘は描画と分離。実経過時間で戦闘時計を進め、250msを超える停止は警告ポーズ。初期シェーダーはロード中に準備。キー処理前も時計を更新。開始とポーズ復帰には半角 `go` の確認を設けた。ミス後の演出は1.5秒保持後、0.8秒ごとに1段階低下する。

## 確認した内容

- `npm run check`: 16テスト、oxlint、TypeScript、Vite production build通過。
- 自動テスト範囲: ローマ字経路、全出題、32 seed全進行、先頭キー集合、誤打後の進捗、期限ちょうどの最終キー、ポーズ/再開、区間リトライ、練習、演出保持/減衰、破損保存・保存拒否。
- ルート `npm test` 38件通過。共有スクリプトの検証であり、ゲーム操作とは別。
- ブラウザのキーイベントで開始→24通常敵→ボス3段階→クリア。ゲーム内部状態を直接変更せず、画面のガイドを読みキーボード操作で進めた。
- 通し結果: 7,050点 / 最大27コンボ / 正確率100% / 戦闘時間1分15秒 / 415 keys/min / リトライ0。練習勤務、ブラウザ操作の自動化による入力。人間の操作感の合格ではない。
- `shi`への途中分岐、終端`n'`、誤打、コンボ解除後の継続、複数敵ロック、3体同時の最高演出。
- 練習をオフ、残業難度で入力せず、3回の攻撃で体力0→敗北。区間リトライで体力3と新たな出題へ戻ることを確認。
- Escapeポーズ、再開前の半角確認、再開確認からEscapeでタイトルへ戻れること、設定保存、低モーション切替。
- 1280×720と1440×900でタイトル/ゲーム/HUD、1024×768でタイトル、375×812で設定画面。375pxはスマートフォンでのゲーム対応ではなく、説明/設定の崩れの確認。
- production previewで開始・入力・戦闘・ポーズを確認。最終ビルドでも18コンボまで通し、誤打直後は採点コンボ0でもNIGHT FEVERの演出が保持されることを確認。
- 素材を意図的に欠落させた一時的な別サーバーで、読み込み失敗と再読み込みボタンの表示を確認。
- GLB実読み込み、腕の歩行補正、前方を向く銃、路面と看板の修正後の画面。最終確認タブでconsole errorは0件。

開発途中の環境変数名エラーと初期シェーダー準備の停止は修正して再起動した。Three.jsを含む約738KBの単一JS chunkにサイズ警告あり。実行用GLBは合計約8.4MiB。
