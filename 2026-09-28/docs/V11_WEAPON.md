# v0.11 銃と手元の立体造形

承認済みの旅程画像 `art/reference/journey-approved-v10.png` の一掃場面では、手前の木製先台、機関部、銃身、支える手がそれぞれ判別できる。v0.10 の実画面 `art/verification/v10-fever.png` はショットガンが直方体と円筒に見え、手がほぼ映らなかった。`src/weapon.ts` の一人称モデルをこの差に絞って更新した。

- ショットガンは元の簡易箱から、丸みのある金属機関部、円筒の銃身と弾倉管、空の薬莢排出口、前後照星、断面を変えた木製の先台と銃床へ変更。ポンプは従来どおり打鍵時に動く。
- 黒い手袋の握る手、先台を支える手、袖、指を独立した立体形状で追加。通常拳銃にも縦向きにグリップを包む手を配置した。元のスキン付き腕素材は読み込みを維持したが、開いた指が画面に大きく見えるため描画を停止した。
- 銃口は `scene.ts` の既存の銃口光と同じカメラ相対座標 `(0, 0.03, -0.28)` に合わせた。新しい光源や外部素材、依存関係は追加していない。
- ショットガン全体の拡大を抑え、銃口の位置を固定したまま銃床を右下、銃身を画面中央方向へ傾けた。拳銃の元 GLB は作者の +X 銃身を −Z に向ける従来の回転を維持した。

ショットガンと手袋はこのアプリ内で新しく制作した手続き的な形状で、外部素材は使っていない。通常拳銃と元の腕 GLB の作者・利用条件は [CHARACTER_ASSETS.md](CHARACTER_ASSETS.md) を参照。参考画像は画質と構図の比較用で、ゲーム内に貼っていない。

1280×720 の実画面で店内の拳銃と集団戦のショットガンを確認した。拳銃の手はグリップに接し、ショットガンは先台・機関部・銃床が判別できる。参考画像ほど精細な手の接写や自然な握りにはまだ届かない。低モーション時の射撃、銃口光との動的な一致、画面幅を変えた手の見え方は未確認であり、型チェックやビルドの成功だけで保証しない。
