# v0.11 環境アートの作り込み

## 目標と参照

承認された `art/reference/journey-approved-v10.png`、追加の `art/reference/store-v11-target.png` と `art/reference/district-v11-target.png` は、構図と質感を検討するための生成画像。実ゲーム画面や背景テクスチャとして使用しない。v0.10 の各場面には、同じ形の壁と箱、店内の左右対称な棚、遠景の大きな空白が残っていた。プレイヤーの移動路と敵の接近路を維持し、五つの場所が異なる用途と生活感を持つようにする。

## 造形

- 店内: 左の乾物・飲料棚には異なる高さの瓶、缶、袋、棚札を配置。右の手前は斜めガラスの青果冷蔵ケース、奥は扉付き冷蔵棚とする。床目地、擦れ、落下商品、天井配管を加える。奥の搬入室は壁・床・箱・小さな暖色灯で奥行きを作り、発光する平面で敵を白飛びさせない。
- 路地: 張り出しの違う庇、電線、居住窓、駐輪車、積み箱と雨樋の設備で、同じ壁が連続する印象を弱める。中央と店内へ曲がる経路を空ける。
- 搬入口: 向かい側の壁で狭さを作り、シャッターの段差と警告色、ドラム缶、配送箱、露出配管、ケーブルを足す。中央と広場へ抜ける位置は空ける。
- 中庭: 左端の配送トラック、汚れた倉庫の壁と奥行きのある開口部、積荷、電線を置く。配送車と階段は戦闘の中心を避ける。
- 屋上: 手すりと笠木、汚れ、空調機、支持脚と帯のある水槽を追加。時計塔に庇・縁・屋根を足し、異なる高さ・間隔の住宅、電柱、丘と雲の層で遠景を作る。

## 技術と素材

新しい外部素材・ライブラリは追加しない。造形、看板、雲、汚れは Three.js と Canvas によるオリジナル素材。既存の路面・シャッター素材の出典は `docs/ENVIRONMENT_ASSETS.md` を継承する。実行中の照明は従来の固定四灯を使い回し、エリアごとに灯具情報のみを変更する。標識の同じ文字・色の Canvas マテリアルは共有する。光源やテクスチャ、形状は `District.dispose()` で解放する。

## 検証項目

`npm run typecheck`、`npm run lint`、`git diff --check`。ブラウザでは店内で敵の顔・入力表示が読めるか、青果ケースと棚の商品が判別できるか、暖色の奥が白飛びしないかを優先して見る。路地、搬入口、中庭、屋上では移動レールからの構図、敵の輪郭、手すり・階段とカメラの接触、動作の重さを確かめる。生成参考画像との質感差は残るため、実画面と分けて評価する。
