# Alpha 0.8: 深夜商店街 OVERDRIVE

## Goal / Context
ユーザーが承認した、パチスロ級の過剰な銃撃・報酬・コンボ・FEVER演出を実装。v0.7のモデル・舞台、入力/戦闘/採点を活用する。game-designのcritiqueとguidance-and-feedbackを参照し、派手さの強化と入力可読性を両立する。

## Constraints
無料素材を新規探索せず、既存音源・Web Audio合成・Three.js/CSSの自作演出へ集中。モデル差し替え、新マップ、課金/抽選/新報酬ルールは追加しない。節目表示は実際のコンボや成功に一致。入力・期限を演出で停止させず、固定入力帯を保つ。低モーション、音量/ミュート、休止、再勤務を維持。長い音/画像生成を避け、音とVFXのみSolへ並行分担する。

## Plan
1. 変更前の実画面を確認。Issue #130を継続。
2. 輝く撃破文字・金枠・段階到達の大当たり表示、FEVER4連戦の進捗と完走演出を統合。
3. コンボで街のアーチ・路面の光が増加、最高段階で金色のOVERDRIVE。カメラ・入力・敵の期限とは独立。
4. 大きな銃口光・軌跡・段階別の火花/衝撃波、FEVER完走とラッキー成功時の花火/紙吹雪。上限と再利用を検証。
5. 報酬音の上昇音階・和音、強い最終打鍵、FEVER突入/4撃破/完走、JACKPOT音。全scheduled nodeの停止・ミュート・上限を検証。
6. 自動検証、通常/低モーション・pause/retry・FEVER成功/失敗・ラッキー・ボスを確認。PR/CI/Pages公開、配信照合と実URL操作。

## Done when
最初の数撃破でv0.7との違いが明瞭。最高段階とFEVER完走が独立した見せ場になり、文章と危険予告を読める。休止や再勤務で演出が残留せず、音・描画オブジェクトに上限がある。実画面証拠と未確認の聴感/実機性能を区別する。
