# v0.4 銃の握りと最終射撃音

## 変更

- 配布済みの拳銃 GLB の `Pistol_Slide` と `Pistol_Slide4` は銃身・フレームから独立していた。`animateWeapon(group, recoil, finishing, motion)` で両スライドだけを銃口と逆の source −X に最大 0.052、最終打鍵では 0.067 移動する。反動が 0 になると元位置へ戻る。低モーション設定では 0.012 に抑える。銃全体の反動、銃口光、薬莢は `scene.ts` が担当する。
- 腕 GLB の元のスキンと骨格を維持し、実画面でスライド上まで伸びていた指を元の指骨の回転で曲げ、腕全体を右下へ配置した。別メッシュの指を追加していない。1280×720 の実プレイ画面では、指がスライドを横切らないことを確認した。グリップを包む指の大部分は銃と画面右端に隠れており、接写での握りの自然さは未確認。
- `shot({zone, finishing, level?})` は互換性を保つ。最終打鍵では主銃声を通常より強くし、別録音の銃声を 9 ms 後に短く重ね、11 ms 後に高めの金属クリックを加える。どちらも短く切り、通常の着弾音と `kill()` による撃破音は残す。最高段階でも単体ゲインは 0.81 以下で、gun / impact / accent の 4 / 5 / 3、総計 12 ボイス上限は維持する。95 ms 未満の通常連打は従来どおり下げるが、最終打鍵は埋もれにくいゲインにする。

音源とその利用条件は [ALPHA_AUDIO.md](ALPHA_AUDIO.md) を参照。新しい外部素材は追加していない。

## 実素材による近似測定

`python3 scripts/audio/check_v04_mix.py --demo /tmp/nightshift-v04-audio-demo.wav` で、配布済み MP3/OGG を ffmpeg でデコードし、3 通常射撃と 1 最終射撃・撃破を 2.2 秒に配置した。銃・着弾・撃破のゲイン、EQ カット、短いフェードを反映している。比較用 v0.3 シーケンスは同じタイミングで追加層だけを除いた。

| 近似ミックス | 全体ピーク | 全体 RMS | 最終 80 ms RMS |
| --- | ---: | ---: | ---: |
| v0.3 相当 | −11.30 dBFS | −27.39 dBFS | −21.31 dBFS |
| v0.4 相当 | −10.39 dBFS | −27.12 dBFS | −20.75 dBFS |

この WAV は音源を使った確認用で、実 WebAudio 出力の録音ではない。スクリプトは BGM、再生速度差、WebAudio コンプレッサーと音楽ダックを再現しない。数値はブラウザ最終ピークの保証や人間の聴感評価ではない。実ブラウザで低音量から、通常連打と最終打鍵・撃破、ミュート切替、ボス戦の重なりを聴いて確認する必要がある。
