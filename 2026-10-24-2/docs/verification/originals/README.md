# 雲海サーファー / CLOUDSEA SURFER

雲海に浮かぶ遺跡をホバーボードで滑り、曲がり、跳び、次の足場へつなぐ3Dアクション。主人公は、凛としてクールで可愛らしさもある女子高校生の凪原 澪（なぎはら みお）。

このフォルダには企画仕様v0.1と生成コンセプトアートを保存した。ゲーム本体は未実装で、掲載画像は実行画面ではない。数値と操作感は、次の試作で検証する初期案である。

## 遊びの概要

自動で前進するボードを操り、広い完走路と、狭いが速い近道を選んでゴールを目指す。下りで加速し、バンクを曲がり、見えている着地点へ跳ぶ。ブーストは短く使う。敵は横へ避ける、跳び越える、通過タイミングを変える判断を作る。

HP、残機、タイムオーバーは設けない。落下してもチェックポイントから走り直せる。初回は完走、再走ではルートの工夫と滑らかな操作でタイムや得点を伸ばす。

## 世界と主人公

雲の上に残る風路は、街と学校、風車、天文台を結んでいる。澪は放課後、その道を走って天文台へ観測記録を届ける。遠くに見える白い輪状遺跡が最初のゴールの目印になる。物語はコースを走る動機として短く伝える。

![凪原澪の人物・衣装・ボードの設定画](art/concepts/01-mio-character.png)

短い紺髪、雲形の小さな髪留め、白いジャケット、紺の制服、珊瑚色のリボンを組み合わせる。落ち着いた通常表情と、走り終わったときの柔らかな笑顔で性格を見せる。

## 雲海と滑走

![雲海の水道遺跡を滑るキーアート](art/concepts/02-cloudsea-keyart.png)

白い石の水道遺跡、雲海、風車、遠くの輪を世界の共通要素にする。上段の近道と下段の完走路が見える構造を目指す。キーアートのカメラは演出用で、プレイ時は進路を見渡せる後方カメラを使う。

## プレイ画面

![後方追従カメラとHUDの生成イメージ](art/concepts/03-gameplay-hud.png)

タイムと得点は上、速度と風力ゲージは下へ置き、中央の進路と着地点を空ける。画像内の値は表示例である。区間進捗、保存失敗、入力切り替えなどの詳細状態は仕様書で定め、実装時に確認する。

## 敵

![照準灯機・掃雲機・風門番の造形イメージ](art/concepts/04-guardian-machines-v2.png)

左から、片側を照らす「照準灯機」、低い棒を伸ばす「掃雲機」、周期的な風の帯を作る「風門番」。倒す必要はなく、滑走ラインを選びながら通過する。下段の小図は造形の補助で、距離や風向きの判定図には使わない。実際の攻撃範囲は仕様書に従う。

## タイトル・結果・ポーズ

![タイトル・プレイ・結果・ポーズの画面構成](art/concepts/05-screen-family.png)

同じ紺色の枠、白い文字、青緑の風力表示、珊瑚色のフォーカスを全画面で使う。結果画面ではタイム、得点、落下回数を分けて示す。ランクは試遊前に決めない。

## 制作段階

次は90秒の操作試作で滑走とカメラを確かめ、その後に第1コース「白環の通学路」を約3分の完成見本にする。完成見本の評価後に「風車水道」「夕凪天文台」を含む3コース構成を検討する。約3分は最初の完成見本の長さで、作品全体の確定規模ではない。

3Dモデルを作る段階ではTripoを利用する。今回の画像は、モデル制作と実画面の比較に使う参考資料として保存した。
