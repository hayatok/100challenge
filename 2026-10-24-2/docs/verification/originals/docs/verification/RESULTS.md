# 企画資料の確認記録

対象は2026-10-24に作成した雲海サーファーの企画仕様とコンセプトアート。ゲーム本体、実3D、実UIは未実装である。

## 確認した資料

- 操作、移動の理論値、ブースト、コース、敵、得点、失敗と復帰、ポーズ、結果、保存の仕様を文書内で照合した。
- 採用した生成画像5点と敵の旧稿1点について、PNGの寸法・CRC・SHA-256、元ファイルとの一致、プロンプトと参照画像の存在を確認した。[manifest](../../art/manifest.json) に対応を記録した。
- 主人公の髪・衣装・ボード、背景の輪状遺跡、HUDと枠の画風を生成画像で目視した。画像と仕様の差は [アート方針](../ART_DIRECTION.md) の第8節に記録した。
- Markdown内のローカルリンクと画像参照が存在するか、確認用のJSONに記録する。推敲原稿と検査ツールの内部記録は、このリンク検査の対象に含めない。
- 開始時からあるルートと既存アプリの差分は変更しない。今回の成果物は `2026-10-24-2/` 内に限定した。

組み込みImageGenで生成した画像と実際のプロンプトを保存した。人物設定画のコピーや寸法、敵の小図、メニューの省略状態は生成画像だけでは確定させていない。新しいライブラリやゲームの依存関係は追加していない。

## フォント

候補フォントをCoreTextで直接読み、以下のサンプルについてグリフの存在を確認した。日本語と数字の描画サンプルも目視した。[収録の記録](font-coverage.json) と [描画サンプル](font-sample.png) を保存した。

上記サンプルの欠落グリフは0。全ての画面文言や別の言語の収録まで確認した結果ではない。本作へフォントを同梱する際には、対応するライセンスも本作内に保存する。現在は既存フォントを確認用に参照しただけで、別アプリへの実行時依存は作っていない。

## 色と画面

指定した不透明な単色同士のコントラスト比を計算した。[計算結果](color-contrast.json) を保存した。

| 組み合わせ | 比率 |
| --- | --- |
| 主文字 / 紺の操作面 | 14.15 |
| 補助文字 / 紺の操作面 | 9.74 |
| 白い文字 / 青緑の主ボタン | 4.67 |
| フォーカス / 紺の操作面 | 5.91 |
| 風力表示 / 紺の操作面 | 8.53 |

これは指定値の計算であり、生成画像の全ピクセルや実画面の合格を示すものではない。実UIの透過、明るい雲の背景、縮小時の文字、動作中の敵予告は未確認。生成画像は元寸法で目視し、実ゲームの1280×720、1920×1080、960×540で操作した証拠には使っていない。

## 日本語とレビュー

日本語の原稿は `originals/` に残し、yomiyasuのlint、原稿との比較、依頼文との照合、最終ファイルのハッシュ照合を行う。機械検査の記録は `yomiyasu/`、確認した候補と判断は `japanese-review.json` に保存する。検査の件数は文章の点数として扱わない。

必須のAI Slopレビューは、`.codex/agents/ai-slop-reviewer.toml` のAstraを対象にする。結果と指摘への対応は、今回の最終報告と [Issue #200](https://github.com/hayatok/100challenge/issues/200) に記す。
