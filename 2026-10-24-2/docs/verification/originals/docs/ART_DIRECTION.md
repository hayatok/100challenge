# 雲海サーファーのアート方針 v0.1

ゲームの操作と判断は [SPEC.md](SPEC.md) を正本とする。本書はキャラクター、世界、文字、枠、音と画面の目標を定める。掲載した生成画像は事前の参考であり、実3Dや実UIの完成を示さない。

## 1. 世界と色

晴れた雲海の上に、白い石の水道遺跡と庭園が浮かぶ。遺跡には長いバンク、上下に重なる通路、風を集める輪が残る。青空と広い雲海で開放感を作り、次に行く足場と着地点は背景より輪郭を強くする。

写実的な汚れや細密さより、セル調の陰影と遠くから読める大きな形を優先する。人物は2〜3段階の影、背景は白い石と緑、青い影でまとめる。粒子と速度線は足元や画面端に寄せ、中央の着地点を覆わない。

第1コースは白い水道と輪、後続候補の風車水道は回転する大きな羽根と水の反射、夕凪天文台は暖かな夕空と長い影で区別する。後続コースの造形と固有要素は完成見本を評価してから決める。

## 2. 凪原 澪

| 項目 | 設定案 |
| --- | --- |
| 名前 | 凪原 澪（なぎはら みお） |
| 年齢 | 17歳、高校2年生 |
| 性格 | 凛として落ち着いている。口数は少なめで、滑走がうまくつながると小さく笑う |
| 髪と顔 | 顎ほどの短い紺髪、青緑の目、本人の左側に小さな雲形の銀色髪留め |
| 衣装 | 紺のセーラー襟の制服、白い風よけジャケット、珊瑚色の小さなリボン、紺のプリーツスカート、フルレングスの濃色スポーツレギンス |
| 足元と手 | 紺と白の足首を支えるボード用ブーツ、スポーツグローブ |
| ボード | 幅のある白いホバーボード。紺の下面、青緑の縁、先端の珊瑚色の一本線。車輪なし |

顔、髪、ジャケットの外形、ボードの配色は各画面でそろえる。衣装は制服らしさと動きやすさを両立させる。髪とリボンは風を伝える程度に動かし、顔や進路に重ねない。

通常時は正面を見据えた静かな表情、ブースト時は低く構えた集中、クリーン着地では口元の小さな笑顔、結果では肩の力が抜けた笑顔を使う。転倒を長く見せず、復帰時にはすぐに前を向く。台詞の例は「この風なら、いける」「……よし」「もう一本、走ろう」。同じ成功台詞を毎回再生しない。

設定画は衣装と印象の参考にする。正確な正投影、骨格寸法、ボード厚み、布の可動域は未確定。生成画像に含まれる英語のコピーや細かな文字は採用しない。今後Tripoで制作したモデルを、正面・側面・背面とゲームカメラで設定画と比較する。

## 3. コースと敵の形

完走路は遠くから見ても連続性が読める幅を持たせる。近道は短い段差や上段の橋で示し、離陸前から着地点を見せる。下段の道へ降りる場合も、そこから進める方向と再合流地点を読めるようにする。

敵は古い風路の守護機械とし、白い石と紺の機構、青緑の風力を使う。危険な範囲は琥珀色と斜線で示す。

| 敵 | 遠目で読む形 | 伝える行動 |
| --- | --- | --- |
| 照準灯機 | 球体、一つ目、細い安定翼 | 固定する照準線と片側の帯を見て横へ避ける |
| 掃雲機 | 低い台座と横に伸びる棒 | 伸びる前の姿勢と棒の範囲を見て跳ぶ・迂回する |
| 風門番 | 三枚羽根の輪と風向きを示す布 | 進行方向を横切る風の帯を見て、通る時刻か道を選ぶ |

敵の設定画は外形と素材の参考にする。特に右下の小図では風の矢印が進行方向にも見えるため、横風の判定図として使わない。実装時は進行方向に直交する帯、残る通路、予告時間をコース上で別に確認する。風門番の命中はSPEC.mdの共通減速処理に従い、主人公を横へ吹き飛ばさない。

## 4. 追従カメラ

プレイ時は後方から全身とボードを映す。主人公の高さを画面高の25〜35%程度にする案から試し、画面中央から上に次の曲がり角・危険範囲・着地点が同時に入るよう調整する。6mほど後ろ、2mほど上を初期案とし、狭い柱の間へ無理に入らない。

キーアートの横寄りの構図は紹介用に限る。走行中に演出カメラへ切り替えない。画面ロールは初期設定で0、視野角は通常68度からブースト時74度まで緩やかに変える案とする。動きを減らす設定では視野角を68度に固定し、揺れと速度線を止める。いずれも未検証値。

## 5. 文字・色・枠

ルートの共通UI定義に対し、本作では雲の白に負けない紺の面と、風路に対応した青緑を操作面に使う。ゲーム内の注意は琥珀、選択中の輪郭は珊瑚色で統一する。これは本作の世界と可読性に合わせた例外である。

| 役割 | 色 | 使い方 |
| --- | --- | --- |
| 操作面と枠の内側 | `#142C3E` | HUD、ポーズ、結果。文字の背後は不透明を基本にする |
| 主な文字 | `#FFFDF8` | 紺の面の上の本文・数値 |
| 補助文字 | `#C8D7DD` | 単位と補足。小さくしすぎない |
| 明るい面の文字 | `#142C3E` | タイトル、白いパネル |
| 主操作の面 | `#087F8C` | 選択中ボタン。白い文字と併用する |
| 風力・成功 | `#58D9E3` | ゲージの塗り、成功の短い輪郭。紺の面と併用する |
| フォーカス | `#F08A7B` | 3pxの外枠と選択矢印。色だけで選択を伝えない |
| 危険 | `#F1B449` | 敵の予告。斜線、形、点滅しない伸縮を併用する |

枠は薄い2pxの輪郭と8pxの隅切りを基本とし、斜め線は枠の角に限定する。ボタンの操作面は高さ48px以上、行間は12px以上。キーボード・パッドのフォーカスには3pxの外枠と矢印を付け、ボタンの面と外枠の間に紺色の3pxの間隔を空ける。確認操作を押すまで選択を実行せず、マウスの移動だけで確定しない。

| 文字の役割 | 書体の候補 | 1280×720での基準 |
| --- | --- | --- |
| 日本語本文・ボタン・通知 | Noto Sans CJK JP Medium | 20px、補助16px |
| タイム・得点・速度 | DejaVu Sans Mono | 主数値36px、単位18px |
| 見出し | Noto Sans CJK JP Medium | 28〜36px |
| タイトル | 上記を基にしたロゴ文字 | 日本語48〜64px、英字は補助 |

既存アプリ内の候補フォントとライセンス文書を参照し、検証記録に記す。日本語の「雲海サーファー」「凪原 澪」、記号、数字の字形と収録は実フォントで確認する。実装時には必要なフォントとライセンスを本作内へ同梱し、別アプリのパスへ実行時依存させない。生成画像内の書体がそのまま利用可能なフォントを示すとは扱わない。

## 6. 各画面

| 画面 | 構成と実際の文言 |
| --- | --- |
| タイトル | 左に「雲海サーファー」と「はじめる」「設定」「クレジット」、右にボードを持つ澪。押下待ちだけの画面は挟まない |
| コース選択 | コース名、自己ベスト、主ボタン「走る」、戻る。初回は「白環の通学路」のみ。内容がないコースを選択可能にしない |
| 読み込み | 「コースを準備しています」。進捗が取れる場合だけ割合を出す |
| 読み込み失敗 | 「コースを読み込めませんでした」「再試行」「タイトルへ戻る」。原因が取得できる場合は短く添える |
| 走行 | 左上にコース名と区間「2 / 5」、タイム。右上に得点とFLOW倍率。左下に速度、右下に「風力 68 / 100」。操作表示は下中央 |
| 復帰 | 小さく「チェックポイントへ復帰」「追加 +3.00秒」。操作不能は短い復帰演出だけとし、直後に走り出す |
| 結果 | 「FINISH」、コース名、TIME / SCORE / FALLS、自己ベスト更新。主ボタン「再挑戦」、補助「コース選択」「タイトルへ戻る」 |
| ポーズ | 「PAUSE」「続ける」「最初から再挑戦」「設定」「タイトルへ戻る」。ゲームは背後で停止する |
| 走行の破棄 | 「現在の走行を終了しますか」「終了する」「戻る」。未完走の記録が保存されないことを示す |
| 設定 | BGM・効果音の音量、動きを減らす、操作表示。入力の再割り当てと補助機能の範囲は試作後に決める |
| 記録なし | コース選択のベストは「記録なし」。ゼロ秒をベストとして表示しない |
| 保存失敗 | 結果に「記録を保存できませんでした」。再走や結果の閲覧を塞がない |
| 非対応環境 | Web版で検出できた場合に「この環境では起動できません」と必要条件・再試行の案内を出す。条件は環境確定後に記述する |
| クレジット | 制作、生成アート、使用フォント、3D素材と音の出典。未制作の素材を使用済みと記さない |

タイトルと結果で進路を見渡せる余白を残し、ポーズ以外の大きなパネルを走行中の中央へ出さない。試遊前に作ったタイムや得点の例を自己ベストや実測として扱わない。

主対象は1280×720以上の横長画面、比較対象は1920×1080。小さい横長の960×540ではHUDを詰め込みすぎず、操作表示を一度に必要な項目へ絞る。縦長と960×540未満では、Webの案内画面で「横向きの広い画面で開いてください」と表示する案とし、初回のプレイ対象には含めない。解像度に応じた文字と枠の縮小方法は、実画面で確かめてから決める。

## 7. 反応と音

| 発生条件 | 文字・枠・音の反応 | 位置と時間の初期案 |
| --- | --- | --- |
| ブースト開始 | ゲージの輪郭を短く明るくし、低い風音から高い風音へつなぐ | 右下、0.15秒。押下中ずっと点滅させない |
| クリーン着地 | 「CLEAN +100」を短く表示し、ボードの光を一度強める | 自機の横、0.6秒。次の着地点には重ねない |
| 近接通過 | 「NEAR +150」と短い風切り音 | 自機の横、0.6秒。敵予告と競合したら音量を下げる |
| 倍率上昇 | FLOWの数字が一度だけ大きくなる | 右上、0.15秒、最大1.08倍の拡大 |
| 敵ヒット | 「減速」、紺の枠の短い琥珀色への変化、短い擦過音 | 画面端、0.25秒。全画面フラッシュは使わない |
| 落下 | 連続成功表示を消す。復帰と追加ペナルティを表示 | 区間名付近、復帰後1秒 |
| ベスト更新 | 結果の該当行へ「自己ベスト」を追加 | 結果画面のみ。入力待ちを追加しない |

得点通知の+100や+150は基礎点の例であり、実表示ではそのイベントに倍率を掛けて実際に加算した点を示す。通知が重なったら短く縦に並べ、同時表示は最大2件にする。ゲージの回復は塗りの増加で返し、大きな回復通知を走行中に追加しない。

BGMは軽快な打楽器と澄んだシンセを中心とする案。曲の拍とジャンプ操作を厳密に合わせるリズムゲームにはしない。滑走速度の変化を風音で伝え、着地の低い一音で接地を返す。曲、効果音、音声は今回未制作。

ポーズとフォーカス喪失では、物理、時計、敵、音、通知タイマー、ゲージ演出を止める。再開はカウント後に再入力を受け付ける。再挑戦では通知と枠の強調を初期化し、前のFLOW表示や成功音を残さない。動きを減らす設定でも文字、数字、敵予告の範囲を読める状態は保つ。

## 8. 画像と仕様の差

採用した生成アートは5点。生成には組み込みのImageGenを使い、実際のプロンプトと参照画像をmanifestに記録した。

- 人物設定画のコピー、細かなラベル、服の寸法は確定仕様ではない。
- キーアートは主人公を大きく見せる横の構図。プレイ用のカメラは03の後方構図を基に調整する。
- 03には区間進捗がなく、05の小さなプレイ画面ではFLOWと操作表示も省略されている。実UIは本書とSPEC.mdに従う。
- 04の右下の風の小図は、横風の正確な範囲を示さない。造形だけを参照する。
- 05の結果には「タイトルへ戻る」と自己ベストの状態がない。実装時には追加する。画面内のタイム、スコア、ゲージは表示例。
- 読み込み、設定、保存失敗などの画面画像は未生成。状態と文言は本書で定め、実装時に確認する。

生成アートと実3Dを同じカメラで比較する前に、見た目の再現を承認済みとしない。主対象解像度と960×540で長い文言、大きな値、フォーカス、明るい雲、敵予告中の表示を実際に確認する。
