# 雲海サーファー / CLOUDSEA SURFER

雲海に浮かぶ遺跡をホバーボードで滑り、曲がり、跳び、次の足場へつなぐ3Dアクション。主人公は19歳の学生、凪原 澪（なぎはら みお）。凛としてクールで、可愛らしさもある。

Godot 4.7.2で、900mの風路を自分で操る滑走ゲームへ作り直した。Sと旋回で風をため、Sを離して加速し、発射台から次の足場へつなぐ。現在の方針は[再設計の仕様](docs/REWORK.md)、実装の接続は[実装資料](docs/IMPLEMENTATION.md)、確認した範囲は[再設計版の記録](docs/verification/rework/RESULTS.md)を参照する。

## 遊びの概要

A / Dでボードの進行方向を回し、離すとその向きを保つ。道が自動で向きを変える処理はない。Sを押しながら曲がって風をため、十分ためたらSを離して加速する。3か所の切れ目では速度と向きを合わせ、発射台から次の足場へ跳ぶ。小さい切れ目は十分な速度でも渡れ、最後の大きな切れ目はSpaceが必要になる。Shiftでも風力を消費して加速できる。

900mのコースは最初のカーブ、解放と跳躍、逆向きのカーブと敵、短い休息、連続カーブと最後の跳躍をつなぐ。落下するとチェックポイントから復帰する。走行時間、操作の分かりやすさ、試遊の範囲は再設計版の記録へ残す。旧コースの自己ベストとは分けて保存する。

| 行動 | キーボード | パッド |
| --- | --- | --- |
| 向きを変える | A / D | 左スティック左右 |
| 風をためる | S + A / D | LT + 左スティック左右 |
| ためた風を解放する | Sを離す | LTを離す |
| 直進中の減速 | S | LT |
| ジャンプ | Space | A |
| ブースト | Shift | RT |
| ポーズ | Esc | Menu |

## 起動と検査

```bash
cd 2026-10-24-2
npm ci
npm run setup
npm run play
```

`npm run dev`でGodotエディター、`npm test`でゲームの自動検査、`npm run build`でWeb出力を作る。`npm run check`は検査とWeb出力を続けて実行する。`npm run preview`の表示URLをブラウザで開くとWeb版を遊べる。保存先は端末内のGodotユーザーデータで、Webではブラウザの保存領域を使う。

Linuxの`setup`は公式Godot本体とWebテンプレートを取得し、SHA512を照合する。macOSではGodot 4.7.2と対応するエクスポートテンプレートを用意する。別の場所へ導入した場合は`GODOT_BIN`を指定する。

## 制作段階

現在は900mの再設計版で、旋回、ため、解放、跳躍、着地と身体の反応を確認する段階である。旧計画の約3分の完成見本や3コース構成を、今回の完了条件には含めない。人による完走、音の聴感、面白さ、最終レビュー、CIの結果はそれぞれ確認して記録する。

3Dの人物・ボード・照準灯機・遺跡アーチ・浮遊庭園はTripo Studioで生成した。[生成記録](art/source/studio/manifest.json)に入力、モデル、消費クレジットと導入状況を残す。コースと衝突形状は調整用のブロックアウト、雲海はシェーダーによる表現である。

新しい人物は成人19歳の設定を維持し、正面・左右・背面の4画像からTripo Studioで制作中。生成、調整、採用判断の状況は[再設計の人物方針](docs/REWORK.md#人物と反応)に記す。旧モデルと新モデルの生成成功を、そのまま採用の根拠にはしない。
