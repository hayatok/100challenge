# 企画書の文章を見直した理由と方針

初版には、主語や目的語を省いた説明、名詞を並べただけの文、比喩に頼った説明が多くあった。また、ゲームの操作、開発者の意図、試作で調べることを同じ段落へ詰め込んでいた。ユーザーから「何が言いたいかわからないところが多い」と指摘されたため、比較資料と6案の本文を全面的に書き直した。

初版でも日本語の検査スクリプトとAstraレビューは実施していた。しかし、検査の実行や指摘の少なさを確認しても、初めて読む人に説明が通じるとは限らない。今回は、企画を知らない評価担当に比較資料から読んでもらい、各ゲームの内容を自分の言葉で説明してもらう手順を加えた。評価担当はAIであり、人間の読者が確認したという意味ではない。

## 説明する順序

各企画の冒頭では、プレイヤーが誰として何を目指すのかを説明する。次に、普段どのような操作をするかを示し、具体的な場面で二つの選択を比べる。選んだ結果として増えるもの、減るもの、次にできることを明記する。開発の見積や試作条件は、ゲームの遊び方と分けて後半に置く。

## 書き直した例

| 初版の説明（要旨） | 書き直した説明 |
| --- | --- |
| 同じレールを輸送路か防壁にする | プレイヤーが可動式レールを跳ね上げると、レールが敵弾を防ぐ壁になる。その間は列車が通れず、砲台への弾薬の補給も止まる。 |
| 予測できる自律行動にする | プレイヤーが移動方法を習慣として登録する。次の任務で同じ条件に出会うと、獣がその習慣に従って動く。 |
| 移動の余地と戦う備えを同じ枝から選ぶ | 横枝を切ると木材が手に入り、装備を作れる。ただし、切った部分は足場として使えなくなる。 |
| 今夜の売上が明日の行動余地を削る | 二泊の客を受けると、翌夜の空室が一室減る。一泊二食なら翌夜の空室は残るが、今夜の食材を使う。 |
| 真相の公開が在庫の相場を動かす | 贋作が出回っていると公表すると謝礼を得られるが、自分が持つ同じ工房の品も値下がりする。 |
| 領地が支払い能力になる | 土地を担保に選ぶと入札額を増やせる。その代わり、その土地は返済するまで生産を止める。 |

## 仕様の未確定と文章の曖昧さを区別する

原文にない効果や数値を足して、説明のつじつまを合わせることはしない。たとえば探偵案では、正しい鑑定を提出するときの時間消費が決まっていなかった。これらはルール説明と制作上の課題に明記し、確定した仕組みと読み分けられるようにした。

日本語の検査では、原文と修正稿を比べて数値、条件、固有名詞、否定、未確認の事項を確認する。検査候補を減らすことを目的にせず、文章を通して読んだときに操作と結果がつながるかを確認する。
