# ホコリ無双 v0.2 — 掃除した道で戦う夜勤

## Task
- Goal: 移動だけで戦う6分の3Dサバイバルに清掃地形・設備復旧・再汚染・2種の装備連携を追加。
- Context: Issue #64、v0.1の #62 / #63、ユーザーが承認した完成版アイデア。共通DESIGN/FRONTEND/DAILY_APP_STYLE。
- Constraints: 平面移動、自動攻撃、固定カメラ、3装備、6分を維持。3DアセットはBlender。既存原本とユーザー変更を保持。新しい依存なし。
- Done when: 道の再利用・設備復旧・再汚染・連携・清掃結果が動作し、テスト・Blender GUI・375/768/1024/1440px・CIで確認。

## 戦闘
WASD/矢印またはスティックで移動。電池で経験値を得て停止中に強化3択。武器4種（吸引、モップ、泡、ディスク）各5段階・最大3枠。補助は移動、回収、HP、攻撃間隔の各3段階。上限能力は提示せず、全能力取得後は回復。通常敵4種、ボス1種。300秒でボス1体、360秒までに撃破で勝利。接触後1秒無敵、回復上限あり。画面外生成、半径28の境界。

## 清掃
0.5m、112×112セルで床を管理。ロボは半径0.95mを掃除。現在地と移動方向の1.8m先が清掃済みなら速度＋18%。新しく掃除しながら進むだけではボーナスを得ず、既存の道を走り直すと速い。障害物内と円形境界の外は清掃面積に算入しない。
出発地点(0,0)から清掃機(-7,-5)の周囲1.5mまで4近傍で清掃セルが接続し、2秒継続すると復旧。接続は0.2秒間隔で判定し、途切れると進捗ゼロ。HP20・経験値5を一度だけ付与。復旧後は清掃半径が2mから最大7mへ拡大し、再汚染を掃除し直す。設備は再ロックされない。接続・清掃率は副目標で、ボス撃破が勝利条件。
45秒以降、泥足が通常出現の14%を占め、0.45秒ごとに半径1mを再汚染。店舗と清掃機には単純な平面衝突判定がある。

## 連携
- 泡バキューム：吸引＋泡を所持すると自動成立。吸引範囲内かつ泡の中の敵を引き込み、半径1.3mに追加ダメージと清掃。
- 泡の滑走路：モップ＋泡で自動成立。モップの清掃半径が0.65mから1.65mへ拡大。
予告を3択に表示し、成立した連携を装備帯に表示。清掃地形はCPUの共通状態を移動と描画が参照し、見た目だけの効果にしない。

## 美術・画面
クリーム #f5eddc、インク #292d31、オレンジ #ed713b、紫 #9282ae、ミント #68bcb1の役割を維持。木材・泥は既存木材色の調整として #ad8260。ゲーム中は清掃率・道の速度状態・清掃機への方向/距離と復旧状態を表示。結果は出動前後の地図、清掃面積と割合、復旧状況を表示。清掃面積は再汚染を除いた終了時の値。
Blender v2原本の色・粗さ・法線をGLBから保持して描画。ロボは面取り、店舗/清掃機は丸い玩具の造形。床は薄い汚れテクスチャで覆い、清掃に応じて模様が現れる。材質別にまとめたインスタンス描画と簡易接地影で負荷を抑える。陰影は立体の読みやすさのための例外。
