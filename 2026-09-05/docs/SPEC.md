# ホコリ無双 — 深夜のおそうじ隊

## Task
- Goal: 移動だけで敵を倒す6分間の3Dサバイバルを制作。
- Context: Issue #62、承認済み会話仕様、ルートdocsのデザイン/フロントエンド/日次スタイル。
- Constraints: Blenderで実モデルを制作しblend/GLB/再生成スクリプトを保存。平面移動、固定角度カメラ。既存アプリを変更しない。
- Done when: 1ステージ/1主人公/通常敵3種/ボス/4武器/最大3装備/強化3択/勝敗/停止/再挑戦/記録が動作し、テストとブラウザで検証。

## Rules
WASD/矢印、または画面スティックで移動。近くの敵へ自動攻撃。電池で経験値を得てレベルアップ中は停止。吸引ノズル、回転モップ、泡スプレー、お掃除ディスクは各5段階、3枠。補助強化は移動速度/回収範囲/最大HP/攻撃間隔、各3段階。選択肢に上限済みの能力を出さない。全能力取得後は回復選択。
通常敵はホコリ玉、予告後直線突進する綿ぼこり、頑丈な段ボール。300秒でボスを1体生成、360秒で時間切れ。ボス撃破で勝利。接触後1秒無敵。回復は上限HPで止める。画面外で敵生成。平面境界は半径28、地形装飾は外周。

## Design
ゲームを大きく表示。クリーム #f5eddc、インク #292d31、オレンジ #ed713b、ホコリ紫 #9282ae、回収ミント #68bcb1。5色の役割を基準に明暗のみ追加。太い輪郭・硬い影・明瞭な見出し。3Dの陰影は立体を読むための例外で、装飾的なグラデーションや発光は使わない。
Blenderモデルは丸みのあるローポリ、黒いバンパー、大きな目。敵も目とシルエットで区別。装備は実モデルが周囲に増える。カメラは上方から、操作方向は画面方向に対応。前景に高い遮蔽物を置かない。

## States and engineering
初期/読み込み/再試行/3D不可/開始/強化/一時停止/敗北/勝利/保存不可。タブ非表示・blur・Escで停止、再開明示。キーボードで強化と再試行も操作。reduced-motionで装飾バウンスを抑制。
ReactはHUD、Three.jsはGLBと反復描画。依存追加はGLB読み込みとGPUインスタンス描画のため。60Hz固定更新、敵描画はインスタンス化、粒子と拾得物に上限、画素密度を制限。アセットはローカル、外部API不要。PC200体60fps/スマホ100体30fpsは目標であり実測と区別する。
