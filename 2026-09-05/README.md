# ホコリ無双 — 深夜のおそうじ隊

移動だけで、倉庫まるごと大掃除。Blenderで制作したロボとホコリの群れが戦う、6分間の3Dサバイバルです。

## 開発

```sh
npm ci
npm run dev
npm run check
```

React / TypeScript / Vite / Three.js / Vitest / oxlint。GLB、UI、効果音をローカルで処理し、外部APIやアカウントを使いません。

## 操作・ルール

- WASD / 矢印キー、スマホ・タブレットはスティックをドラッグして移動。攻撃は自動。
- 敵の電池を回収してレベルアップ。停止中に3択から装備を選ぶ（数字1/2/3にも対応）。
- 武器は吸引ノズル・回転モップ・泡スプレー・お掃除ディスク。最大3装備、各5段階。
- 移動・回収範囲・最大HP・攻撃間隔の補助強化は各3段階。
- 5分でボス「大掃除のこし」出現。6分までに撃破するとクリア。HPゼロ・時間切れで終了。
- Esc / 一時停止 / タブ非表示 / フォーカス離脱で停止。再開は明示操作。
- 音は初期OFF。演出軽減では装飾バウンス・拾得物の回転を省略。攻撃の範囲と予告は維持。
- 終了時に最高討伐数・クリア実績を `hokori-best-v1` に保存。保存できなくてもプレイ可能。

## Blender原本と再出力

`assets/source/cleaning-kit.blend` が画面上でレビュー・修正した正本です。ロボ、敵4種、武器4種、拾得物2種、床、小物3種、計15アセットを含みます。

Blenderをcomputer-useで開いてロードし、全体配置と主人公・ボスを拡大確認しました。ボスの白目が凹凸に埋まっていたため、Blenderのプロパティ画面で白目/瞳を2倍にして前へ移動。マテリアル画面でオレンジ・インク・紫の色を調整しました。確認画像は `screenshots/blender-*.png`。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/export-assets.py
```

これは保存済み原本を読み、各モデルの配置を一時的に原点へ戻してGLB出力します。原本を上書きしません。`public/models/manifest.json` にBlender版、各ファイルのサイズ・三角形数を記録します。

`create-assets.py` は初期モデルの生成履歴です。レビュー済み原本がある場合は停止します。`-- --rebuild-base` は画面上の修正を破棄する明示オプションなので、通常は使いません。

## 検証

`npm run check` はlint、12テスト、型チェック、本番build。移動正規化・境界・停止・画面外生成・接触無敵・回復上限・勝敗・強化制限・全武器・突進予告・3seedの通し走行・15GLBの構造・記録の破損/保存失敗を検査します。

DEV限定の検証画面（本番では無効、記録を保存しない）：

- `?qa=upgrade`：強化3択、キーボード操作
- `?qa=boss`：最終装備のボス戦
- `?qa=stress`：200体を固定した描画負荷テスト（シミュレーション時間停止）
- `?qa=won` / `?qa=lost`：結果と再挑戦
- `?qa=error`：初回失敗→再試行→正常読み込み
- `?seed=42`：通常プレイの乱数初期値固定

詳細な検証記録と制限は `docs/VERIFICATION.md`。
