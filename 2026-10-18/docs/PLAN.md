# 実装計画

- Goal: 音声ファイルの必要部分を、外部送信せずブラウザ内でMP3/M4Aに切り出し保存する。
- Context: ルート共通UIとWeb指針、既存Viteアプリ/カタログ構成を参照。新規アプリなので既存UIの変更はない。
- Constraints: 同梱依存のみ、解析/外部取得/アップロードなし、入力と出力を永続化しない。元ファイルは変更しない。公開しない。
- Done when: 実音声から両形式を出力し、実ブラウザ操作・出力の内容・通信なしを検証。AstraレビューとPR/CIの証拠を記録。

## 順序
1. 最小エンコード試作でMP3/M4Aと同梱worker/WASMを確認。
2. 範囲と時間の純粋処理、読込/再生/エンコードのライフサイクルを実装。
3. ファイル読込→波形選択→試聴→出力を一画面に実装。
4. 実音声・異常入力・キャンセル・オフライン・異なる幅で検証。
5. カタログへ登録し、Astraレビュー、PR、CIへ進む。

## 分担
親: 音声エンジン、時間・範囲処理、依存、検証、統合、Git管理。
UI担当: Appと波形UI/CSSのみ。APIは親の契約を使用。
調査担当: 公式エンコーダーのAPI、サイズ、互換性、ライセンスの調査のみ。
