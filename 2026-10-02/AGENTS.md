# BLACK RELAY / Urban slice

Goal: an original Godot zombie typing rail shooter. Current approved scope is one exceptional60–90second shopping-street slice before extending stages. The prior station milestone is backed up outside this repo; preserve old apps and deliverables.

- Godot4.7.2 / GDScript. Main, world, enemy, HUD and romaji remain separate scripts
- Native runtime pixels are the quality gate, not engine selection or number of tests
- Skinned human enemies, visible connected FPS hands/gun, authored city traversal, readable worlds
- Primary rule: one full word kills. CUT is optional contextual stagger, never required armor
- Wrong keys do not erase progress; preserve alternate romaji, terminal n/nn, per-target partial input and score-profile fairness
- No hard typing timeout:75seconds advances the route; remaining threats keep the encounter active
- Licensed free assets may be reused with original source/license verification and distribution notices. No ripped franchise assets
- Keep effects away from words. Reduced motion suppresses bob/shake, not necessary route traversal
- Run `GODOT_BIN=/workspace/shared/godot/bin/godot npm run check`, export native builds, and perform actual native interaction/capture QA
- Browser ERR_BLOCKED_BY_CLIENT is an access restriction, not an invitation to bypass it
- Cloud has llvmpipe, not a discrete GPU. Distinguish software rendering measurements from unverified GPU performance
- Do not modify older dated apps or publish, push, create PRs, merge or deploy without authorization
