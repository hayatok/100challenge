# ちび車グランプリ

- Goal: 1コース、CPU3台、3周レース、タイムアタック。
- Context: 承認済み企画、Kenney Racing Kit、Godot 4.7.2。
- Constraints: コースの配置と保存はGodot GUI。実行時のコース生成なし。既存アプリを変更しない。
- Done when: 周回・順位・再走・保存を検証し、エディタ編集の反映とデスクトップ/モバイル実画面を確認。

## 手順
1. 素材取得と道路部品の準備。
2. GUIで道路を並べて試走、カーブの速度と視認性を調整。
3. CPU・周回・記録・UI・タッチ操作。
4. headlessロジック検証、GUIとWebの実走・幅確認、GitHub PR。

## 制作方法
道路部品は静的な再利用シーン。コース内へのインスタンス追加・移動・回転・保存はComputer UseでGodotを操作する。道路の中心線は部品ごとのローカル座標を読み取るもので、シーンを生成しない。
