# かきかたノート

## 目的と制約

Markdown初心者がメモや手順書を書き、必要な記法をその場で確かめるブラウザアプリ。編集本文、プレビュー、任意の練習を分ける。本文で記法を使ったことと練習の完了を区別し、習得や学習効果を保証しない。

本文はブラウザ内に保存する。本文を外部へ送信する機能を追加しない。インポートはUTF-8のMarkdownとテキスト。入力を検証し、HTML表示は必ずDOMPurifyを通す。

## 技術と実行

Vanilla JavaScriptとVite。`npm ci`、`npm run dev`。検証は`npm run check`。Markedの構文木をプレビューと練習判定で共用する。記法の正規表現検出だけで練習を完了扱いしない。

## 画面の確認

主対象はPCの1440×900。390px、768px幅でも本文の編集、プレビュー、練習、ファイル保存を操作できること。日本語IME入力中の置換を避ける。保存不可、空文書、ファイル読込失敗、練習の正答・誤答を確認する。

仕様は`docs/PLAN.md`、見た目は`docs/DESIGN.md`を参照する。
