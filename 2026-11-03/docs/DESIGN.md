# 画面の設計

紙の手帳と編集机を手がかりに、入力と仕上がりを読み比べられる画面にする。見出しはシステムの明朝体、操作と本文はシステムの日本語サンセリフ、Markdownは等幅フォント。フォントファイルや外部フォントは配信しない。

ルートの共通UIトークン、44px以上の主な操作面、フォーカス輪郭、4pxの角丸を使う。用紙に相当するプレビューだけ白い面にする。主操作は赤、練習完了は緑で文字も添える。学習の補助色として青を使う場合も状態の意味色を置き換えない。

PCはMarkdownとプレビューを主面に並べ、書き方ガイドを右に置く。小さい画面では書く・プレビューの切替を表示し、ガイドを下へ送る。学習ガイドは記法を一つずつ示し、練習を任意で開く。見出しとツールバーは本文の編集位置を奪わない。

初期文書は記入例と分かる短いメモ。テンプレートを選ぶときとファイルを読み込むときは、本文を置き換える前に確認する。空欄には記入の手がかりを表示する。保存結果とエラーは文字で伝える。
