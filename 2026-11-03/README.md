# かきかたノート

メモや手順書を書きながら、Markdownの書き方を確かめるブラウザアプリです。

## 使い方

1. 記入例のメモを書き換えるか、「ひな形から始める」で手順書や空白の文書を選びます。
2. 左にMarkdownを書き、右のプレビューで仕上がりを確認します。狭い画面は「書く」「プレビュー」を切り替えます。
3. 記法を忘れたら書式ボタンで挿入し、手引きで意味を確かめます。
4. 「自分で試す」を開くと、本文を変えずに練習できます。回答にもプレビューが付きます。
5. 「.mdを保存」でファイルを手元に残します。「開く」からUTF-8の`.md`、`.markdown`、`.txt`を読み込めます。

見出し、太字、箇条書き、リンク、引用、コード、タスク、表を扱います。本文での使用と練習の完了は別に記録します。完了表示は課題の条件を満たした記録であり、記憶の定着や習得の判定ではありません。

## 保存と表示

下書き1件と練習の完了を、このブラウザのlocalStorageに保存します。別の端末・ブラウザ・配信URLには同期しません。ブラウザのデータを削除すると下書きも消えます。保存できない場合は画面に表示するので、`.md`ファイルとして保存してください。本文は100,000文字、読込ファイルは500KBまでです。

本文はブラウザ内で処理し、アプリから外部へ送信しません。プレビュー内のリンクを開くとリンク先へ移動します。生HTMLは文字として表示し、画像は代替テキストを表示します。画像URLからの自動読込は行いません。表とタスクはGFMの拡張記法です。表示先によって見た目や対応範囲が異なります。

## 開発

Node.js 24で次を実行します。

```bash
npm ci
npm run dev
npm run check
```

`check`はNode.jsのテストとViteの本番ビルドを実行します。JavaScriptのアプリのため独立した型チェックはありません。`dist/`を静的配信でき、相対パスのビルドに対応しています。

記法の解析には[Marked](https://marked.js.org/)、HTMLの無害化には[DOMPurify](https://github.com/cure53/DOMPurify)を使います。書式の組合せを独自の簡易パーサーで実装せず、表示と練習で同じ構文木を使うためにMarkedを追加しました。Markedの出力はそのまま表示せず、DOMPurifyを通します。Viteは依存をブラウザ向けにまとめるために使います。

制作方針は[PLAN.md](docs/PLAN.md)、画面の設計は[DESIGN.md](docs/DESIGN.md)、検証の範囲は[VERIFICATION.md](docs/VERIFICATION.md)に記録しています。
