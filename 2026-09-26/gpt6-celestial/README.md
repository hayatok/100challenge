# GPT–6 / CELESTIAL

24秒の非公式コンセプトティザー。Astra＝星座、Sol＝太陽、Luna＝月。

現在は **CUT 02**。星がASTRAの文字になる粒子アニメーション、文字への接近と星空の通過、太陽の放射運動と日食、LUNAの帯状の文字組み立て、三分割のモデル紹介、粒子から6への変形を収録しています。前の版は `versions/v1.html` に保存しました。

**`index.html` をブラウザで開き「PLAY FILM」を押してください。** フォント・描画コード・オリジナルの音声合成コードを内包した単一HTMLです。通信、サーバー、インストールは不要です。

- 再生／一時停止、最初から、シーク、場面ジャンプ、全画面。
- 音は初期OFF。「音：ON」にするとオリジナルのシンセ音を映像と同期して再生します。
- キーボード：操作部品以外にフォーカスがあるとき、Spaceで再生／停止、左右キーで1秒移動。スライダーは標準キー操作ができます。
- 画面を離れると一時停止。自動再生・自動ループなし。
- 16:9の映像を画面に収めます。モバイルでも映像比率は維持します。

## 編集

`src/film.js` は時刻だけからCanvasを描くレンダラー、`src/score.js` は同じ24秒の音声波形生成、`src/player.js` は再生コントロールです。`src/page.html` と `src/style.css` が外枠です。

```sh
npm run check
npm run build
npm run dev
```

buildはNode標準ライブラリだけで単体HTMLを作ります。ランタイムの外部ライブラリ、HyperFrames、MP4、画像・動画生成サービスは使用していません。`?t=6` のように時刻を指定すると、その場面で停止して開けます。

## 素材と表現

Space Grotesk（SIL Open Font License、`assets/OFL.txt`）を埋め込み。天体・図形はコードで描画し、音楽は独自の数式合成で、外部音源なし。名称と天体モチーフを紹介する映像であり、性能比較や公式広告・公式ブランド仕様を表明するものではありません。
