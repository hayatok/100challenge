# CELESTIAL / GPT–6

Astra・Sol・Lunaを天体と文字の動きで紹介する、24秒の非公式コンセプト映像。
HTML / CSS / JavaScript / Canvasで制作。HyperFramesや外部ランタイム依存は使用していません。

公開URL: https://hayatok.github.io/100challenge/2026-09-26/

- `npm run check`: 映像の構文・音声テストとPages用ビルド。
- `npm run build`: 自己完結したCUT 02のHTMLと一覧用サムネイルだけを `dist/` に出力。
- `npm run dev`: ローカルの映像プレーヤーを起動。

ソース、フォントライセンス、制作・検証記録は `gpt6-celestial/` にあります。
これは映像作品の公開であり、モーショングラフィック制作アプリの実装ではありません。
