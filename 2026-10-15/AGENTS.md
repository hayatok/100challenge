# 表のコピペ救出

## Goal / Context

画像内の日本語の表を、端末内で認識し、元画像と並べて修正し、Excelなどへ貼り付けられる静的Webアプリを作る。ルート `AGENTS.md`、`docs/DESIGN.md`、`docs/FRONTEND.md` に従う。Issue #166。

## Constraints

- React + TypeScript + Vite。OCRと表構造の復元を分離する。OCRの出力は座標と信頼度を検証して使う。
- 画像・OCR結果をサーバーへ送らない。OCRコード・モデルの取得だけを許し、UIで初回取得を説明する。
- WebGPU / WASM の表示は実際の実行プロバイダに基づく。対応確認だけでGPU実行済みと扱わない。
- 1枚のPNG/JPEG/WebP等の横書き・印刷体の表を主対象とする。日本語・英数字・空白セルを扱い、罫線のある表を優先する。複雑な結合見出し・斜め撮影・手書き・PDF直接読込は初版の保証範囲外。
- サンプルも実画像から同じOCR処理を通す。固定の認識結果やテスト専用成功経路を実装しない。
- 認識前後のセル編集、行列修正、Undo/Redo、TSV/HTMLコピー、CSV保存を実装する。外部表計算に式として実行される先頭文字は既定で保護する。
- 未追跡の過去アプリの作業物を保持。変更はこの日付フォルダと登録に必要な `apps.json` / `README.md` / カタログテストに限定。公開・タグ作成はしない。

## Done when / Verification

`npm run check` を正とし、意味のある表復元・書き出しテスト、lint、型、buildを行う。実ブラウザで日本語と数値・空白セルの認識、貼り付け、修正、Undo/Redo、クリップボード内容、CSV、失敗と再試行、キャンセルを検証する。1440pxと375pxを確認し、未確認を `docs/verification/RESULTS.md` へ記録する。主対象はデスクトップChromium。iPhoneなど未実測の端末を検証済みにしない。
