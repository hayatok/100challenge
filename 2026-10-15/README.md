# 表のコピペ救出

スクショや画像内の表を読み取り、元画像と並べて直し、ExcelやGoogleスプレッドシートへ貼り付ける作業机です。

## 使い方

1. 表のスクショを貼り付けるか、画像ファイルを選択します。日本語サンプルでも実際のOCRを試せます。
2. 表以外の文字がある場合は、画像をドラッグして表の範囲を指定します。数値指定もできます。
3. 「表を読み取る」を押します。初回はモデルとランタイム（約56.3MB＋認識コード）をこのアプリの配信元から読み込みます。
4. 元画像とセルを見比べ、文字や行・列を修正します。Tabで次、Enterで下、Alt+Enterで改行。Undo/Redoできます。
5. 「表をコピー」でTSVとHTMLをコピーするか、UTF-8のCSVを保存します。

画像と認識結果はブラウザ内だけで処理します。外部OCR API、アカウント、APIキーは不要です。画像や表の自動保存はしないため、ページを閉じる前にコピーか保存をしてください。

## 対応範囲

- PNG / JPEG / WebP / BMP、12MB・1600万画素まで。認識時は長辺2400px以下へ縮小します。
- 日本語・英数字の横書き印刷体。罫線のある単純な表を優先し、罫線なしは文字の配置から推定します。
- 最大100行×40列。セルを押すと元画像の認識箇所を強調表示します。
- 罫線のある空白セルは位置を保持します。罫線なしの完全な空白行・列、結合セル、手書き、斜め撮影は正しく復元できない場合があります。
- PDF直接読込は対象外。PDFの表はスクショにして取り込んでください。
- 数式になる先頭文字はアポストロフィで保護します。通常の負数は維持します。HTMLコピーには文字列形式のヒントを付けますが、CSV/TSVの読み込み先が先頭ゼロを数値に変換する場合があります。

主対象はデスクトップのChromium系ブラウザです。GPUが使える場合はWebGPUでOCR推論し、自動選択で利用できない場合はWASMへ切り替えます。実際に使った処理方式は画面下の詳細に表示します。WebGPUが常に速いとは限りません。

## 開発

```bash
cd 2026-10-15
npm ci
npm run setup
npm run dev -- --port 4185
```

`npm run setup`は公式モデルを取得し、サイズとSHA-256を検証してローカルに固定します。モデルを更新する際はハッシュと実画像の検証も更新してください。

```bash
npm run check
npm run preview -- --port 4185
```

依存関係はPaddleOCR.js（日本語OCR）、ONNX Runtime Web（WebGPU/WASM）、OpenCV.js（Worker内画像変換）、React/Vite（UI/ビルド）です。モデルとランタイムはビルド時に用意し、実行時に外部OCRサーバーへ画像を送りません。
