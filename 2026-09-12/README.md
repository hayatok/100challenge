# まるのみ怪獣 — 0.5

小さな怪獣「モグ」が街を食べて大きくなる、PC向けの3Dアクションゲーム。
車を戦車へ弾いて装甲を崩し、射撃の隙にコアをかじる。成長すると、武器にしていた車も、怖かった戦車も、そのまま食べられる。

[GitHub Pagesで遊ぶ](https://hayatok.github.io/100challenge/2026-09-12/)

## 遊ぶ

```sh
npm run play --prefix 2026-09-12
```

Godot 4.7.2 が必要。macOSでは `/Applications/Godot.app` を使用。別の場所の場合は `GODOT_BIN` を指定する。開発環境の準備は `npm run setup --prefix 2026-09-12`。

Web版:

```sh
npm run build --prefix 2026-09-12
npm run preview --prefix 2026-09-12
```

[ローカルで遊ぶ](http://127.0.0.1:8122/) — WebGL 2対応ブラウザ、キーボードとマウスが必要。スマートフォンのタッチ操作は未実装。

| 操作 | 動作 |
| --- | --- |
| WASD | 移動 |
| マウス | 狙う方向 |
| 左クリック / 押し続ける | かじる |
| Space | 突進。2回分を使い分け、時間で回復 |
| 右クリック | 変異技 |
| Esc | 一時停止 / 再開 |

最初は自販機を食べるか、車を弾いて戦車の装甲を崩す。敵の予告線に留まらず、撃った後の隙へ。大怪獣になったら大通りの奥の工事ロボ「ドーザン」へ向かう。突進・地面攻撃を避け、露出したコアを3回かじる。3つのコアを壊せばクリア。

## 0.5の内容

- 1つの街区、3段階の成長、成長で変わる捕食対象と壊せる建物。
- 雷のツノ / ドリルの頭 / バネの脚。姿と技が変わる3系統、各1段階の強化。
- 砲撃戦車 / 突進車 / 迫撃砲の3種と、3コアのボス戦。
- 突進の回数管理、予告と攻撃後の隙、車の連鎖衝突、捕食回復。
- 待機・歩行・走行・停止・捕食・突進・被弾・成長・喜びの9アニメーション。
- タイトル、一時停止、変異選択、勝敗、即再挑戦。覚えた変異を次の冒険の最初から選択。
- 接触時の短いヒットストップ、破片、口元への捕食演出、オリジナル効果音と音楽。

## Godotで編集する

`game/project.godot` を開き、`game/main.tscn` を選ぶ。街・道路・建物・敵・プレイヤーは、実際にGodot GUIでインスタンスを追加し、Inspectorで配置して保存したもの。実行前からローカルのシーンツリーに存在する。

| 変更したいもの | 開くファイル / 操作 |
| --- | --- |
| 街、敵、車の配置 | `game/main.tscn`。各ノードのTransformを変更 |
| 足の運び、口、尻尾の演技 | `game/scenes/player.tscn` → Visual → AnimationPlayer |
| 主人公の形・色・部位 | `source/mogu.blend`。頭・顎・腕・脚・尻尾の階層を保持 |
| 車・建物・敵の形 | `source/miniatures.blend`。モデルごとのCollection |
| 戦車の察知距離・予告・隙 | `game/scenes/tank.tscn` のInspector |
| 光 / カメラ距離 | `game/scenes/lighting.tscn` / `camera_rig.tscn` |
| 変異パーツ | `game/scenes/mutation_*.tscn` |
| UIの位置と文字 | `game/scenes/hud.tscn` |
| 入力・成長・敵AI・勝敗 | `game/scripts/` |

再利用シーンの初期ファイルとモデルは制作ツールで準備し、レベルの追加・配置・光・カメラ・戦車の数値調整には実際のGUIを使用した。ランタイム生成は弾、破片、接触エフェクト、選択した装備など一時的な要素に限定。アニメーションは3Dの部位ごとのキーフレームで、一枚絵の移動ではない。

`source/*.blend` と `.tscn` が編集の正本。`scripts/make_models.py` は原型の再生成用で、実行すると手作業のモデル修正を上書きするため、通常の編集では実行しない。
