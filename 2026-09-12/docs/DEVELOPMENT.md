# まるのみ怪獣 0.5 制作記録

Goal: 小さな怪獣が街の物を弾き、装甲を崩し、食べて成長し、以前の脅威を蹴散らしてボスを倒す一周を作る。
Context: 承認済みの「まるのみ怪獣」への作り直し企画。前作は停止したまま同じ入力で勝て、成長と演技が欠けていた。
Constraints: Godot 4.7.2 / Compatibility / 型付きGDScript。レベル配置は実際のGUIで作成・保存。ロジックと静的配置を分離。設定項目は後工程。既存アプリは保持。画像生成モデル名・品質パラメータは内蔵ツールでは確認不可、ユーザー承認済み。
Done when: 3体格、3変異と各強化、3敵種、ボス、成長と変異選択、勝敗、保存される解放、再挑戦が繋がる。関節アニメーション、接触演出、効果音と音楽を備え、実画面と操作、行動テスト、Web出力を確認する。

## 工程
1. 編集可能なキャラクターモデルと再利用パーツ、プロジェクトを準備。
2. Godot GUIで試験用の遭遇とレベルを配置。入力、捕食、車の衝突、砲撃予告を実装し操作確認。
3. 成長、変異、敵の行動、ボス、勝敗・再挑戦を接続。
4. 実際のゲームカメラでアニメーション・街・UI・音を調整。
5. ネイティブ操作、行動テスト、Web版と複数画面幅を確認。検証済みと未確認を分けて記録。

## 制作方針
- 半径約35mの街区、徒歩速度6m/s、突進約7m。開始位置から安全な捕食、単体戦車、複数射線、工事広場へ進む。
- 敵を倒せばその射線が消え、安全に食べる時間になる。成長直後の既存敵を強化しない。
- 3Dの関節ごとのキーフレームをAnimationPlayerに取り込み、歩行・走行・捕食・突進・被弾・成長を使い分ける。
- 再利用する部品のファイル作成にはツールを使う。街のインスタンス追加、配置、カメラと光の調整、保存、再実行はGodot GUIで行う。
- 原画の綺麗さのみをアセット品質としない。ゲーム中のシルエット、足の接地、顔、接触との一致を確認。

## 実装・検証結果

- 3体格、3変異と強化、3敵種、3コアのボス、保存される変異、再挑戦まで接続した。
- main.tscnの街区配置をGUIで保存し、カメラ・光・戦車の察知距離と隙をInspectorで調整して再実行した。
- 足が滑る印象を減らすため、移動中の体の向きと走行周期を合わせた。捕食中は顎の位置へ対象を移す。
- 初期ボスの一度きりの隙では単調だったため、突進と地面攻撃、3つのコア、各3回の捕食を組み合わせた。
- 画像生成は道路テクスチャに使用。キャラクターは3D部位アニメーションへ変更し、GLBとBlender編集元を同梱。
- 挙動33項目、3変異の自動クリア、ネイティブ操作、Webと複数画面幅、変異・強化・結果画面を確認。詳細はVERIFICATION.md。
- ゲームの一周は成立したが、体感の面白さと初見のプレイ時間については人の評価を次の調整材料にする。
