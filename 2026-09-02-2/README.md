# 勇者監督局

勝手に冒険する勇者へ、のうりょく査定と攻略方針だけを出す観察型ダンジョンゲームです。

seed付きで生成される5階層の迷宮を勇者が自動探索します。プレイヤーは直接移動や攻撃を命令せず、レベルアップで3ポイントを配り、階段前に`安全第一 / 経験値優先 / 奥へ進む`の方針を選びます。最下層の「迷宮事業部長」を倒せば攻略完了です。

## Development

```bash
npm install
npm run dev
npm run check
```

## Validation routes

- 通常: `/`
- seed固定: `/?seed=20260902`
- 完全オート検証: 派遣後に右側の`全自動局長`レバーをON
- 攻略方針指定: `/?policy=deep`
- のうりょく査定: `/?demo=levelup`
- 階段前: `/?demo=checkpoint`
- 殉職報告: `/?demo=dead`
- 攻略報告: `/?demo=victory`

## Implemented

- 40×28タイル、全5階層の決定的なランダム生成
- 3方針で目標選択が変わる自動探索AI
- `全自動局長`レバーによる配点・方針変更・階段移動の完全オート
- 通常敵、エリート、ボスとの自動戦闘と方針別の退却基準
- 宝箱、戦利金、回復薬、能力付き装備と実況イベント
- 腕力、体力、すばやさ、運へのレベルアップ配点
- 停止、1倍、2倍、4倍の観察速度
- 375pxでは勇者を追う20×16タイル表示
- briefing、査定、階段、殉職、攻略完了の各画面
- 追尾カメラ、敵別pixel sprite、宝箱、斬撃、damage/loot表示
- 同じseedでの再挑戦と端末内の直近10報告の保存
