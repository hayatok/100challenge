# 勇者監督局 — Concept Spec v0.1

## 1. Product summary

### 一言でいうと

勝手に冒険する勇者を「勇者監督局」の職員として見守り、節目の人事査定だけで生還へ導く、1プレイ12〜20分の観察型ダンジョンゲーム。

### 体験の核

- 普段は、勇者の判断と小さな事件を眺めて楽しむ
- レベルアップでは3ポイントを配り、次の数分の展開を変える
- 階段前のチェックポイントでは、攻略方針を切り替える
- 直接移動や攻撃は命令できない。思い通りにならない勇者を育てる
- 最下層のボス撃破、または勇者の死亡で1回の冒険が終わる

### 仮タイトルとコピー

- Product name: **勇者監督局**
- Tagline: **また勝手に奥へ行きました。**
- Player role: 王国勇者監督局・地下迷宮遠隔指導室の担当官

## 2. Design goals

1. 3秒見れば「勇者が自動でダンジョンを歩いている」と分かる
2. 30〜60秒ごとに、戦闘、発見、危機、成長のどれかが起きる
3. 介入は少ないが、配点と方針で結果が明確に変わる
4. 数字を最適化するだけでなく、勇者の間の悪さや意外な生還が物語になる
5. 失敗しても「次は別の育て方で」とすぐ再挑戦できる

避けること:

- 手動移動、手動攻撃、戦闘中スキル連打
- 放置しても必ず勝てる進行
- 通貨、ガチャ、デイリー報酬など、冒険外の管理要素
- 常時変更できる細かすぎるAI設定
- 特定の既存作品のキャラクター、UI、マップ表現の模倣

## 3. One-run loop

1. **採用** — 名前、顔、初期能力、1つの性格がランダムな勇者を確認する
2. **派遣** — seedから5階層の迷宮を生成し、自動探索を開始する
3. **観察** — 勇者が移動、戦闘、宝箱、回復、撤退判断を自動で行う
4. **査定** — レベルアップ時に時間が止まり、3ポイントを能力へ配る
5. **指導** — 各階の階段前で、次階の攻略方針を1つ選ぶ
6. **決着** — 第5階層のボスを倒すか、HPが0になる
7. **報告書** — 到達階、死亡理由、配点履歴、印象的な3事件を1枚で表示する

想定テンポ:

- 1フロア: 2〜4分
- レベルアップ: 1ランで5〜8回
- 方針変更: 最大4回
- ボス戦: 30〜60秒
- 全体: 12〜20分（2倍速なら7〜12分）

## 4. Player decisions

### 4.1 レベルアップ査定

レベルアップでゲームを自動停止し、3ポイントを配る。配点確定前は何度でも戻せる。

| 能力 | 主な効果 | 見た目で分かる変化 |
| --- | --- | --- |
| 腕力 | 与ダメージ、重い武器の適性 | 敵を倒す手数が減る |
| 体力 | 最大HP、防御、回復薬の効率 | HPバーと生存余裕が増える |
| すばやさ | 攻撃間隔、回避、逃走成功率 | 戦闘と退却が速くなる |
| 運 | 会心、良品ドロップ、罠回避 | たまに大きな番狂わせが起きる |

補助操作:

- **おすすめ配分**: 現在の弱点を説明付きで提示するが、自動確定はしない
- **この冒険は自動査定**: 以後は選択中の育成型で自動配分する
- 自動査定中も、レベルアップ演出と配点結果は2秒表示する

### 4.2 攻略方針

方針変更はレベルアップ画面と階段前だけ。いつでも切り替えられる設定にはしない。

| 方針 | 行動傾向 | 退却目安 | 向いている状況 |
| --- | --- | --- | --- |
| 安全第一 | 格下、回復、既知の安全路を優先 | HP 45% | 瀕死、装備不足 |
| 経験値優先 | 経験値/時間が高い敵、エリートを優先 | HP 30% | レベル不足を解消したい |
| 奥へ進む | 未探索の扉と階段を優先、不要戦闘を避ける | HP 20% | 十分育った、時間を縮めたい |

各ボタンには抽象名だけでなく、現在の勇者についての予測を添える。

例: `安全第一 — 勝てそうな敵だけ狙います / 推定生還率 82%`

### 4.3 観察速度

- 停止
- 1倍
- 2倍
- 4倍

レベルアップ、初見のエリート、ボス遭遇では高速中でも1倍へ一時的に落とす。`prefers-reduced-motion` ではカメラ移動を瞬時に切り替える。

### 4.4 完全オート

指示盤の物理レバー「全自動局長」をONにすると、レベルアップ配点、状況に応じた方針変更、次階への移動を自動で処理する。ONの間も判断結果は実況電報へ残し、いつでもOFFへ戻せる。通常モードでは従来どおり査定と階段前で停止する。

## 5. Simulation rules

### 5.1 Dungeon

- 1フロア40×28タイル、全5階
- 部屋と通路をseed付き乱数で生成する
- 開始地点から階段まで必ず到達可能にする
- 通常敵、エリート、宝箱、回復所、罠、階段を配置する
- 未踏部分は黒、隣接部分は輪郭、踏破部分は通常色で表示する
- 深層ほど敵の基礎危険度と良品率が上がる

### 5.2 Hero AI

勇者は毎回、見えている候補へ点数を付けて次の目的地を決める。

`目的地スコア = 方針の優先度 + 報酬 - 推定危険度 - 移動距離`

推定危険度は正解ではなく、未遭遇の敵には誤差を持たせる。これにより、ときどき判断ミスが起こるが、理不尽な自殺には見えないバランスにする。

性格は数値補正より、行動の癖を1つだけ加える。

- 慎重: 未知の部屋の危険度を高めに見積もる
- 強がり: HPが半分を切るまで回復所を軽視する
- 拾い魔: 見えている宝箱へ少し寄り道する
- 方向音痴: 同点の経路選択をたまに間違える

### 5.3 Combat

- 同じタイルに接敵すると、0.3〜0.6秒ごとに自動攻撃する
- 通常敵は2〜8秒、エリートは8〜15秒、ボスは30〜60秒を目安にする
- ダメージ、回避、会心、回復薬使用は頭上の短い数値と1行実況で伝える
- HPが退却目安を下回ると、勇者は既知の回復所または安全な部屋を目指す
- 逃走経路を完全に塞がれることはあるが、生成時に不可避の即死配置は除外する

## 6. Screen design

### 6.1 Desktop: 1440×900

```text
┌ 第3地下迷宮 ─ 勇者アルト Lv.12 ─ HP 38/50 ─ EXP 72/120 ─ 00:42:18 ┐
├──────────────────────────────┬──────────────────┤
│                              │ 勇者監督局       │
│   ランダム生成ダンジョン     │                  │
│   ・勇者を常に画面内へ       │ 攻略方針         │
│   ・未踏は黒                 │ [安全第一]       │
│   ・戦闘時だけ軽く寄る       │ [経験値優先]     │
│                              │ [奥へ進む]       │
│                              │                  │
│                              │ 実況電報 3件     │
├──────────────────────────────┤ 速度 1x 2x 4x    │
│ [停止]  次の節目: あと35EXP  │ 音 / ルール      │
└──────────────────────────────┴──────────────────┘
```

優先順位:

1. ダンジョンと勇者
2. HPと次の危機
3. 現在の方針
4. 実況、速度、補助操作

レベルアップ時は中央に「のうりょく査定票」を重ね、背景の迷宮を暗くする。数値の`+`だけでなく、確定後に何が変わるかを行内へ表示する。

### 6.2 Mobile: 375×667

- ヘッダーは階層、Lv、HPだけに圧縮する
- 正方形に近いダンジョンを最上部へ置き、勇者を追尾する
- 下部に`停止`と現在方針の2操作を固定する
- 詳細は`勇者 / 方針 / 実況`のボトムシートで切り替える
- レベルアップは全画面ではなく下から出る査定票にし、迷宮上部を少し残す
- 能力4行、残りポイント、確定ボタンを667px高の初期viewportに収める
- hover前提にせず、タイルの詳細はタップ後の短いラベルで示す

### 6.3 Important states

| State | 表示 | 次の操作 |
| --- | --- | --- |
| 初回 | 採用通知と勇者の性格 | `この勇者を派遣` |
| 生成中 | 地図用紙が1枚ずつ押印される | 600ms以内、操作不要 |
| 観察中 | ダンジョン、勇者、現在方針 | 停止または待つ |
| レベルアップ | 査定票、残り3pt | 配点して確定 |
| 階段前 | 次階の危険予報 | 方針を選ぶ |
| 瀕死 | HP枠と実況に警告、色だけに頼らない | 観察のみ |
| 死亡 | 死因と直前3事件 | 同seed / 新seedで再派遣 |
| クリア | ボス撃破と冒険報告書 | 新しい勇者を採用 |
| 保存失敗 | 記録だけ保存できない旨 | 冒険は継続 |
| sprite失敗 | 単色の記号タイルへfallback | 冒険は継続 |

## 7. Visual direction

### Metaphor

主役は「迷宮」だが、外枠だけは用途に対して過剰に官僚的な勇者管理設備にする。レベルアップを能力画面ではなく人事査定、ゲームオーバーを殉職報告、クリアを事業完了報告として扱う。

ジョークは勇者の死そのものではなく、命がけの冒険を承認印と件数カウンターで管理する制度のズレに置く。

### Palette

| Role | Color | Usage |
| --- | --- | --- |
| Parchment | `#E8D6A8` | 査定票、本文面 |
| Soot | `#171A17` | 背景、文字、太い輪郭 |
| Moss | `#536B3D` | 安全、通常操作 |
| Ochre | `#C58A22` | 経験値、注意、選択中 |
| Brick | `#A53B2F` | 危険、奥へ進む、HP低下 |

### Shape, type, motion

- 12×12または16×16基準のオリジナルpixel sprite
- 3px前後の太い暗色輪郭、ぼかしなしの硬い影
- 角丸カード、ガラス、発光、グラデーションは使わない
- 見出しは太い日本語ゴシック、数値と機械ラベルは等幅
- 攻撃は2〜4pxのノックバック、被弾は80msの明滅、レベルアップは判子が180msで着地
- 通常の演出は700ms以内。常時揺れや常時点滅は行わない

## 8. MVP scope

含める:

- seed付き5階層ダンジョン生成
- 勇者1人、性格4種、敵6種、ボス1種
- 自動探索、自動戦闘、自動回復と撤退
- 能力4種、レベルアップ配点
- 攻略方針3種
- 速度変更、停止
- 冒険報告書と端末内の直近10件
- desktop / mobile layout
- reduced motion、keyboard操作、sprite fallback

Version 1では含めない:

- 複数勇者、パーティ編成、職業ツリー
- 装備の手動付け替え、戦闘中スキル
- 永続強化、通貨、ショップ
- オンラインランキング、外部通信
- マップエディタ、ユーザー作成ダンジョン

## 9. Technical and testable constraints

- React + TypeScript + Canvasを第一候補とする
- シミュレーションと描画を分離し、同じseedと入力履歴なら同じ結果にする
- `requestAnimationFrame`の経過時間ではなく固定tickで進行する
- background tab復帰時に時間をまとめて進めない
- 生成テストで、開始地点から階段と必須回復所への到達可能性を検証する
- AIテストで、各方針の目的地選択、退却閾値、同点処理を検証する
- 10,000 seedの自動走行で、即死率、平均クリア時間、方針別勝率を集計する
- 375、768、1024、1440pxで、ダンジョンと主操作が初期viewport内に見えることを確認する

## 10. Done when for implementation

- 初見で自動探索中だと理解できる
- 方針3種で実際の移動先と戦闘相手の傾向が変わる
- 配点の違いで生存時間または討伐速度が観測できる程度に変わる
- 1ランが通常速度で12〜20分に収まる
- 同じseedを再挑戦でき、結果の違いを比較できる
- loading、観察、査定、階段前、死亡、クリア、保存失敗、sprite失敗を確認できる
- keyboardだけで停止、速度変更、方針選択、配点確定ができる
- lint、unit test、typecheck、buildが通る

## 11. Recommended first playable slice

最初から5階層すべてを作らず、1フロアだけで次を縦に通す。

1. seed付きマップ生成
2. 勇者の自動移動
3. 通常敵との自動戦闘
4. `安全第一 / 経験値優先 / 奥へ進む`で目的地が変わる
5. 1回のレベルアップで3ポイントを配れる
6. 階段到達または死亡で報告書が出る

このsliceで「眺めて面白いか」「介入が効いたと感じるか」を確認してから、階層、敵、装備を増やす。
