# 街の暮らしと自然をつなぐ改善

2026-10-01。初版の「要素が変わるだけ」「人の流れが断続的」「もっとかわいいドット絵」というフィードバックへの改善。

## Goal / Context / Constraints / Done when

- Goal: 通勤・買い物の行き先、道路による到達性、仕事と客足、土壌と水分が街の変化を生む。人の移動を連続させ、その理由と結果を景色と観察ノートから読めるようにする。
- Context: 初版のsimulation.ts / renderer.ts / main.ts、PLAN.md、既存の画面記録、共通UI方針。初版の近隣集計は使えるが、道路上の往復演出は住民や需要と切り離されている。
- Constraints: 48×48、観察中心、Canvasによる自作ドット絵、外部API・有料素材・実行時ライブラリなし。既存の保存、操作、低モーション、背景停止を保持。公開・リリースは行わない。
- Done when: 居住地から仕事・買い物先への道を歩いて帰る人を追える。到達できない仕事は雇用に数えず、客不足や土の劣化が時間をかけて変化を生む。自然は水分・肥沃度・植生の遷移を持ち、畑には生育と収穫がある。丸い樹冠、色の違う小さな家、庭、服や持ち物を描き分け、動く人と建物の前後関係を保つ。

## 実装順と分担

1. 共有型を先に決める。住民、経路、時計、自然と経済の状態を保存できる形にする。
2. シミュレーション担当: 到達性と容量に基づく働き先・買い物先、連続移動、雇用・来客による維持と成長、自然の遷移、旧保存の移行。
3. 描画担当: 連続した住民の位置を描く。淡い限定色、ころんとした木、小さな家の個性、建築途中、畑の生育、天候と水辺。シミュレーションの状態に忠実な表現。
4. メイン: 時計と固定更新を統合し、住民と経路の観察、天候・雇用・食の表示、仕様と制限を更新。既存Issue #144 / PR #145を継続。

## 確認

- 前の依頼のテスト不要という指定を尊重し、テストランナーは実行しない。型チェック・lint・buildと、許可された範囲での画面操作で確認する。
- 実画面はlocalhostへのブラウザアクセスが現在拒否されているため許可待ち。許可がなければ未確認として報告し、別経路で回避しない。
- デスクトップとモバイル、停止・速度・ズーム・地点選択・再生成・復元を確認する。建物が消えても移動中の人が瞬間移動しないことと、背景停止を確認する。
- 面白さ、実際の都市計画・生態系の予測としての正確さ、端末実機は保証しない。設計上の仮説と確認できた挙動を分けて記録する。
