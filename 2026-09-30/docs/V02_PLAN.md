# v0.2 開発計画

2026-10-02。ユーザーが自由な箱庭を選び、v0.2の開発を依頼。

- Goal: 街の発展・荒廃、天候と災害、無制限の神様操作を住民の暮らしの因果でつなぐ。
- Context: 現行v0.1、`GOD_SANDBOX_DESIGN.md`、実際の公開画面。Canvas2D / TypeScript / Viteを継続。
- Constraints: 使用回数・資源・クールダウンなし。既存町を移行。かわいい整数ドット絵、新しい実行時依存なし。公開更新はこの開発の完了と分ける。
- Done when: 下記一連の体験を実装し、保存・決済・被災中経路・固定時計を検証。アプリ内ブラウザで操作とレスポンシブを確認し、未確認事項を明記。

## 作るもの

1. 人物一人が人口一人。働く人と扶養される人、健康・空腹・備蓄・避難先。
2. 45秒の日、12日の季節、48日の年を共通の0.25秒固定ステップで進める。
3. 現場の労働による食・資材の生産、区画在庫、道を通る配送、在庫のある買い物、消費と不足。修繕・発展と荒廃。
4. 晴れ・曇り・雨・雪・嵐、地形を残す浸水、火と延焼、橋の通行止め。雷・地震・小隕石から終末規模。
5. 雨・日差し・嵐・雷・地震・隕石・芽吹き・入植の8つの力。地点プレビュー、予約取消、単歩、直前バッチ前の復元。
6. 避難・待機・修繕・荷物・配送・損傷をドット絵で示す。低モーション対応。
7. V3保存とV1/V2移行。既存人口を照合して補い、旧暦履歴と移行猶予を持つ。壊れた道路を含む途中の保存を許す。
8. 全滅後も自然が続く。初期食・資材・道具を持つ入植で再出発。

## 分担と統合

共有型・UI・文書はメイン、生活/保存、災害、水と火の描画は各担当。共有型は`src/types.ts`、時間と閾値は`constants.ts`。同一ファイルを並行編集しない。命令→災害→配送→住民移動→購入・消費→労働・修繕→日単位の発展の順と、命令ID順を固定する。乱数は街と災害で分離し、描画は消費しない。

## 検証

テストは新しい因果と保存を対象にする。食の生産・購入・消費、壊れた橋を歩かない、固定時間の分割によらない未来、旧保存人口、被災中復元、滅亡と再入植を確認。型・lint・buildを実施。デスクトップと768/390/320pxで操作を確認。localhostの保存済み拒否は別設定のため、解除されない場合は実画面未確認として記録し、別ポート等で迂回しない。

面白さは実装や数値の検証と区別し、無操作の暮らし、雨の助けと限界、橋の分断の影響、被災後に追う住民、再出発を実際に観察する。
