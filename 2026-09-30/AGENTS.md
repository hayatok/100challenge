# まちの呼吸 固有方針

## Goal / Context / Constraints / Done when

- Goal: 近隣マスの影響で成長・衰退・再生する街を、斜め見下ろしの2Dドット絵で眺めるWeb箱庭を作る。
- Context: ユーザーが承認した「街のライフゲーム」。最初に `docs/PLAN.md` とルート `docs/DESIGN.md` / `docs/FRONTEND.md` を読む。
- Constraints: 48×48マス、観察が中心。LLM・外部API・有料素材は使わない。建物の変化を近隣・人口・雇用・環境・老朽化から説明できること。アプリ固有のコード、依存関係、記録はこのフォルダ内に置く。
- Done when: 実時間で街が変化し、停止・倍速・ズーム・建物の観察・再生成が動く。長期シミュレーション、型・lint・build、デスクトップとモバイルの実ブラウザ検証を通す。

## 技術と実行

- TypeScript + Canvas 2D + Vite。UIはDOM、シミュレーションはブラウザに依存しない純粋なモジュール、ドット絵はCanvasで自作する。
- `npm ci` / `npm run dev`。`npm run check` はNodeのシミュレーションテスト、oxlint、TypeScript、Vite production build。
- `src/types.ts` がモジュール間の契約。型の変更は分担先へ連絡してから行う。
- 毎フレームDOMを作り直さない。シミュレーションは固定ステップ、画面描画はrequestAnimationFrame。背景タブでは時間を積み上げず、戻った瞬間に大量更新しない。

## 画風と操作

- 世界は手描き風の限定パレット・整数座標・nearest-neighborで表示する斜め見下ろしのドット絵。素材はコードで制作し、外部画像の流用なし。
- 操作UIはルートの共通トークンに従う。街の緑、屋根の赤茶、水の青は作品部分の色。本文は読みやすいシステムフォント、タイトルのみ日本語serif。
- キャンバス外にも人口、季節、街の記録、選択地点の説明を表示する。主要操作はタッチ・キーボード対応。低モーション設定では人・煙等の細かな演出を抑える。
- 成長を無限に増やすだけにしない。衰退と再生の理由を表示し、住民や建物が全滅して停止する吸収状態を避ける。
- 検証結果と未検証事項は `docs/RESULTS.md` に記録する。画面の楽しさの仮説とテストで確認した事実を区別する。
