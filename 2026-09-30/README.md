# まちの呼吸

建てなくても、町は育つ。近所の人口、仕事、道路、環境、建物の年齢から変わっていく街を眺める、2Dドット絵の箱庭です。

![成長した町](./public/town-cover.png)

## 起動

Node.js 24を推奨します。

```bash
cd 2026-09-30
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開きます。開発サーバーは通常 `http://localhost:5173/`。実行時に外部API、LLM、ログインは必要ありません。

```bash
npm run check   # テスト10件、lint、型チェック、production build
npm run preview # ビルドしたdist/を確認
```

## 眺め方

- 一時停止・1×・4×・12×で、町の時間を調整できます。通常2秒で1週、48週で1年です。
- 建物や土地を選ぶと、人口や活力、変化の理由が観察ノートに表示されます。「町のこぼれ話」からも場所を選べます。
- ＋/−で拡大縮小、ドラッグで移動。「全体を見る」でカメラを戻します。
- 街にフォーカスして矢印キーで地点を選び、Spaceで停止、＋/−でズーム、Escapeで選択解除できます。
- 「別の町を眺める」で新しい土地へ。「前の町に戻る」は直前の町へ一度戻せます。
- 「写真を撮る」で今の景色をPNGに保存します。

川の両岸の小さな集落から始まります。家が増えると店が生まれ、仕事が増えると家が育ちます。需要不足や老朽化が続くと空き家になり、草地へ戻り、条件の良い場所に新しい暮らしが生まれます。道路は既存の道から伸びます。

昼夜は窓明かりや街の表情を楽しむ150秒の演出周期、季節と建物の年齢は町の週数で進みます。人の往来・煙・水面は環境を表す演出で、住民一人ずつの通勤経路や生活を個別にシミュレーションしているわけではありません。

## 保存

現在の町をこのブラウザのlocalStorageに自動保存します。読み込み直すと町の続きが開きます。ブラウザのデータを消すと記録も消えます。保存できない環境でも観察は続けられます。バックグラウンドでは町の時間を止め、離れていた時間をまとめて進めません。低モーション設定では停止状態で始まり、小さな動きを抑えます。

## 構成と記録

- `src/simulation.ts`: シード生成、近隣集計、成長・衰退・再生、統計、保存復元。
- `src/renderer.ts`: 自作のドット絵、昼夜・季節、カメラと地点選択。
- `src/main.ts` / `src/style.css`: DOMの観察UI、固定ステップ、操作、保存。
- [開発前の計画](./docs/PLAN.md)、[検証結果](./docs/RESULTS.md)、[Issue #144](https://github.com/hayatok/100challenge/issues/144)。

素材はCanvasのコードで制作したオリジナルです。外部の画像・音声素材や実行時ライブラリは使っていません。Chromiumで動作を確認しています。Safari・Firefox・スマートフォン実機は未確認です。
