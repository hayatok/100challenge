# まちの呼吸

建てなくても、町は育つ。住民が道を歩いて働き、買い物をし、雨が土と作物を育てる。暮らしと自然のつながりを眺める、2Dドット絵の箱庭です。

![成長した町](./public/town-cover.png)

## 起動

Node.js 24を推奨します。

```bash
cd 2026-09-30
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開きます。開発サーバーは通常 `http://localhost:5173/`。実行時に外部API、LLM、ログインは必要ありません。

```bash
npm run check   # シミュレーション・移動・描画のテスト、lint、型チェック、production build
npm run preview # ビルドしたdist/を確認
```

## 眺め方

- 一時停止・1×・4×・12×で、町の時間を調整できます。通常4秒で1週、48週で1年です。
- 「住民の一日を追う」でひとりの通勤・買い物・帰り道を追えます。歩く人を直接選ぶこともできます。「道のつながり」で経路を表示します。
- 建物や土地を選ぶと、人口や活力、変化の理由が観察ノートに表示されます。「町のこぼれ話」からも場所を選べます。
- ＋/−で拡大縮小、ドラッグで移動。「全体を見る」でカメラを戻します。
- 街にフォーカスして矢印キーで地点を選び、Spaceで停止、＋/−でズーム、Escapeで選択解除できます。
- 「別の町を眺める」で新しい土地へ。「前の町に戻る」は直前の町へ一度戻せます。
- 「写真を撮る」で今の景色をPNGに保存します。

川の両岸の小さな集落から始まります。住民は道路と短い敷地内の通路を通って到達できる職場へ、定員に応じて割り当てられます。実際の通勤到着と来店を記録し、家の活力、店の維持、作物の収穫に反映します。新しい住まいは道路で届く仕事の余裕から育ちます。建物は需要が続くと育ち、維持できる建物は年数だけで消えません。

雨と川からの水分、土の肥沃度、工場の負荷を土地ごとに保持します。畑は生育と収穫を繰り返し、働き手が届かなければ収穫できません。空いた土地は草を取り戻し、条件の良い場所では若木が芽吹きます。季節の色、草の回復、作物の背丈、工事中の敷地が状態の変化を表します。

住民として描くのは世帯人口のおよそ半分に相当する活動人口です。人口全員の年齢、賃金、価格、物流を再現するモデルではありません。食の蓄えは収穫と消費の目安の量です。150秒の暮らしの一日と、48週の季節の一年は観察しやすい別の縮尺です。実際の都市・生態系を予測する用途ではありません。

## 保存

現在の町と住民の旅の途中をこのブラウザのlocalStorageに自動保存します。初版の記録は町の土地と建物を保持して新形式へ移行します。読み込み直すと町の続きが開きます。ブラウザのデータを消すと記録も消えます。保存できない環境でも観察は続けられます。バックグラウンドでは町の時間を止め、離れていた時間をまとめて進めません。低モーション設定では停止状態で始まり、小さな動きを抑えます。

## 構成と記録

- `src/simulation.ts`: シード生成、近隣集計、成長・衰退・再生、統計、保存復元。
- `src/mobility.ts`: 道路による到達性、働き先の定員、住民の連続した移動と到着。
- `src/renderer.ts`: 自作のドット絵、昼夜・季節、カメラと地点選択。
- `src/main.ts` / `src/style.css`: DOMの観察UI、固定ステップ、操作、保存。
