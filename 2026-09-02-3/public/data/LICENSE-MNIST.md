# MNIST attribution

This application contains a deterministic subset of the MNIST database and weights trained from it.

- Dataset: MNIST database of handwritten digits
- Copyright holders: Yann LeCun and Corinna Cortes
- Derived from: original NIST datasets
- License: Creative Commons Attribution-Share Alike 3.0
- Source used for this build: https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz
- Dataset information: https://keras.io/api/datasets/mnist/

The generated subset keeps the original training and test split. Selection details and checksums are recorded in `manifest.json`.
