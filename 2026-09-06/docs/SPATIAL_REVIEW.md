# 店舗と人の動線の再確認

Goal: 道路から入店、売り場、会計、退店までの不自然な配置・移動を修正する。
Context: navigation.gd、simulation.gd、store_scene.gd、初期店と通常営業の画面。
Constraints: 経営機能や完成版の範囲を追加しない。配置・資金・在庫を維持し、既存の経路探索と待機列を使う。
Done when: 店員と会計客がレジの反対側に立ち、入口や待機列を棚で塞げない。住人が店内に突然出現せず、歩道と扉を通り、退店後に街の端まで歩く。通常営業と実画面で確認する。

開始時点のブランチには、壁沿いの冷蔵ケース、中央の背中合わせの棚、入口側のレジ、レジ裏の店員位置、売り場・会計の待機列が実装済み。初期店の実画面でもこの配置を確認した。

追加で見つかった問題は、道路の端から入口まで車道沿いを歩けることと、街の端で人物が25%の不透明度で突然現れること。車道から歩道へ接続する経路に制限し、端では完全に透明になるよう修正する。旧版の保存済み経路も、次の移動時に現在位置から再探索する。

## 検証結果

- 動線49項目が成功。全3段階の敷地で往復が歩道と扉を通ること、旧経路が隣の歩道へ移ることを確認。3日間の通常営業では入店85人・退店85人、会計中373分、最大3人の列を観測し、店内での出現・消失、壁抜け、会計客と店員の位置混同はなかった。
- 棚の順番待ち・追加購入・補充後の店員の退避を検証。コア347項目とUI50画面、Webビルド、差分の空白チェックも成功。専用のlintコマンドはなく、GDScriptはGodot実行・ビルドで確認した。
- macOS 1187×768で通常生成した棚の列から営業を進め、会計5人から16人への増加を確認。Webは375×812でレジの反対側にいる店員と客、1440×900で棚の前の買い物客と空いたレジ前の通路を目視確認した。確認画像は `screenshots/spatial-review-mobile.png` と `screenshots/spatial-review-desktop.png`。
- この記録は店舗の配置と動線の修正に限定する。ゲーム全体の完成版としての品質判定や、56日間の全攻略監査を完了したという意味ではない。
