# 2026-11-21 のアプリ

開発時は [ルートの AGENTS.md](../AGENTS.md) に従う。

## 試作の範囲と起動

- 玉を落としてピンを倒すブラウザゲーム。2面・各面の手持ち3球スタート・連鎖で手持ちを補充・面の間の強化2択。仕様と確認条件は [試作仕様](docs/SPEC.md) を参照する。
- Node.js 24 と npm を使う。`npm ci` のあと `npm run dev` で起動。`npm run check` でゲームルールのテスト、型チェック、本番用ビルドを実行する。
- 描画は Three.js、ゲームルールと玉の移動は `src/game.ts` で扱う。球とピンの当たり判定は描画と別に進める。
- デスクトップ Chromium を主対象とする。マウスとタッチでは盤面上のレールを直接操作し、キーボードでは左右キーと Space で玉を放てるようにする。

## 制作の進め方

- 面を増やす前に、同じ配置で再挑戦して落とす位置を変えたくなるか、強化を替えると狙う位置が変わるかを確かめる。
- 不具合を比較するときは、同じシードと入力を使う。状態を直接設定する検証に加え、ブラウザの通常操作でも確かめる。

フォルダ構成の候補と試作・検証の具体例は [開発ガイド](docs/DEVELOPMENT.md) を参照する。
