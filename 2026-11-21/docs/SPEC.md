# ピンボードの試作仕様

## 確かめること

- 玉が分裂し、次々にピンを倒して得点が伸びるとき、落とした位置と結果のつながりが分かるか。
- 同じ第2面でも、青と黄のどちらを強化したかによって玉を放す位置が変わるか。

## 1回の遊び方

盤面上のレールに触れたまま左右に動かし、狙った位置で放す。クリックやタップでもその位置に玉が落ちる。手持ちがあれば、先に放った玉が盤面にいても続けて放せる。放した玉ごとに連鎖を数え、同じ一投から倒したピンには順に1、2、3点と加点する。分裂や追加で生まれた球は、元の一投の連鎖に含む。倒れたピンはその面の盤面から消える。

手持ちは各面3球から始まる。一投で6連鎖するごとに、手持ちに1球を補充する。手持ちが0の最中に補充されても、前の球が落ちている間に再び投球できる。

| ピン | 最初の効果 | 第1面クリア後に選べる強化 |
| --- | --- | --- |
| 丸い通常ピン | 加点 |  |
| 二本線の青ピン | 当たった玉がその場で2球に分かれる | その場で3球に分かれる |
| ＋印の黄ピン | レールの左、中央、右にある印のいずれかから追加1球 | 左と右の印から各1球を追加 |

第1面は85点、第2面は155点がノルマ。盤面の球がすべて落ちきり、手持ちかピンがなくなったら判定する。第1面に成功したら強化を一つ選ぶ。どちらかの面でノルマに届かない場合は終了。結果では合計得点と一投での最高連鎖を示す。

初回は比較用に固定シード `20261323` を使う。「同じ配置で再挑戦」では両面の配置と、黄ピンが追加球の位置を選ぶ乱数列を再現する。「別の配置で遊ぶ」は、手配置した土台の左右とピンの細かい位置をシードから変える。

## 画面と反応

濃い緑のホーロー盤を固定視点から見下ろし、金属のピンを輪郭、色、記号で見分ける。手持ち、得点、ノルマ、面数、最高連鎖は上枠の計器に収める。銅色の金属枠、琥珀色の数字、ピンと対応する青と黄で筐体全体をそろえる。この試作ではルートの共通 UI のページ背景、見出し、カードのスタイルの代わりにこの配色と枠を使う。主要操作には押したときの反応を付け、キーボードフォーカスを枠で示す。日本語と数字はシステム書体を使う。

各面の最初だけレールに投球のヒントを出す。手持ちの復帰やノルマ達成は短く知らせ、プレイ中は盤面と計器に視線を戻せるようにする。面の間の強化と終了時の結果は、直前の盤面が見える状態で盤面内に出す。選択や再挑戦で表示が消え、同じ場所で投球に戻る。青・黄の強化は、盤面と同じピンの色と記号を使う。読み込みや描画が止まったときも、盤面内で状態と対処を示す。

命中時はピンの位置で光と加点が出る。球が増えると「＋1球」などの表示が出て、盤面が短く揺れる。分裂で生まれた球は青、追加球は黄で、出現直後に光の輪を付ける。5、10、20、30連鎖では盤面に連鎖数を表示し、10連鎖以降の節目とノルマ達成では盤面の左右から紙吹雪が飛ぶ。連鎖に合わせて音程を上げ、分裂、追加、ノルマ達成にはそれぞれの音を付ける。効果音は画面上でオフにできる。動きを減らす設定では揺れや紙吹雪、動く加点表示、球の軌跡を抑える。非表示タブでは玉の移動と連鎖を止め、表示に戻ったときに同じ状態から続ける。

補充した球数は、手持ちの数字の横に「＋1」などと表示し、専用の効果音でも知らせる。動きを減らす設定でも手持ちの数字と補充のお知らせは更新する。

## 画面改修の制作指示

> 遊びの中心を盤面に置く。最初の一球はレールを見れば放せる。プレイ中は手持ちとノルマが一目で分かる。強化や結果を読むために盤面から視線を外させず、選択した場所から次の投球へ戻れるようにする。盤面と表示に同じ金属枠、ピンの色と記号、数字の光を使う。2面、手持ち3球、補充、連投、強化2択は引き継ぐ。

- Chrome の通常操作で開始、補充した球の即投球、両方の強化、クリア、失敗、同じ配置と別の配置での再挑戦を確認する。
- 320px幅のタッチ操作と横向きでも、盤面内の選択肢がスクロールなしで読み取れて押せる。キーボードでは強化・結果から投球へフォーカスが戻る。動きを減らす設定でも操作と通知が届く。
- 変更前後の同じ場面を実画面で比較し、操作の流れや盤面の見え方を損なう問題を直す。修正した場面は同じ入力と画面幅で再確認する。
