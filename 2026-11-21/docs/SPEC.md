# ピンボードの試作仕様

## 確かめること

- 玉が分裂し、次々にピンを倒して得点が伸びるとき、落とした位置と結果のつながりが分かるか。
- 同じ第2面でも、青と黄のどちらを強化したかによって玉を放す位置が変わるか。

## 1回の遊び方

盤面上のレールに触れたまま左右に動かし、狙った位置で放す。クリックやタップでもその位置に玉が落ちる。残り球があれば、先に放った玉が盤面にいても続けて放せる。放した玉ごとに連鎖を数え、同じ一投から倒したピンには順に1、2、3点と加点する。分裂や追加で生まれた球は、元の一投の連鎖に含む。倒れたピンはその面の盤面から消える。

| ピン | 最初の効果 | 第1面クリア後に選べる強化 |
| --- | --- | --- |
| 丸い通常ピン | 加点 |  |
| 二本線の青ピン | 当たった玉がその場で2球に分かれる | その場で3球に分かれる |
| ＋印の黄ピン | レールの左、中央、右にある印のいずれかから追加1球 | 左と右の印から各1球を追加 |

第1面は85点、第2面は155点がノルマ。手持ちの3球を放ち、分裂と追加で生まれた球もすべて落ちきったら判定する。第1面に成功したら強化を一つ選ぶ。どちらかの面でノルマに届かない場合は終了。結果では合計得点と一投での最高連鎖を示す。

初回は比較用に固定シード `20261323` を使う。「同じ配置で再挑戦」では両面の配置と、黄ピンが追加球の位置を選ぶ乱数列を再現する。「別の配置で遊ぶ」は、手配置した土台の左右とピンの細かい位置をシードから変える。

## 画面と反応

濃い緑のホーロー盤を固定視点から見下ろし、金属のピンを輪郭、色、記号で見分ける。残り球、得点、その面での最高連鎖は盤面の上の数字で追う。筐体の褐色と真鍮に合わせて、ルートの共通 UI の背景・本文色・アクセントを暖色に寄せる。主要操作には輪郭と押したときの反応を付け、フォーカスを枠で示す。日本語と数字はシステム書体を使う。

命中時はピンの位置で光と加点が出る。球が増えると「＋1球」などの表示が出て、盤面が短く揺れる。分裂で生まれた球は青、追加球は黄で、出現直後に光の輪を付ける。5、10、20、30連鎖では盤面に連鎖数を表示し、10連鎖以降の節目とノルマ達成では盤面の左右から紙吹雪が飛ぶ。連鎖に合わせて音程を上げ、分裂、追加、ノルマ達成にはそれぞれの音を付ける。効果音は画面上でオフにできる。動きを減らす設定では揺れや紙吹雪、動く加点表示、球の軌跡を抑える。非表示タブでは玉の移動と連鎖を止め、表示に戻ったときに同じ状態から続ける。
