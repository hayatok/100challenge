# ピンボードの試作仕様

## 確かめること

- 玉が分裂し、次々にピンを倒して得点が伸びるとき、落とした位置と結果のつながりが分かるか。
- 同じ第2面でも、青と黄のどちらを強化したかによって狙う投入口が変わるか。

## 1回の遊び方

7つの投入口から一つ選んで玉を落とす。全ての玉が盤面から出ると次の1球を落とせる。同じ一投で倒したピンには順に1、2、3点と加点し、当たったピンはその面の残りの投球から消える。分裂や追加で生まれた球も、元の一投の連鎖に含む。

| ピン | 最初の効果 | 第1面クリア後に選べる強化 |
| --- | --- | --- |
| 丸い通常ピン | 加点 |  |
| 二本線の青ピン | 当たった玉がその場で2球に分かれる | その場で3球に分かれる |
| ＋印の黄ピン | 左端、中央、右端のいずれかから追加1球 | 左端と右端から各1球を追加 |

第1面は85点、第2面は155点がノルマ。各面で元の玉を3球落とし終えてから判定する。第1面に成功したら強化を一つ選ぶ。どちらかの面でノルマに届かない場合は終了。結果では合計得点と一投での最高連鎖を示す。

初回には、強化によって第2面で高得点を狙える投入口が変わる固定シード `20261323` を使う。「同じ配置で再挑戦」では両面の配置と、黄ピンが追加球の位置を選ぶ乱数列を再現する。「別の配置で遊ぶ」は、手配置した土台の左右とピンの細かい位置をシードから変える。

## 画面と反応

濃い緑のホーロー盤を固定視点から見下ろし、金属のピンを輪郭、色、記号で見分ける。球数、得点、連鎖は盤面の上の数字で追う。筐体の褐色と真鍮に合わせて、ルートの共通 UI の背景・本文色・アクセントを暖色に寄せる。主要操作には輪郭と押したときの反応を付け、フォーカスを枠で示す。日本語と数字はシステム書体を使う。

命中時はピンの位置で光が広がり、連鎖に合わせて音階が上がる。分裂と追加球に短い別々の音を付ける。ノルマを達成した瞬間には得点の色、文言、成功音を切り替える。効果音は画面上でオフにできる。動きを減らす設定では装飾の軌跡やパルスを抑える。非表示タブでは玉の移動と連鎖を止め、表示に戻ったときに同じ状態から続ける。
