# 試作の検証結果

## 通常操作での結果

macOS の Chrome で本番用ビルドを開き、固定シード `20261323` の同じ盤面で、2種類の強化を試した。第1面では横幅680の盤面で x=431 → 158 → 522 を連続クリックし、最初の命中より先に3球を放せた。4回目のクリックでは球は増えず、盤面の玉が落ちきってから強化が選べるようになった。どちらの回も第1面は175点だった。

| 第2面の強化 | 連続投球した位置の順 | 第2面の得点 | 結果 |
| --- | --- | --- | --- |
| 青ピンで3球に分裂 | 158 → 522 → 249 | 308 | クリア |
| 黄ピンから2球追加 | 340 → 340 → 613 | 251 | クリア |

分裂や追加で球が生まれたときの光の輪と「＋1球」の表示、盤面の揺れ、連鎖の節目とノルマ達成時の紙吹雪を確認した。球が増える演出の途中でも、レールから次の球を放せた。

## 確認した範囲

- Node.js 24で `npm run check` のルールテスト6件、型チェック、本番用ビルドが通った。3球が同時に存在しても、分裂球と追加球が元の投球の連鎖に加わり、同じピンを二重に得点しないことをテストした。Vite は約584 kB（gzip 約150 kB）の JavaScript にサイズ警告を出した。
- Chrome の1440 × 900で両強化、同じ配置での再挑戦、演出のリセットを確認した。360 pxのタッチエミュレーションで連続3球を放てた。動きを減らす設定では得点が伸びても揺れと紙吹雪が出ず、320 pxでも横にはみ出さなかった。通し操作でコンソールエラーは発生しなかった。
- Enter を押し続けると1球だけ放たれ、球が残っている間に Space を2回押すとさらに2球を放てた。結果に移るまでに盤面の揺れが収まったことも確認した。

連鎖の気持ちよさ、効果音の聞こえ方、プレイヤー自身が強化に応じて狙いを変えるかは、人による試遊で確かめる。スマートフォン実機と Chrome 以外のブラウザも未確認。
