# 試作の検証結果

## 通常操作での結果

macOS の Chrome で本番用ビルドを開き、レールのクリックとドラッグで各ルートを開始から結果まで操作した。両方とも固定シード `20261323` で、同じ第2面を使った。横幅680の盤面座標で、第1面は x=249 → 522 → 340 から玉を放し、139点だった。

| 第2面の強化 | 玉を放した位置の順 | 第2面の最初の一球 | 第2面の得点 | 結果 |
| --- | --- | --- | --- | --- |
| 青ピンで3球に分裂 | 522 → 158 → 249 | 22連鎖 | 308 | クリア |
| 黄ピンから2球追加 | 158 → 340 → 522 | 26連鎖 | 364 | クリア |

同じ第2面の x=158 と x=522 から一球だけ落として比較すると、青強化では x=522 が253点、x=158 が171点。黄強化では x=158 が351点、x=522 が78点だった。

## 確認した範囲

- Node.js 24で `npm run check` のルールテスト5件、型チェック、本番用ビルドが通った。連続した位置からの発射と、レールの両端での位置補正をテストした。Vite は約581 kB（gzip 約149 kB）の JavaScript にサイズ警告を出した。
- Chrome の1440 × 900で、押したまま玉を動かす間は残り球が減らず、離したときに一球だけ減ることを確認した。Escape で取り消せること、左右キーと Space で玉を放てること、命中した位置の加点と連鎖数が出ることも確認した。ドラッグ中の Enter、Enter の長押し、長押ししたまま強化選択画面に移った場合に、意図しない投球や強化選択が起こらないことを確認した。
- 360 pxのタッチエミュレーションで投球、ノルマ未達、別配置での開始を確認した。高さ520 pxの画面で結果と再開後のレールが表示範囲に入り、320 pxでも横にはみ出さなかった。動きを減らす設定では、命中して得点が伸びても盤面の加点表示を追加しなかった。Codex 内蔵ブラウザでもドラッグして一球を放ち、12連鎖と78点を確認した。

連鎖の気持ちよさ、効果音の聞こえ方、プレイヤー自身が強化に応じて狙いを変えるかは、人による試遊で確かめる。スマートフォン実機と Chrome 以外のブラウザも未確認。
