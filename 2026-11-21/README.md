# ピンを連鎖で倒す

玉を落とす位置を選び、分裂と追加球でピンを倒すブラウザゲームの試作です。各面は手持ち3球から始まります。第1面のノルマを達成したら、青ピンと黄ピンの強化から一つ選びます。

## 起動

Node.js 24 を使用します。このフォルダで以下を実行し、表示された URL を WebGL 2 対応ブラウザで開きます。

```sh
npm ci
npm run dev
```

## 操作

- 盤面上のレールに触れたまま左右に動かし、狙った位置で放します。レールのクリックやタップでも、その位置から玉が落ちます。
- 残り球がある間は、盤面の玉が落ちきる前に次々と放せます。
- 赤いキッカーに上から当てると、矢印の方向へ玉が飛びます。
- 一投で6連鎖するごとに、手持ちが1球増えます。増えた玉もすぐに放せます。
- キーボードでは左右キーで玉を動かし、Space で放します。Tab でレールにフォーカスした状態でも操作できます。
- 結果から「同じ配置で再挑戦」を選ぶと、同じ第2面で別の強化を比べられます。「別の配置で遊ぶ」は新しいシードで始まります。

`npm run check` でゲームルールのテスト、型チェック、本番用ビルドを実行します。ビルド後の確認には `npm run preview` を使えます。
