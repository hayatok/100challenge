# ピンを連鎖で倒す

玉を落とす位置を選び、分裂と追加球でピンを倒すブラウザゲームの試作です。各面3球。第1面のノルマを達成したら、青ピンと黄ピンの強化から一つ選びます。

## 起動

Node.js 24 を使用します。このフォルダで以下を実行し、表示された URL を WebGL 2 対応ブラウザで開きます。

```sh
npm ci
npm run dev
```

## 操作

- 番号ボタン、盤面のクリック・タップ、または左右キーで投入口を選びます。
- 「玉を落とす」か Space で発射します。効果音などのボタンにフォーカスがあるときは、Space でそのボタンを操作します。
- 結果から「同じ配置で再挑戦」を選ぶと、同じ第2面で別の強化を比べられます。「別の配置で遊ぶ」は新しいシードで始まります。

`npm run check` でゲームルールのテスト、型チェック、本番用ビルドを実行します。ビルド後の確認には `npm run preview` を使えます。
