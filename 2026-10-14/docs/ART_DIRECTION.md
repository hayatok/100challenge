# 全力退勤：アートとゲームイメージ

## この初稿で共有するもの

消火器で椅子を噴射し、本人だけ必死で定時に帰る。その無茶な動きと平然とした職場の組み合わせを、一枚で伝える。

ユーザーが選んだ題材は「全力退勤」。最初の工程はコンセプトアートの生成と共有。その後、派手な演出とグラフィックのバカゲー感を強めた仕様と画面イメージを依頼された。

初稿：[`../art/zenryoku-taikin-concept.png`](../art/zenryoku-taikin-concept.png)。画像生成ツールで新規生成した1672 × 941のPNG。絵は初期の方向案であり、実ゲームの画面ではない。

## 画風

丸い人形とミニチュアのオフィスを使った、明るい3D調。大きな頭、小さな体、揺れるネクタイ、傾く椅子で動きを誇張する。表情と姿勢から、あせりと勢いが伝わるようにする。

夕日の暖色とミント色の家具を背景にして、赤い消火器を主役の目印にする。目立つ出口は緑のサインと暖かい光で示す。

| 用途 | 色の方向 |
| --- | --- |
| 消火器・タイトル | 朱赤 `#E63B2F` |
| 椅子・家具 | 青緑 `#3E8F87` |
| 床・書類・壁 | 生成り `#F4F0E8` |
| 夕日・出口の光 | オレンジ `#F6B45F` |
| ズボン・強い輪郭 | 濃紺 `#26323F` |

これらは作品部分の色指定。メニューと操作部品にはルートの `docs/DESIGN.md` の共通トークンを参照する。

## 絵からゲームへ引き継ぐ要素

- 主役：白シャツ、緩んだネクタイ、オフィスチェア、大きな赤い消火器。
- 反動：白い噴射を後方へ出し、その反対方向へ椅子が進む。
- 動き：椅子の傾き、体の揺れ、軌跡、舞う書類。
- ゴール：遠くから見える、開いたエレベーター。
- 笑い：本人の大あわてと、平然と仕事を続ける同僚。
- 時間：定時から出口までにかかった秒数。

主役と出口を常に読めるようにする。書類や噴射で進路が隠れる場合は、量や不透明度を抑える。初稿の画面手前のぼけや大きなロゴは紹介用の演出で、操作画面への採用は別途判断する。

## 最小のゲーム案

向きを変える → 噴射する → 反動と回転を読む → 衝突しても立て直す → 出口に到達する → 時間を見て再挑戦する。

操作案は左右の旋回と、押している間の噴射。まずオフィス一面で、噴射を続けて速く進むことと、離して姿勢を整えることの使い分けを試す。

プレイ中のカメラは、進路と障害物を読める斜め上からの視点を候補にする。アートの低めのカメラは主役を見せる用途とし、操作時の視点はプロトタイプで比較する。

ゲームの速さ、慣性、衝突後の復帰、再挑戦の手軽さは、まだ設計上の仮説。実装後に実際の操作で確かめる。

## 初稿の確認

画像を表示し、主役と消火器、後方への噴射、出口、タイトルの視認性を確認した。ゲーム本体と操作画面の検証は次の工程。

## v0.2：派手なバカゲー方向

初稿の丸い3D造形と夕日の職場を引き継ぎ、赤・黄・マゼンタの局所バースト、太い漫画文字、顔と椅子の伸縮、巨大な紙の塔、飛ぶ靴を追加する。主役の大騒ぎと、平然とした同僚の温度差を保つ。

通常プレイの噴射、連鎖の盛り上がり、大衝突の短い停止、退勤成功の祝福を別々に設計する。タイムは主記録、被害総額は副記録として画面に出し、演出の発生条件と仮値は [仕様 v0.2](SPEC.md) に定める。

| 画面モック | 狙い |
| --- | --- |
| [通常プレイ](../art/screens/01-play.png) | 後方噴射、緑の進路、連鎖、定時ラッシュ |
| [大衝突](../art/screens/02-impact.png) | つぶれる顔と椅子、紙の扇、漫画文字、跳ねる加算金額 |
| [退勤成功](../art/screens/03-result.png) | 巨大判子、SSSの金色、泣き笑いと消火器トロフィー |

画像を表示し、文字、値、主役、噴射、出口と三状態の違いを確認した。モックは表情と演出を共有するために主役と通知が大きい構図。実装ではより遠いカメラも比較し、主役と進路の可読性で決める。

生成条件と原本のパスは `../art/screens/generation.json` に保存した。初稿の原本と保存版は保持している。

## 画面モック v0.3：控えめなボクセル要素

2026-10-15（Asia/Tokyo）、ユーザーの希望に合わせて三枚のモックを更新した。丸い会社員と椅子を中心に、紙箱、家具の角、観葉植物の一部、演出の粒子へ、小さな立方体と段差のある輪郭を加える。

ボクセル要素は小物と粒子のアクセントとして扱う。顔、髪、体、椅子のクッション、消火器は滑らかな曲線で表現し、表情と伸縮の笑いを引き継ぐ。紙の大きな薄い形と柔らかい粉へ、少量の四角い粒子を混ぜる。

| 更新モック | ボクセル要素 |
| --- | --- |
| [通常プレイ](../art/screens/v0.3/01-play.png) | 紙箱、家具の角、植物の葉、噴射の端に小さな立方体 |
| [大衝突](../art/screens/v0.3/02-impact.png) | ワゴンの一部と箱、書類の扇に混ざる四角い破片 |
| [退勤成功](../art/screens/v0.3/03-result.png) | 周辺の小物、紙吹雪に混ざる金色の立方体 |

三枚を表示し、キャラクターの表情、漫画文字、タイム、金額、連鎖、残圧の表示と、小物のボクセル感を確認した。更新は画風の調整で、ゲーム本体の操作確認は試作工程で行う。

v0.3の生成条件と原本は [`../art/screens/v0.3/generation.json`](../art/screens/v0.3/generation.json) に記録した。v0.2のモックは上の比較用リンクから参照できる。
