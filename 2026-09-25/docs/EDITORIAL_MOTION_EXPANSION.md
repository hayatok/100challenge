# タイポグラフィーを主役にする追加表現（2026-09-25）

## Goal

「テンプレートらしさが残り、もっとスタイリッシュでクールなモーションがほしい」という使用時の指摘に応える。文字を小さな中央タイトルとして置く構図から離れ、文字自体を面・奥行き・粒子の構造として扱う。

## Context / 作例から得た原理

- [HOLOGRAPHIK / Visvim Kinetic Type](https://dribbble.com/shots/16500549-Visvim-Kinetic-Type): 小要素の単純な動きを重ねて強い全体像を作る。採用するのは多層の位相差という原理。
- [DIA / Nuits Sonores](https://dia.tv/project/nuits-sonores/): 文字が粒子として振動・分解・再結合する。採用するのは字形を形状生成の種として使う原理。
- [Studio Dumbar / Tempo](https://studiodumbar.com/work/tempo): 文字幅の伸縮を表現の中心に据えたシステム。採用するのは文字サイズ・幅・間隔の変化を主役にする原理。
- [Studio Dumbar / Utah Jazz 50](https://studiodumbar.com/work/utah-jazz-50): 文字・パターン・動きのリズムを揃える。採用するのは全画面の反復が文字の動きに呼応する原理。
- [NJ Himel / Optical Geometry Typography](https://www.behance.net/gallery/246098085/Optical-Geometry-Typography-Modern-Poster-Series): 放射幾何と文字を一つの平面に統合する。採用するのは静止画でも動きを感じる光学的構成。

現行の9表現は全体に同じ中央寄りタイトル寸法と余白を共有する。単純に背景の線や帯を増やすと同じ印象が続くため、新3表現では字形の占有面積、輪郭、粒子化の仕方を変える。参照作品の画像・ロゴ・固有の色やレイアウトは複製しない。

## Constraints

- p5 P2D、既存recipeのversion 1、ブラウザ内処理、プレビューと出力の同一描画、6秒/30fpsを守る。新依存は追加しない。
- 日本語の主文字は全時刻で読める。最大32字、明示改行、補助文、正方形/縦長、保存済み作品とJSONを維持する。
- 減速設定では自動再生しない。静止0秒でも独立した表紙になることを先に確認する。

## Done when

- 「迫る」（巨大な活字の押し出し）、「干渉」（光学的な全画面パターン）、「散る」（字形から生まれる粒子）の3表現を各3構図で使える。
- 新作が最初の4候補と画像付き選択に現れる。保存済み利用者のおまかせ4案にも毎回新表現を2案入れる。旧作品の固定・履歴・JSON読み込みは維持する。
- 全構図・2比率のPNGを目視し、実MP4を復号・再生し、ループ継ぎ目とPNG同時刻一致を確認する。375/768/1024/1440px、lint・unit・型チェック・build・E2Eを通す。

## 実装順

1. 新しい字組みと3つの静止構図を描き、プレビューの縮小サイズで見比べる。
2. 各表現の3構図と周期運動を追加し、全構図を実MP4で検査する。
3. 初期4案、選択見本、一覧サムネイルを更新する。
4. 操作・保存互換・画面幅・失敗状態をブラウザで確認し、検証結果を記録する。
