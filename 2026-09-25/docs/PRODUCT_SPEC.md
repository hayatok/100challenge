# 製品仕様 v4

## 1. 約束する体験

ユーザーはデザイン用語やコードを知らなくても、実際に入力した文字が入った候補を見比べられる。気に入った候補を起点に探し直せて、前の良い案を失わない。イベントの告知、作品のタイトル、SNS投稿の表紙に使える出力を作る。

初回はサンプル「余白の、その先。」を使う4案を自動表示。説明ツアーは不要。新規保存領域の初回4案には「迫る・干渉・散る・流れる」を含める。既存の保存済み作品はそのまま復元する。以後の「おまかせ」は新3表現から2案、既存9表現から2案を重複なく巡回して選ぶ。ランダム生成の待ち時間を演出で水増ししない。

## 2. 画面と主操作

単一ページ。比較・選択・調整は同じ作業場で行う。

```text
動く表紙の試着室                       お気に入り  履歴
言葉を着せ替えて、動く表紙に。

[タイトル                 ] [補助テキスト] [正方形 / 縦長]
[見本つき表現選択: おまかせ＋12表現] [4案を見る]

[候補 A]  [候補 B]   | [選択中の大きなプレビュー]
[候補 C]  [候補 D]   | 色    文字組み    形    動き
                     | □固定  □固定     □固定 □固定
                     | [この案から4案]   [お気に入り]
                     | 調整する ▾       [書き出す]
  ひとつ前の候補へ / 履歴を開く
```

候補はサムネイル全体の選択ボタンと、その外側のお気に入りボタンで構成する。ボタンの入れ子を作らない。1番目を初期選択し、フォーカスは勝手に奪わない。候補ラベルは「織る・余白」など表現と構図を示す。候補の説明はタイトル、表現、配色、文字組みをHTMLテキストでも提供する。

### 入力

- タイトル: 必須、1〜32書記素、明示改行は最大3行。前後の空白と空行を除去、改行をLFへ正規化する。本文中のスペースは維持。改行を除いてカウントする。
- 補助テキスト: 任意、0〜48書記素、改行なし。制作日やイベント名の用途。空なら配置スペースを確保しない。
- 日本語・英数字・一般的な句読点を対象にする。絵文字、制御文字、双方向制御文字は説明付きで拒否。結合文字は書記素単位で扱い、文字数判定にUTF-16のlengthを使わない。
- まれな漢字・記号の完全な収録は保証しない。確認用プレビューを必ず示し、文字欠けを確認した場合は対応字体への変更を案内する。通常の日本語が欠ける状態は出荷不可。
- IME変換中のEnterで生成しない。入力はdraft、ボタン押下でcommit。入力途中で作品を書き換えない。
- 未反映の入力があれば「入力に変更があります」を表示。この間「この案から4案」は無効。選択中の旧作品は保存可能で、書き出しダイアログにそのタイトルを明示する。
- 上限超過やレイアウト不能は入力欄に理由を表示。自動切り捨て・黙った省略・勝手な文言変更をしない。

### 比較と選択

- 「4案を見る」: commitした文字・比率・表現フィルタから新しい候補セットを作る。探索範囲を広げる操作で、ロックは適用しない。ボタンに選択した表現名を添え、既存履歴は残す。
- 表現選択は実際の描画から生成した静止見本を持つボタン13個。「おまかせ」と12表現の違いを生成前に比較できる。見本の文字は固定だと明示し、実作品には入力文字を使う。押下状態を色以外の枠・チェックとアクセシブルな状態で示す。「迫る・干渉・散る」を先に並べる。
- おまかせの4枠は新3表現から2つ、既存9表現から2つを重複なく選ぶ。生成ごとに起点を進め、継続して探索すると全表現に出会える。
- 特定表現なら4案ともその表現。構図を少なくとも2種類、パレットを少なくとも2種類含む。
- 1セット内で同一recipeの重複は不可。初回用の固定seedで4案を品質管理し、2回目以降は新seedを取得する。
- 選択だけでは新しい履歴を作らない。選択中のIDを現在セットに保存する。

## 3. 気に入った案からの探索

「この案から4案」は選択中の作品を親にする。表現、文字内容、比率は必ず維持する。親作品は大きなプレビュー上部の「元の案」として戻れる。候補セットを遷移し、親セットは履歴に残す。

| 固定項目 | 固定されるデータ | 変更できるものの例 |
| --- | --- | --- |
| 色 | 背景・本文・補助・アクセントの実色値 | 用意した配色への変更 |
| 文字組み | 書体、整列、文字サイズ比、字間、行間 | 明朝/ゴシック、左/中央、大小 |
| 形 | 構図、密度、傾き、図形生成seed | 帯・面・セルの配置と数 |
| 動き | 振幅、1周期の回数、位相seed | 静かな/標準/大きな動き |

形や文字組みを固定しても、別項目の動きによる画面上の位置は変わりうる。「固定」は設定値を維持する意味で、各フレームのピクセルを固定する意味ではない。

- 初回は全項目が未固定。候補選択後も現在の固定チェックを維持する。
- 派生候補は親から**未固定の1項目、または2項目**だけを変更。最大2項目で、2つ目を変える場合も軽微にする。
- 数値変更は定義域の10〜25%以内。列挙値は同じ表現の有効な近傍だけ。最低1項目は見て違いが分かる量を変える。
- 4候補それぞれに「色だけ変更」「形と動きを変更」など差分ラベルを付ける。seedだけ変わって見た目が同じ案を数えない。
- 全固定ならボタン無効、「変えたい項目の固定を外してください」。有限の候補しかない場合は最大32回の試行後に有効な1〜3案を表示し「条件に合う別案はN件です」。0件なら現在セットを残す。
- 再度「この案から4案」を押すと、その時点の選択作品から派生。生成中は多重実行を防ぎ、失敗時に旧セットを残す。

### 手動調整

「調整する」を開くと、配色11種、書体2種、整列2種、文字サイズ3段階、選択表現の構図3種、密度3段階、動き3段階を表示。生の数式・数十個のスライダーは出さない。

調整は選択中作品の編集draft。プレビューへ反映し、「調整を適用」で1作品の新セットを履歴に追加、「取り消す」で元に戻す。固定済み項目も手動変更は可能。説明文は「固定は別案を作るときに適用されます」。適用まで候補選択・履歴遷移・書き出しを無効にし、適用/取り消すへ誘導する。

表現と比率は手動調整に置かず、上部入力で新しく探す。無効な構図を別表現へ引き継がない。

## 4. 履歴・お気に入り・保存

- 履歴は候補セット単位。親セットIDと起点作品IDを記録する。日時順の一覧に起点のミニ画像と「この案から」を表示する。複雑な樹形図は初版不要。
- 初回以外の新セットは、操作開始時の現在セットを親にする。「新しく探す」も戻れるが、作品の派生を意味しないため起点作品IDはnull。作品データは不変、選択と固定チェックはセットの復元用メタデータとして更新する。
- 「ひとつ前の候補へ」は現在セットの親へ。履歴から過去セットへ戻って再生成しても、以前の子セットを消さない。
- セット復元時は候補順、選択、入力、比率、フィルタ、固定チェックを復元。再乱数化しない。
- 最大50セット。新セット追加時、現在と直近の親を保護して古い順に削除する。消えた参照は「以前の候補」と表示し、戻るボタンを無効化する。削除済み作品を必要とするお気に入りは独立コピーで存続する。
- お気に入りは最大50作品のimmutable recipeを別保存。IDを除いた描画設定のhashが同じ作品の二重登録不可。星を外す操作には5秒の取り消しを提供。上限時は勝手に消さず整理を案内する。
- お気に入りから「この作品で続ける」で1作品セットを新規作成。形・色等と文字内容を保持し、固定チェックは全解除して明示する。
- 確定操作後にIndexedDBへ自動保存。「保存済み」はtransaction完了後だけ表示。失敗しても画面の作品を消さず「この端末に保存できません。JSONを保存してください」。
- リロードで最後の確定セットへ復帰。未反映入力と未適用調整は保持しない。保存領域はブラウザと端末に依存することを保存メニューに短く表示。
- 同時タブは競合を検知して後発書き込みを止める。古いタブには「別のタブで更新されました」＋「最新を読み込む」「この作品をJSON保存」。自動上書きをしない。

### JSONの持ち出し

書き出す対象は選択中1作品。schemaVersion、rendererVersion、実パラメータ、入力文字、フォントIDを含み、履歴やお気に入り全体は含めない。ファイル名は `moving-cover-<短いID>.json`。読み込んだ作品は検証して新規1作品セットにし、既存データにマージしない。未知の版や不正値はエラー。外部URL、スクリプト、任意フォントの参照を受け付けない。

## 5. 書き出し

書き出しダイアログに作品サムネイル・タイトル・形式・サイズ・尺を出す。

| 形式 | 仕様 |
| --- | --- |
| PNG | 選択した静止フレーム。短辺1080px、背景あり、sRGB。正方形1080×1080、縦長1080×1920 |
| 動画・標準 | 短辺720px、正方形720×720 / 縦長720×1280、6秒、30fps、無音、背景あり |
| 動画・高画質 | 短辺1080px、同じ比率・尺・fps。対応判定を通る場合に選択可能 |
| JSON | 再編集できる1作品の設定 |

PNGの初期位置は位相0（作品ごとに読みやすい構図）。0〜179のフレームスライダーで選択可。動画は常に位相0から180フレームで1ループ。PNGの選択位置は作品の動きや動画の開始時刻を変えない。

動画は利用可能な形式を明示して選ぶ。初期選択はMP4/AVC、不可ならWebM。両方不可なら理由とPNG/JSONへの導線を出す。対応判定成功後でもencoderが失敗する場合はあり、無言で別形式や低解像度へ切り替えない。

書き出し開始時にrecipeを凍結し、編集を一時無効化、プレビュー停止。進捗は「42 / 180フレーム」、最終処理中は別表示。キャンセル可能。完了後に「動画を保存」ボタンを出し、ユーザー操作でダウンロードする。保存ボタンを押しただけで「端末への保存完了」と断定しない。アプリ復帰・再試行で操作不能にならない。

## 6. 初版の品質条件

- サンプルから書き出しまで、必須操作は「候補を選ぶ」「書き出す」「動画を作る」「動画を保存」の4操作。タイトル変更は任意の追加操作。
- 表現を切り替えると、構図・図形・文字との関係が変わる。色だけ違う4枚を基本体験にしない。
- 初回候補表示の目標はローカル資産読み込み後1秒以内。フォントの初回取得時間は分けて計測し、読み込み中を表示する。
- 入力は外部送信しない。静的ファイルの初回取得は必要。完全なオフライン再起動やブラウザを閉じた後の無期限保存は初版の約束に含めない。
