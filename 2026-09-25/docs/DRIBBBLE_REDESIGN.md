# 表紙の造形を深める（2026-09-25）

## Goal

「表現数は増えたがPowerPointのテンプレートに見える」という実使用の指摘に応える。入力した文字が主役でありながら、生成グラフィックと組み合わさった作品を、専門操作なしで作れるようにする。

## Context

- 現行の6表現は同じ `compile()` の中央寄りのタイトル位置と近い文字寸法を共有する。新3表現の構図比較でも、タイトルに細線・円・残像を添えた印象が残る。
- ユーザー指定の [Dribbble p5.jsタグ](https://dribbble.com/tags/p5js) を実画面で調べた。参考にするのは次の**構成原理**であり、画像、ロゴ、固有の配色やレイアウトは転用しない。
  - [RITM Generator Moving Poster](https://dribbble.com/shots/19561995-RITM-Generator-Moving-Poster): 幅広い帯が画面全体を占め、流れの間に文字情報を置く。
  - [Generative Typography in Motion / 2](https://dribbble.com/shots/18153018-Generative-Typography-in-Motion-2): 細い線の集積が一つの大きな形に見える。
  - [Generista Posters](https://dribbble.com/shots/24432882-Generista-Posters): 小さな反復要素と大きな余白で密度を編集する。
  - [REFRACT / Generative Web-Tool](https://dribbble.com/shots/22421352-REFRACT-Generative-Web-Tool): 文字と変形した背景が同じ方向性を持つ。実作例はシェーダーだが、このアプリでは既存P2Dの描画契約を維持する。

## Constraints

- 既存6表現、既存recipe、IndexedDBの保存とJSONの再編集互換性を維持する。作品の描画は `drawScene(recipe,time)` に集約し、PNG/MP4にも同じ処理を使う。
- 追加依存と外部画像を用いない。見本は実描画フレームから生成する。
- 日本語1〜32文字、明示改行、正方形と縦長、safe area、補助文、reduced-motionを維持する。画面外へはみ出してよいのは装飾だけで、主タイトルは全フレーム読める。
- 6秒周期の位相とフレーム境界を検査する。動きの効果を見せるために不可読なフレームを作らない。

## Done when

- 既存と関係が異なる新3表現を各3構図実装し、静止時に違いが分かる。新しい文字配置、密度、色の使い方を最初の4候補にも反映する。
- 日本語・英語、2比率の全構図PNGを目視し、実MP4を再生してPNGとの同時刻比較と継ぎ目を検査する。
- 見本、履歴、固定、保存、JSONを実ブラウザで使い、375 / 768 / 1024 / 1440px、lint、unit、型チェック、build、E2Eを確認する。

## 実装順

1. 新しい文字配置と配色を含むrecipe/描画を追加し、まず3枚の静止画を比較する。
2. 各3構図へ広げ、描画を周期運動にする。PNGとMP4を実生成して目視調整する。
3. 初期4案、選択見本、一覧サムネイルへ新作を反映する。
4. 操作・保存互換、画面幅、動画、テストを検証し、結果を追記する。

## 造形方針

| 新表現 | 主役 | 文字との関係 | 構図の差 |
| --- | --- | --- | --- |
| 流れる | 画面を横断する大きな色帯 | 帯の間の切れ目に大きなタイトルを置く | 上下の潮流・交差・縦のうねり |
| 張る | 細い直線の集積による立体的な網 | 網の緊張点にタイトルを置き、網の一部を文字の背後で切る | 扇・レンズ・ねじれ |
| 増殖 | 小さな活字の反復が作る面 | 大きな主文字と微細な反復文字でスケールを対比 | 密集・余白の裂け目・円環 |

作品の造形はランダム装飾の足し算でなく、どこを密にし、どこを抜き、どこに文字を置くかで決める。新表現の色は高彩度と暗色だけに偏らず、強いモノクロ案も用意する。
