# 表現・UI仕様 v2

## 1. 美術方針

完成したポスターの構図に、文字と図形の関係を変える動きを与える。停止しても成立し、動かすと発見があること。画面全体を一律に揺らす、背景の粒子だけを動かす、といった実装を3表現の代用にしない。

初版の**織る・めくる・組む**に、**切る・巡る・響く**を追加する。p5の2D描画、クリップ、平面変形で実現する。粒子シミュレーション・流体・本物の3D布・物理エンジンは不要。

## 2. 共通の構図とタイポグラフィー

- 論理座標は幅1080、高さ1080または1920。横と縦に同じ画像を切り抜くのでなく、比率別の文字領域・図形配置を定義する。
- 重要な文字のsafe areaは左右10%、上下8%。補助文は下端から10%内側。SNS各社の操作UIを避けることまで保証する領域ではない。
- 主役の文字領域は幅80%、高さ50%以内。構図に応じて上・中央・下へ配置。補助文領域と最低48論理px離す。
- 書体はNoto Sans JP 700とNoto Serif JP 600。補助文はNoto Sans JP 400。偽の太字を使わない。初期の文字組みは「織る=明朝・左」「めくる=ゴシック・中央」「組む=ゴシック・左」。すべての表現で2書体に対応。
- サイズ「小/標準/大」は初期目標128/176/220論理px。収まらなければ48pxを下限に縮小する。日本語は書記素と禁則、英語は語境界を優先して最大3行へ自動改行。明示改行は保持し、それぞれの行を必要に応じて折り返す。結果が3行を超える場合も縮小を試し、不能なら生成せず入力修正を案内する。
- 行間1.15、字間0を初版の既定値にする。文字組みのデータには含めるが、初版UIでは行間・字間を独立操作にしない。
- ラテン文字の長い1語も書記素単位で最終的に折り返せる。行頭の閉じ括弧・句読点、行末の開き括弧を避ける。Canvasで文字列全体を測定し、実際のascent/descentを使う。1文字ずつ等間隔に置く処理を通常の文字組みに使わない。
- 補助文は最大2行に自動折り返し、目標30px/下限24px。入力には改行を認めないが、表示上の折り返しは許可する。
- すべての構図で位相0はタイトルが完全に読める。常時読める主文字レイヤーを基本にし、重複文字・切片・図形で変化を付ける。

## 3. 3つの表現

### A. 織る / weave

**見えるもの:** 大きな文字の前後を、平行な細い帯がゆっくり通る。帯の部分だけ文字が別色になり、文字と線が同じ素材を分け合って見える。

**構図:** `sweep` 左下→右上に斜めの束、`arch` 文字の周りに弧を描く束、`margin` 左右の余白に束を寄せる。

**描画順:** 背景 → 帯の後半群 → 主タイトルと補助文 → 帯の前半群。ただし前半群では帯のクリップ内にタイトルを再描画し、文字を埋没させず色が切り替わる形にする。

帯は8/14/20本。各帯の中心曲線を、構図の基準パスに周期的な垂直偏位を加えて作る。振幅は短辺の0.02/0.04/0.06倍。隣接帯に位相差を付ける。曲線を64区間以下でサンプリングして帯の多角形へ変換。線幅は4〜14論理px、帯同士の間隔は12px以上。1px相当の密な干渉縞は作らない。

文字は行ごとに最大0.04emの微小な上下移動。帯の動きと同じ周期関数から計算する。文字そのものの輪郭は歪めない。補助文は静止。

**完成見本:** 明るい紙色に濃い明朝「余白の、\nその先。」、朱色の帯が左下から文字を横切る。背景の余白が全体の35%以上見える。

### B. めくる / fold

**見えるもの:** タイトルを載せた平らな面と、隣接する色面が扇のように開閉する。文字が面に貼られているため、面の動きに自然についてくる。

**構図:** `fan` 左下を軸に開く3枚、`gate` 中央のタイトル面と左右2枚、`stack` ずれた3〜5枚の積層。

**描画順:** 背景 → 後ろの面 → タイトル面 → その面と同じ変換を適用した主タイトル → 静止した補助文。影は平らな濃色面をずらす表現。ぼかし・3D照明は不要。

後ろの面は3/4/5枚。周期的な開き角は最大8/14/20度、タイトル面は最大2/4/6度。タイトル面のscaleXは1から最小0.94、位置移動は短辺の最大2%。主タイトルのbboxを変換後もsafe area内に収める。文字を細いスリットへ分割したり裏返したりしない。

位相0では面が静かに開いた、読みやすい構図。`1 - cos(2πu)`を基礎にして最初と最後の角速度を0にする。隣接面の振幅を変え、1枚の板が平行移動するだけにしない。

**完成見本:** 墨色の地に紙色とコーラルの3枚が開く。太いゴシック「まだ、\n途中です。」が中央の紙面にある。板の開閉が明快で、文字は全フレーム読める。

### C. 組む / tile

**見えるもの:** 大きなタイトルの周囲で、文字の断片・円・矩形がグリッドに沿って入れ替わる。静かな主タイトルと、活発な周辺の対比を作る。

**構図:** `frame` 外周にセル、`corner` 対角の2隅へ集積、`columns` 左右の縦列と中央の文字領域。

グリッドは正方形6×6、縦長6×10。主タイトルの領域に重なるセルを除外。動くセルの数は8/12/16個。各セルのコンテンツは矩形・円・タイトルをクリップした拡大断片からseedで選び、文字断片を少なくとも3個含める。

セルの中で1〜2個の要素を周期的に水平または垂直スライド。クリップ境界の外へ出た要素は反対側の同じ内容と連続する。周期の端で内容を乱数で交換しない。位相は行/列ごとにずらす。主タイトルは0〜0.03emの行別移動まで、補助文は静止。

**完成見本:** 紙色と黒に青のアクセント。「PLAY\nWITH TYPE」の大きな文字に対して、外周のセル内でPやYの断片と円が移動する。日本語でも全く同じ仕組みが動く。

## 4. 動きの共通契約

```text
u = ((timeSeconds / 6) % 1 + 1) % 1
θ = 2π × u
offset = amplitude × sin(integerCycles × θ + phase)
```

- 初版のUIは「静か / 標準 / 大きく」。振幅を変える。cycle数は表現のプリセットで1または2、必ず整数。速度スライダーを追加してループを壊さない。
- 位相offsetを持つ成分も周期を守る。形と時間から値を直接求め、前フレームの状態を積分しない。
- テクスチャを使う場合も固定seedの静止パターン。フレームごとのrandomやnoiseの時間直進を使わない。
- 全画面フラッシュ、激しい点滅、急な明暗反転を使わない。
- 表現のパラメータが変わっても文字がsafe areaから出ないようcompile段階で範囲を計算する。速度と一緒に可読時間が消えることを防ぐ。

役割は背景 `bg`、主文字 `ink`、補助面 `surface`、アクセント `accent` の4色。本文はbgまたはsurface上のinkで描く。アクセント色は細い本文に使用しない。

| night / 夜と珊瑚 | #171B27 | #F7F0DF | #2D3548 | #FF826C |

帯のクリップ内や色面上へ文字を再描画するときは背景とのコントラストを検査し、inkまたはbgから読みやすい方を選ぶ。UI本文4.5:1、作品の主文字3:1を最低基準にする。数値だけで線の細さや帯による読みにくさを合格にしない。

## 6. ツールUI

作品を見比べるため、UIの地は落ち着いた紙色。ルート共通の太い輪郭・硬い影は主ボタンと選択中の作品枠に残す。候補の入れ替えを「表紙を差し替える」180msの短い演出にする。

**共通規約への限定的な例外:** 常時モーションと抽象図形は、このアプリの成果物そのものに必要。作品canvas内に限って許可する。ツールUIに背景アニメーション、発光、ガラス表現を追加しない。比較を邪魔する全面の傾きや巨大なヒーローは置かない。

共有の実装済みトークン/コンポーネントパッケージは見つからなかった。以前の日付のソースをimportせず、次のアプリ内トークンをCSS変数として1か所に定義する。

| 用途 | 値 |
| --- | --- |
| UI背景 / 面 / 文字 / 補助文字 | #F4F0E8 / #FFFDF8 / #20201E / #5B5A54 |
| 主操作 / エラー / 成功 | #C94332（白文字、実測で4.5:1確認） / #A52E25 / #245B3D |
| 罫線 / 選択枠 / 角丸 | 1px #C9C4BA / 3px #20201E / 4px |
| 主ボタンの影 | 3px 3px 0 #20201E、押下時は影を縮める |
| 余白 | 4 / 8 / 12 / 16 / 24 / 32px |
| UI文字 | システム日本語フォント、本文16px、補助13px、ラベル14px、見出し24px |
| 操作領域 / focus | 最低44×44px、2pxの明瞭なoutline、offset 3px |

標準の保存・再生・戻る・固定などはLucideのアイコンをラベルに添える。候補の図形は作品でありUIアイコンではない。固定チェック、選択枠、状態は色以外の形とテキストを持つ。

### レスポンシブ

- 1024px以上: 左55%に2×2候補、右45%に選択作品と操作。全体最大1440px、ページ余白24px。縦長は候補内に全体を収め、トリミングしない。
- 768〜1023px: 上に2×2候補、下に選択作品と操作を2列。余白24px。
- 767px以下: 候補は2列、選択作品と操作はその下に1列。余白16px、gap12px。候補名と選択操作を省略しない。選択すると詳細を開くが、勝手に大きくスクロールしない。「選択中の案へ」のリンクを出す。
- フォームはモバイルで縦積み。履歴/お気に入り/書き出しはネイティブdialogを利用し、狭い画面では余白16pxの全幅。safe-areaと内部スクロールを確保する。
- canvas領域はaspect-ratioで先に確保。フォントや画像の読み込みで周囲の操作を動かさない。
- reduced-motion時は作品も初期停止。ユーザーの明示的な再生で作品だけ動く。UIの差し替え移動は常に省略。

## 8. 追加表現と選択UI

参考事例と実装順は [表現拡張計画](STYLE_EXPANSION.md) に記録する。既存3表現のrecipeと描画は維持する。

| 表現 | 3構図 | 静止時に見える関係 | 6秒周期の動き |
| --- | --- | --- | --- |
| 切る / slice | `slit` 横断、`steps` 階段、`split` 縦割り | 主文字の一部に細い切片を重ね、異なる位置とアクセント色を見せる | 切片だけが短距離を往復。主文字を覆い隠さない |
| 巡る / orbit | `halo` 光輪、`eclipse` 食、`duo` 双円 | 大きな円盤と円弧が文字の内外をまたぎ、円盤内は文字色を切り替える | 円盤の中心が微動し、途切れた円弧が巡る |
| 響く / echo | `trail` 余韻、`mirror` 鏡面、`burst` 放射 | 主文字の奥に輪郭文字の残像がある | 残像の間隔と方向が変化する。主文字は静止 |

新しい配色は暗緑とライムの `acid`、淡い紫と濃い文字の `lilac` を追加する。主文字はすべての表現・時刻で塗りのある完全な文字列として描き、断片や輪郭だけをタイトルにしない。新H4〜H6を固定作品として各比率・4時刻・実動画で確認する。

入力欄の下に「おまかせ」と6表現を並べ、同じ見本文字「動く\n言葉」を共通描画処理から描いた小さな静止見本を添える。見本は入力文字と区別して説明する。選択中は枠・チェック・`aria-pressed`で示す。狭い画面では2列にする。候補を生成するまで既存作品は変更しない。

## 9. 造形の見直しと新しい3表現

表現拡張後の実画面では、タイトルが似た位置・寸法で、図形だけが変わるテンプレート感が残った。ユーザー指定の作例と改善方針は [造形の見直し](DRIBBBLE_REDESIGN.md) に記録する。以下は既存recipeを変えずに追加する。

| 表現 | 3構図 | 文字との関係 | 6秒周期の動き |
| --- | --- | --- | --- |
| 流れる / current | `tide` 潮流、`crossflow` 交差、`columnflow` 縦流 | 画面外まで続く太い帯と、大きな文字の面を重ねる。帯の方向とタイトルの高さを構図で変える | 波形と帯の位置が周期的に呼吸し、開始位置へ戻る |
| 張る / lattice | `stringfan` 扇糸、`lens` レンズ、`twist` ねじれ | 多数の細線が一つの張力や奥行きを作る。主文字は線の前に抜ける | 線群の制御点へ位相差をつけた波を送り、網全体の張力が変わる。激しく点滅させない |
| 増殖 / glyph | `matrix` 密集、`rift` 裂け目、`corona` 環状 | 入力タイトルの書記素を小さく反復し、大きな主文字とのスケール差を作る | 密集・裂け目は反復文字が往復し、環状は隣り合う文字の輪が逆向きに揺れる |

H7は `current/tide/royal`、H8は `lattice/stringfan/cinder`、H9は `glyph/rift/carbon` を固定作品とする。3表現とも日本語・英語、正方形・縦長を検査し、描画された主文字を断片や輪郭だけにしない。新規保存領域の初回4案はH7〜H9とH4の造形を、同じ入力文字で比較する。既存の保存済み初回ボードは置き換えない。表現選択は「おまかせ」＋9表現の10ボタンとし、新3表現の見本を先に並べる。

## 10. 動きの見え方

実画面の指摘により、プレビューは描画回数でなく実時間から6秒周期の時刻を求める。スマホで表示中の候補も再生する。作品が静止画に見えないよう、全27構図の実MP4で0秒と1.5/3/4.5秒の復号フレームを比較する。「切る」は切片の走査、「響く」は残像の広がり、「張る」は細線の波を特に明確にする。動きを強めても塗りのある主文字を常時残す。詳細は [動きの調整計画](MOTION_VISIBILITY.md)。

## 11. タイポグラフィーが動きの構造になる3表現

ユーザーの再指摘を受けた作例調査と採用原理は [追加表現計画](EDITORIAL_MOTION_EXPANSION.md) に記録する。既存9表現・27構図の描画を維持し、3表現・9構図を加える。

| 表現 | 3構図 | 静止画と動きの関係 |
| --- | --- | --- |
| 迫る / monolith | 押し出し・連なり・縦の圧力 | 大きな主文字を多層の輪郭・傾いた色面・巨大な一字で押し出す。輪郭と色面に位相差をつけて往復する |
| 干渉 / interference | 同心・波面・奥行き | 全画面の光学的な線群と主文字を一つの面に収める。中心・波・透視線を周期変形し、太い背景色の縁で主文字を常時読めるようにする |
| 散る / scatter | 粒像・分裂・走査 | 入力タイトルの最初の書記素を粒子化した大きな字形にし、全文の主文字を独立して置く。粒子が膨張・左右分裂・走査波で動き、字形へ戻る |
