# 表現拡張計画（2026-09-25）

## Goal

現行の「織る・めくる・組む」を維持し、タイポグラフィーと図形の関係が異なる「切る・巡る・響く」を各3構図追加する。表現名だけのselectを、実際の出力フレームを見て選べるUIへ変更する。

## Context

- `src/domain/model.ts` のfamilyと構図、`src/domain/generate.ts` の4案生成・固定、`src/render/layout.ts` と `draw.ts` の共通描画、`src/app/App.tsx` の入力と候補を変更する。
- 現行画面をChromeで確認した。上部の「表現」は文字だけのselectで、作品の違いが候補生成前に分からない。
- 参考事例の**仕組み**を取り入れ、図版やロゴ、固有の書体、作品の構図を複製しない。
  - [Studio Dumbar / Tempo](https://studiodumbar.com/work/tempo): 限られた色と明快な文字を基準に、文字幅の変化をシステム化。
  - [Studio Dumbar / Utah Jazz 50](https://studiodumbar.com/work/utah-jazz-50): タイポグラフィー、パターン、動きのリズムを一体化。
  - [DIA / Chaumont Biennale](https://dia.tv/project/chaumont-biennale/): 生成システムから予想外の候補を作り、人が選ぶ。
  - [Brand New School / Keep Walking](https://www.brandnewschool.com/work/johnnie-walker-keep-walking): 単色に近い強い文字構成を複数の画面比率へ展開。

## Constraints

- 既存recipeとIndexedDB履歴を読み続けられる。schemaVersion 1のフィールドは変えず、familyと構図の列挙のみ増やす。
- 作品はp5 P2Dの既存`drawScene(recipe,time)`を使い、PNGとMP4にも同じ結果を出す。6秒の周期関数だけを使い、位相0と最後の継ぎ目を保つ。
- 主タイトルは全フレーム読める。正方形と縦長は構図ごとに調整し、既存の日本語組版・safe areaを維持する。
- UIは現在の紙色・太い輪郭・角丸と44px操作領域を継承する。見本はアプリの描画から生成し、外部画像を取り込まない。依存は増やさない。

## Done when

6表現×3構図が日本語・英語、正方形・縦長で描画できる。見本から表現を選び4候補を生成でき、固定・履歴・保存・JSON復元が維持される。新表現の実PNG/MP4を生成・再生してプレビューと比較し、375/768/1024/1440px、キーボード、reduced-motion、lint、unit、型チェック、build、ブラウザテストを確認する。

## 実装順

1. family・構図・生成分布を拡張し、古いrecipeと履歴の互換性をテストする。
2. 新しい3表現を描画する。静止画を先に見比べ、次に6秒周期の動きを調整する。
3. 共通描画から選択用見本を生成し、画像付き表現選択を実装する。
4. 全構図、比率、動画、操作状態、画面幅を検証して結果を記録する。

## 表現案

| 表現 | 静止画の構成 | 動き | 構図 |
| --- | --- | --- | --- |
| 切る | 太い文字を基準に、同じ文字の切片と幅広い色面をずらす | 数本の切片が別方向へ滑り、元の文字と再び合う | 横断・階段・縦割り |
| 巡る | タイトルを囲む大きな円盤と輪郭、円盤の中の反転文字 | 円弧と円盤がゆっくり位相を変える | 光輪・食・双円 |
| 響く | 主タイトルの奥に輪郭文字の残像を重ねる | 残像が方向を変えて広がり、主文字へ戻る | 余韻・鏡面・放射 |

各案とも、静止時の主文字の可読性と余白、補助文を先に成立させる。動きだけで差を作らない。
