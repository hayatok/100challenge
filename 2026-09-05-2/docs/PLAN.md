# LOOP EATER 2D 開発計画

- Goal: 3D版を廃止し、ImageGenの絵をそのまま活かすGodot 2Dゲームを新規実装する。
- Context: 原企画の一筆書き・自動攻撃・陣取りと、よふかしシグナルの世界観。旧実装・3D仕様は採用しない。
- Constraints: Node2D/Controlのみ。主人公・敵・背景・エフェクト・装飾画像はbuilt-in ImageGenで生成。フォントと動的な文字・数値・判定形状はGodot。ネイティブmacOS/Web双方に出力する。既存の別アプリと共通docsの変更を保持する。
- Done when: 新仕様書、生成元付き素材、導入からボス・結果・再挑戦までの1ラン、コアテスト、Web/macOSビルド、Godotとブラウザの実画面検証を揃える。

## 順序

1. 旧版を開発ディレクトリ外へ退避し、新しい2D仕様を定義。
2. 参照設定画から主人公スプライトと立ち絵、見下ろし背景、敵・ボス・VFX/UI素材を生成して目視確認。
3. 新規のピクセル座標シミュレーションと囲み判定、戦闘・成長・ボスを実装。
4. Sprite2D/CanvasItem描画、導入・操作ガイド・HUD・三択・停止・結果・記録を実装。
5. 通常プレイと固定seed検証、複数画面幅、ネイティブ/Web出力。
