# LOOP EATER 開発計画

- Goal: 3〜5分で移動・囲み・回収・陣地・成長を試せるmacOS/Web共通のGodot試作。
- Context: 2026-09-05に共有されたゲーム企画書と世界観設定書。共通docsの可読性・状態・操作原則を継承。
- Constraints: 移動だけで戦闘する。ゲーム判定は平面、3D描画は分離。1自機/1マップ/敵1種/自動武器1種/強化6種。素材正本はblend、受け渡しはGLB。既存変更を保持。
- Done when: コアテスト、macOS/Web出力、Godot/Blender GUIとブラウザ実操作、検証記録。

## 実施順序
1. Godot GUIで新規Compatibilityプロジェクト。対応Export Templates準備。
2. 画像生成でキャラクター基準と会話用ビジュアル。Blenderで少量のモデルを制作しGUI確認。
3. 交差/閉領域/固定時間シミュレーションとテスト。
4. 戦闘描画、HUD、導入、三択、結果、音、保存、リトライ。
5. Web/macOS書き出しと操作、サイズ、状態、性能を検証。
6. READMEと記録、GitHub PRへ整理。

## 初期仕様と未実装の製品機能
標準試作ラン180秒。時間終了はリハーサル終了であり、製品版の12分ボス/14分敗北と明確に区別。HPゼロは撤収。
軌跡6秒、直近0.25秒を交差除外。交差順の最初の有効閉領域のみ採用、消費後は現在位置から描き直す。
陣地8秒、最大3個、敵を止めない。回収撃破の経験値は1.3倍、他の撃破は1倍。
ボス、3キャラ選択、3章、進化6種、製品版中断セーブは後段。

## デザイン判断
本作は企画に合わせて暗い都市床/珊瑚ピンクの自機/水色の線/橙の敵/クリームのUIを使用。ネオンは通信境界と復旧の意味を持つ箇所に限定。共通のフラットな色面・太い輪郭・短い操作反応を継承。
既存Web部品はGodotへ直接移植せず、GodotのControlとThemeで統一する。
375/768/1024/1440幅で画面確認。狭い縦画面は横画面案内を表示し、PCのゲーム範囲を保つ。

## 前提
対象OSの回答が未着のためmacOS先行、デスクトップWeb対応。画像生成はこの環境のbuilt-in imagegenを使用。Blender/GodotのGUI操作はComputer Use。
