# 検証記録 — 2026-09-05

Godot 4.7.2、Blender 5.2.1、macOS、Codex Computer Useの組み込みChromiumで検証。

## 自動検証

- `npm run check`: GLB構造・保存済みblendのSHA-256・日本語フォント・画像、Godotインポート/構文、32項目のコア検証、Web release書き出し。
- コア検証は交差、なぞり戻し除外、境界、面積、冗長点削減、経験値二重加算防止、陣地上限、停止中の時計、三択連続処理、候補交換上限、敵上限、時間切れ、seed再現性を含む。
- 表示しているチュートリアルの経路を実際の移動入力で追い、10秒以内に囲みが成立することを確認。
- 通常条件の3seedランは囲み・成長を経て正常に撤収。seed101:124.43秒/21囲み、202:173.30秒/30囲み、303:47.92秒/8囲み。これは生存完走の証拠ではない。自動経路の成績にばらつきがあり、実プレイの難度調整は今後も必要。
- `npm run build:mac`: universalアプリの書き出し。GUIで起動・操作を別途確認。

## Computer Useで確認した画面

- Blender: 制作スクリプト実行、モデルと配色を確認、色の補正をGUI経由で行って正本保存。出力GLBと正本の一致を検証。
- Godot: Compatibilityプロジェクト作成、エディタ起動、ゲーム実行、Web/macOSプリセット表示。
- macOS release: 最新アプリを起動し、タイトル→通常ラン→移動入力→Esc停止→タイトルの遷移を確認。
- Web release: `?qa=lost`を付けても検証用撤収画面にならず、通常タイトルが表示されることを確認。
- Web 1280×720: タイトル、移動、軌跡、敵群、囲みから三択への遷移、HP回復、停止、音/演出の切替。
- Web 1024×768: 三択全文・操作ボタン・HUDの収まり。
- Web 1440×900: 停止と結果画面。
- Web 768×1024、375×667: 横向きの案内。縦画面用ゲームUIは提供しない。
- `/qa-load-error/`: 意図的にエンジンJSが404になる経路でエラー案内・再試行ボタンを操作。障害が続く場合は再度案内を表示する。
- スクリーンショットをツール上で目視確認。PNGファイルとしての検証画像保存は行っていない。

## 性能

Web debugのstress条件で600体を繰り返し補充し、180秒まで実行。形状を保った冗長点削減後、100〜171秒の各10秒ログはフレーム時間p95が約16.67ms、シミュレーションp95が2.4〜2.9ms。171秒時点で46囲み。計測は実行中の直近最大3600フレームを使用し、停止・結果画面は除外する。

このPC・このブラウザの局所的な結果であり、すべての端末で60fpsを保証しない。追加のGodot実行やビルドを同時に動かした初期計測では25〜27msまで増加した。通常ランの難度テストと負荷条件の完走は区別する。
