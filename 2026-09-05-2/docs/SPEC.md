# LOOP EATER 2D — 雨灯横丁、開演します

本書が現行仕様。旧3D仕様を置き換える。原企画の12分製品案は将来の展開として扱い、今回の実装範囲と混同しない。

## 体験と物語

「逃げ道を、わたしたちのステージに。」成人の地下アイドル三人組・よふかしシグナルが、暴走した無人機の占拠する雨灯横丁で回収ライブを開く。自機は21歳の鳴瀬こはく。白瀬りつと雨宮ねむは短い会話で支える。敵は人間ではなく無人機。

移動で光の線を引く → 自分の線を横切って囲む → 内部へ回収バースト → 経験値を回収 → 短命の自動攻撃ステージが生まれる → 三択で次の囲み方が変わる。

## 今回の1ラン

1ステージ、150秒で看板制御機が登場、210秒までに撃破すれば勝利。時間生存だけでは勝利にしない。HPゼロまたは制限時間で撤収。導入、簡単なチュートリアル、成長、ボス、勝利/撤収会話、再挑戦まで実装する。

## 2D画面設計

- 論理画面1280×720。カメラ固定の見下ろし。背景はImageGenの描き込まれた雨上がりの横丁、中心は見通しのよい広場。
- 自機は設定画に基づく描き込み2Dスプライト、移動方向と歩行フレームを切り替える。3Dモデル、3Dカメラ、疑似3Dキャラクターは使わない。
- 背景の青灰、こはくの珊瑚赤、軌跡のミント、敵の橙、UIの生成りを役割で使い分ける。上部HUD、下部操作ヒント。戦闘の中心をUIで塞がない。
- 主要な画材画像はすべてbuilt-in ImageGen。PNG正本を保存し、アトラスはGodotの矩形参照で使う。人物を図形や未完成モデルで代用しない。
- 動的な軌跡・陣地の境界は判定点列から描画し、生成した光のテクスチャと組み合わせる。可変の文字、バー、フォーカス枠はControlで構築する。
- 縦長画面は横向き・表示領域拡大の案内。小さい表示を了承して開始するボタンも用意する。横画面ではWASD/矢印、ゲームパッド左スティック、クリックした地点への移動・ドラッグ移動（タッチ対応）。停止はEscまたはボタン。三択はクリック・1〜3キー。

## 判定と戦闘

- 判定は画面上の足元の2D座標。キャラクターの頭や衣装には当たり判定を広げない。
- 軌跡の初期寿命6秒。直近0.25秒、隣接区間、平行な折り返しを除外。新しい移動区間の進行順で最初の有効閉領域を採用。最小面積900平方px。使った線は消費する。
- 回収バーストは初期4ダメージ。標準敵を一掃できる。内部の落下経験値も同時回収。回収撃破の経験値は1.3倍、それ以外は等倍。二重撃破・二重加算を防ぐ。1回で5体回収するごとにHPを3回復、上限9。HPゼロからは復活しない。
- 陣地は8秒、最大3個。敵を止めず、内部を優先して近くの敵に周期ダメージ。4個目で最古を置換。
- 自動射撃は最寄りの敵へ、初期0.72秒間隔・1ダメージ。敵との接触は4ダメージ、1.2秒無敵。HP初期100。軌跡に触れても被弾しない。
- 敵3種: 接近するコールビット、予告後に突進するラッシュビット、低速で硬いアンプガード。時刻で比率が変わる。敵上限300、経験値200、短期演出120で暴走を防ぐ。
- ボスは看板制御機。予告付きの帯状攻撃と、囲むとシールドが下がる外部端子。シールド解除中に射撃とループが有効。1回の回収で与えるボスダメージは最大HPの8%まで。少なくとも一つの安全な回り込み経路を残す。

## 成長と状態

経験値でレベルアップすると戦闘・時間・線・陣地・攻撃予告を全停止し、3候補を表示する。威力、軌跡延長、陣地強化、射撃速度、走力、回復、連鎖、吸引から候補を作る。段階上限と満HP時の回復候補を考慮し、候補を重複させない。HP45未満では回復候補を1つ保証する。リロールは1ラン2回。

ループ威力と連鎖が各2段階で「連鎖花火」へ進化。撃破爆発は世代数と対象数を制限する。陣地と吸引が各2段階で「ブラックホール・ステージ」へ進化。単なる火力だけでなく、敵をまとめる行動へつながる。

状態: title → briefing → running ↔ upgrade/paused → won/lost。別ウィンドウへ移ると停止。強化画面でフォーカスを失っても状態を壊さない。勝敗が同じフレームならHPゼロを優先する。

最高同時回収、最高スコア、クリア回数、演出設定をローカル保存。読み込み失敗は初期値で続行、保存失敗は結果画面へ表示する。検証モードは保存しない。

## 実装と検証

Godot 4.7.2 Compatibility、単一スレッドWeb。macOS universalのローカル起動版も作る。エンジンとExport Templatesは既存導入環境を使う。

新しいRefCountedシミュレーションは描画・音・保存・UIに依存しない。seed付き乱数、固定dtで再現確認。幾何境界、線の消費・期限、一時停止、成長の連続処理、ボスのシールド、勝敗、経験値、保存データの検証を自動テストする。通常難度と無敵/早送りのQAは別に記録する。

## 初回版の範囲外

複数ステージ/操作キャラクター切替、全章ストーリー、フルボイス、12〜14分版、一般配布向け公証、Windows/Linux/iOS/Android専用出力、オンライン機能。ImageGenは音声生成器ではないため、音はGodot内の合成フィードバックに留め、外部の音声素材は採用しない。
