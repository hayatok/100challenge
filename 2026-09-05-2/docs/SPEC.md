# 試作の実装仕様

## コアループ

60Hzで平面シミュレーションを更新し、3Dモデルと2Dの軌跡を描画する。自機1体・雨灯横丁1面・コールビット1種。操作は移動のみで、自動射撃、線の交差、囲み回収、陣地の射撃、経験値、三択強化につながる。

囲みは新しい移動区間と古い軌跡の有限線分交差から作る。直近0.25秒と隣接区間を除外。同一直線のなぞり戻しは無効。古い尾を除いた領域の面積が2以上で成立し、境界上の敵も含む。冗長な同一直線上の点だけを削除し、形状を保ちながら領域判定を軽量化する。採用した囲みで軌跡を消費する。

基本の軌跡寿命6秒、回収ダメージ3、回収撃破XP1.3。通常撃破は位置にXP1を落とし、自機が近づくと回収する。同じ敵の二重撃破と経験値重複を防ぐ。

陣地寿命8秒、最大3個。超過時は最古を置き換える。敵の移動を遮らず、0.65秒ごとに内部の敵2体を射撃する。内部に敵がいなければ、実際の多角形境界から2以内の敵を狙う。

自動武器は距離8以内の最寄り1体に0.9秒間隔で1ダメージと押し戻し。HP100、接触7ダメージ、被弾後1秒無敵。敵は時間とともに出現数・HP・速度が増える。上限600体、XPドロップ400、短いエフェクト160。空間バケットで領域候補を限定し、敵はMultiMeshでまとめて描く。

## 成長・状態

経験値閾値は8から始め、レベルごとに4増える。回収威力、軌跡時間、陣地、自動射撃速度、移動速度、HP回復から三択。回復以外は各4段階まで。三択中は敵・自機・陣地・ラン時間が停止する。複数レベル分の経験値がある場合は同じ停止状態で順に選ぶ。候補交換は1ラン2回。

ready → running → upgrade/paused → running → won/lost。HPゼロと180秒が同じフレームなら撤収を優先。フォーカス離脱時は戦闘を停止する。最高同時回収の非負整数だけを保存し、保存できない場合は結果画面に表示する。

## 再現性と検証専用経路

乱数はシミュレーション所有のseed付き生成器。試作は同じseedで再挑戦する。異なるOS間のビット単位一致は保証しない。初期難度を再現し、操作・強化選択の違いを比較するための仕様。

`npm run build:debug`でのみURLの`?qa=loop`, `upgrade`, `lost`, `stress`が有効。コマンドラインは`-- --qa=...`。画面に検証モードと記録保存なしを表示する。releaseでは指定を無視する。

stressは通常の経路移動・囲み・射撃を動かしつつ敵を600体まで補充、被弾無効、強化自動選択を行う**負荷専用条件**。通常難度の完走実績として扱わない。通常ランのテストは被弾無効化や敵補充なしで別途実行する。
