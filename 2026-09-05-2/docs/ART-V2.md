# 雨灯横丁 アート改修

- Goal: 検証用の簡易形状を置き換え、衣服と髪の造形、材質、密度のある店舗と雨上がりの路面を持つゲーム空間へ更新する。
- Context: ユーザーから「アセットが雑すぎる。最新のゲームのようなモデル・マップ。重くてもよい」との指摘。初版のブロック形状・単調な建物反復・格子床を撤去する。
- Constraints: こはくの珊瑚色ジャケットと雨灯横丁の世界観を継承。囲み・戦闘・成長のルールは継続。Web/macOS両方を維持し、従来の小さなポリゴン上限より造形を優先。元のblendと既存の未コミット変更を保存する。
- Done when: 保存済みの新しいBlender正本、GLB、テクスチャ、Godotの材質・照明・カメラ、両ビルド、キャラクター近景と通常ゲーム画面の実機目視確認、コア回帰テストが揃う。

## 制作方針

アニメ調の街歩きアクションを目標に、顔・毛束・衣服を曲面で構成する。ジャケットの襟・袖口・裾・縫い目、プリーツ、スニーカーのソール・紐、ヘッドホン・マイクを造形する。手足は個別ピボットで歩行に追従し、髪と衣服にも小さな追従を付ける。

マップは喫茶店・レコード店・麺屋・機材店の異なるファサード、ガラス戸・タイル・庇・室外機・ダクト・架線・自販機・自転車・箱類で構成。戦闘床は湿った舗装、排水溝、マンホール、消えかけた白線、水たまりで密度を持たせる。建物・機材の金属/ガラス/塗装と服の粗さを分け、実際の灯り・影・ハイライトで形を見せる。

最新の大規模商用作品と同等の品質を達成したと機械的には宣言しない。実際のゲーム画面と近景を成果物として評価する。

## 実装した内容

新原本は`art/source/amedori-v2.blend`。顔・髪・開口のあるジャケット・襟・シャツ・プリーツ・靴紐・ヘッドホン・マイク・バックパックを制作。近景で見つかった目の突出、前合わせの重なり、靴紐の埋没を原本上で修正した。胴・頭・左右の腕と脚・左右の髪のピボットをGLBに保持し、ゲームの移動に追従させる。骨格スキニングや表情、布の物理シミュレーションは今回含まない。

| 素材 | 三角形数 | GLBの分割メッシュ数 |
| --- | ---: | ---: |
| こはく | 148,760 | 8 |
| コールビット | 8,556 | 1 |
| 雨灯横丁 | 688,042 | 36 |

街は7店舗の異なる看板と外装、窓枠・バルコニー・庇・室外機・ダクト・配線・屋上タンク、街灯・提灯・自販機・カフェ家具・自転車・植木・排水溝・マンホール・白線・機材ステージを含む。コアの移動可能範囲の外側に小物を置き、既存の戦闘判定を変えていない。

`game/world_art.gd`に描画を分離。材質別の粗さと金属反射、透明ガラス、店舗照明、影、生成した路面テクスチャ、ワールド座標の目地表現を実装。macOSはForward+でSSAO・SSR・Glow、WebはCompatibilityで共通素材を表示。ホイール拡大と近い追従カメラを追加した。

`scripts/export_art_v2.py`は保存済み原本を読み、編集や上書きをせずにGLBを出力する。初回構築と近景修正のスクリプトも残すが、今後の編集正本はblend。Blenderの変更中状態は`.cache/pre-v2-session.blend`と`.cache/pre-dressing-session.blend`へ退避した。

## 画質チェックで追加したルール

シェーダーからコードで読み込む3Dテクスチャは、自動の3D用途検出に依存しない。路面に繰り返し見えたちらつきの原因は、読み込み設定の`mipmaps/generate=false`だった。これをtrueにし、`check-assets.mjs`で検証する。遠景で粒立って見える場合は粗さだけを調整せず、まずミップマップと縮小フィルターを確認する。

## 検証の区別

`art/review/kohaku-v2.png`は実際の原本モデルのBlenderスタジオレンダーであり、ゲーム画面のスクリーンショットではない。ゲーム内はComputer Useで別途確認する。debugの`?qa=art`でキャラクター近景、`?qa=map`で街全体を確認できる。releaseはこれらの指定を無視する。

コア32項目は初版と同じ結果で通過。原本ハッシュ・GLB構造・関節ノード・路面テクスチャ設定も検証する。初版の600体時の性能値はv0.2には流用しない。アートを優先したため、実機の負荷と読み込み量は増えている。

### 最終確認

- `npm run check`: 素材検証・Godot構文解析・32項目のコアテスト・Web release成功。`npm run build:mac`も成功。HUDの縁取り調整後にも両ビルドを再実行した。
- Computer Use: Blender近景、Webのモデル近景・街全体・囲み成立→三択→回復→陣地射撃、ホイール拡大を確認。1024×768と1440×900、縦画面375×667と768×1024の表示を確認した。
- macOSの最終releaseを起動し、通常プレイ→停止→タイトル復帰を確認。実行ログはMetal 4.0 / Forward+ / Apple M5。Webの確認中にコンソールのwarning/errorは検出されなかった。
- 実画面のスクリーンショットを目視確認。PNGとして保存したモデル近景はBlenderレンダー。
- ネイティブのクリーンな梱包コピーは`codesign --verify --deep --strict`を通過。ローカル用アドホック署名であり、配布用公証は未実施。
- ルートのカタログテスト3件と差分の空白検証も成功。既存の他アプリのblendと共通`docs/DESIGN.md`の変更を保持した。

Safari/Firefox、モバイル実機、ゲームパッド実機、v0.2での600体長時間性能計測は未実施。
