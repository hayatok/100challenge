# へんないきものの系譜

**なんでこうなった。**

Godot 4.7.2 / GDScript の2D進化観察ゲーム、v0.3。32匹の生き物が島で勝手に採餌・求愛・産卵し、両親の遺伝情報を受け継いだ子孫を残します。

## 遊ぶ

生き物をクリック・タップすると特徴を観察。「親子・系譜を見る」で両親の姿と子孫へ移動できます。追跡は生きている子孫にも引き継ぎます。「手帳」には出来事・操作説明・おまかせ観察・控えめな動き・新しい島への移動があります。

- Space: 停止/再開、1/2/4: 速度、N: 次の個体、F: 追跡、R: 雨、L: 系譜、H: 手帳、O: 島の変化、S: 保存、Esc: 閉じる。
- ドラッグで島を移動、ホイールまたは「拡大」でズーム。モバイル縦画面にも対応。
- 卵は4秒、成体は18秒から。元気が十分な成体2匹が出会うと繁殖。両親がエネルギーを負担します。
- 草地・茂み・浅瀬で形態による移動効率と消耗が変化。季節と雨で餌の再生量が変化。
- 世界と系譜は30秒ごとに端末内へ保存。バックグラウンドやオフラインの進化は計算しません。

## 開発

```sh
npm ci
npm run setup
npm run dev          # Godotエディタ
npm run play         # ネイティブで遊ぶ
npm run check        # import + 遺伝/構造/生態/保存/UIテスト + Web build
npm run build:debug  # 検証用ルートを含むWeb版
npm run preview     # http://127.0.0.1:4198/
npm run build:mac    # builds/macos/Creature Lineage.app
```

ランタイム・テンプレートは既存アプリと同じ公式Godot 4.7.2。`GODOT_BIN` で実行ファイルを指定できます。Nodeはビルド補助のみで、ゲーム内に外部通信・LLM・追加のnpm依存はありません。日本語フォントとライセンスは既存アプリから再利用しています。

## 環境への適応と発見

草地には種、茂みには実、浅瀬には藻。脚/翼・触手・ヒレと既存の体質から、餌の取りやすさを計算します。得意な餌を探し、同じ食料から多くの元気を得られる個体ほど繁殖の機会を得やすくなります。器官を何でも付けると得意が分散し、不得意な環境では維持負担も増えます。

**「手帳 → 島の変化と発見」または Oキー**で、地域ごとの生物の姿・器官を持つ割合・平均世代を確認できます。30秒ごとに集計し、5分前と比較。初めて祖先にない器官が発現した子や、地域の割合が大きく増えた場面は姿付きで保存します。移動や出生・死亡も分布を変えるので、分布差だけを進化の証明とはしません。

旧v1/v2の島・名前・系譜・食料は引き継ぎ、観測は読み込んだ時点から開始。閉じている間の時間は進みません。

## v0.3の範囲

14形質に加え、両親から1本ずつ受け継ぐ体の設計情報を持ちます。1〜6体節のつながり・枝分かれ、最大6組の脚/ヒレ/触手/翼、取り付く節と位置、1〜3個の目が遺伝します。連続的な形の揺らぎと、節・器官の追加/削除/接続・種類の変異を組み合わせます。親子比較で体の構造と器官数を確認できます。見た目と運動は遺伝子から再現されます。

脚は草地、ヒレは浅瀬、触手は茂み、翼は地表での移動を少し助けます。器官と節が多いと維持コストが増えます。自由飛行はありません。旧版の島・名前・系譜は読み込み時に移行し、子孫から構造変異が現れます。最初から幅広い姿を見たい場合は手帳から新しい島を始められます。

種の科学的分類、捕食を含む食物網、物理法則だけから未知の器官が生まれる仕組みは実装していません。

通常上限120匹、検証時200匹。系譜は最大2万個体まで保持し、到達したら停止して新しい島への移動を案内します。全滅時にも系譜は残ります。新しい島を始めると前の島を一つ保存します。
