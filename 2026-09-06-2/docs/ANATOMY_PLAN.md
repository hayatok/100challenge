# 体の構造が遺伝する版

- Goal: 体のつながり・器官の種類・取り付く節/位置を遺伝させ、共通の体形の数値違いを超える派生を作る。
- Context: 初期版の14形質、`genome.gd`、共通の生物描画、親子比較、v1保存形式。直前の提案を採用。
- Constraints: 最大6体節・6組の器官・1〜3眼。脚/ヒレ/触手/翼の描画規則と、遺伝・連続変形・構造変異を組み合わせる。地表の2D観察ゲームを維持。自由飛行、捕食、種族認定、環境別の食物網は今回含めない。既存の個体名・祖先・島を引き継ぐ。追加の外部依存なし。
- Done when: 両親由来の設計情報、体節の追加/削除/接続変更、器官の追加/削除/種類と位置の変更が成立。複数世代でも有効な体を生成し、親子比較で特徴を確認できる。旧セーブ移行・新保存の未来一致・生態の継続・形態の画面内収まりを検証。375/768/1024/1440pxの実画面、Web/macOS build、対象アプリのCIを通す。

## 実装順

1. 2本の構造設計情報と、接続を壊さない交叉/変異、旧遺伝情報の補完。
2. 体節のつながりと器官を共通描画。拡大図は実際の輪郭範囲に合わせる。
3. 器官による地形適性と維持負担、個体観察/親子比較の説明、保存形式更新。
4. 構造・境界・移行・長期生態テストと、実際のWeb/macOS表示を確認。
5. Issue/PR、差分CI、mainへの反映。

## 結果

構造遺伝・描画・親子比較・v1移行を実装。器官の追加が長期生態を崩さないよう負担を調整し、5 seedsの15分試験と3 seedsの1時間監査を通過。詳細は `VERIFICATION.md`。Issue #84で管理。
