# 環境への適応と発見

- Goal: 草地の種・茂みの実・浅瀬の藻と器官による採餌適性を導入し、環境ごとの分布変化と家系で初めて現れた器官を姿付きで観察する。
- Context: v0.2の構造遺伝、core/world.gd、親子比較と手帳、v1/v2保存、既存の生態・UIテスト。
- Constraints: 2Dの自律観察、既存の画面と描画規則、保存した島と祖先を維持。万能な多器官構成を避けるため得意の分散と不得意な環境での負担を設ける。進化先の固定・捕食・種認定・自由飛行は含めない。追加依存なし。公開タグを作らない。
- Done when: 餌が形でも区別できる。器官が採餌効率・餌選択・消耗へ作用し、対照試験で環境ごとの利益が確認できる。実測に基づく分布比較と祖先全体を調べた初出記録を表示・保存する。移行後は過去の分布を捏造せず観測開始。複数seed/長期生態/保存/境界/UIテスト、375/768/1024/1440pxの実画面、Web/macOS export、差分CIが通る。

## 実装順
1. 食性と地形負担を独立したEcologyへ定義し、世界の採餌へ接続。
2. 30秒ごとの地域調査、5分比較、家系で初めて発現した器官を記録。v3保存とv1/v2移行。
3. 地形ごとの餌を描画、手帳の先頭から島の変化と姿付き発見へ進める。個体の採餌適性も表示。
4. 対照試験・長期生態とGUIで確認、Issue/PR/CI/main/Projectを同期。

観測は分布の変化を示す。移動や出生・死亡も影響するため、割合の上昇だけを自然選択の証明とは表示しない。

## 実装結果

上記1〜3を実装。器官の配分で採餌の得意を分散し、環境が遺伝子を直接変更しない方式を採用した。対照試験・3seedの1時間試験・保存互換・画面確認の結果は [VERIFICATION.md](VERIFICATION.md) に記録。個体情報の追加は既存の5行へ収めた。内蔵ブラウザの既知のタブクラッシュは再現したが、新しいタブで発見→系譜・通常保存の操作を確認済み。GitHub Issue #88で管理。
