# v0.2仕様

## 遺伝と形態

`core/genome.gd` は14形質の2本のallele (0..1)と、`core/anatomy.gd` の2本の構造設計情報を扱う。数値は両親から1本ずつ受け取り、連続形質は0.65/0.35で表現。一部の離散形質は先頭alleleを使う。数値alleleは12%で小変異、その8%で大きめの変異。

構造も両親から設計情報を1本ずつ継承し、順番をランダムに入れ替える。体の接続と目数は先頭、器官は6つの相同スロットを交互の設計情報から発現。隠れた情報も次の世代へ継承する。器官が参照する体節が発現した体より多い場合は最後の節へ取り付ける。両親の接続グラフを無条件に合体する方式ではない。

- 体節: 1〜6。各節に親節index、曲がり、長さ、太さ。親indexは必ず自分より前で、根は-1。これにより循環・分離を防ぐ。
- 器官: 6スロットに空、または種類（脚/ヒレ/触手/翼）、取り付く節、周上の位置、大きさ。1スロットを左右1組として描画する。目は1〜3。
- 小変異: 節の形、器官の位置・サイズ・取り付く節。各設計情報は20%で構造変異を試みる。節の追加/葉節削除/接続変更、器官の種類変更/追加/削除、目数変更。上限などにより変化しない場合もある。
- 事前定義は器官の描画規則と制約。形態・配置・接続の数値は手続き生成。計算機上の有限精度と上限があり、文字どおり無限ではない。

`creature_art.gd` は実際の節と器官から描画範囲を計算し、島の選択・表示判定と親子ポートレートに共用する。目は外周間に隙間を確保し、体から柄を伸ばす。形態キャッシュは最大512。構造のPRNGは14形質を小数6桁相当に丸めた整数列から生成する。浮動小数点の最下位bitの差が別の構造へ増幅されることを抑える。模様も遺伝値から生成し、生態のPRNGを消費しない。生きている個体の形態は世界側にもキャッシュし、復元時に再構築する。

器官による移動倍率の補正: 草地は脚1組+0.015、翼+0.025。浅瀬はヒレ+0.06、触手+0.02、翼-0.015。茂みは触手+0.035。自由飛行はない。従来の体質による消耗に、2組を超える器官と2節を超える体節それぞれ1つにつき0.001/秒を加算する。

## 世界

1100×760の島。32匹から開始、通常上限120。固定0.2秒刻み。食料96地点は有限量を持ち、季節で再生速度が変わる。浅瀬は季節の影響を抑え、雨は14秒間再生を2倍。雨の再使用は35秒後。

各個体は年齢・元気・向き・目的地・交配待機時間を持つ。元気64以上、年齢18秒以上、待機時間0の異なる2個体が30単位以内で出会うと卵を1つ産む。両者22を負担し18秒間待機。卵は4秒で孵化。寿命は170〜265秒程度。元気が尽きても死ぬ。これは娯楽向けの簡略モデルであり、現実の生物学の再現ではない。

世代番号はmax(親の世代)+1。系譜は両親を残す有向非循環グラフ。創始familyは管理用祖先属性で種数ではない。祖先は死後も削除しない。最大2万個体に到達すると、観察を停止し保存/新しい島を案内する。

## UI

クリーム #f7f2df、インク #253d36、草 #b4ce9b、水 #99c8bb、朱 #dc694b。2px輪郭と硬い影。生物の遺伝色と地形の明暗はコンテンツとして別管理。ブラウザの表示倍率（DPR）が途中で変わっても論理画面サイズを再計算する。850px未満では4列2段の操作帯と、島の下の観察パネルへ切り替える。手帳/系譜はスクロール可能。モーダル中は時間停止。生物の移動は生活の主情報として残し、控えめ設定では脚の振り/体の揺れ/雨粒を停止。

## 保存と境界

世界・系譜・PRNG stateはGodot Variant bytes (Object decodingなし)をDEFLATE圧縮してbase64化しSHA-256を付け、JSON封筒へ入れる。数値のJSON往復による精度差を避ける。復元は形式、有限数、範囲、IDの重複、親参照、最大頭数、食料数を検証。まず一時ファイルへ書き、flush/closeしてからrenameする。破損時は新しい島を表示して自動保存を停止、ユーザー操作で元ファイルを退避後に保存。既存の壊れたファイルを黙って上書きしない。

v2は圧縮方式と元サイズを封筒に記録。展開前に元サイズを96MB以内へ制限し、展開後のサイズも照合する。旧v1の非圧縮封筒を引き続き読める。v1の14形質を保存したまま、従来の節数・脚数から2本の構造設計を補完する。個体ID、名前、親、死んだ祖先、世界のPRNG stateを保持する。アプリ更新前後で生態ルールは変わるが、更新後の保存復元では未来の一致を検証する。保存先名は移行用に `lineage-v1.json` のまま維持する。

## 検証用入口

debug Webのみ `?qa=anatomy`（32体の成体構造を停止して一覧）/ `?qa=family` / `?qa=empty` / `?qa=crowd` / `?qa=save-error`。ネイティブdebugは `-- --qa=family` など。検証用の島は通常の保存に書き込まない。`/qa-load-error/` はプレビューサーバーでエンジン読込失敗を再現する。`--capture=/absolute/file.png` はGodot自身のviewport保存。
