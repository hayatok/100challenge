# 初期版仕様

## 遺伝と形態

`core/genome.gd` が遺伝情報の唯一の定義。14形質に2本のallele (0..1)。両親からランダムに1本ずつ受け取り、並び順も入れ替わる。離散構造は先頭allele、連続形質は0.65/0.35の重みで表現。後ろのalleleも子孫に伝わる。各alleleは12%の確率で小変異、その8%は大きめの変異。脚・節は最大4、値の範囲を出生時とロード時に検証する。

`creature_art.gd` が生成・キャッシュする胴体輪郭/斑点に、形態に応じた関節の動きを重ねる。模様の乱数は遺伝値から決まり、生態の乱数を消費しない。頭数や描画フレームレートを変えても遺伝過程に影響させない。

## 世界

1100×760の島。32匹から開始、通常上限120。固定0.2秒刻み。食料96地点は有限量を持ち、季節で再生速度が変わる。浅瀬は季節の影響を抑え、雨は14秒間再生を2倍。雨の再使用は35秒後。

各個体は年齢・元気・向き・目的地・交配待機時間を持つ。元気64以上、年齢18秒以上、待機時間0の異なる2個体が30単位以内で出会うと卵を1つ産む。両者22を負担し18秒間待機。卵は4秒で孵化。寿命は170〜265秒程度。元気が尽きても死ぬ。これは娯楽向けの簡略モデルであり、現実の生物学の再現ではない。

世代番号はmax(親の世代)+1。系譜は両親を残す有向非循環グラフ。創始familyは管理用祖先属性で種数ではない。祖先は死後も削除しない。最大2万個体に到達すると、観察を停止し保存/新しい島を案内する。

## UI

クリーム #f7f2df、インク #253d36、草 #b4ce9b、水 #99c8bb、朱 #dc694b。2px輪郭と硬い影。生物の遺伝色と地形の明暗はコンテンツとして別管理。850px未満では4列2段の操作帯と、島の下の観察パネルへ切り替える。手帳/系譜はスクロール可能。モーダル中は時間停止。生物の移動は生活の主情報として残し、控えめ設定では脚の振り/体の揺れ/雨粒を停止。

## 保存と境界

世界・系譜・PRNG stateはGodot Variant bytes (Object decodingなし)をbase64化しSHA-256を付け、JSON封筒へ入れる。数値のJSON往復による精度差を避ける。復元は形式、有限数、範囲、IDの重複、親参照、最大頭数、食料数を検証。まず一時ファイルへ書き、flush/closeしてからrenameする。破損時は新しい島を表示して自動保存を停止、ユーザー操作で元ファイルを退避後に保存。既存の壊れたファイルを黙って上書きしない。

## 検証用入口

debug Webのみ `?qa=family` / `?qa=empty` / `?qa=crowd` / `?qa=save-error`。ネイティブdebugは `-- --qa=family` など。検証用の島は通常の保存に書き込まない。`/qa-load-error/` はプレビューサーバーでエンジン読込失敗を再現する。`--capture=/absolute/file.png` はGodot自身のviewport保存。
