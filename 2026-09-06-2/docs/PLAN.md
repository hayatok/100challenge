# へんないきものの系譜 — 初期版

- Goal: Godot 2Dで、遺伝するプロシージャル生物を眺める観察ゲームを作る。
- Context: 今回の合意済み企画、共通DESIGN/FRONTEND/DAILY_APP_STYLE、LOOP EATERのGodotビルド基盤。
- Constraints: 既存アプリを変更しない。型付きGDScript、Compatibility、シングルスレッドWeb。完成キャラクターの抽選ではなく、遺伝データから形態と動作を生成。無操作で継続。公開タグは今回作成しない。
- Done when: 自律採餌・求愛・出生・成長・死、親子の形態継承、環境による移動/消耗差、個体観察・系譜・保存復元・雨・速度操作が成立し、固定seedテスト、長期生態テスト、Webビルド、GUI検証、GitHub PR/Actionsが完了する。

## 実装順
1. Issue/Project登録、専用worktree・日付フォルダ。
2. 独立した遺伝/生態モデル、再現可能なseedと保存検証。
3. 体形生成・歩行、3環境の島、親子比較と観察手帳。
4. 初回/空/保存失敗/読込失敗、レスポンシブと操作検証。
5. seed横断・200匹負荷テスト、全体チェック、PR、Actions、マージとtracker同期。

## 視覚方針
クリーム紙、黒緑の太い輪郭、セージの草地、アクアの浅瀬、朱色の発見アクセント。地形と生き物が主役。既存共通トークンは未定義のため本アプリの具体値として記録する。生物の意味ある体色変異はUIの5色制約とは別。手描き風の輪郭は生物コンテンツでありUIアイコンではない。

## 初期版の境界
同時120匹を通常上限、200匹を負荷検証。草地/茂み/浅瀬と季節・雨。遺伝には連続値、離散構造、潜性コピー、小/大変異。捕食食物網、任意の新器官、完全な物理進化、種の科学的分類、バックグラウンド/オフライン進行は後続。系統は創始集団の祖先情報として扱い、新種数は表示しない。
