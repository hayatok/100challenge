# ゲーム開発スキル

[awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) の76スキルとルーターを、このプロジェクトの `.agents/skills/` で利用できます。未導入だった73スキルと `router` を追加し、既存の `godot-physics`、`physics-tuning`、`level-design` は元の版を保持しています。

## 使い方

対象の日付フォルダと、作りたいものや直したい操作を伝えます。ルーターを明示する場合は、次のように依頼してください。

```text
$router 2026-10-24-2 のゲームを改善したい。ヒット時の手応えとカメラの動きを見直して。
```

Codexはスキルの説明に合う依頼でも読み込みを判断します。選択を確実に伝えたいときは `$router` や個別のスキル名を指定してください。追加したスキルは次のターンから利用できます。表示されない場合は新しいチャットで確認してください。

| 相談や作業 | 主に使うスキル |
| --- | --- |
| 操作の手応え、ヒットストップ、揺れ | `game-feel`、`camera-systems` |
| 面の構成、難易度の流れ | `level-design` |
| HUD、メニュー、操作案内 | `game-ui-ux`、対象エンジンのUIスキル |
| 統一した画風とゲーム素材の制作 | `create-game-assets` |
| 遊びの核を確かめる小さな試作 | `prototype-fast` |
| Godotの移動、アニメーション、保存 | `godot-2d-movement`、`godot-animation`、`save-systems` |

ルーターは対象アプリ内でエンジンとバージョンを調べ、必要なスキルだけを選びます。スキル本体は `.agents/skills/<name>/SKILL.md` にあり、同梱の参照資料は必要になったときに読みます。上流の分類用パスを、ローカルの読み込み先と取り違えないように調整しています。

利用者の指示、ルートと対象アプリの `AGENTS.md`、承認済みの企画を優先します。設計案の妥当性と実際に遊んだ結果は分けて記録し、面白さや使いやすさは実物を操作して確かめます。

## 出典と更新

今回追加したファイルの出典はコミット `184b72be02884f782a0058f2eeae2ce4277453e4` です。各フォルダにApache-2.0の `LICENSE` と `NOTICE` を同梱し、[sources.json](sources.json) に出典、ローカルでの変更内容、SHA-256を記録しています。既存のスキルにはそれぞれの出典とライセンスを引き続き適用します。

更新時は上流との差分と既存スキルとの重複を確認し、採用するファイルと `sources.json` を合わせて更新してください。ルーターに加えた日付フォルダ単位の判定と、ローカルの参照パスを保持します。

## 同梱ツール

一部のスキルにはPythonの確認用スクリプトや雛形が含まれます。素材の確認と一覧画像の作成にはPillowが必要です。追加の依存関係は該当するツールを使う作業で必要になったときに準備してください。

同梱されたCIの雛形はスキル内の資料です。この導入では、実行されるGitHub Actions、グローバル設定、フック、ゲーム本体の依存関係は追加していません。公開・アップロード用スキルの導入だけで公開作業を始めることもありません。
