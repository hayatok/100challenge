# 説明書メーカー — Windowsアプリの紹介ページ

Windows 11 x64向けの手順書作成アプリです。スクリーンショットに印と説明を付け、画像入りのHTMLを出力します。

このディレクトリには公開用の説明ページとその検証だけを収録しています。アプリ本体のソースは含みません。

- [紹介ページ](https://hayatok.github.io/100challenge/2026-09-15/)
- [Windows 0.1.3試用版](https://github.com/hayatok/100challenge/releases/tag/manual-maker-v0.1.3)
- 検証: `npm run check:site`

Pagesは`site/`だけを配信します。配布ZIPはGitHub Releasesで提供します。Windows実機での0.1.3の改善効果は未確認です。
